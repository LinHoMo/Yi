# Yi 术数（六爻 / 八字）· Yan 插件入口说明

本插件把 Yi 仓库的两科术数引擎打成可直接调用的工具。**排盘与推演全部由随包 Python
引擎完成，你不得自己心算或推算任何卦象、干支、纳甲、旺衰、应期。**

## 激活后先读技能

用 `plugins_read_resource` 读 `skill:yi-divination`，里面有完整的用法、工作流与边界。
需要核对判据时读 `resource:kb-index`（总路由表），再按它指向的句柄读具体那一篇。

## 工具（4 个）

Yan 会把工具名改写成 `t_<hash>` 形式，但**原名不变、schema 不变**，描述开头的方括号里
也写着原名。按描述里的名字认：

- `yi_liuyao`：六爻纳甲。起卦（coin/time/number/manual）→ 装卦 → 断卦 → 出正文。
- `yi_bazi`：八字四柱。排盘 → 十神/藏干/旺衰/格局/喜用/大运流年 → 出正文。
- `yi_kb`：判据知识库检索（纯 Node，不经 Python）。返回 `文件:行` + `resource` 句柄 +
  节标题 + 摘录。**先检索定位，再按句柄读那一节**，不要整篇读。
- `yi_report`：完整排盘报告文件（单文件 HTML/MD），落系统临时目录，把返回的路径告诉用户。

## 使用要点

1. **先把人话变成可算输入**：所问何事、求测者性别与身份、起卦时刻。占感情时性别会改变
   用神（男占婚取妻财、女占婚取官鬼），务必问清再起。八字缺出生时辰必须先问，不可臆测。
2. **一卦一事**：同一问题不重复占卜（再三则渎）。用户换了实质角度（换用神、换层面、
   假设未来、比较两人、测人心）时，提议**另起一卦**，不要在原卦里硬推。
3. **照工具输出讲**：返回的 `narrative` 是引擎按本仓规范写好的正文。你的价值是把它与
   结构化字段翻译成当事人听得懂的话，而不是重写判据。
4. **重试一次即止**：工具抛错就重试一次；仍失败如实说「排盘异常」，**不得手动替代排盘**。

## 边界

这是象征推演与方向参考，**不是预言**。凶象用「偏向／有…信号／结构上」，不用
「注定／一定／绝无可能」。医疗、法律、投资、重大决策一律提示以专业意见为准。

**口径**：库内一切分数是「古籍案例对齐分」（引擎输出与古籍案例要点的吻合度），衡量不了
现实命中率；现实侧样本为零。**不得**把任何数字说成预测准确率、命中率或断事能力。

古籍案例库按隔离纪律**永不随包**：断卦时不得联想、类比或引用历史案例；用户明确要求
「事后校验」或问「有无类似案例」时，说明这需要完整仓库环境，不要自行编造。

## 运行环境

- 需要 **Python 3.10+**（引擎是 Python）。找不到时工具会如实报错并列出尝试过的路径，
  此时请提示用户安装 Python，或在插件配置里填 `python.exe` 的绝对路径。
- 完全离线：不发起任何网络请求，不读取任何凭据。
- 报告文件写在系统临时目录（`%TEMP%/yi-reports`），**不写用户工作区**。
