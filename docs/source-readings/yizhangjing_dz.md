## 一、书目与版本

**书名与托名**。登记题名《神机妙算一掌经》，传统托名唐代天文家一行禅师（僧一行）所传，民间亦称「达摩一掌经」「佛家一掌经」，属掌诀命术一系。主源本身无任何题署与目录（provenance 统计 headings=0），文首自题书名却是另一名目，源L1：`六度神数`——「六度」当指其十二星分属**六道**（佛、鬼、人、畜、修罗、仙）轮转布宫的体系特征，与通行《一掌经》十二星宿内容完全同构，可判为同书异名或坊刻改题。托名一行与达摩均无实据，此书实为明清以来民间流传的掌诀推命术定型文本之一，本源为殆知阁志愿转录本（**简体、带句读、未经专业校勘**，OCR 噪声重，详 §五）。

## 二、逐卷（章）深读

### 六度神数·十二星总论（L1–L61）

本卷是全书算法核心，其余各卷皆是其断语库的展开。起例总纲源L16：`六道神数算法是以男顺女逆，由生年之宫起数至生月之宫，再由生月之宫起数至生日之宫，最后由生日之宫起数至生时之宫。`——四宫递进、男顺女逆，与掌上十二支宫位配合。十二星与十二支宫的固定映射由星序给出：源L12：`佛道天贵星　　鬼道天厄星　　人道天权星`（以下两行续畜道天破、修罗天奸、仙道天文、佛道天福、鬼道天驿、人道天孤、畜道天刃、修罗天艺、仙道天寿），即**子天贵、丑天厄、寅天权、卯天破、辰天奸、巳天文、午天福、未天驿、申天孤、酉天刃、戌天艺、亥天寿**，六道各占两宫（佛＝子午、鬼＝丑未、人＝寅申、畜＝卯酉、修罗＝辰戌、仙＝巳亥）。算法自带两则金标准算例，男命源L18：`子年为子宫天贵星，三月则由子宫起顺数三宫，为寅宫天权星，十八日则由寅宫起顺数十八宫，为未宫天驿星，卯时则由未宫起顺数四宫，为戌宫天艺星。`；女命源L20：`午年为午宫天福星，六月则由午宫起逆数六宫，为丑宫天厄星，初八日则由丑宫起逆数八宫，为午宫天福星，酉时则由午宫起逆数十宫，为酉宫天刃星。`——两例可机械复核：落宫序＝（年支序 ±（月−1＋日−1＋时−1））mod 12，且**年宫本身即正月**（子年起三月落在子宫＋2，可证）。

十二星逐星给七言诗断＋释义断语，吉凶语气分上中下命：天贵星诗断源L23：`时辰落在天贵星，一生清贵事和同，志气不凡人出类，安然自在性明通。`；凶星如天破星源L32：`时辰落在天破宫，堆金积玉也成空，夜眠算计图家富，钞袋谁知有蛀虫。`。每星释义还嵌「若得××星相助／若逢××星」的组合判据（如天贵遇天权禄马助则荣昌、犯重者中下、逢孤厄破刃照命为朝堂折挫之人）。卷末**十二星总论**是全书最密的一段（源L60 单行近千字）：先立性别总纲——`男怕孤驿凶星，有天福天贵者不妨，女怕破刃厄星，有天权星者助夫旺子，`；再逐星论「两重／三重／四重」的吉凶翻转（如「奸星见重者，反不奸而正大，有三奸星者，狡狯下流之人」），末以「十二星之理，于斯备矣」收束。重星论是本术的特色判据层：年月日时四宫各落一星，同星重现按重数改断。

### 论出生月（L64–L101）

以**出生月**为独立维度，十二个月各配一首七言诗与一段白话断语，断语结构高度模板化：心性＋六亲＋「初限平平，中限发福，末限荣华富贵之命」式的三限框架（如三月生人源L74：`三月生人，心性宽宏，凡事忍耐，初限平平，中限发福，末限荣华富贵之命。`）。此卷不依赖十二星，是独立的月系断语表；三限（初/中/末）口径与后文时辰卷的寿数列同属断语模板。

### 论出生日（L105–L123）

三十日按**初一组**轮值六星：太阳（初一/初七/十三/十九/二十五）、太阴（初二/八/十四/二十/二十六）、天武（初三/九/十五/二十一/二十七）、天福（初四/十/十六/二十二/二十八）、天皇（初五/十一/十七/二十三/二十九）、太乙（初六/十二/十八/二十四/三十）。表头列星名源L106：`太阳星太阴星天武星天福星天皇星太乙星`。逐星断语如太阳星值日源L113：`此日生人，太阳星值日，为人衣禄有余，初限平当，末限大好，十九二十五岁男享荣华，有父母得力，女人乃旺夫发福之命。`；太乙星值日源L123：`此日生人，太乙星值日，为人多学多能，清闲高贵文墨之命，初限大贵，中限平稳，末限大旺财禄之命，兄弟无依方可。`。此六星名与十二星宿体系**不同名**，是另一套日系断语表。

### 论出生时（L127–L275）

全书篇幅最大的断语卷。十二时辰各先给总断＋一行寿数列（如子时源L130：`子时生人性急命带刚强，俭事反覆不定，招人是非，父母妻子有力，日手成家之命也，十二，十八，三十六，四十五，五十八，八十九岁之寿。`），再分**初／中／末**三分断（各配短诗），如「子时初生人先克母……末限享福」「子时末生人先主克父……晚景好」。三分断把同一时辰切为三段，判据粒度到「时辰三分之一」。卷末**总论**（L274–L275）自认以子平为纲——`详夫观命之法，原以八字为主，八字俱好无冲克刑破，如根基深固，不怕风摇`——并把掌诀算法定位为八字之外的快捷通道，收束口诀源L275：`年上起月，月上起日，日上起时，时上起刻，男顺行，女逆行，逢凶即凶，逢贵即贵，运掌之间，昭然莫能逃。`（「年上起月，月上起日」此处指掌上逐宫递数，与前卷起例同义）；总论还给润月生人前后半月折算、地支四字阳多阴少断克父克母等细则。

### 论得病（L279–L285）

以**五行命属的墓库日**占病期吉凶：源L280：`推五命人得病日期金命之人墓在丑，己丑日得病大凶，木命之人墓在未，癸未日得病大凶，`（水墓辰壬辰、火墓戌甲戌、土墓辰丙辰），配「大月从上数至下，小月从下数至上」的数日诀与「马立人生灾有救，马倒收拾入幽冥，马斜有灾即便治，禄正病重命不伤」的禄马倒斜诀。墓库取法与 core 墓库表同源（金墓丑、木墓未、水墓辰、火墓戌、土墓辰——水土木同墓辰的写法与通行「水土同宫」口径一致）。此卷涉疾病生死断言，按铁律三只能作「偏向/信号」级软表述，且必须提示专业医疗意见。

### 杂论（L287–L357）

四个独立判据组：①**每月生时小儿煞**，口诀源L289：`正七休生巳亥时，二八辰戌不堪推，三九卯酉难存立，四十寅申生悲泣。`（五月十一月防丑未、六月十二月忌子午），月组×时支的小儿关煞表；②**桃花煞**，源L291：`论桃花煞（命宫犯此不可出莉）`——「出莉」为「出嫁」之讹，煞位口诀源L292：`申子辰鸡叫乱人伦‘酉’，亥卯未鼠子当头忌‘子’，`（巳酉丑见午、寅午戌见卯），与 core 三合局取桃花完全一致；③**论十二时夫妻犯**，源L295：`羊鼠相逢一旦休，从来白马怕毂牛，蛇逢猛虎如刀截，猪见猿猴似箭投，`——六组属相相犯即六害取象（未子、午丑、巳寅、亥申、卯辰、酉戌），与《玉匣記》「断头婚」同源；④三合时论三段（子午卯酉时、寅申巳亥时、辰戌丑未时按时初/时正细分）与**年月逢识论**——十识（方丈、通天、三合、菩提、福禄、悢莉、消灾、善知识、成就、佛法）各配「某年生人逢某月」的月份表，全为查表数组。

### 日遇吉凶定人偏正论（L359–L383）

又一张三十日值星断语表，结构与「论出生日」同而**星名不同**：太阳（源L360：`太阳薛值日生人，初一，七，八，十三。`）、太阴、天文、天母、天帝、太乙。「薛」为「星」之讹；所配日期亦与前排不合（太阳前排为初一/七/十三/十九/二十五，此表作「初一，七，八，十三」）。逐星给四六句断语，多为「初年不足，末运硐达」式三限语。此卷当是另一传本日宿表的混入或转录错位，作版本异文处理，不与前表合并使用。

## 五、不适用与存疑

**医疗与寿数断言（铁律三红线）**：「论得病」全卷与各时辰的寿数列（如源L130「十二，十八，三十六……八十九岁之寿」）属疾病生死断言；任何实现或转述只能作「偏向/有……信号/结构上」表述，并强制提示以专业医疗意见为准。「论桃花煞」涉婚姻伦理判断，输出同样禁绝对化措辞。
