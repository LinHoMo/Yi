## 一、书目与版本

## 二、逐卷（章）深读

### 观物内篇·观物篇五十一至五十三（L7-135）—— 象数配义理的起点

本节以"物之大者无若天地"立论，逐层把天地万物归到**动静阴阳刚柔**四组对待上：
天之体尽于日月星辰，地之体尽于水火土石，天之变尽于暑寒昼夜，地之化尽于雨风露雷，
再以性情形体／走飞草木各安其位。这一"体—用—变—化"的分层，是全书后续一切推演的
骨架：后世（外篇）所谓"体数八、用数六"的差异，在内篇已伏下。

核心判据：

- 源L8：`物之大者无若天地，然而亦有所尽也。` → 全书立论起点：大有其至（天地）而仍有所尽，
  故须以"观物"分限，不许把象数当无限的东西。
- 源L14：`天生于动者也，地生于静者也，` → 动属天、静属地——此句是内外篇分派标准的源头
  （先天主心／后天主迹）的雏形。
- 源L20：`动之大者谓之太阳，动之小者谓之少阳；` → 四象命名的第一处：太阳/少阳从**动的体量**
  分，不从五行分。太阳＝日、少阳＝星、太阴＝月、少阴＝辰（L22）。
- 源L15：`一动一静交，而天地之道尽之矣。` → 动静交为"道尽"——理学本体论的一句话锚点。
- 源L956：`故曰分阴分阳，迭用刚柔，` → 内外篇共用的分派口诀（对应外篇 L954-L957 展开为
  一分二、二分四、四分八、八分十六）。

### 观物内篇·观物篇五十四（L136-250）—— 四经 × 生/长/收/藏 十六格

本节是全书**最典型的"象数配义理"结构**：把《易》《书》《诗》《春秋》四经与
生、长、收、藏四象交叉成十六格，每格配一德（意/言/象/数/仁/礼/义/智/性/情/形/体/圣/贤/才/术），
再配三皇五帝三王五伯。本节**没有任何占断**——纯粹是义理分类学，是"义理辞句"的最密集区，
也正是铁律三最需要防守的区域。

核心判据：

- 源L137：`观春则知易之所存乎？` → 四经配四时：易在春、书在夏、诗在秋、春秋在冬。
- 源L141：`易之易者，生生之谓也；` → 十六格之起点：易-易＝生生。
- 源L160：`生藏者，修夫数者也。` → 生藏（易之春秋）修"数"——**数在四经中只占一格**，
  此句可作"本书不以断事为主、以数为其一端"的直接依据。
- 源L173：`修夫意者，三皇之谓也；` → 十六格配人祖：意→三皇、言→五帝、象→三王、数→五伯。

### 观物内篇·观物篇五十六至五十九（L311-525）—— 世道消长的义理史

本节以周秦汉楚的历史叙述讲"时有消长，事有因革"。**注意其表述全为义理评价
（好生／好杀、尚行／尚言、尚义／尚利），不是吉凶断语**。观物篇五十九论秦"杀人之多"
出于"无生路可迍"，属政论而非占断。

核心判据：

- 源L404：`天之道，人之情，又奚择于周秦汉楚哉？ 择乎善恶而已。` → 世道消长归到
  **善恶二元**，不归到吉凶——义理口径的直接证据。
- 源L411：`时有消长，事有因革，前圣后圣非出乎一途哉？` → 消长/因革是**制度变迁**，
  非人事祸福。
- 源L446：`夫天下将治，则人必尚行也；天下将乱，则人必尚言也。` → 治乱以风气论，
  **不预言何年何事**，是典型的义理总纲而非占断。
- 源L448：`天下将治，则人必尚义也；天下将乱，则人必尚利也。` → 同上，义利之辨。
- 源L453：`言之于口，人得而闻之；行之于身，人得而见之；尽之于心，神得而知之。` → 言行心三级。

### 观物内篇·观物篇六十（L526-598）—— 元会运世四级推演（全书算法核心）

这是本书最"技术"的一节，也是所谓"皇极经世"的真正算法层。四级刻度定义于 L527：
**日＝元、月＝会、星＝运、辰＝世**；L528-L543 给出 4×4＝16 种"经"关系（以某级经某级，
知某级的元/会/运/世），L544-L549 给出各级数量，L550-L565 给出"以春行夏时"式的四时推移
对应，L566-L581 给出皇/帝/王/伯 × 道/德/功/力 的 4×4 矩阵。**注意：全段无一处占断吉凶**，
最接近"吉凶"的是"三皇春也，五帝夏也"（L585），也只是节令比附。

核心判据：

- 源L527：`日经天之元，月经天之会，星经天之运，辰经天之世。` → **元会运世四级刻度定义**
  （日→元、月→会、星→运、辰→世）。这是本书最常被后人误解为"推算国运"之处，
  原文语境是"日月星辰各循天经"，**只是刻度命名，不含断事规则**。
- 源L529：`以日经月，则元之会可知之矣；` → 四级交叉推演的示范：日经月即得"元之会"。
  这是纯**数推**（两层相乘定数），不是占断。
- 源L544：`元之元一，元之会十二，元之运三百六十，元之世四千三百二十；` → 元一→会十二
  →运三百六十→世四千三百二十（1→12→360→4320 的十进制倍增链）。
- 源L549：`世之世一千八百六十六万二千四百。` → 世之世＝1,866,240,000，为全级最大数
  （按 4×4 交叉推算所得）。**本条仅可作数链条留底，不得转写为"某年某世"式断语。**
- 源L550：`元之元，以春行春之时也；` → 时令对应法：以"主级"配"客级"的四时，十六格皆然。
- 源L566：`皇之皇，以道行道之事也；` → 皇/帝/王/伯 × 道/德/功/力 的 4×4 矩阵——
  **是伦理位阶表，不是吉凶表**。
- 源L585：`三皇春也，五帝夏也，三王秋也，五伯冬也，七国冬之余洌也，` → 历史分期配四时余气，
  分期学而非占断。
- 源L594：`吁！古者谓三十年为一世，岂徒然哉？` → "世＝三十年"的由来：**一世＝三十年**，
  是长周期历史分期单位，与后世"一世一运"误读不同。
- 源L597：`昔乎时无百年之世，世无百年之人，比其有代，则贤之与不肖何止于相半也？` →
  百年之期的人事公理，属史论。

### 观物内篇·观物篇六十一至六十二（L599-713）—— 动数植数与"以物观物"

六十一节给太阳/太阴/少阳/少阴等的体数与用数（160/192/112/152），相乘得动数、植数
各 17,024，通数 289,816,576。六十二节列"日日""日月""月月"等十六类物，
并以"反观"作全书义理收束。

核心判据：

- 源L608：`以太阳少阳太刚少刚之用数唱太阴少阴太柔少柔之用数，是谓日月星辰之变数；` →
  用数相"唱"（匹配）得变数。
- 源L610：`日月星辰之变数一万七千二十四，谓之动数，` → 动数＝17,024；
  源L612 给动植通数＝289,816,576。
- 源L612：`再唱和日月星辰水火土石之变化通数二万八千九百八十一万六千五百七十六，` →
  动植通数＝289,816,576。
- 源L698：`所以谓之反观者，不以我观物也；不以我观物者，以物观物之谓也。` → **"以物观物"=
  反观**，理学认识论的纲领句（与"以我观物"相对）。
- 源L699：`既能以物观物，又安有我于其间哉？` → 消去主客对待的义理终点。

### 观物外篇选·上之数（L718-1108）—— 河图全数、先天象数、圆图、方图、后天理数

外篇上之数是**邵雍的算学层**，十二节（缺第五）。河图天地全数第一给出"天数五地数五
合而为十"与大衍五十／卦数六十的关系，并以蓍策七九为阳、六八为阴。后天周易理数第六
（L1070）给出"象生则言彰，言彰则意显"与"象数则筌蹄也，言意则鱼兔也"——**明确的
认识论：象数是工具（筌蹄），言意才是目的（鱼兔）**。这一段是"本书非占筮书"的最强
内证，也是本篇铁律三的文本依据。

核心判据：

- 源L720：`天数五，地数五，和而为十，数之全也。` → 河图天地全数：十为"数之全"。
- 源L740：`五十者，蓍数也，` → 五十＝蓍数（七七四十九＋归奇）。
- 源L741：`六十者，卦数也，` → 六十＝卦数。
- 源L767：`是故七九为阳，六八为阴也。` → **蓍策七九属阳、六八属阴**（大衍占筮的
  底层规则，是本项目六爻纳甲／蓍法同源处，但本书据此只论数不占事）。
- 源L949：`八卦者，明交相错，而成六十四卦也。` → 八卦由"交相错"重成六十四卦。
- 源L954：`是故一分为二，二分为四，四分为八，八分为十六，` → 先天象数四分法。
- 源L1008：`夫易根于乾坤而生于复姤，` → **易根于乾坤、而生于复姤**（一阳来复／一阴往复），
  是先天卦序消长的总纲。
- 源L1009：`盖刚交柔而为复，柔交刚而为姤，自兹而无穷矣。` → 复＝刚交柔、姤＝柔交刚——
  十二消息卦的生成原理。
- 源L1017：`故易以二生，数以十二起。` → 圆图"以二生、以十二起"。
- 源L1086：`象数则筌蹄也，言意则鱼兔也。` → **象数＝筌蹄（工具），言意＝鱼兔（目的）**。
  本书自陈象数居工具位——故不得转写成断事吉凶。
- 源L1095：`天下之数出于理。` → 数出於理，义理为体。
- 源L1097：`世人以数而入于术，故不入于理也。` → **"以数而入于术"是世人误用**；
  本书立场是以数入理。此句是"本书非占筮书"的第二强内证。
- 源L1105：`太极不动性也。` → 太极＝不动之性。
- 源L1106：`发则神，神则数，数则象，象则器，气则变，复归于神也。` → **神→数→象→器→变→神**
  的生成链，是全书义理层的最简公式。

### 观物外篇选·下之数（L1109-1388）—— 大小运数推演与"心学第十二"

下之数第七至第九节把元会运世落成**可运算的时长刻度**：以三百六十为时、十二万九千六百
为日、一百六十七亿九千六百一十六万为月、二万八千二百一十一兆…为年（四季/十二月/三十日/十二时），
并给出"前六限为长，后六限为消"的消长规则与"小运之变凡六十日，而成三百六十有六日"的闰余机制。
末节**心学第十二（L1377）**是全书的义理宣言：反对"作伪任数""用智数由径以求之"。

核心判据：

- 源L1111：`天自明夷以下，地自否以下，交数也。` → **天自明夷、地自否以下是"交数"**：
  明夷/否为天地交变之起点，是先天象数与后天周易的接榫点。
- 源L1114：`干之五爻分而为大有，以当三百六十之数也。` → 干卦爻位分出六十四卦以当数——
  干之五爻＝大有＝360 数。
- 源L1123：`分大为小，皆自上而下，故以阳数当之也。` → 消长方向：自上而下（分大为小）用阳数。
- 源L1132：`长小为大，皆自下而上，故以坤数当之。` → 方向对偶：自下而上（长小为大）用坤数。
- 源L1152：`三百六十，变为十二万九千六百。` → 360 → 12,960 的十进倍增。
- 源L1161：`则大小运之例立矣。` → **"大小运之例立"**——推演格式确立的标志。
- 源L1163：`后六限为消，以当一年十二月之数，而进三百六十日矣 。` → **"前六限为长后六限为消"**

## 四、对勘与口径分歧

- **无对勘本**：registry `crosscheck: []`；`tools/crosscheck_source.py` 的配对表中无本书条目。
  故本书**无异本对勘留痕**，无法核对四库本与其他版本（道藏本、周本、张行成《衍义》
  单行本的差异）孰为原文。本篇所有结论只对主源（文渊阁本系统简体转录）负责。

- **本批内无直接冲突**：与已落盘的 48 篇解读（`docs/source-readings/`）中，
  《周易》／《皇极经世书》同属义理象数一支者无；与六爻、梅花、八字等断事类
  **无口径冲突**——因为本书不提供任何断事层判据，不存在与子平/滴天/纳甲的口径分歧。

- **需防的口径分歧（三处，均为"易被误并入占筮"的分歧）**：

  1. **数序分歧**：本书圆图"以二生、数以十二起"（源L1017）与 core
     `XIAN_TIAN_TRIGRAM_NUMBERS`（梅花口径：乾1、兑2、离3、震4、巽5、坎6、艮7、坤8）
     **不是同一套序**。本书之"十二起"指十二消息/十二月，不可与梅花取数表合并。
  2. **"长/消"口径分歧**：本书"前六限为长后六限为消"（源L1163）是**消息方向**；
     若下游断事书把"长"读成吉、"消"读成凶，即为口径误并，本篇判为违规（铁律三）。
  3. **"一世"口径分歧**：本书"一世＝三十年"（源L594）是史学分期；后世"一世一运"
     的命理用法与本书无关，不得回填成"某人一生某运"。

- **与衍义（张行成注）分层**：本书"邵雍原著"与"张行成注"须分层引用。
  主源 L1389 起为衍义（L1389-2747），本文所有引文均已在行号与内容上标明层次；
  涉先天/心/诚的义理命题（如源L2332、源L2619）**属衍义层**，不等于邵雍原义。
