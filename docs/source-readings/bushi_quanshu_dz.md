## 一、书目与版本

《卜筮全书》十四卷＋《阐幽精要》附篇＋卷十四神煞歌例，是清代坊刻六爻汇本之集大成者。卷首有崇祯十年（1630）东吴顾宗孟《叙》，云「以京房易论为主，以青囊经书辅之」（源L18），坐实全书宗法京房——八宫、纳甲、六亲一系。书名页题「谈易斋重订」，卷一署名吴门逸叟姚际隆删补（源L6）。

**主源形态与版本要点**：①以钱代蓍，不用蓍草大衍法（源L260：「且以京房、管辂以钱代蓍之法行之，有似乎赘，今故删去」）；②卷首原刊河图、洛书、蓍室诸图皆佚，仅存八卦方位一图（源L257–L266）；③转录本卷首叙为草书、多字以方括号缺出；④卷二所附《易经》卦爻辞按上海古籍 1996 年通行本次序录入（非八宫序，源L723 明示）。

### 卷首：刊记、叙、目录、凡例、图说（L1–L266）

**刊记与叙（L1–L29）**：书名页题「谈易斋重订」，木坊刊记说明此书经「百愚姚先生」删繁补缺重订梓行：源L6：`今木坊敦（1）请百愚姚先生删繁补缺，迴（2）异他书` ——即卷一署名「吴门逸叟姚际隆删补」之姚际隆。卷首叙为草书转录、多字以方括号缺出，署：源L23：`崇祯庚午夏四月既望` （整理者注公元 1630 年），东吴顾宗孟撰。叙文交代全书方法定位：源L18：`大要以京房易论为主，以青囊经书辅之` → 六爻装卦体系宗京房（八宫、纳甲、六亲），与内核京房系诸表同源。

**目录（L33–L240）**：十四卷总目——卷一启蒙节要、卷二卦爻呈象、卷三通玄妙论、卷四／卷五阐奥歌章（上下）、卷六／卷七天玄赋（上下）、卷八至卷十三黄金策（一至六）、附阐幽精要、卷十四神煞歌例。本分稿行段尽卷一至卷四并及卷五章首；卷八起为《黄金策》单行本（huangjince_dz）重叠文本，归 p2／p3 段，本段不涉及。注意目录卷五首章作「阴暗雨晦章」（L117），正文实作「阴晴雨晦章」（L3533），目录讹字。

**凡例（L243–L254）**：八则编辑与使用守则，其中与仓库铁律直接同源者三。①总纲：源L245：`故卜筮之道贵在融通，勿泥形迹。` → 全书反泥象总纲（与卷四「断易勿泥神杀歌」呼应）。②一卦一事：源L248：`卜以决疑。既卜之后，若可若否，悉凭卦象。毋率己意` ——同句续云「再复再占，以渎（11）先圣」并引《易》「初筮告，再三渎，渎则不告」→ **仓库 AGENTS.md §五「一卦一事／再三则渎」的书源级出处**。现状映射：属对话层守则，引擎无「拒绝重复占卜」机械门（未核）。③用神优先：源L249：`凡自占或与人占，事在六亲之中，当以用爻（13）推看。` ——有事出异常难以生克剖断者，方以世、应、日辰旺衰生克定吉凶→「用神为主、世应日辰兜底」的两层结构，即 `disciplines/liuyao/scripts/liuyao_step2.py`（step2_identify_use_god）＋ `disciplines/liuyao/data/rules/question_use_gods.json`（分事取用）的实施纲。

**八卦方位之图（L257–L266）**：原刊删河图、洛书、蓍室诸图，仅存八卦方位一图，删图理由即占法底盘之自述：源L260：`且以京房、管辂（2）以钱代蓍之法行之，有似乎赘（3），今故删去` → 全书以钱代蓍、不用蓍草 fifty 大衍法。转录本原图佚失，虎易补配两图并作文字转写（L264–L266）。

### 卷之五 阐奥歌章 下（L3530–4393）

本卷是**按事类分章的七言歌诀集成**，凡二十六章，每章一首至十一首，多为「分宫取象＋六亲动变吉凶」的速断口诀，注文夹注起例（勾陈杀、白虎杀、丧门、归忌煞等）。性质与卷六、卷七《天玄赋》的骈文分章互为表里：同论一事（家宅、疾病、求财、婚姻等），歌诀版给口诀，赋体版给展开注解。分门占法与《黄金策》分章体系**同源**（卷八起直接收录黄金策），但卷五歌诀层多出大量「逐爻分宫」细节（如家宅初井二灶、行人初足二身），是本书独有、黄金策总断里没有的口诀层。

- 一．阴晴雨晦章（L3550–3563）：占晴雨的歌诀层。章（一）在 L3533–3549（属 p1 交界），本段含（二）至（四）与占雨/占晴的逐爻取象注。核心是六爻分象：源L3560：`占雨：以初爻为云、二为电、三为风、四为雷、五为雨、六为天。`——初至六爻依次拟云、电、风、雷、雨、天，动于何位即何象应；占晴同一骨架换为云、露、霞、虹、日月、天（源L3561：`水化火骤雨晴明，火化水晴天变雨。六爻无水火逢空，不晴不雨阴天气。`）。→ 天气占的用神与取象层；项目占雨/占晴已入 `disciplines/liuyao/data/rules/question_use_gods.json`（「天气·雨/天气·晴」族），逐爻分象表未核。

### 卷之六 天玄赋 上（L4397–4972）

《天玄赋》为骈文分章占法总集，与卷五歌诀同构但逐条带注，注中大量引《海底眼》《金锁玄关》《卜易玄机》《通玄妙论》互证。卷六含序、总论提纲与十章（身命至行人），卷七续八章（家宅至地理）。

- 序（L4399–4401）：太极两仪八卦的宇宙论开场，无判据。
- 一、总论提纲（L4404–4423）：全赋方法论。动静纲领：源L4411：`如逢卦静，专寻暗动及空亡；若见爻兴，便察吉凶分造化。`——静卦找暗动与空亡、动爻察生克，与引擎暗动（liuyao.andong）旬空（liuyao.xunkong_zhenjia）两规则同构。日辰世应：源L4415：`六爻上下，吉凶全系乎日辰；一卦中间，主宰莫逃乎世应。`六亲宜忌对举：源L4419：`官鬼不宜持世，求名婚娶两相宜；妻财俱喜扶身，父母文书偏畏忌。`——同一六亲因所占事类不同而吉凶反转，即「占用」原则，与 question_use_gods 分事取用神完全同构。

### 十一、医药（尾段，L7200–L7239；篇首 L7122 在 p2 域）

### 十四、蚕桑（L7452–L7530）
- 占蚕事：以火爻（巳午）为蚕命（蚕神马头娘为蜀女化蚕之典）、子孙为蚕身、妻财为丝绵桑叶；水爻当权主寒湿之灾。初爻蚕种、二爻蚁蚕……逐爻定蚕之各阶段。春蚕忌水、夏蚕不忌水，是卦宫五行语境化断法的典型。
- 核心判据：
  - 源L7461：`凡占蚕，必看火爻者，蚕为蜀女所化，故也。` → 火爻为蚕命的文化取象依据；「诸家皆取巳午爻为蚕命」（同段）。
  - 源L7488：`占蚕以初爻为蚕种。临财福,蚕种必好，蚁出必齐；临死绝，必不齐；临父母，一半出；临鬼死绝处，已变亦不能出。` → 逐爻（初至六）分断蚕事各阶段，原文此处「临财福，」为半角逗号（转录原样）。
  - 源L7521：`乾兑宫卦，子孙属水。其性皆逆，春蚕必难兴旺，故利夏蚕。` → 春蚕怕冷忌水、夏蚕要凉不忌水——同一象（子孙属水）在不同占季下吉凶反转，与第十七仕宦章「占官忌子动／临敌喜子动」同构，均为语境依赖断法。

### 十五、六畜（L7533–L7641）
- 占六畜总以财福为主，明确反对诸家按「分宫本命」断一物（分宫例本为家宅而设）。子孙为畜命定肥瘦驯劣形色，财为力与利，父动伤畜、兄动不长、鬼动有病灾。附置买、赌斗、渔猎、乳抱、医治分占。
- 核心判据：
  - 源L7537：`盖本命分宫，古人为家宅内看吉凶，故立此例。今人不究其理，虽只占一物，亦以分宫断之，则失其旨。学者详之。` → 作者自我声明：分宫本命法仅限家宅域，占六畜不得套用——「断法有适用域」的方法论声明，对引擎按问法分流是古籍依据。
  - 源L7540：`禽虫六畜之命，皆属子孙。旺相有气，不空，必然长养易大。` → 六畜用神统取子孙。
  - 源L7561：`乾为头，坎为耳，震为前足，艮为后足，巽为腰，离为目，坤为腹，兑为口。青龙色青，白虎色白，朱雀赤，玄武黑，勾陈螣蛇色黄。` → 八卦定畜体部位、六神定毛色的形色推断法（「凡占以子孙所临为本身颜色，以他动来生克者，断别处有异色」，源L7562）。六神五行归属引擎在 disciplines/liuyao/scripts/chain_tables.py（SIX_SPIRITS 及五行表：勾陈土、螣蛇土）。
  - 源L7596：`乃知前者螣蛇鬼动，而鸡夜鸣；今亦螣蛇鬼动，而致此异也。况孟月四爻，仲月五爻，正临怪爻发动，所以然也。自后屡验皆应，始知螣蛇真怪异之神也。` → 螣蛇＋怪爻诀的实战验证记录（鸡瘟→蜂聚两例互证），与前「十二、鬼神」怪爻诀呼应。
  - 源L7626：`凡遇占此，要世爻有气克应，子孙发动，即是我胜。` → 斗赛占：世旺克应＋子孙动则我胜，规则与战争占同构。

### 卷界 L7649：卜筮全书卷之十一 黄金策 四

### 十六、求名（L7651–L7757）
- 占科举功名：父母为文章、官鬼为官职，二者缺一不成；财福在此反为恶杀（财克父、子克鬼），兄弟为同经夺标之人。论卷面（父被克则文有破绽）、考官（月建为考试官）、龙虎二爻动主魁选、太岁临鬼主登黄甲、六冲难成六合易得。
- 核心判据：
  - 源L7656：`凡占功名，以父为文章，鬼为官职。二者一卦之主，缺一则不成。` → 双用神结构。
  - 源L7660：`财福二爻，凡占皆喜见之，惟卜功名，反为恶杀。盖财能克父，子能克鬼。故也。` → 用忌随占题反转的显式表述；引擎按问法定六亲的机制（question_use_gods.json）可承载此理。
  - 源L7673：`且如财动则伤父，子动则伤官，兄动则他人有所先，鬼动则事体有变，父动则文不纯正。` → 五亲发动于求名各自的破坏方向；「凡动则有变……故凡乱动卦，不必仔细推究，其不吉大概可知矣」（L7674）与独发独静章义互证（引擎 registry liuyao.dufa_dujing，实现 disciplines/liuyao/scripts/classical_enhancements_dufa.py）。
  - 源L7745：`求名以官父用爻，若得旺相不遭刑克，必中科第。如遇世爻发动，变入死墓空绝，恐名成后，不能享福。` → 世化死墓空绝定身后凶（游魂死于途中、归魂到家而死、墓绝是太岁逾年而死，L7745 后段）。游魂归魂断法引擎在 classical_enhancements.py（L1120 起），registry liuyao.soul_hexagram 出处即《黄金策·千金赋》——与本部同源。

### 十七、仕宦（L7760–L7855）
- 占仕途：官鬼为爵、妻财为俸、父母为印绶文书、子孙为伤官之杀、兄弟为劫俸。分职类断：风宪之职看月建官爻、掌印正官看鬼临世应、佐贰看鬼临旁位、出巡看五爻世动游魂、将帅临敌反喜子孙发动、僧道医官忌文书发动。
- 核心判据：
  - 源L7765：`未仕求名，不要财爻；已仕贵人，要见财爻。盖有爵必有禄，未有无俸而得官者。` → 同一六亲（财）在求名/仕宦两问法下用忌相反——问法分流的最典型例子。
  - 源L7773：`子孙乃伤官之杀。最喜空亡墓绝，尤宜安静受制则吉。` → 官占中子孙为忌的标准定位。
  - 源L7820：`凡遇凶兆，或得鬼爻临身持世，或本宫鬼伏世下，虽见责罚，官职犹在。` → 身边伏鬼为「官星有根」的转凶为存判据；与「伏藏有用，终辞白屋之人」（求名章 L7694 篇题句）同一飞伏法理。
  - 源L7842：`如临敌卜问，则喜子孙发动，必成剿捕之功，更得岁君月建生合，仍有升赏。官鬼不作爵位，当作贼寇论之。` → 战阵语境下用神整体换位：官鬼由爵位变为贼寇、子孙由忌变喜。语境化用神规则，引擎未见对应实现（未核）。

### 十八、求财（L7858–L8010）
- 占财总纲：财为利息、福（子孙）为财源，二者为主；财来就我（生合克世持世）易得，我去寻财难。分占：合伙、公门、九流术士、六畜血财、放债、开行、索借、赌博、商贩、置货、停榻（囤积）、脱货（抛售）。后段「要知何日得财」是全书最系统的应期条目之一。
- 核心判据：
  - 源L7863：`财为利息，福为财源。二者占财用神。` → 双用神总纲。
  - 源L7899：`财来就我，终须易；我去寻财，必是难。` → 财与世的生合冲克方向定难易。
  - 源L7939：`财爻有气，合日得财；或本日得财。` → 应期细则起句；下接「太旺，墓库日得；休囚，生旺日得；太过，收藏日得；合住入墓，破合破墓日得；旺空，过旬日得；伏藏，提起日得」（源L7940–L7945），以及源L7946：`财爻死绝，而得子孙动来扶起，即以子孙爻断。` → 状态→应期映射表。引擎应期在 disciplines/liuyao/scripts/liuyao_timing.py（候选支收集＋法则＋择优），registry liuyao.yingqi_rules 为《增删卜易》直读法口径，与本章旺衰生合体系同类而细则不同（未逐条核对一致性）。

### 十九、家宅（L8013–L8253）
- 占宅总纲：内卦为宅、外卦为人；「合为门，冲为路」不必明见于卦。论宅之新旧（青龙新修、白虎破旧）、门路方位、租赁/异姓同居/换易宅基、宅生人/宅克人、人眷刑伤（鬼临白虎）、墓门开合大忌，后段以「身命爻」配世应断家中人各别祸福（子承父业、妻夺夫权、妻犯夫家杀等），并引入本命五行生克（如木命人火鬼有助无制）。
- 核心判据：
  - 源L8018：`凡内卦：初爻为宅基，二爻为宅舍，三爻为门外。外卦：四爻为父母，五爻为兄弟，六爻为妻财。` → 爻位宅象总纲（内三爻定宅体；赋句「内为宅，外为人，详审爻中之真假」在源L8017）。
  - 源L8022：`合为门，冲为路。卦爻内不必明见冲合。` → 以支合/冲暗取门路（如姤卦二爻亥水为宅，寅合为门、巳冲为路，L8023），是「隐性取象」规则。
  - 源L8092：`且如木命人占乾兑卦，以火为官。木能生火，为鬼有助。若卦体无水生命，为鬼无制，主人衰弱。` → 家宅章引入求测人「本命五行」参与论鬼之助力——本命维度在六爻引擎中不存在（六爻盘面无年命输入；未核），此为本书与当代六爻引擎的体系差异点。
  - 源L8243：`贴身鬼带破碎杀，主有破相之疾。乾主头面小肠，喘急咳嗽之疾；坎主两耳，肾间之疾；` → 八宫定病位（后接艮震巽离坤兑），与「十一、医药」「阐幽·疾病论」的八卦病灶体系同源。

### 二十、坟墓（L8256–L8479）
- 占坟地风水：世爻定穴之世代吉凶（一世二世王侯、五六绝嗣、游魂出商、八纯归魂凶）；以六爻配来山朝案龙虎水口（穴骑龙、山带水、玄武吐舌、朱雀开口等形势术语全以爻象表达）；路形十二种（扭械路、交叉路、十字路等以冲法定）；并论改葬、劫冢、偷埋、骸骨不明（四大空亡）等特殊断。
- 核心判据：
  - 源L8260：`一世二世，子孙出王侯将相之英；世四世三，后嗣主富贵繁华之茂。` → 世爻所在爻位定穴之贵贱，六爻位象断风水的总纲。
  - 源L8402：`又云：金为尸首木为棺，土为墓兮仔细看。` → 金尸木棺土墓的物象映射，改葬判断的元件。
  - 源L8417：`甲午乙丑，甲申乙亥，甲戌乙酉，壬子癸丑，壬寅癸未，壬辰癸巳，以上乃天地空亡。` → 「四大空亡」起例：六组干支（纳音五行逢六旬无气），主骸骨不明。此为坟墓章特有神煞，引擎 core/yishu_core/shensha.py 与 bing_yao_shensha.py 均未见（未核）。

### 卷界 L8487：卜筮全书卷之十二 黄金策 五
- 自此卷起：求师、求馆、词讼、避乱、逃亡、失脱。

### 二十一、求师（L8489–L8600）
- 求师以父母为师道主象：旺相为模范、休囚局促；带刑害好施杖威；按父母所在卦宫分专经（乾坤离）/杂学（震巽艮坎兑）；父化子孙能诗赋、鬼连兄杀多诈奸；父宜静旺不宜动空，动则师无坐性（游魂尤甚，一年迁一馆）。并论束修、荐师来历（财化父妻族荐等）与代占取主。
- 核心判据：
  - 源L8506：`凡推师之专经杂学，不可依《金锁玄关》以本宫他宫言之。当以父母在震巽艮坎兑五卦为杂学，乾坤离三宫为专经。` → 明确驳《金锁玄关》旧说、自立判据——书内学派辨异的直接证据。
  - 源L8557：`凡卜求师，若子弟自占，以世为生徒，不看福爻。父兄来占，以子孙为生徒，不看世爻。` → 自占/代占取主不同，又一处「问法→取象」分流规则（与行人章「代占以应爻论之」互证）。
  - 源L8594：`凡求师，不可专指道学之师。如欲投学，百工技艺，及拜僧道为师类，皆是。` → 求师域扩展到百工技艺，仍以父母为师象、世为学者主象。

### 二十二、求馆（附束修，L8603–L8736）
- 站在塾师立场占开馆：世为西席、应为东家；父母为书馆（不可逢空）、妻财为束修（怕化兄弟）、子孙为门生（旺相多）、官鬼为纠率子弟之人/荐馆之人。论东家身份（应临六亲＋六神定官吏/农户/僧道/妇人作主）、束修斤两（生成数）、供膳、白眼与济济门生。
- 核心判据：
  - 源L8608：`凡占书馆，以世爻为西席之位。如临父，其先生必是明经之人。` → 世应角色分配。
  - 源L8643：`占馆，不可以父母为师，当作书馆论之。旺相有气，则有好书馆。` → 同一六亲（父母）在求师/求馆两问法下象义切换（师→馆），问法分流的又一显式声明。
  - 源L8683：`占馆以福爻为门生。旺相多，休囚少。` → 子孙定门生多寡；「子化子，生徒必多」。
  - 源L8638：`占馆以妻财为束修。旺相多，休囚少。` → 财定束修厚薄，并引《易》天一地二生数（L8640）论斤两。

### 二十三、词讼（L8739–L8871）
- 占讼以世应定原被两造（自占则以世为己、应为对头）；相生相合成和、相冲相克欺凌、鬼为问官（克应他遭责、克世我遭责）、日辰为书吏、财为理、兄弟破财、父母为案卷文书、卦身为讼之根由（空则情虚）。论罪名的五行（金极刑火充军木笞杖水土徒罪）、狱占（世墓入狱、岁挈福神天恩）与消散应期。
- 核心判据：
  - 源L8747：`占讼：以世为原告，应为被告。若被告占，以世为自己，应为对头。` → 世应角色随占者立场切换。
  - 源L8775：`卦身一爻，乃词讼根由。旺则事大，衰则事小；动则事急，静则事缓。` → 卦身为事体规模之尺（后接以所临六亲定起讼之由：父母田房、兄弟争斗、子孙僧道医药、财婚姻财物、官人命贼盗）；引擎安月卦身见 classical_enhancements.py L468。
  - 源L8861：`凡卜罪名轻重，以鬼爻定之。旺则罪重，衰则罪轻。` → 罪名五行轻重表（带刑加白虎旺动克世，金受极刑；火主充军；木主笞杖；水土徒罪）。
  - 源L8864：`要知消散日期，若福动鬼静，以子孙生旺月日断；鬼动福静，以官墓月日断。` → 消散应期：看何爻有权即以彼爻生旺/墓绝定日期，与求财章应期体系一致（引擎 liuyao_timing.py，未逐条核）。

### 二十四、避乱（附避役，L8874–L9028）
- 为嘉靖倭患而作的避难专章（小序明言「海倭窃发，横行吴越之间」），是《卜筮全书》成书于明中后期的内部证据。以官鬼为倭寇（驳众人以玄武论倭），论贼势旺衰、避地选择（鬼所临方勿往、子孙所临方宜行）、宅路逢鬼勿归勿出、三合鬼局必投陷阱、世空为避空吉兆、子孙持世对面不相逢。附避役（避差徭）诸条。大量附断例。
- 核心判据：
  - 源L8880：`世之占者，皆以玄武为倭贼，予则以官论。玄武倘临福德，亦作倭断耶。故凭五类，勿论六神。` → 明确的用神辨正：玄武不主贼、官鬼方主贼；「凭五类勿论六神」是把六神排除在此占判断链之外的声明。
  - 源L8904：`子爻福德北宜行，午象官爻南勿往。` → 避地方位：以子孙/官鬼所临地支定吉方凶方（「临午爻，勿往南方」）。
  - 源L8966：`且如五月戊寅日，有卜倭，得明夷之谦卦。二鬼俱静，子孙独发，皆欣喜。予独戒其，慎之。` → 著名断例：子孙独发本吉，然被日辰扶起克世、变官又系世墓（带病入墓），终应官兵之祸非倭祸——「子孙化官，官兵不道」。
  - 源L8978：`凡动爻日辰伤克，必有灾咎。若受伤之爻，生旺而有气，纵有惊险，不致伤命。` → 受伤之爻旺衰定生死分界（后接断例：五月庚寅日大壮之小过，子坐绝地而死、兄临旺土而回，L8980）。

### 二十五、逃亡（L9031–L9153）
- 占奴婢妻妾等逃亡：以用爻（依逃者身份取六亲）定去向（静看所临方位、动看变爻方位）、藏身处（宫位＋伏神＋墓库）、归期难易（生世合世终有归期、动空无寻路）、途中助力阻碍（动爻刑克有人阻、日建生扶有伴同去）、世应冲克定能否捕获。
- 核心判据：
  - 源L9040：`用爻发动，以变爻定其方向。如临午动变出寅，可言初去在南方，今移于东北方也。` → 动爻以变爻更新方位——方位随动变的时序推断。

### 二十七、出行（L9352–L9457）
- 占出行：父母为行李、妻财为盘缠、世为行人、应为所往之地、间爻为途径与伴侣。论世衰不堪奔波、应空谋事难成、间静一路平安、世克应宜行、鬼临何爻定何处有灾（初脚痛、二身灾、三伴病、四家有官事、五道路梗塞、六地头不利）、鬼地墓乡不可往而财方父向可登临。
- 核心判据：
  - 源L9443：`在初爻，脚必痛；二爻，身有灾；三爻，伴侣病；四爻，去后家有官事相扰；五爻，道路梗塞；六爻，地头谋望不利。` → 官鬼逐爻位定出行灾应点位（后结「六爻无鬼，方为大吉之兆也」）。
  - 源L9446：`子为福德，又为解神。若不上卦，或落空亡，则鬼杀专权；凡有灾祸，必无救援。故《海底眼》云：卦无子孙不喜悦。` → 引《海底眼》为据——书内征引他书的实例。
  - 源L9400：`鬼地者，世属金，南方是也。墓乡者，世属火，西北方是也。他仿此。若往此方，必有灾咎。` → 以世爻五行定「鬼方」（克我之方）与「墓方」（我所墓之方）避忌；财方父向则宜往（赋句在源L9399「鬼地墓乡，岂堪践履；财方父向，恰可登临。」）。

### 二十八、行人（L9460–L9593）
- 占在外之人：先按身份取主象（官/福/财/兄/父，不在六亲者看应爻）；动则已行、静则未思归；看动爻所在爻位定行程远近；应生世则身未动而怀归；合住定羁绊之因（六亲逐一定：父母文书、财妇人财物、兄弟朋友口舌、子孙小口僧道、官鬼贵人官灾）；伏神定不归之由（伏官下凶事羁、伏兄下是非、伏子下乐酒、伏父下文书、伏财下买卖、伏应财下身赘他家）；父动有音信、财兴无雁信；末段系统给归期推法。
- 核心判据：
  - 源L9465：`官员公吏看官爻，僧道卑幼看福爻，妻妾奴婢看财爻，兄弟朋友看兄爻，尊长老人看父爻。不在六亲之中者，看应爻。` → 行人用神按身份映射，与「用神多现取舍」同属问法→六亲机制；引擎映射表 disciplines/liuyao/data/rules/question_use_gods.json（registry liuyao.use_god_multi 称 195 问法），是否含行人身份条目未核。
  - 源L9481：`看临何爻，便知何处转去。要知行几里路去，以生成数断之。如一六水数，二七火数，三八木数，四九金数，五十土数。` → 用河图生成数＋爻位阴阳定量里程（生旺倍加、死绝减半）——罕见的数量化推断，引擎未见（未核）。
  - 源L9589：`代占，以应爻论之。远以年月断，近以日时推。` → 归期时间粒度规则；同段前文「用爻旺相，归必速；休囚，归必迟。生旺墓日归；休囚死绝，生旺日归」（源L9583）为应期主法。

### 二十九、舟船（L9595–L9625）
- 买船占与船户占同断：六亲持世定船新旧，诸鬼动临定船体节病（金钉少、土灰少、木有缝、水漏、火燥裂），初二前舱、三四中舱、五六后舵，父为梢公、龙为船尾、蛇为索缆、虎为帆樯、勾陈为铁锚——六神全部物化为船具。
- 核心判据：
  - 源L9601：`财福持世，是新船；父母持世，是旧船；兄弟持世，半新半旧；鬼爻持世，灾惊不利。` → 世临六亲定船况。

### 三十、娼家（L9628–L9703，黄金策全篇终）
- 以娼家主人立场占居宅与生意：世为主娼之人、应为宿娼之客；财为娼妓、官为宿客，二者不可相无；六冲空来空往、六合最吉（与常人占宅反忌六合成对——同象异断）；财化福主从良、鬼居刑地门招恶病。L9698 明注「此乃黄金策全篇结语」，L9703 有「—— 黄金策全文完 ——」。

## 四、对勘与口径分歧

**与《增删卜易》之分歧（暗动口径）**：本书卷三「逢冲暗动」定义源L3119 `且如六爻安静，不遇冲则不动。若日辰相冲，名曰暗动。` **无旺衰条件**；引擎 `compute_an_dong` 采用《增删卜易》口径，加「旺相逢冲暗动、休囚为日破」条件。本书口径更宽——同一卦在两书下一断一不判。宜按"两书并注"处理，勿单方面改引擎。

**与《增删卜易》之分歧（随官入墓）**：本书三分法（身随/世随/命随鬼入墓）与「杀墓＝丁未、戊戌」支值（源L3105）为引擎所无；引擎引《卜筮正宗》歌诀。属本书独有细部，补录即可，不必改判定。

**与《卜筮正宗》之关系**：本书卷一自述伏神口径与《卜筮正宗》同（源L722 `伏藏之爻，采用八宫首卦之六亲为伏神`）；卷一十七月卦身诀与 effects.py 所引《卜筮正宗》同诀异源（本书作「五（午）月」并嵌注）。**本书是引擎装卦层的更早母本**，凡《卜筮正宗》已入库者，本书可作对勘第二源。

**与《黄金策》之重叠**：卷八起为《黄金策》单行本（`huangjince_dz`，另作独立解读）。引用时应标明取自哪一版本；两本卷次划分不同，勿混引。

**本批内无其他直接冲突。**

## 五、不适用与存疑

**不采内容及理由**：

- **卷二判曰层**：六十四卦四六骈文断辞（如源L742 `判曰：乾者，健也。大哉乾元。荫覆无偏，玄运造化，万物资始。`）为京房系象数铺陈，属 narrative 候选语料，进引擎须按铁律三转措（结构上偏向…），不得直陈吉凶断语。
- **卷十四神煞歌例**：吉神约三十目、凶神约四十目（L10176–L10457）。本书卷四「阐奥歌章」明写「断易勿泥神杀歌」（与卷首凡例源L245「卜筮之道贵在融通，勿泥形迹」呼应）——**本书自editor立场反对泥神煞**。故神煞表若要入库，须先在 core `shensha.py` 定位真实使用场景（是否仅检索辅助、是否参与吉凶），属 P1 审计项。
- **《阐幽精要》观人断法十九篇**（L9707–L10169）：观人形貌定吉凶祸福，属相术范畴；AGENTS.md 明定相科不做，不入库。

**OCR/转录缺陷登记**：

1. 源L480 纳甲歌小注「戍」当作「戌」（两处）、「戊子」当作「戌子」（一处）——内核表为正、此小注为讹。
2. 目录卷五首章作「阴暗雨晦章」（L117），正文实作「阴晴雨晦章」（L3533）——目录讹字。
3. 卷首叙为草书转录，多字以方括号缺出（如源L6「迴（2）异他书」、源L334「叩（2）之即应」）——转录体例如此，非衍文。
4. 半角标点为转录原样（如源L651 `试论泰复夬需旅,鼎解大畜豫贲推`）。

**存疑**：

- **世身未入库**：卷一十六「安身决」源L577 `子午持世身居初，丑未持世身居二，寅申持世身居三，卯酉持世身居四，辰戌持世身居五，巳亥持世身居六。` ——虎易注 L579 明言「本法在现代运用已经很少……不要和月卦身搞混淆了」，本书亦仅卷二逐卦标注、引擎装卦不输出。属**书源自陈边缘**，是否补入须先定现代口径。
