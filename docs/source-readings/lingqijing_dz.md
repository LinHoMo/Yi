## 一、书目与版本

**题署与作者**：旧题汉东方朔撰，或以为张良受于黄石公，或又以为淮南王刘安；四库提要定为"术士依托"，**成书年代不得早于六朝**（源L3引南史所载繇词为今经第三十七卦象词）。**唐李遠**于防昌九年（849）作序，是现存最早确证——源L7：`唐防昌九年秋九月之吉尚书司门员外李逺叙`。源L7记其法：李遠遇泗上宗兄安，安授以卜，后果验。

**注家谱系**（源L3与L7合参）：梁·顔防明、宋·何承天为注（见源L3），李逺作叙，元·庐山陈师凯作解（源L3）；明初刘基仿易传作注（"词简义诚"，四库评价最高）。书源收有颜/何/陈/刘四家注及"许曰"一组（总论体）。

**卷帙**：四库本二卷（卷上、卷下）；源L27明书"灵棋一百二十五卦象"，然实为 124 课（三部面数 0..4，全零不成课，125 - 1 = 124；晁公武旧载 120 系遗漏）。版末阴阳㝃课（纯阴十二棋皆覆，"混沌未明"）另列，**不计入 124 课**。

**主源形态**：四库全书子部七/术数类四，851 行，繁体断句源简转繁，以「。」为主要句读，散见 OCR 缺陷。

## 二、逐卷（章）深读

### 卷一（卷首）：仪式、造棋、占仪

本卷记灵棋卜法的硬件与仪式程序，非课表。

**造灵棋法**（L19）：源L19：`用霹雳木或梓木木檀香木为棋子十二枚形圆周尺一寸二分厚三分四书上字四书中字四书下字` → 棋子 12 枚分「上/中/下」各 4，以「面」计数 0..4。工序：择木造棋 + 择日下笔（六甲日分六步）。

**发课一次定卦**（L22）：源L22：`以十二棋子一时掷之依所得上中下成卦不可再掷再则无騐` → 核心机制：**一掷定卦**，不可重掷。三部掷数各 0..4，组成 `${上}-${中}-${下}` 课号，全零不成课——ketables.json 的 keys 即此 124 个非零三元组。

**六戊禁卜**（L19后段）：源L19末尾：`甲子日旋棋子甲戌日书字甲申日刻字甲午日填硃甲辰日入柜甲寅日致祭六戊日不宜占卜` → 六戊日（戊子/戊寅/戊辰/戊午/戊申/戊戌）为禁卜日，与六仪择日同理。

**刘注总论"阳始生"微辞**（L50）：源L50：`刘曰从小至大阳始生也三人同行宜游行也不利伏韬其道光明也` → 借文言阐发课象"大通"——阳气初生、天地人得位、不利伏遁（与象辞"宜出逺行"合）。

**四家注＋李逺叙 结构**（L46-53全景，2026-10-07 逐条核准，题名原写「三家」有误）：源L47：`顔曰以小慕大可致富豪若居大慕小则有危亡` → 以"慕大/慕小"二元论占；源L48：`何曰仕宦髙迁宜显不宜隠病者不宜暗处宜出外避之吉口舌无居家守恒行师吉战鬬胜孕生男田蚕渔猎大获吉利` → 以仕宦/口舌/行人/田蚕逐项占验；源L49：`陈曰一气之始三才之端纯阳至健进退不已与干合体故曰云云` → 取"一气/三才/干体"的学说框架；源L50：`刘曰从小至大阳始生也三人同行宜游行也不利伏韬其道光明也` → 借文言阐发"大通"课象。四家各以象数/占验/学理释义，**均属象数解读层，不入库判据**（铁律三同 lingqi 科"逐字直录、无书外发挥"纪律）。

### 卷上·灵棋卦断上（课 1-62）

卷上含六十二课。每课体例：编号+课名+象曰+顔曰+何曰+陈曰+刘曰+诗曰。以下逐段抽读核心判据。

**第一大通卦（1-1-1）**（L46）：源L46：`第一大通卦【纯阳得令干天西北】一上一中一下升腾之象象曰从小至大无有颠沛自下升髙遂至富豪宜出逺行不利伏韬` → 全 1 为"纯阳得令"，取三才之初、自下升上之象。象辞"宜出逺行，不利伏韬"与刘注"不利伏韬其道光明也"一脉。

**第三吉庆卦（1-1-3）**（L60）：源L60：`巍巍赫赫家有金帛物备事办不求自获` → "富昌"取三位皆阳、地道产物之盛。

**第六惊怖卦（1-2-2）**（L79）：源L79：`雄鸡昼鸣登屋延颈雌在墙下为貍所惊絶声来赴得免损倾` → 取象：雄鸡登屋、雌为狸惊，先危后安。顔注"百事先破后成"。

**第四十三强盛卦（3-3-3）**（L316）：源L316：`众盛复强既富且昌利用建功莫之御当` → 三阳（三位皆 3）为"众辅之象"，大事可行；与第一大通同取重阳而此更显极盛。

**第六十四众凶卦（4-4-4）**（L477）：源L477：`众祸暴至凡事不利疾病系官动有颠踬` → 最凶课之一，全 4（老阴极盛），三位皆穷。顔注"出处黙黙都无吉利"。

**课名命名规则**（全书一致）：取象定名——三位数字对应「上-中-下」天/人/地三部。0=全阴，1=少阳，2=少阴，3=太阳，4=老阴。若三位数字相同，卦名直取其象（如大通、强盛）；若不同，取三部组合义（如渐泰=1+2=阴阳渐进而泰）。

### 卷下·灵棋卦断下（课 63-124 + 阴阳㝃）

卷下续课 63-124（其余 62 课）+ 纯阴十二课与阴阳㝃（无课号）。

**第七十四晚就卦（3-2-4）**（L535）：源L535：`担耒躬耕四月举趾黾勉趋时禾黍靡靡` → "有象"喻勤耕得获——农事意象入断。

**第九十四荡覆卦（4-2-4）**（L660）：源L660：`天龙暴怒雷公击皷兴云致雨流潦下土` → "除灾之象"；顔注"惟求雨吉"——取雨此课反为吉。

**第一百零六雨灾卦（3-2-4）**（L739）：源L739：`连降滛雨洪水防天人民巢居无有火烟` → "阴阳相薄"致雨水患，占者百事不宜。

**第一百一十二口舌卦（4-4-4 下）**（L775）：源L775：`东家娶妇西隣防客缚猪啾啾打狗咋咋戒慎祸患将成灾厄` → 两家竞宴、小人之情乐极生忧。

**阴阳㝃组**（L843-852）：含"第一百二十一化育卦…第一百二十二地利卦"等 24 单中位课（一下、二下、三下、四下各 6 条），+ 纯阴十二卦（一中~四中、二中/~四中等）+ 阴阳㝃（无形）。后者不参与 124 课查表，书源附录全收。

## 四、对勘与口径分歧

- **dz 主源 vs wikitext 对勘本字形差异**：`祸禍`、`礼禮`、`归歸`；wikitext 用简体/新細明體。ketables.json 从 wikitext 抓取，逐字去空白入库。fz 注（顔何陈刘）仅在 dz 此维基本，不影响课表只影响注文引用。
- **课名歧异**（少数）：wikitext 用「小戒卦」/ dz 同；主要差异在 OCR 噪点——dz L852 以"刘曰本立事定地道成也饮清食甘各保性命也本课求事有始终大吉"作收，较 wikitext 更全。
- **口径一致性**：两本课名/象曰/詩曰口径一致（仅简繁体）；与项目纪律"124 课表逐字书源、无书外发挥"无冲突面。
- **与心镜/古灵棋本互校**：本批仅对勘 dz/wiki 二本，古本（如《十万卷楼丛书》本）未提供对勘，故古本差异（若有）本次不入报告。

## 五、不适用与存疑

**不适用理由**：

1. **仪式部分非推演**：造棋、祭仪、祝文、送神辞（L18-26）非课表判据，与铁律一"机械推演"无关，仅登记。注：源L21祝文长达 L21-22 含神名无数，均为文本内容。
2. **注文为「象数解读」**：四家注（顔/何/陈/刘，见 §二 谱系表）均为象数阐释，按项目纪律 lingqi 科"逐字直录、无书外发挥"只在 narrate 层引入（经 LLM 转述），**绝不能作为机械判据**。另有维基本独有的 `许曰` 一条，**已在 124 课 notes 内**（实测标注名统计见 §二），不另作外置。
3. **诗曰层次**：每课末尾诗曰（七言绝句）为韵文重述象辞，非独立判据。
4. **阴阳㝃不参与查表**：纯阴全覆为"混沌未明"，非 124 课内。

**OCR 缺陷登记**（引文照录）：

- L19 "霹雳木或梓木木檀香木"中「」为亂碼，疑為「棗」；存疑不改。
- 多處"貍"通"狸"（L79 "雌在墙下为貍所惊"），字義可行。
- 繁体正字/异体字不归一："隂/陰""禍/祸""禮/礼"，wikitext/dz 口径平行。
- L648「丁加辛」是否「陰权大富」为异文，存疑不改。

**缺书登记**：书源卷下末（L852 后）无内容，四库本全书止 852 行；若通行本有额外附录待核查。
