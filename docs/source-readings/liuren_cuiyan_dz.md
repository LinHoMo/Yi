## 一、书目与版本

**题署与成书**：源L3：`蛟门刘赤江慕甫编` → 清代荆门刘赤江（字慕甫、慕农）编撰。源L6：`道光六年岁次丙戌夏至前三日` → 道光六年（1826）刊梓。全书十四卷，是清人辑录《毕法》与《指南》两家的**辨非＋补谈**式汇刻本。

## 二、逐卷（章）深读

### 卷一·辨非十则（L9-43）——十条与主流读数相左的机械口径

卷一十条是本书的**辨伪总纲**，每条都是机械结构层的直接指令，对项目口径有实质影响。

**月将第一（L11）**：源L11：`用月将之法，诸书皆以每月中气为过宫。` → 确认「中气换将」为正法，与项目 `core/yishu_core/liuren_tables.YUEJIANG_POLICY = "zhongqi"` 一致。源L11：`至姚广孝用河图生成之数，阳从生数，阴从成数，因其数而超之，创为异说，更属荒唐，断不可从。` → 明确否定姚广孝「生成数越宫」说，项目未采，正确。

**十干贵人第二（L13）**：源L13：`甲戊庚用丑未，六辛用寅午` → 确认《通龟》《订讹》口径（甲戊庚丑未、六辛寅午），并以《协纪》与子平天乙贵人同证。项目 `liuren_tables.noble_of` 依《六壬大全》贵人歌「甲戊庚牛羊／六辛逢马虎」取昼贵丑未、夜贵寅午，与此一致。

**旦暮贵人第三（L15）**：源L15：`如得卯辰巳午未申六时，则用阳贵，得酉戌亥子丑寅六时，则用阴贵。` → 卯辰巳午未申六时用昼贵、酉戌亥子丑寅六时用夜贵。**这正是项目 `is_day()` 的卯酉分界口径**（`liuren_tables.py` L97-98：「流派有寅时起昼一说，第一版固定卯酉分界并显式声明」）。本书明确**否定**「以日出日入定时」与「日占即得夜时亦用日贵」两说——等于为项目现有的 `verified=False` 卯酉歧义读数提供了一部书源侧的分歧登记依据。

**五行十干生墓第四（L17）**：源L17：`不知此法乃子平家所用，六壬向无此类。` → 主张六壬用**五行生墓**（不论阴阳顺行），不用十干生墓。项目 `core/yishu_core/symbols.TOMB_MAP` 正按五行立表（火墓戌、水墓辰、木墓未、金墓丑），与之相合。

**土墓从火第五（L19）**：源L19：`戊己墓神，有从水用辰者，有从火用戌者，各执一是，莫适其归。` → 源L19：`故戊己断以用戌作墓，方得其真。` → **本书主张土墓从火用戌**。项目 `TOMB_MAP` 现取「土：辰（从水）」——此为**实打实的口径分歧**，须在 §四 登记，不得按本书单方读数改数据（AGENTS.md §数据缺陷铁律）。卷六 L324 复申此说，可为对勘互证。

**涉害第六（L21）**：源L21：`从地盘历数归于本家，以受克深者为用。` → 涉害取用算法：以克贼之神自地盘历数归本家，涉害深者为用。与项目 `jiuzongmen._she_hai_deep()` 同口径。源L21：`至择比一法，涉于趋避，断不可从。` → **本书否定「涉害兼取比」**。项目 `_ke_tree()` 现状是「贼克→比用→涉害」分位串行（比用与涉害为并列先后关，非并入），与「不可并」并不冲突，但涉害支内**未做**「择比」这一步——即与本书一致。

**别责第七（L23）**：源L23：`刚日既取干合上神为用，柔日亦宜取支三合前位上神为用。` → 刚日取干五合上神、柔日取支三合前位上神。项目 `jiuzongmen` 昴星/别责支的柔日读数已标 `verified=False`（「别责柔日前三合」歧义），本书正是「柔日前三合」一系的明确支持书源。

**八专第八（L25）**：源L25：`如无克贼者，则用顺逆三神之法为合云。` → **主张八专不取遥克**。项目 `jiuzongmen.py` L240-241 注释写「两课无克号八专（论克不论遥，故先于遥克）」，并在 L248 记 `verified=False`——本书为项目现有读数提供了正面依据。

**行年第九（L27）**：源L27：`行年之法，男起丙寅，女起壬申，此正法也。` → 行年男起丙寅顺行、女起壬申逆行。项目 `scripts/` 与 `liuren_tables.py` **均无行年实现**（grep 无命中），是一条**明确缺失**的机械结构（详见 §六 OPT-02）。

**列宿分野第十（L29-43）**：列二十八宿分野古今推移（岁差致分野移宫），主张「仍录古法于图考」而备考新法，源L43：`但遵用新法，则经中所谓牛女乘常，斗牛相加，风伯会箕，雨师会毕诸法，均不可用矣。` → 纯天文/历算，**六壬结构层不适用**。

### 卷二·毕法补谈一·立课（L44-108）——四课九传的完整机械细则

**起课总纲（L46）**：源L46：`再用月将加于占人所得之时。月将即太阳也。` → 地盘（亥子丑北、寅卯辰东、巳午未南、申酉戌西）既布，以月将加占时得天盘；再依十干寄宫取四课（干上阳神／干上阴神／支上阳神／支上阴神）。项目 `chart.py`＋`jiuzongmen.four_courses()` 全同。此行还逐气列出**十二月将名对应**（冬至大吉丑将、大寒神后子将……小雪功曹寅将），与项目 `yuejiang_of()` 的十二月将表同源，属已入库项。

**九宗门立法（L48）**：源L48：`立传之法有九。一克贼，二比用，三涉害，四遥克，五昴星，六别责，七八专，八伏吟，九返吟。` → 九门顺序与项目 `jiuzongmen.MEN_ORDER` 完全一致（9 门，`verdicts.json#men` 亦为 9 键）。

**贼克/元首（L50、L52）**：源L50：`立课之法，先取一下克上为用，虽有二三课之上克下，亦所不计，名曰重审。` → 重审取下贼上，且**不因上克下而改取**——项目 `_ze_ke_courses()`＋`san_chuan_full()` 的「先下贼上」同。源L52：`元首课。谓课得一下克下为用，曰元首。` → **注意此处「一下克下」系传抄脱讹**（与同段 L50「上克下为元首」矛盾，应作「上克下」），见 §五 脱字登记。

**涉害三课见机/察微/复等（L58、L61、L62）**：源L58：`先取孟位上乘神为和，曰见机。如孟位无以，则取仲位上乘神为用，曰察微` → 涉害见机取四孟上神、察微取四仲上神（不取季）。项目 `_meng_zhong_ji()` 已有「孟深仲浅季当休」三级序，与之同构。源L61：`谓涉害有与日俱比，俱在孟位上，取时之先见者为用。名曰复等。` → 复等课：俱比又俱在孟位，取**先见者**为用。卷二 L62 复申古法并强调「近来诸家皆无用之」，源L62：`归地盘本家亥闰，五重者较一重为深`（「闰」为「闰/润」形讹，见 §五）。

**昴星（L68、L70）**：源L68：`谓四课无克，又无遥克，取酉将上下祥为用，曰卯星。` → 昴星取酉将上下神为用；阳日仰视取地盘酉上神、阴日俯视取天盘酉下神。**此处「上下祥」「曰卯星」皆形讹**（当作「上下神」「曰昴星」），见 §五 讹字登记。源L70：`谓柔日昴星，取天盘酉下神为用，中用日上神，末用辰上神，为俯视格。` → 阴日昴星中末传次序明确（先日后辰）。项目 `jiuzongmen.san_chuan_of()` 阳仰阴俯两支已实现并标 `verified=False`，本书是**第三部**（继大全、指南后）支持此读数的书源。

**别责/不备、顺数三神/逆数三神/独足（L72-81）**：刚日别责取干五合上神，柔日别责取支三合前位神；八专刚日干阳顺数三神、柔日支阴逆数三神。源L81：`如己未日，三传酉酉酉，干支上又俱乘酉，课传回归一神，名曰独足。` → **「独足」为独立结构名**（三传与干支上神归一神），项目 `kemu.json` 六十四课目中**无「独足」**，是一条可落地的结构课体。

**伏吟/杜传（L83-L90）**：伏吟有克仅乙癸两干（源L84：`伏吟有克，惟乙癸二干`）→ 项目 `jiuzongmen` 伏吟支同。杜传四例（干刑杜传／支刑杜传／初中二传杜传／中传杜传）各有取法与算例，是**纯机械**的，但项目未立此四格。

**返吟/无亲（L92-L94）**：源L94：`谓返吟无克，取支之驿马为用，中用支上神，末用干上神，曰无亲。` → **「无亲」为返吟无克时的独立结构名**（初传取支驿马、中传支上神、末传干上神），项目 `kemu.json` 无此课目名。

### 卷三·毕法补谈二·经课（L110-159）——三传形态学与「十二盘无遗漏」完备性声明

本卷把九宗门之外的**三传形态**系统枚举，全部是「三传在地支环上的相对位置」这一机械条件。

**进茹/退茹（L112、L116）**：源L112：`亥子丑曰龙潜，子为一阳初生，未离乎亥，如龙之潜而勿用。` → 三传顺行连茹，八课各名（龙潜/将泰/正和/升阶/日昃/回阴/铸刃/革故）。源L116：`戌酉申曰返驾，戌为地狱，人至于此，宜返驾而回。` → 逆行退茹八课（返驾/就明/当阳/发生/拱斗/联芳/收藏/重阴）。

**进间/退间（L120、L124）**：源L120：`凡课得间一位作三传，顺行而进，曰进间。` 源L124：`谓课得间一位作三传，逆行而退，曰退间。` → 「间一位」＝三传之间各隔一位，纯几何条件。

**三合四局（L127-L141）**：曲直（亥卯未）、炎上（寅午戌）、从革（酉丑巳）、润下（申子辰）四局，各分顺合逆合并**标定课数**（如源L127：`谓三传之神，合成木局，曰曲直。`；源L135：`谓三传之神合作金局，曰从革。`）。项目 `kemu.json` 有「全局」课目（implemented=True），但**未按四局分别标名、未分顺逆**。

**元胎/关格/稼穑（L143、L147、L151）**：源L143：`凡孟神相加作三传，曰元胎。` 源L147：`谓四仲相加作三传，曰关格。盖子午为关，卯酉为格。` 源L151：`谓季神相加作三传，曰稼穑。以土有生物之义也，顺行三课：辰未戌、未戌丑、戌丑辰。` → **元胎＝四孟顺逆（生胎/病胎）、关格＝四仲、稼穑＝四季**。项目有「玄胎」（卷一歌诀名，课经作「元胎」），但**关格、稼穑未立课目名**。

**四绝/四墓（L155、L157）**：源L155：`谓阴日禄神临于绝地，曰四绝。` 源L157：`谓阳日干上神乘日墓，曰四墓。` → 纯结构（阴干禄临绝地／阳日干上神乘墓）。项目 `kemu.json` 无「四绝」「四墓」课目名（`kemu.py` L322 仅在 partial 里记「用起四墓/自坐四墓/干支乘墓诸格未逐格分列」）。

**本卷最关键的机械声明（L159）**：源L159：`谓十二地盘中丑加子为进茹，亥加子为退茹，寅加子为进间，戌加子为退间，辰加子为顺三合，申加子为逆三合` → 后文续列卯加子／酉加子（顺逆三交、关隔、稼穑）、巳加子为四墓、未加子为四绝，合返吟伏吟两课，「十二盘中之课，已无遗漏」。**这是一份完备性清单**：以十二地盘中丑加子为基点，把十二盘课型全部枚举。**这为项目 `dev_tools/check.py` 的 720 课式全枚举门提供了一份可对拍的课型完备性基准**（详见 §六 OPT-01）。

### 卷四~卷六·要将／吉神／凶煞（L161-395）——结构条件密集，但吉凶断语占绝大多数

卷四至卷六是「格例」层：每格句式统一为「条件句 + 课数 + 例课 + 吉凶断语」。**条件句多为机械结构，断语一律 narrative 候选**。

- **天将/太岁/月建发用**（L170、L174）：源L170：`岁谓太岁，甲年见甲，乙年见乙，谓之岁君。` 源L174：`谓课值月建发用，乘吉神生合则吉，乘凶将刑克则凶。` → 「太岁发用」「月建发用」是机械结构条件，「乘吉神生合则吉／乘凶将刑克则凶」是方向断语，**超出骨架**。项目 `kemu.json` 的「天祸」课目 implemented 未设（属「需节气的天祸」类），与此吻合。
- **旬丁动神**（L178）：源L178：`谓丁为动神，如庚辛壬癸四干，课传年命见旬丁，水日主财动，金日主凶动。` → 「课传年命见旬丁」是结构条件，方向断语超出骨架。
- **闭口**（L184）：源L184：`谓癸为闭口，凡旬尾加旬首发用，名闭口。` → 「旬尾加旬首发用」纯结构。项目 `kemu.json`「闭口」implemented=True，已入库。
- **罡塞鬼户／魁度天门**（L188、L190）：源L188：`辰加寅发用，名罡塞鬼户。` 源L190：`谓戌为河魁，亥为天门，戌加亥发用，名魁度天门。` → 均为「某支加某支发用」型结构名，后者与《六壬大全·毕法赋》同名（`liu-ren-da-quan.md` §五已登记）。
- **德/禄/旺/鬼四表**（L227、L235、L238、L293）：源L227：`干德者，甲己在寅，乙庚在申，丙辛戊癸在巳，丁壬在亥。` 源L235：`谓甲丙戊庚壬五阳干，以寅巳申亥为禄；乙相己辛癸五阴干，以卯午酉子为禄` 源L238：`旺神甲乙在卯，丙丁戊己在午，庚辛在酉，壬癸在子。` 源L293：`鬼者贼害之神。甲乙日用金，丙丁日用水，戊己日用木庚辛日用火，壬癸日用土` → **四张全是机械表**。项目 `liuren_tables.DAY_DE` 已有日德、日禄旺神；「鬼」表未独立入库（`KE_CYCLE` 可推）。
- **元武无内战例（L311）**：源L311：`其余诸将，皆仿此推，惟元武无内战例。` → **书源自陈的否定例外**，是「内战」判据的**零触发登记**依据（见 §五）。
- **四课全空/三传全空（L352）**：源L352：`谓课有四课全空，有三传全空，有日干空亡，有上下俱空，分列于左。` → 旬空四种形态（四课全空／三传全空／日干空亡／上下俱空），是可机械化的结构族。
- **墓门开（L343）**：源L343：`墓门开格。谓日墓乘蛇虎二煞，临卯酉加支，名冢墓门开。` → 结构名＋条件，方向断语超出骨架。

### 卷七~卷八·格例／占法（L397-511）——纯机械条件密度最高的两卷

**卷七格例**：引从（初居干支之前为引、末居之后为从）、拱贵／拱禄／两贵拱年命（源L413：`谓干上乘旬首，支上乘旬尾，为一旬周遍格。`）、三奇二格（源L415：`谓三奇课，有二格。一旬奇，丑为日奇，子为月奇，亥为星奇是也。`）、六仪（源L420：`谓课得旬首发用，曰六仪。`）、铸印／斲轮／轩盖（源L422：`谓巳戌卯为三传，名铸印。`／源L424：`谓卯戌巳为一传，名斫轮。`／源L426：`谓午卯子为三传，名轩盖。`）、四路驿马（源L429：`岁月日时俱以寅为马，名四路驿马`）、三交（源L437：`谓四仲日占，值四仲时为一交，值四仲作月将为二交，又四仲发用为三交。`）、绝嗣无禄（源L439：`谓课有四上克下者，名无禄；四下贼上者，名绝嗣`）、根断源消（源L443：`谓四下生其上神，为根断源消。`）。

其中**旬奇/六仪/闭口/铸印/斲轮/轩盖/三交/无禄**项目 `kemu.json` 已入库且 implemented=True；**「绝嗣」与「无禄」在本书中是一对（L439 明确并列）**，而项目只收了「无禄」，**「绝嗣」缺失**；**「根断源消」「一旬周遍」「四路驿马」「三交之三交条件」**亦未见独立课目。

**卷八占法**：本卷是**七论速判法**，几乎全是「发用／三传／四课 × 贵人前后／干支前后」的纯几何结构：

- **旺相休囚四格**（L448-L451）：得旺／失时／将来／既往。源L448：`或三传合局得旺气，名曰得旺。` 源L450：`如干支发用，或三传合局，得相气，曰将来。` → 四格条件为「干支发用或三传合局 × 旺相休囚」，纯机械（须节气定旺衰）。
- **迟速（贵人前后）**（L453-L457）：源L453：`谓欲观克应，须以发用干支与贵人较其前后，而事迟速乃知。` 源L454：`谓干神二课发用，贵人顺行，用在贵前，主事速。` → 「用值贵前＝速／贵后＝迟」纯几何。
- **撞干撞支**（L459）：源L459：`谓干前一位为关，支前一位为事。` → 「干前一位」「支前一位」的取法定义。
- **传出传入（L462）**：源L462：`三传自干支内发用，传出四课之外 ，主事虽急而终慢。` → 「发用是否在四课之上」的二分条件。
- **朝干朝支（L464）**：源L464：`谓三传有支神发用，朝其干神，为朝干格。有干神发用，朝其支神，为朝支格。` → 纯几何。
- **夹定三格（L468-L470）**：夹定／夹定虚一／夹不住，条件为「日辰前后夹定三传」「三传透出干支之外」。
- **回环/相会（L472-L473）**：源L472：`三传全在四课之中，曰回环。` 源L473：`谓不备课中，干支回环，自作三合，名干支相会。` → 「三传是否落在四课集合内」是可直接落地的**集合判据**。
- **不入（L482）**：源L482：`皆在四课之外发用，名曰不入。` → **「不入」是对课体结构本身的二级分类**（昴星/别责/八专/无依四门共有），可作 `kemu.py` 的结构标签维度。
- **遁干/阴神（L492、L495）**：源L492：`一、旬干，二，五子元干。用遁干加于课传年命上，看其生克如何` 源L495：`天乙贵人，旦暮互为阴阳，其余十一将，各以本家所乘神为阴神。` → 遁干两法（旬干／五子元干）与十一将阴神取本家所乘神，皆机械可推。
- **应验/十件（L507、L511）**：源L507：`论课之法，须将占人年命细参。而吉凶乃准。` 源L511：`十件者，初中末三传，干支上神，行年本命、占时、月将、岁建也。` → 「十件」是**参数清单**（结构层输入项），非断语；**占人年命**是本书反复强调的必参项，项目结构层目前**不取年命**（`kemu.py` 多处 partial 注明「年命条件未并入判据」），此为口径缺口登记。

### 卷九~卷十二·指南汇笺（L513-905）——十六占法门，纯 narrative

卷九至卷十二按占事分门：婚姻、孕产、考试、仕宦、经商、求财、出行、行人、趋谒、捕亡、疾病、公讼、盗贼、阳宅、阴地、晴雨（各门有卷内第 N 的次级标题），后附仕宦章专论。每门体例为「七言占歌 + 逐句白话疏」。**全卷无一条机械结构判据**——占歌本身就是吉凶断语。源L505：`十二神将，各有所司。占婚姻视财官龙后` → 十二将各有所司的取用对照（可作「占类→取何将」的映射表，但映射结果直接指向吉凶方向）。

**处置**：卷九~十二 全卷标 **不适用（超出骨架）**。其「十二将各有所司」的映射表价值在**为将来扩科（择吉／择日）留底**，不进结构层（见 §五）。

### 卷十三~卷十四·慕农占验集（L906-1368）——验案集，物理隔离

占验集逐案给出「某年某月某日某时某将占＋三传＋断语＋应验」。例：L907 起「庚辰三月庚辰日子时戌将，乡友陈立斋占胡省文庶常朝考可留馆否」，课传子寅辰午，断作「有顾祖之象＋马至四重」。

**处置**：属**案例库**（`disciplines/liuren/data/cases/`）素材。按 `liu-ren-da-quan.md` §五第 3 条同一纪律——古籍占验仅可作案例库，**不作实时推理依据**（铁律二：案例库与交付过程物理隔离）。本书占验案由作者亲历，可信度高于《六壬大全》课经集故事，但纪律不变。

## 五、不适用与存疑

### 不适用（超出骨架，登记不采理由）

1. **卷九~卷十二《指南汇笺》十六占法门全卷**：婚姻、孕产、考试、仕宦、经贸、求财、出行、行人、趋谒、捕亡、疾病、公讼、盗贼、阳宅、阴地、晴雨。每门「七言占歌 + 逐句疏」本身即吉凶断语，无机械结构条款。**不采信为结构判据**；价值在为将来扩科（择吉／择日／择物）留底。
2. **卷十三~卷十四《慕农占验集》463 行**：逐案课传＋断语＋应验。按铁律二，占验**只作案例库素材**，与交付过程物理隔离，**不得作实时推理依据**。本书占验由作者亲历（L5 自称「余观陈公献先生所传《占验》一卷」并称郭御青「如老吏折狱」），可信度较高，但纪律不变。
3. **「十二将各有所司」占类映射（L505）**：源L505：`十二神将，各有所司。占婚姻视财官龙后` → 映射结果直接指向吉凶方向，属 narrative 候选，**不进结构层**。
4. **全部「乘吉神生合则吉／乘凶将刑克则凶」句式**（如源L174）：条件部分（太岁发用、月建发用）可落结构，方向部分（吉／凶）**一律不采**。
5. **卷一第十「列宿分野」（L29-43）**：二十八宿分野随岁差推移（源L43：`但遵用新法，则经中所谓牛女乘常，斗牛相加，风伯会箕，雨师会毕诸法，均不可用矣。`）→ 属天文历算，六壬结构层不适用。本书自陈「仍录古法于图考」并「备载新法」，本书内部即持两存，**不据任一方改动项目**。
6. **「旺相休囚」四格（L448-L451）中的方向判断**：「得旺则无不亨泰」「既往则不可有为」等属 narrative 候选；**仅四格的判取条件**（干支发用或三传合局 × 旺相休囚）属可落结构的部分。

### 存疑与转录缺陷（如实登记，禁止脑补）

1. **L52 元首课脱讹**：源L52：`元首课。谓课得一下克下为用，曰元首。` → 依同段 L50「上克下谓之克，下克上为之贼」及 L52 自身后半「以上克下，大顺之征」，此处「一下克下」**当为「上克下」之脱**。**项目采「上克下」正确**；书源讹字不据以改判，登记待校本勘误。
2. **L68 昴星条双重形讹**：源L68：`谓四课无克，又无遥克，取酉将上下祥为用，曰卯星。` → 「上下祥」当作「上下神」、「曰卯星」当作「曰昴星」。**判取条件本身可读**（四课无克无遥→取酉将上下神），讹字不影响结构提取，但引文照录原样，不擅改字。
3. **L62 涉害算例形讹**：源L62：`归地盘本家亥闰，五重者较一重为深` → 「闰」为「润」或「闰」误植（涉害历数例中论及亥位归家）。**算法本身可读**（丑加卯历乙木一重归本家、亥加丑历辰戊己未戌土五重归本家，五重深于一重故取亥为用），与项目 `_she_hai_deep()` 口径一致。
4. **L74 阴备课脱字**：源L74 段末有「则干阴缺一课参」→ 「参」为衍文（余文此类均作「矣」或「是也」）。**「阴不备」定义可读**（干支之阴神缺一课），不据讹字改判。
5. **L75 刚日别责脱字**：源L75 段中有「取干五合上神为用，澡末末取干上神」→ 「澡末末」当为「中末末」之形讹（其余各门皆作「中末取干上神」）。**别责三传结构可读**，不擅改字。
6. **L70 末用/中用混用**：源L70：`谓柔日昴星，取天盘酉下神为用，中用日上神，末用辰上神，为俯视格。` 段内他处（L69 仰视格）作「中用辰上神，末用日上辰」。本书仰俯两格中末次序**确为相反**（俯视先日后辰、仰视先辰后日），与项目 `jiuzongmen.san_chuan_of()` L275 阴俯「先日后辰」一致。**登记为本书内部刻意差异而非讹字**，以项目现读数为正。
7. **L311 元武无内战例（书源自陈的零触发例外）**：源L311：`其余诸将，皆仿此推，惟元武无内战例。` → 「将逢内战」判据在元武名下**应为零触发**。此为一条**反向断言**，可作该判据的负例对照，登记为「不采为正向判据，仅作负例登记」。
8. **L83 伏吟条「乙日用杜传例」与「六甲六丙六戊六庚」列举不完整**：本书自任课（L85）列「六甲日三传寅巳申，六丙六戊日三传巳申寅，六庚日三传申寅巳」——**未列六壬日**（源L85 段内亦无壬）。此为**书源脱漏**（六壬日伏吟三传未举），不臆补，登记待勘。
9. **卷三「三传形态」只列至季神，未见「不备」类名**：卷三 L143-L151 依孟/仲/季列元胎/关格/稼穑，而「阳不备／阴不备」在卷二 L73-L74 已列。**两卷合并方成完整三传形态学**，本文已在 §二 交叉登记，不重复计入课体数。
10. **本书「计 N 课」诸数字未与项目 720 课式对表**：本书多处标课数（重审 256、元首 120、比用 95、见机 53、察微 26、复等 3、蒿矢 40、弹射 25、昴星仰 4/俯 12、别责刚 3/柔 6、顺数 6/逆数 10、无亲 6；另卷八 L482 称昴星 16 课、别责 9 课、八专 16 课、无依 6 课）。**两处数字口径不同**（L68-L76 逐门分列 vs L482 合列），不据任一方改动引擎；作为 OPT-01 完备性对拍的**参考基线**而非真值。
