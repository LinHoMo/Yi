## 一、书目与版本

**作者与成书**：旧题"西蜀易镜先生"撰，又题"兰台妙选"，为古法禄命（以年柱纳音为主论命）体系的赋文总汇。与《五行精纪》同为古法集大成，而与《渊海子平》《子平真诠》的"以日干为命主"子平体系路子不同。全书以"纳音取象＋干支组合"定格——同一组干支组合对应一个吉格名（如"马化龙驹""水绕花堤""昆山片玉""脱体化神"）。

**全书性质**：古法纳音取象格局辞典——不以日干强弱、十神格局论贵贱，而以"年柱纳音五行 × 干支方位／生肖取象"判断入何格、主何福。最大特色：大量"取象格"名，是命学里"赋文取象"一脉的巅峰，对后世《三命通会》纳音章影响深远。

**主源形态**：殆知阁转录单文件，以"上篇／中篇／下篇"三分（L4、L319、L383）。上篇专论吉格取象（纳音地支取象），中篇专论恶煞疾病夭折贫愚，下篇三元四柱兼论贵格与遇不遇。已知缺陷：① 志愿转录、未经专业校勘，形讹（"加"通"如"、"水"误植等）散见；② 部分取象句依赖上下文干支组合，单句难以独立机械化；③ 简体带句读，标点半角全角混用。

## 二、逐卷（章）深读

### 上篇（L4-318）——古法纳音地支取象吉格总汇

本卷开篇即定体系："上篇 原出琴堂次专以纳音地支取象"（L4）——全书以年柱纳音五行配合地支生肖、方位取象定格，是古法禄命（以年为主）的赋文体。术语随文白话：**纳音**＝六十甲子每对干支的五行属性（如甲子乙丑海中金）；**取象**＝把干支、地支生肖、方位比作具体物象（午＝马、辰＝龙、酉＝凤、亥＝天门）再据此断格；**局**＝三合局（申子辰水局、亥卯未木局、巳酉丑金局）。这与子平"以日干取用"的路子根本不同，属古法口径。

核心判据：

- 源L4：`上篇 原出琴堂次专以纳音地支取象` → 全书体例正名：古法以纳音＋地支取象，非子平日干法。
- 源L17：`是故马化龙驹奔凤阙，器业峥嵘` → 著名吉格"马化龙驹"：午（马）见辰（龙）合酉（凤），主器业峥嵘；取象而非日干。
- 源L18：`午属马，辰属龙，酉为凤。以此取象，人得丙午，壬辰合酉可以类此` → "马化龙驹"取象细则：午马、辰龙、酉凤，丙午（火马）配壬辰（水龙）合酉即可类推。
- 源L32：`休垂后裔则是水绕花堤，休美也` → 著名吉格"水绕花堤"总纲：主子孙繁衍之福。
- 源L33：`便为水绕花堤之格` → 取象细则：两木在内、两水在外，木不炎、水不漂，为水绕花堤之格。
- 源L54：`脱体化神，超凡入圣` → 著名吉格"脱体化神"：本命纳音与其所化纳音相遇（如金命得剑锋金等），主变化超达。

### 上篇·取象吉格续析（L55-318）——昆山片玉／鱼跃龙池等

本卷中段继续铺陈数百取象格。值得注意的是这些格普遍"以年柱纳音为体、以干支组合为用"，与子平"以日干取用"截然不同。术语随文白话：**三元**＝天干（天元）、地支（地元）、纳音（人元）；**入垣**＝五行归墓库（金人乙丑、水人壬辰等）；**三奇**＝乙丙丁／甲戊庚／壬癸辛。古法"局"的取法以三合局为格之基，与子平月令取格不同路。

核心判据：

- 源L63：`昆山片玉` → 著名吉格：金生人见戊寅，或戊寅生人得一金，二金三金则非。
- 源L64：`金生人见戊寅是也，或戊寅生人而得一金，皆合此格，二金三金非` → "昆山片玉"细则：金命见戊寅（艮山）或戊寅见一金，多金反不格。
- 源L306：`鱼跃龙池，攀龙诚易` → 著名吉格"鱼跃龙池"：鱼（亥）跃龙池（辰）。
- 源L307：`亥生人得壬辰时，乃合此格。` → "鱼跃龙池"细则：亥（双鱼）生人得壬辰时，辰人得亥则非。
- 源L9：`未饶格局之真格者，取用于生月。何神为用以定其格局者，支辰见申子辰，亥卯未，巳酉丑者谓之局者是也` → 古法"局"的取法：三合局为格之基，与子平月令取格不同路。

### 中篇（L319-382）——恶煞疾病凶格专论

本卷转论凶格："专论恶煞疾病，夭折贫愚之类"（L320）。与上篇吉格取象对称，中篇以"煞中逢鬼""白虎衔尸""羊刃重重""剑殒锋芒"等断夭折贫贱。术语随文白话：**煞中逢鬼**＝生时众煞聚而反克年干；**阴鬼蹑足**＝下克上（胎克时、时克日、日克月、月克年）；**干鬼临头**＝干支层面层层相克。凶格取象属"古法凶格候选"，结构上偏向夭折贫愚，不得直接并入子平结构层（铁律三：不用"注定"）。

核心判据：

- 源L320：`专论恶煞疾病，夭折贫愚之类` → 中篇体例正名：专论凶格，与取象吉格互补。
- 源L358：`大抵羊刃之煞，最可畏也。三重克身带煞，必主征伐而终。` → "羊刃重重"凶格：羊刃三重克身带煞，结构上偏向征伐而终。
- 源L354：`局内有伤，谓五行自旺处，逢鬼相克，福身刑空破败` → 吉格逢冲破则反凶：五行自旺处逢鬼相克、福身刑空破败，主贫死夭亡（朱门饿莩）。

### 下篇（L383-450）——三元四柱兼论贵格与遇不遇

本卷："下篇"（L383）"且夫神机妙论……必三元可据，四柱堪凭。格清为台阁之臣，局妙居钧衡之任"（L384）。下篇在取象基础上补入"遇与不遇"之辨——同一格，得禄马贵人则贵、失禄马则平作道途。术语随文白话：**遇不遇**＝入格却无禄马贵人相催，则为平人；**格清失逢于禄马**＝清格而无禄马，判为平作之人。

核心判据：

- 源L383：`下篇` → 下篇分篇标记。
- 源L384：`格清为台阁之臣，局妙居钧衡之任` → 下篇总纲：格清局妙可居台阁钧衡，仍以取象格局为本。
- 源L423：`三奇勿遇，文章空负不成名;六合正逢，家赀实若藏珍宝` → 遇不遇之辨：三奇不遇则文章不成名，六合正逢则富足（主源此处用半角分号"；"照录）。
- 源L419：`格清失逢于禄马，判为平作之人;局妙陷屈于贵人，断是道途之士` → "遇不遇"定论：清格无禄马＝平作；妙局无贵人＝道途之士。

## 四、对勘与口径分歧

**与子平体系（重日干）的根本分歧**：

1. **论命主体不同**：本书古法以"年柱纳音"为命主（上篇 L4 明示"专以纳音地支取象"），而《渊海子平》《子平真诠》以"日干"为命主（"以日为主，年为本"）。本项目 chart.py／evaluate.py 的日干主轴是子平口径，兰台妙选的纳音取象格局不在该主轴内。
2. **取格方式不同**：子平以"月令用神→格局"（如官格、杀格、财格），本书以"纳音五行×干支生肖方位取象"定格（如马化龙驹＝午见辰合酉）。两者判据不可混用，混用会双重计格。
3. **与《五行精纪》关系**：本书与《五行精纪》同为古法纳音体系，许多取象格在《五行精纪》中亦有收录，可互为平行源；本项目若有纳音取象入库，应以本书或《五行精纪》其一为正源并标注。
4. **与本项目 verdicts.json 的口径**：`disciplines/ming/data/verdicts.json` 当前"格局提纲／格局顺逆／格局成败引文／从格引文"全部源自《子平真诠》《滴天髓》（子平口径），未含兰台妙选任何一句（grep 验证无任何 lantai／兰台 命中）。因此本书纳音取象格属"古法平行源"，入库时须单列、不与子平顺逆句混。
5. **与 ming_tables.py 的纳音表**：`core/yishu_core/symbols.py` 的 `NAYIN`／`NAYIN_TO_ELEMENT`／`nayin_of` 仅提供"干支→纳音五行"的查表，是取象格的底层数据，但尚无"纳音取象格名→条件"的表。本书数百取象格正可在此基础上建 `NAYIN_XIANGGE` 表。

**对勘本**：本批内无兰台妙选对勘本（crosscheck 空）；结论以主源 `data/sources/lantai_miaoxuan_dz.dz.txt` 为准。

## 五、不适用与存疑

**不适用登记**：本编未发现全书级否定条文。中篇（L319-382）虽专论凶格，但其为"凶格取象"而非"否定某格可用"，属另一套判据，应在项目内标"古法凶格候选"，不得直接并入子平结构层。

**转录缺陷（照录原样，采信时须留意）**：

1. 主源为殆知阁志愿转录、未经专业校勘，形讹散见——如 L71"更如{加}卯"（"加"当为"如"）、L348"乙卯鼠[水]"（"水"疑为误植）、L394"生必嫉[妒]"（脱字）。引文尽量取干净句，避免讹字句。
2. 部分取象句依赖上下文干支组合、单句难以独立机械化（如 L18 须"丙午＋壬辰＋酉"三者合参），机械采信时须以整段取象条件为准，不可断章取一句。
3. 主源标点半角全角混用（如 L423、L419 用半角"；"），引文照录原样，勿"修正"。

**未读懂／无法机械化的段落**：

1. 取象格多为"赋文诗化"表述（如"器业峥嵘""功名赫奕""风光显赫于乡闾"），属文学化贵贱描述，无法转化为精确量化判据——应作为 narrate 叙事候选，不进结构层（铁律三：凶象仅用"偏向／有…信号"）。
2. 部分格的"得时／失时"条件（如 L126"生于春三月"、L208"缺一则借"）需结合月令旺衰，机械化时须映射到月份区间，尚待立项。
