## 二、逐卷（章）深读

### 御制序（L2-7）：择吉之哲学立场

**乾隆帝序**（L2-3）：源L3：`粤昔帝尧命羲和敬授人时厥民知析因夷隩之节后圣有作推而弥广至于外事用刚日内事用柔日此皆载之经典百王不易者也厥后滥觞日以讹谬术士以吉凶祸福之说震惊朕师不可方物` → 序从帝尧羲和「敬授人时」起笔，言后世术士讹谬日甚。

**序中关键判据（L6-7）**：源L6：`如曰如是则吉如是则凶如是则福如是则祸则明者所弗道也虽然敬不敬之间吉凶祸福随之矣` → 乾隆帝以「敬不敬之间」作吉凶判断的最高原则，而非逐一神煞断语——这个哲学口径正与铁律三「凶象用偏向/信号、不用注定/一定」的精神相合。项目建除/黄黑道/星宿裁决以「结构标签+得分」方式体现「敬不敬」，不绝对断吉凶。

### 奏议节（L11-80）：四库重修缘起与神煞辩误

此段为礼部/钦天监/大学士鄂尔泰等奏议，逐条驳旧本选择通书之谬。

**天德辩误**（L40-41）：源L40：`一天徳乃月建三合五行中和之气孟月用隂干季月用阳干仲月用库宫如申子辰月三合水局申孟月以癸为天徳辰季月以壬为天徳子仲月以巽为天徳水库在辰属巽宫也天徳不用地支故不用辰而用巽` → 定天德之义并以「通书子月巳月误载天徳宜改正」为正。项目 `core.yishu_core.zeji_tables` 实现这一口筘，以三合五行定天德（非旧本巳月子月）。

**九空大败辩误**（L44）：源L44：`一九空乃月建三合库地对冲之日如寅午戌月合火局火库在戌故以辰日为九空通书九空误为寅午戌月辰卯寅日卯未亥月丑子亥日辰申子月戌酉申日己酉丑月未午巳日俱宜改正` → 库地冲日为九空，旧本非是。项目建除/神煞表落此口径。

**神在日驳斥（最关键）**（L98）：源L98：`一通书以甲子乙丑丁卯戊辰辛未壬申癸酉甲戌丁丑己卯庚辰壬午甲申乙酉丙戌丁亥己丑辛卯甲午乙未丙申丁酉乙巳丙午丁未戊申己酉庚戌乙卯丙辰丁巳戊午己未辛酉癸亥三十五日为神在日其日宜祭祀曹震圭作明原谓为唐贾耽所集曲为之解而不能通又引撮要曰旧本错误十有八日今依官本改正未审旧本为非新本为是选择宗镜则曰神无所不在以此三十五日为神在日其不在日又何在乎今徧查诸家通书皆无解说惟道藏玉匣记云许真君考天曹案簿三十一日诸神在人间地府祭祀受福余日诸神在天求福反祸察其日数虽比通书少四日不同九日然其为根本于玉匣记而又加之以传譌亦可断矣荒诞不经实甚宜昔人之疑而驳之也` → 《协纪辨方书》明辟「神在日」为玉匣记荒诞不经之说，正式删削。项目 `data/citations.json` 亦记录「神在日」缺书状态（《协纪辨方书》缺书即以此为依据）。

**男女合婚驳斥**（L46）：明言男女合婚为「牵合非伦」，请删去。项目择日不涉及合婚——正确。

### 义例一·建除十二神（L1854-1868）：择吉第一权

**建除十二神定义**（L1855-1868）：源L1855：`建除十二神`，次接：
源L1857-1868 以逐行列出十二神别名与丛辰同位：建/除/满/平/定/执/破/危/成/收/开/闭，每神附同位丛辰（如建=兵福/小时/土府，除=吉期/兵宝，成=天医/天喜等）。

**建除释义口筘**：十二神皆从月建（月支）起建，以当日支位所值定除/满/平/定/执/破/危/成/收/开/闭。源L1870：`月建`──定义月建为月支（寅月建寅、卯月建卯）。项目 `core.yishu_core.zeji_tables.jian_chu_of(月支,日支)` 实现此机械对应。

### 义例中的六黄道六黑道（L4825-5002）：择吉第二权

**六黄道定义**（L4825）：源L4825：`按六黄道以位置得宜为吉犹秩叙典礼无徃不宜也旧本谓宜修宫室缮城郭结婚姻进人口则无义例可推今选时之法谓诸事皆宜而无专宜之事六黑道亦无专忌之事当以时例为断` → 六黄道：以位置得宜为吉，「诸事皆宜而无专宜之事」；六黑道：「无专忌之事，当以时例为断」。项目依据此口径实现 `is_huang_dao(日支)` 裁决，不将黄道黑道与某些特定事类吉凶作机械绑定。

**六黑道相关**（L5002）：源L5002：`按旧本六黑道忌兴众务而仍从吉神所宜并无专忌之事若选时则诸事皆忌也并详六黄道` → 仍从「无专忌之事」的原则。

### 义例·鸣吠/鸣吠对（L4826-4829）：安葬第三权

源L4826-4827：`鸣吠`——宜破土安葬；源L4828-4829：`鸣吠对`——宜破土启攒。此二日为葬事之吉神，配六十甲子在义例六「安葬」节下有对应日表。

### 纲领性判据——吉凶祸福神之总驳（L258-264，四库提要）

源L258-259 四库提要尽数选择通书旧本谬误，并列本次重修成果——天德/月恩/复日/九空/大败/蚕官等诸神本的传譌皆「条列改驳」；男女合婚等玉匣记说「悉皆删削」；「荒诞无稽如男女合婚嫁娶大小利用及诸依托许真君玉匣记之説者悉皆删削使览者咸得晓然于趋吉避凶之道」。

## 五、不适用与存疑

**不适用理由**：

1. **利用一/二（兵法择日）不适用**：兵法择日（卷三十三/三十四利用篇）；非本项目八科范畴。
2. **神在日/男女合婚/太白游方/长星短星等——本项目正确留空**：《协纪》已明辟为荒诞不经；项目留空是正确行为，登记为「缺书」（data/citations.json `#verbatim_policy`）。
3. **御制序/奏议篇非推演**：御制序（L2-7）为乾隆哲学立场；奏议（L12-80）为重修题本——文本价值在「辨伪」而非「推演」。
4. **年表/月表/日表数万行数据为静态历表**：年/月/日表逐页逐年/逐月/逐日神煞值，是静态数据层，项目无万年日表落地——仅核验义例起例之通则，日表以「可用判据 #8」口径抽样。

**存疑/OCR 缺陷登记**（照录不改）：

- 全文多處「礼」误作「礼」（实为「禮」之简体，不误）；但「问/间」「已/己/已」「土/士」在 OCR 中偶有混用，存疑不改。
- 源L98「许真君考天曹案簿三十一日」与《玉匣记》对比、《协纪》本《协纪》称「少四日不同九日」——书源内部已记录差异；项目保留缺书不臆补。
- 源L40「天德」引「申子辰月三合水局申孟月以癸为天德辰季月以壬为天德子仲月以巽为天德水库在辰属巽宫也天德不用地支故不用辰而用巽」——此为「天德」定义之根本，「巽」代「辰」的理由尚待易学考证，但项目照录数据，不另作义理推演。

**《协纪》未采之星煞（项目正确留空）**：破败五鬼、飞天独火、玉皇銮驾、暗刀煞、头白空亡、五姓修宅、嫁娶周堂、太白游方、长星短星、伏断日、密日、七圣日、大明日——以上神煞《协纪》明辟为「荒诞不经」或「悉皆删削」，项目择日裁决不含这些因子（完全正确的行为）。
