## 二、逐卷（章）深读

### 上卷·释天至释辰（L5-46）天地四时与干支名义

本段是全书义理根：先以《乾凿度》太易—太初—太始—太素—太极立天地之始（L6），次释天地（L7-L10）、四时（L13-L18）、十干名义（L22-L31）、十二支名义（L35-L46）。术语随文：**刚日柔日**＝干之阴阳，配十二支之刚柔，是六壬「刚日仰视、柔日俯视」「刚日用日上神、柔日用辰上神」诸条的分档依据。

源L34：`谓甲、丙、戊、庚、壬、五干为阳日，为刚日。` → 五阳干为刚日。刚柔名单是**纯分类条件**，非吉凶。

### 上卷·释五行至释五味（L51-109）五行生克与五色五音五性六情五味

以《白虎通》立五行方位（L52-L57），次以五色间色配五干阴阳（L61-L65）、五音配五常五事（L69-L74）、五性配五脏（L78-L82）、六情配十干（L93-L98）、五味配五行（L104-L108）。本段的实际占法只在两句「释例」上：

源L109：`释例曰：五色以主五味，皆有象也。假令占人，用起木神，则其性仁而恻隐。在物而色青，在味则酸，在病则肝。` → 用起某行神 → 色/味/脏的**机械对应链**。源L89：`假令正月甲子日寅时占事，用起胜光火神加酉一，上克下为用。` → 同一「用神五行→所主」路数，并明确「上克下为用」即取用判据。**「其病在心」「在病则肝」属占断叙事**（超出骨架），可采者只有「用神五行→色/味/脏」的机械对应表。

### 上卷·释四门（L118-123）四门方位

四门各以两支定位。源L120：`天门：在西北。西北者，戌亥之间，秋冬相交之际，草木黄落，天门之内，故天门在西北也。` → 天门＝戌亥。地户＝辰巳（L121）、人门＝申未（L122）、鬼门＝丑寅（L123）。四门是**纯地盘分组表**，与 `data/verdicts.json#tianjiang.贵人.note` 的「贵登天门为当权，到辰戌上为入狱」共用同一「门」概念。

### 上卷·释德（L125-129）十干德与十二支德

源L127：`十干德者，甲、丙、戊、庚、壬阳干，德自处。乙德在庚，丁德在壬，己德在甲，辛德在丙，癸德在戊。` → 阳干德自处（德即其位），阴干德在所合之干（乙庚合故乙德在庚，余同）。源L128：`十二支德者，子在巳，丑在午，寅在未，卯在申，辰在酉，巳在戌，午在亥，未在子，申在丑，酉在寅，戌在卯，亥在辰。十二支德，岁月日时同用。` → 支德＝顺移五位（子→巳、丑→午、余仿此），且明言「岁月日时同用」——**可用于年/月/日/时四层的机械德位取法**。注意本表与项目 `core/yishu_core/liuren_tables.py::DAY_DE`（甲寅乙申丙巳丁亥戊巳己寅庚申辛巳壬亥癸巳，出六壬大全卷一）**取值体系不同**（见 §四）。

### 上卷·释刑至释害（L131-146）三类刑与六害

释刑分三段。源L138：`甲刑在申，乙刑在酉，丙刑在子，丁刑在亥，戊刑在寅，己刑在卯，庚刑在午，辛刑在巳，壬刑在戌，癸刑在未。` → 十干刑（与 L150 干鬼表**逐字同值**）。支刑三段：无恩之刑寅巳申（L140）、恃势之刑未刑丑丑刑戌戌刑未（L141）、无礼之刑子卯与自刑辰午酉亥（L142）。

释害给六害并逐对命理名目。源L145：`酉戌相害者，谓戌以死火，害酉生金，此名为鬼害也。` → 六害含「鬼害／恃势相害／少凌长相害」等**名目**（名目可登记，凶断不采）。六害对本身与 `core/yishu_core/symbols.py::HARM_PAIRS` 十二对**逐对一致**，可直接对拍。

### 上卷·释鬼至释数（L148-166）干支鬼、三杀与数

源L150：`干鬼者：甲鬼在申，乙鬼在酉，丙鬼在子，丁鬼在亥，戊鬼在寅，己鬼在卯，庚鬼在午，辛鬼在巳，壬鬼在戌，癸鬼在未。` 支鬼十二（L151）亦成表。

释杀分四组三合。源L155：`巳、酉、丑，劫杀在寅，寅中有阴气生火也。灾杀在卯，卯为日门，阴气所入。天杀在辰，辰为四季阴气，能游天上也。` → 巳酉丑组：劫杀寅、灾杀卯、天杀辰；余三组见 L156-L158。另列金神三杀。源L159：`金神三杀者，寅申巳亥，三杀在酉。子午卯酉，三杀在巳。辰戌丑未，三杀在丑。` 劫/灾/天三杀与金神三杀均为**纯表推导**（按三合局），可机械生成。

释数给两套数。源L165：`五行数者，水，生数一，成数六。火，生数二，成数七。木，生数三，成数八。金，生数四，成数九。土，生数五，成数十。` 源L166：`十二支数者，子午数九，丑未数八，寅申数七，卯酉数六，辰戌数五，巳亥数四。十干数者，甲己数九，乙庚数八，丙辛数七，丁壬数六，戊癸数五。` 生数／成数与十干数五行纳音同源，为数法之底。「大凶也」类断语（L161）**不采**。

### 下卷·释相生至释月将（L170-189）十二月将名与建月

源L177：`正月将徵明：《金匮经》曰：建寅之月，阳气始达，徵召万物而明理之，故曰徵明。` → 十二将名按**建月**配：寅月徵明（亥）、卯月天魁（戌）、辰月从魁（酉）、巳月传送（申）、午月小吉（未）、未月胜光（午）、申月太乙（巳）、酉月天罡（辰）、戌月太冲（卯）、亥月功曹（寅）、子月大吉（丑）、丑月神后（子）。此序列与 `liuren_tables.py::ZHONGQI_YUEJIANG` 的中气换将表**逐位一致**，是项目月将口径的一份独立互证。L189 末「旺气/相气/死气/囚气/休气所胜，忧县官/财物/死丧/囚系/疾病」——五气分级可机械判定，「忧何事」为叙事，不采。

### 下卷·释璧度至释昏晓（L191-288）分野与天文历表

释璧度以十二次配十二将并定「于辰在某」十二支。源L193：`自轸宿十二度，至氐四度，为天罡，于辰在辰。` → 天罡在辰，余十一次同式（L194-L204），此表给出**将名→支的换算**（登明亥、河魁戌……神后子），是 L291 释天乙读将名当支的桥梁。释日度（L207-L233）给二十四节气日宿度，L233 明文「用大吉为月将」与「二十日以前用式占事，犹用功曹为月将」，即**超神接气**的实际换将界。释日出没（L236-L260）给每日日出日入刻数，源L236：`古法曰：一昼夜有二十时，总一百刻，逐时更分，各有长短，谓辰戌丑未四时，各十三刻，其余八时各六刻，共成一百刻也。` 释昏晓（L263-L288）给二十四节气晓中星／昏中星，与**昼夜贵人起昼夜的判据直接相关**（详见 §四分歧）。

### 下卷·释天乙与释天官（L290-305）昼夜贵神与十二将家支

源L291：`天乙常以甲戊庚日，旦治大吉，暮治小吉。乙己之日，旦治神后，暮治传送。丙丁之日，旦治征明，暮治从魁。壬癸之日，旦治太乙，暮治太冲。六辛之日，旦治胜光，暮治功曹也。` → 昼夜贵人**以将名表述**：昼 甲戊庚＝大吉(丑)、乙己＝神后(子)、丙丁＝征明(亥)、壬癸＝太乙(巳)、辛＝胜光(午)；夜 分别＝小吉(未)、传送(申)、从魁(酉)、太冲(卯)、功曹(寅)。**此处壬癸「旦治太乙(巳)、暮治太冲(卯)」与项目 `NOBLE_DAY["壬"]=卯 / NOBLE_NIGHT["壬"]=巳` 相反**，是本书最有价值的分歧发现（见 §四、§六 OPT-01）。

释天官逐将给出「家在某干支＋某神」与旺相休囚死五气。源L294：`天乙居中贵神主，帝王之象，家在己丑，土神。` → 天乙家己丑土神。源L305：`后六天空，天乙司直。` → 天空列于**后六**之末，与项目 `TIAN_JIANG_ORDER` 把天空置于青龙之后的顺排**不一致**（见 §四）。

### 下卷·释造式、释用式、释避忌、释次客、释次筹、释行年（L307-328）用式全流程

释造式（L308-L309）给枫子为天、枣心为地、式局尺寸与刻式法——属器物制作传统。释用式（L312-L314）是**本书机械价值最高的一段**，九宗门取用次第全在本此。

源L312：`四课之中，察其五行，先取相克者为用，先以下克上为用，若无下克上，即以上克下为用。` → 贼克先下贼上的取用根本条件。源L313：`别责之课，其数有九。刚日有三，谓戊辰、戊午、丙辰，日各有一课。` → 别责九课的**日干支枚举**（刚三柔六）。源L314：`返吟课多相克，惟丁丑、己丑、辛丑、丁未、己未、辛未无克` → 返吟无克六日的**明确枚举**，与 `jiuzongmen.py` 的 `{丁丑,己丑,辛丑,丁未,己未,辛未}` 集合逐字一致。L314 同时给出六乙日自刑、六癸日自刑、伏吟刚柔异取、八专刚日顺数三辰柔日逆数三神等特法。

释避忌（L317-L318）给月忌时与日忌时。源L318：`右忌日时不可占事，误用者当损用式之人也。` 释次客与释次筹（L321-L325）给十二客加法。源L321：`阳将临正时，先用后三，次用前五。阴将加正时，先用前五，次用后三。` 源L322：`第一客月将加正时，第二客用月建加太岁，第三客用太岁加月建` → 十二客为十二种天地盘加法，纯机械。释行年（L328）给男顺女逆起运。源L328：`男一岁从丙寅顺行，从一岁移一辰，十一岁丙子，二十一岁丙戌。`

### 下卷·释将传至释卦略（L330-351）将传断语、神变、常例与应期

源L331：`《玄女》曰：六壬之道，皆取三传。相生则吉，相克则凶。` 逐将主事（朱雀文书口舌、六合嫁娶婚姻、勾陈斗讼田土……）**整段属 narrative**，只可作叙事候选。源L342：`伏吟事近，返吟事远。` 与同段「日辰阴阳，在天一前主事速，在天一后主事迟也」是**课体→距离/迟速**的结构映射，不含吉凶方向，是可落的结构标签。源L351：`神将内战，祸害难解。神将外战，祸微易解。神克将为内战，将克神为外战也` → **「内战／外战」的判定条件（神克将为内战、将克神为外战）纯属机械生克方向**，是本书第二个高价值可落点；后半「祸害难解／祸微」为叙事，不采。释卦略（L345-L350）给应期算法。源L347：`得岁不出岁，得月不出月，得日不出日，得时不出时也。` 源L348：`《黄帝》曰：数之一魁离日。假令占事，河魁加未，未数八，河魁数五，五八四十，为吉凶之事在四十日之内也。` 应期属**时间主张**（非吉凶方向），但项目 `analyze.py` 已明文「应期未落地——登记于 docs/TECH-DEBT.md」，故本轮不落，只登记。

## 四、对勘与口径分歧

- **对勘本**：登记表 `crosscheck: []`，本批内无直接对勘本。分歧均以「与仓内已落数据／其他书源」对举。
- **与《六壬大全》分卷（`liu-ren-da-quan.md`）的月将口径**：本书 L177-L188 十二月将按**建月**配将名（寅月徵明即亥将、卯月天魁即戌将……），大全与项目 `ZHONGQI_YUEJIANG` 按**中气**换将。二者逐位等价（本书「徵明」即「登明」，皆亥将；「天魁」即「河魁」，皆戌将），**不构成冲突**，本书是项目月将口径的一份独立互证。
- **昼夜贵人·壬癸（本篇最重要分歧）**：本书 L291「壬癸之日，旦治太乙，暮治太冲」，即昼＝巳(太乙)、夜＝卯(太冲)；而 `core/yishu_core/liuren_tables.py` 的 `NOBLE_DAY["壬"]=NOBLE_DAY["癸"]="卯"`、`NOBLE_NIGHT` 作「巳」。按大全贵人歌「壬癸蛇兔藏巳卯」顺读为昼蛇(巳)夜兔(卯)，**与本书一致、与项目现值相反**。项目自身文档亦记有「壬癸兔蛇藏巳卯」，故现值在仓内不自洽。按 AGENTS.md 数据缺陷条款，本轮**不擅改数据**，提请裁定（OPT-01）。
- **十二天将布序**：本书 L294-L305 释天官标「前一螣蛇…前五青龙，**后一天后、后二太阴、后三玄武、后四太常、后五白虎、后六天空**」，天空列后六之末；项目 `TIAN_JIANG_ORDER` 为贵人、螣蛇、朱雀、六合、勾陈、青龙、**天空、白虎、太常、玄武、太阴、天后**（天空居第六）。两者「前六」一致、「后六」次序相反。通行布将口径以项目现值为是，本书「后一～后六」或为篇中方位叙述而非布序依据。**未核**是否有第三本可裁，登记存疑不动数据。
- **德表体系**：本书 L127-L128 德＝「阳干德自处、阴干德在所合之干」＋「支德顺移五位」；项目 `DAY_DE`（甲寅乙申丙巳丁亥戊巳己寅庚申辛巳壬亥癸巳）取自大全卷一，是另一体系。二者**不是同一张表**，不可互相校改。建议双表并存、各自标出处（OPT-04）。
- **昏晓与昼夜分界**：本书 L263 以「星没为晓，星出为昏」＋L265-L288 二十四节气昏晓中星表定昼夜；项目 `liuren_tables.is_day` 固定卯酉分界（源码注释已自记「寅时起昼一说，第一版固定卯酉分界并显式声明」）。本书提供了第三种（星象）口径，**不静默择一**；若采纳须作显式开关。
- **与《六壬断案》《六壬指南》互校**：断案为验案集、指南重日辰毕法，与本书同属「月将加时起四课＋九宗门取三传」门派，起例骨架无冲突；本书额外提供德/刑/鬼/杀/数/四门六类机械表，是断案与指南均未给的表组。

## 五、不适用与存疑

**不适用（超出骨架，一律不采）**：

1. **十二将主事与旺相休囚死五气断语**：源L161：`凡上三传，吉将与杀并者，吉事速。凶将与杀并者，其凶尤重。` 及 L294-L305 逐将「在旺有…在相上有…在死上有…在囚上有…在休上有…」、L331 逐将主事（朱雀文书口舌、六合嫁娶婚姻…）——**全为吉凶方向与事项归属**，属 narrative 候选，只登记不采；`data/verdicts.json` 亦不得引入本书此段。
2. **《玄女》极致断语**：L336「入水不溺，入兵不伤，入病不死，恶寇不逢，所求必得，所作必成」——**修辞性极致断言，不具可判定条件**，禁止任何形式的采信或转写。
3. **应期与迟速的吉凶化用**：L347、L348 的数法应期属时间主张，项目已在 `analyze.py` 登记 TECH-DEBT，本轮不动；L342「事速事迟」仅作结构标签候选（时间/空间属性），不得改写为吉凶。
4. **造式器物与避忌**：L308-L309 式局尺寸、刻式法、L317-L318 月忌日忌时，属择吉与器物传统，八科中无对应归属（zeji 亦未覆盖式造）。
5. **占验举例的吉凶归属**：L89「若占人疾，其病在心」、L109「在病则肝」、L345-L346「本年四月丙丁日，当有县官失火事」——举例中的事项归属为叙事，只可作说明文，不得入判据。

**转录缺陷与异文（逐条登记，不脑补）**：

1. **L16 秋条脱字**：「秋，□也，（颜师古曰：□，子由切）」——正字缺失，释例不可复原。
2. **L27 己条脱字**：「己也，纪也…□□□□□。班固曰：万物出于甲，终于己也」——五字脱缺。
3. **L34 形讹**：「丑、卯、**已**、未、酉、亥、六支为阴辰」——「已」当作「巳」。
4. **L63 疑讹**：「西方有间色缥也（庚白、辛**栗**）」——「栗」疑为形讹，不擅改。
5. **L210 疑衍**：「大寒，女宿六度**七十七分**」——全表皆作「初度＋x分」或「x度x分」，此处「七十七分」不合体例，登记疑衍。
6. **L230-L232 重出**：「小雪，尾宿一度四十八分。／大雪，尾宿一度四十八分。／大雪，箕宿初度三十分」——大雪重出两次且与小雪同度，疑倒错或衍文。
7. **L192 人名疑讹**：「又有**费真**说《周易》、蔡邕《月令章句》」——「费真」疑为「费直」之讹。
8. **L207／L263 书名疑讹**：「依大宋《**祟**天历》」两见——「祟」当作「崇」（崇天历）。
9. **L313 自相矛盾**：别责「柔日有六，谓辛未、辛丑日各有二课，丁酉、辛酉日各二课，**辛酉曰有一课**」——辛酉日既称二课又称一课，同一行内自相矛盾。引擎 `jiuzongmen.py` 现取大全「刚三柔六共九课」口径，本书此读不采，登记不臆补。
10. **L318 前篇讹字**：「二六十月忌子时**,**三七十一月忌酉时」——半角逗号排印混入。

**存疑未读懂处**：

1. **L127「阳干德自处」的确切取位**：「甲、丙、戊、庚、壬阳干，德自处」——「自处」是指德在干之寄宫、还是在干之本位，字面不足以判定；本书亦未给书例（L129 书例只示范阴干乙德在庚）。登记存疑。
2. **L145「凡占遇六害者，各以本意决之」**：「本意」指各害对之义（鬼害／恃势相害／少凌长）还是另有他指，未读懂；名目可登、口诀不可推。
3. **L342「仰视俯视」「刚日远行稽留关梁」「柔日伏藏不出邑里」**：与昴星课刚柔取传相关，但此处只给断语未给推导路径，无法机械化，登记存疑。
4. **L191-L204 释璧度「于辰在某」的推算原理**：已知其可作「将名→支」换算用，但书中未言其法；本项目按表值取用即可，不复推其天文来源（避免脑补）。
5. **L290-L305 十二将「前/后」编号是否等同布将次序**：与 `TIAN_JIANG_ORDER` 不一致，成因未明（见 §四），未核。
