## 一、书目与版本

**作者与成书**：西汉焦延寿（焦赣）撰。《焦氏易林》以《周易》六十四卦为框架，为每一卦
配六十四变辞，得 64×64＝**4096 条占辞**。书名"易林"即取义于"卦＋变"成林：每卦之下
六十四变如林木蔚起，故又称"焦林"。它是《周易》占辞体系的一次大规模象数化扩张——
把《周易》本卦的静态爻辞，扩展为"本卦×变卦"的动态吉凶矩阵。

**性质定位**：属**占辞体系**（"某某之某某"＋一句四字格占断语），不是起卦法。
六爻（《周易》卦爻辞）与梅花（万物类象）都是**起卦法**——由卦产生象；本书恰恰相反，
是由既定的卦对直接**查辞**。故项目当前**无对应学科**，本篇判据一律标
`不适用(无对应学科)`，价值在为将来扩"易占"科留底。

## 二、逐卷（章）深读

本书无"卷"层，只有"卦"层，故按卦节分 `###` 小节；同型相邻卦节合并推进，逐节不跳。

### 前段 · 乾—蛊（18 卦节，L1-2340）：卦之变两行式

**本段讲什么**：这是全书的"前一半"，18 个卦节，每节 130 行。行式为"变卦名行＋占辞行"
交替，节首以 `■■■此起为X卦■■■` 标起、节尾以 `■■■X卦终■■■` 标止。占辞本身**不用
《周易》本卦爻辞的字句**，而是另起炉灶造语——这是本书最要紧的体例事实：它与
《周易》卦爻辞**不是引用关系，而是同源分流**（同出《周易》卦象系统，但辞语独立）。
术语随文白话：**"乾之坤"读作"乾卦变作坤卦"**（前字＝本卦／母卦，后字＝变卦／子卦）；
"之"即变。**首条"乾之乾"＝不变（pure hexagram）**，可视为自占基线；**末条"乾之未济"**
落在通行卦序的最后一卦，**首尾相衔**（未济之后又回到乾节），构成一个环形。

核心判据／体例（占辞原文照录；吉凶含义保留书源口径，本解读不据此推理）：

- 源L1：`■■■此起为乾卦■■■` → 全书第一条是节标而无序言，直接入卦；**本书无总纲、无
  占法说明、无卷目**——用书须知此点（体例上的"无判据可循"，故本项目无对应学科亦非
  仓促判断）。
- 源L3：`道徙多阪，胡言连蹇。译喑且聋，莫使道通。请遏不行，求事无功。` → 乾之坤。
  四字格连缀六句，句式为"**四字-四字。四字，四字。四字，四字。**"（`，，。，。` 型，
  全篇最常见 2649 条）。内容结构＝**天象/物象（道徙、胡言、喑聋）→ 行事受阻
  （莫使道通、求事无功）**。
- 源L9：`鵊鵴鸤鸠，专一无忧。君子是则，长受嘉福。` → 乾之蒙。三鸟并名起句，
  后接"无忧""长受嘉福"——吉断的典型收束语（"长受嘉福""无咎""无害"）。
- 源L23：`不风不雨，白日皎皎，宜出驱驰，通理大道。` → 乾之泰。吉断的**占断建议句**
  可辨：观象（不风不雨、白日皎皎）→ 断可行（宜出驱驰）。这类"象→断"两句式是
  全书判读骨架。
- 源L29：`上帝之生，福佑日成。修德行惠，乐且安宁。` → 乾之大有。**"修德行惠"**
  指出本书并非只观外象，亦有**行为建议**（德行条目）——此点在 §三 单列。
- 源L105：`民怯城恶，奸人所伏。寇贼大至，入我邦城，妻子俘获。` → 乾之艮。
  凶断的"分层升级"范式：先民情（民怯）→ 再地形（城恶）→ 后灾变（寇贼大至）→
  末及人身（妻子俘获）。**凶象落在"信号"层**（民怯、城恶为兆，寇贼大至为应）。
- 源L123：`舜升大禹，石夷之野。征诣王庭，拜治水土。` → 乾之中孚。**用历史人事
  为占**：舜→大禹、石夷之野、拜治水土。此类"本事"句在本书占比可观，**是叙事而非
  判据**（AGENTS.md 铁律二：属叙事候选／超出骨架）。
- 源L128：`乾之未济` → 乾节末条行。以卦名行收束，对应通行卦序末卦；乾节 64 条
  （L2-129 逐行两行一组）已抽样核平。

### 前段 · 坤—随（17 卦节，L131-2210）：体例承前，仅举异例

本段 17 节（L131-2210）与乾节**体例完全同型**，无结构创新，故不逐节罗列，
仅举两条与乾节不同的**语义类型**（体例一致性本身就是可机检的判据）：

- 源L437：`履位乘势，靡有绝毙。替为隶圉，与众庶伍。` → 履之比（比卦节内）。
  **"靡有绝毙"**＝"没有绝灭之虞"；**"替为隶圉"**（隶圉＝养马人）为身份位阶之象。
  此类"称名职务"（大夫/侯王/公卿/隶圉）是本书判词的**第三类取象**：非物象、
  非灾变，而是**人事位阶**。
- 源L163：`铅刀攻玉，坚不可得。尽我筋力，胝茧为疾。` → 坎卦节内。**取象于
  器物用途失当**（铅刀攻玉）＋**身体代价**（胝茧＝足茧）。此条兼"谋事不成"
  与"身体有伤"两重，是复合断的典型。

### 后段 · 临—革（21 卦节，L2341-4356）：卦名＋辞同行式

**本段讲什么**：行式骤变为"　变卦名　占辞"（卦名与辞间**两个全角空格**），
节首为**纯卦名行**（如 `　临　`，尾随一个全角空格）。占辞内容与前段一脉相承，
但**行式差异显著**，且**校记残文大量涌入辞中**（详见 §五）。

- 源L2341：`临　` → 后段首行即节标（**行首无缩进**，纯卦名＋尾随全角空格；后段节标
  行首缩进并不统一，或有或无）。节标体例在两段间**完全不一致**（前段 `■` 包裹、
  后段无包裹），是本书转录的最显著形式特征。
- 源L2342：`　临　　弱水之西，有西王母。生不知老，与天相保。行者危殆，利居善喜。`
  → 临之临。后段占辞**普遍更长**（前段均长 21.4 字／后段 26.6 字），可容**三层信息**：
  定位（弱水之西）→ 人物/神异（西王母）→ 分断（行者危殆 vs 利居善喜）。
  **同一辞内吉凶并陈、分对象分断**（"行者危殆，利居善喜"），是本书重要体例。
- 源L2347：`　需　　重瞳四乳，目聪耳明。普仁表圣，为作元辅。` → 临之需。
  极罕见之**具象重瞳四乳**，颂圣之辞。属**人物类象**（可与梅花万物类象对照，
  但本书**不做**类象起卦，只在辞中取象）。
- 源L2395：`　归妹　域域牧牧，忧和相伴。隔我岩山，室家分散。` → 临之归妹。
  首二字叠字（域域牧牧）为**叠字格**；结"室家分散"——**家庭/婚姻域**的典型断。
- 源L2543：`　讼　　羊惊狼虎，耸耳群聚。行旅稽难，留连愁苦。` → 贲之讼。
  断**行旅**（行旅稽难、留连愁苦）。行旅域在全书可辨（"行旅""出行""征""旅"
  四类语汇合计约 181 条）。
- 源L2696：`　离　　跖并桀处，民困愁苦。行旅迟迟，留连齐鲁。` → 剥之离。
  用**历史人物并处**（跖＝盗跖，桀＝夏桀）作凶象，兼断行旅。同类"本事"句不少，
  一律按叙事候选登记。

### 后段 · 鼎—未济（25 卦节，L4357-5332）：收束段与衍文标记

后段最后 25 节。**离卦节（L3056-3120）与大壮卦节（L3316-3380）之间**、
**大过（L2926）节内**、**小过节起（L5137）**多处出现节标脱漏与衍文校记。

- 源L2928：`.　乾　　日在北陆，阴蔽阳目。万物空虚，不见长育。` → 大过之乾。
  **行首多一西文句点 `.`**——排版噪声，非文本内容。照录以存真（§五 登记）。
- 源L5310：`　损　　厌浥晨夜，道多湛露。沾我襦裤，重难以步。` → 未济之损。
  "襦裤"（内衣裤）为**贴身衣物**取象。全篇此类**衣物/身体**取象频繁，是本书
  万物类象体系的一个特色面（可与梅花类象对源，见 §三 第 9 条）。
- 源L5332：`　既济　大蛇巨鱼，相搏于郊。君臣隔塞，郭公出庐。` → 未济之既济。
  全书**倒数第二条**（既济节恰在未济节前，序位与通行卦序一致）。以"君臣隔塞"
  作断而**无明吉凶字面**——此为本书常见体例：**只陈述象与事，不加断词**，
  吉凶由读者自会。此体例事实本身是判读前提。
- 源L2409：`　坤　　继祀宗邑，追明成康。光照万国，享世久长。病疾不医，下即蒿芦。此二句疑衍）`
  → 贲之坤。**辞末裹入校记者语**"此二句疑衍）"——右括号无左括号，为转录残留。
  §五 登记。

## 四、对勘与口径分歧

**无对勘本**：登记表 `crosscheck: []`。故本节无异文对照，只能登记**转录源内部的
口径分歧**（同一书源两段行式的差异）与**与本项目其他书源的对照**。

**书源内部的两段口径分歧**：

1. **行式两歧**（最要紧）：前段 L1-2340 为"卦之变"两行式（变卦名单行＋占辞单行，
   卦名与辞**分属两行**）；后段 L2341-5333 为"卦名＋辞"同行式（卦名与辞**同一行**，
   中隔两个全角空格）。转录源显然是**两批不同底本拼合**。凡机读 4096 条，
   须**按段分别写解析器**，不可用单一正则通吃。
2. **节标体例两歧**：前段用 `■■■此起为X卦■■■`／`■■■X卦终■■■` 包裹；后段**无任何
   `■` 包裹**（纯卦名行如 `　临　`）。部分后段节标**脱漏**（详见 §五）。
3. **标点密度不一**：前段占辞均长 21.4 字、后段 26.6 字；句读点密度后段更高
   （`四-四。四，四。` 型在两段均有，`四，四，四，四。` 型几乎只见于后段）。
   这使**前段偏简省、后段偏铺陈**的语感差异，可能是底本繁简或抄刻详略之别。

**与项目其他书源的口径对照**：

4. **与六爻《周易》卦爻辞（`core/yishu_core/hexagram_texts.py`）**：**无辞语交集**。
   本书是占辞，不引爻辞原句。二者共享的只有**卦名与卦画层**。故六爻引擎的
   爻辞判读**不能**拿来解释《易林》占辞。
5. **与梅花万物类象**：本书含大量**取象**（鵊鵴鸤鸠、铅刀、襦裤、重瞳四乳、
   河伯、瓠瓜），语汇层面与梅花类象**可对源**；但**机制不同**——梅花由卦起象、
   由此推事，《易林》由卦对**直查辞**。故比对可以做，**并轨不可做**。
6. **与灵棋经（`lingqi`）**：灵棋经 124 课是"课名→课辞"的查表体系，与本书
   "卦对→占辞"同属查辞型，**是本书将来扩科时最可参照的样本**（同为无起卦法的
   查辞架构）。

  **叙事候选／超出骨架**。
