## 二、逐卷（章）深读

### 卷一·通论赋（L116-317）：太微赋为核心判据

本卷为全书理论纲领，诸赋以律诗/骈句总括安星要义、格局判据与占验口诀。

**太微赋**（L116-165）：源L118：`斗數至玄至微，理旨難明，雖設問於百篇之中，猶有言而未盡，至如星之分野，各有所屬，壽夭賢愚，富貴貧賤，不可一概論議。` → 开篇明义——斗数至玄，星曜各有分野（十二垣），寿夭/贤愚/富贵/贫贱不可一概论。源L119：`其星分布一十二垣，數定乎三十六位，入廟為奇，失度為虛，大抵以身命為福德之本，加以根源為窮通之資。` → 核心判据：**十二宫分布 + 三十六星位 + 入庙/失度 + 身命为福德本 = 穷通资**。

**例曰段**（L126-165）：源L128：`祿逢沖破，吉處藏凶。馬遇空亡，終身奔走。` → "禄存被冲破则吉中藏凶；天马遇空则终身奔波"——**禄马互勘判据**，为格局成立之必要条件。源L131：`日月最嫌反背，祿馬最喜交馳。` → 日月反背（太阳夜生、太阴日生）为凶、禄马交驰（同宫或对照）为喜；项目 `data/verdicts.json` 已落地此条。源L135：`輔弼夾帝為上品，桃花犯主為至淫。` → 格局红线：左辅右弼夹紫微（命宫三方四正）= 上品格局；贪狼与紫微同垣且见桃花星（天姚/咸池）= "至淫"——此条虽道德语气浓烈，按铁律三转述必须软化为"结构上偏向"/"有…信号"；与内核符号不冲突。

**增补太微赋**（L281-317）：源L283：`前後兩凶神為兩鄰，加會尚可撐持，同室與謀最難堤防。` → 凶星三方影响尚可，同宫最难防——"三方/同宫"权重判据。源L285：`劫空親戚無常，權祿行藏靡定。` → 劫空入命主亲缘无常；与 SKILL.md 内 SKILL.md 引用"天空地劫"呼应。

**诸星问答论（37 问）**（L319-~L470+）：逐星作答，每问含"答曰+希夷先生曰+歌曰"三段。项目 21 星已入库（紫微/天机/太阳/武曲/天同/廉贞/天府/太阴/贪狼/巨门/天相/天梁/七杀/破军/文昌/文曲/左辅/右弼/禄存/擎羊/陀罗）；**天魁/天钺/天马/火星/铃星/地劫/地空/天刑/天姚/天哭/天虚/龙池/凤阁/三台/八座/台辅/封诰等副星仍待采集**（见 OPT）。

**紫微所主**（L321-354）：源L323：`紫微屬土，乃中天之尊星為帝座，主掌造化樞機，人生主宰。仗五行育萬物，以人命為之立定數。` → 紫微立"帝座"义。源L328：`無輔弼同行則為孤君，雖美玉不足。` → 格局判据：**紫微无左右为"孤君"**——这是 SKILL.md 引"佐帝为相"的具体判据。歌曰"紫微原屬土，官祿宮主星，有相為有用，無相為孤君"（L345-346）同义。

**贪狼所主**（L415-418）：源L417：`貪狼北斗解厄之神，第一星也。屬水，化氣為桃花，為標準，乃主禍福之神。` → 贪狼化气为桃花，主祸福。源L417：`會破軍迷花戀酒而喪命，同祿存可吉。遇耗因以虛花，遇廉貞也不潔，見七殺或配以遭刑。` → 贪狼组合忌：破军+贪狼（桃花劫）、廉贞+贪狼（不洁）、七杀+贪狼（遭刑）。

**形性赋**（L168-201）：源L170：`原夫紫微帝座，生為厚重之容。天府尊星，也作純和之體。` → 性情判据：紫微厚重、天府纯和——项目不做性格推断，此登记为 nature 候选，非机械推演。源L178：`俊雅文昌眉清目秀，磊落文曲口舌便佞，在廟定生異痣，失陷必有斑痕。` → 星性入形貌，形性判据用于星性 text 引文。

## 五、不适用与存疑

**不适用理由**：

1. **赋语句为象数解读**：太微/形性/星垣诸赋为律诗骈句,含大量"寿夭/贤愚/富贵/贫贱/淫奔/破败"等道德与命运断语——按铁律三,项目只做机械排盘+格局骨架,不输出任何"命定"结论。此层内容由 narrate 在转述时"结构上偏向/有…信号"化用,**绝不能入库判据层**。
2. **小儿篇/女命篇不适于通用排盘**："论小儿命""女命骨髓赋""论男女命同异"含小儿夭折断（如"二五岁必然夭折"）及女命"刑夫克子"等道德断语,项目冒用为绝命断言属凶象,只做登记不予输出——铁律三"凶象用偏向/信号,不用注定/绝无"。小儿篇另涉"小儿七岁前不与大限"的特殊论断规则(卷三L82),与通用大限排法不同,项目暂不实现小儿独立通道。
3. **形貌判据非机械推演**：形性赋含"紫微肥满""天府精神""擎羊身体遭伤"等形貌占验,属相科范畴(项目范围外),登记存疑。

**存疑/版本伪托**：

- L114 罗洪先序"时陈子去希夷公,一十八代,讳道号'了然',年方二十有六"——疑为建构陈氏世系以自羽翼的托名叙事；嘉靖本系明代士子借陈摶以立言,视为"明中期辑纂本"是稳妥口径。
- 目录"卷一/卷二/卷三"维基文库互见"同一页面全部显示"与"分卷显示"并存,个别 L63/77 目录标记分卷号为"2/3",但正文分卷不显;引用时一律以"源L<行号>"为准,不分卷。
