## 二、逐卷（章）深读

### 卷一·象数易理篇之一（L159-233）：先天起卦法总纲

本篇是全书机械内核：先天八卦数、五行生克、卦气旺衰、干支归属四张基础表，加"卦以八除、爻以六除"两条取余规则与互卦立例，再铺开十来种起卦入口（年月日时、物数、声音、字数、丈尺、为人、自己、动物、静物）。全篇无一句吉凶断语，纯是可代码化的算法描述，与 `disciplines/meihua/scripts/chart.py` 的对应度是八科中最高的。

核心判据：

- 先天卦数（乾一兑二…坤八），全书的数→卦映射根基。源L163：`干，一；兑，二；离，三；震，四；巽，五；坎，六；艮，七；坤，八。` → 以数起卦即按此序取余数定经卦。现状映射：`core/yishu_core/symbols.py` 八卦序 + `disciplines/meihua/scripts/chart.py` `_trigram_from_number`，且 chart.py 自检即用观梅占数字（5,12,17,9）断言得革、初爻动、体兑用离、互乾巽、变咸——与源L251 完全同构。
- 八卦象例口诀。源L178：`干三连，坤六断，震仰盂，艮覆碗，离中虚，坎中满，兑上缺，巽下断。` → 爻形记忆诀，canonical 爻序在此。现状：core 卦表为真值源，本诀属注释层。
- 卦以八除。源L188：`凡起卦不问数多少，即以此数作卦数，过八数即以八数递除。` → 除八取余，余尽作坤；引擎 `_normalize` 余 0 归 8，同构。
- 爻以六除，并明"加时"入动爻。源L190：`若一爻动，则看此一爻，是阳爻则变阴爻，阴爻则变阳爻。取爻当以时加之。` → 动爻=（年月日时总数）除六取余；阳变阴、阴变阳即变卦立法定义。
- 互卦起例。源L192：`互卦以重卦去了初爻及第六爻，以中间四爻分作两卦，看得何卦。` → 二三四为下互、三四五为上互；`chart.py` `interacting_trigrams` 同构。但下一句特例"又云：乾坤无互，互其变卦。"（源L193：`又云：乾坤无互，互其变卦。`）引擎未实现（乾坤互仍得本卦，书义当取变卦之互），见 §六 OPT-01。
- 年月日时起卦（观梅数本法门）。源L195：`年月日为上卦。年月日加时总数为下卦。又以年月日时总数取爻。` → 子年一数至亥十二数、正月一数至十二月、初一一数至三十日、子时一至亥时十二；引擎 `way=datetime/lunar/numbers` 三入口覆盖（lunar 即"观梅占原文式输入"）。
- 物数占。源L197：`凡见有可数之物，即以此数起作上卦，以时数配作下卦。即以卦数并时数总除六取动爻。` → 引擎 `way=two_numbers` 同构。
- 字占以平仄声调为数（四字以上）。源L206：`平声为一数，上声为二数，去声为三数，入声为四数。` → 引擎无对应 way，未实现（见 OPT-03）。
- 丈尺/尺寸占。源L215：`丈尺之物，以丈数为上卦，尺数为下卦。合丈尺之数取爻。寸数不用。` → two_numbers 可表达（丈/尺作两数），未单列。
- 为人占列八种入口（语声/人品/诸身/诸物/服色/外物/年月日时/书写来意）。源L219：`凡为人占，其例不一。或听语声起卦，或观其人品，或取诸身，或取诸物，或因其服色，触其外物，或以年月日时，或以书写来意。` → 人品/服色/外物入卦实为外应起卦，引擎 `way=manual` 可承接卦名，但"触外物即取卦"无自动化。
- 占动物占静物的"动机"门槛。源L231：`凡占群物之动，不可起卦。如见一物，则就以此物为上卦，物来之方位为下卦。` → 物+方位+时，即后天端法雏形。静物同理：源L233：`若观梅，则见雀争枝坠地而占。牡丹，则见有问而占。茂树，则枝枯自坠而后占也。` → "不动不占"的入口约束。

### 卷一·象数易理篇之二（L235-293）：后天端法与九大占验卦例

本篇前半给出后天端法定义与八卦万物属类速查表，中段是全书最著名的九则占验（观梅、牡丹、邻夜扣门、今日动静、西林寺额、老人忧色、少年喜色、牛哀鸣、鸡悲鸣、枯枝坠地），每则从起卦数到体用互变到克应期完整走一遍推演链；末尾补风觉鸟占与听声音/形物/验色三占。

核心判据：

- 后天端法定义。源L237：`后天端法：以物为上卦，方位为下卦，合物卦之数与方卦之数加时数以取动爻。` → 物卦数+方卦数（均按先天数）+时数取爻；引擎 `way=two_numbers`（上数=物数、下数=方数、hour_num=时数）或 `way=manual`（直接给上下卦）可表达，同构。
- 观梅占推演链（先天数起卦的范本）。源L251：`辰年五数，十二月十二数，十七日十七数，共三十四数，除四八三十二，余二，属兑，为上卦` → 34÷8 余 2 得兑上卦；加申时 9 数共 43，43÷8 余 3 得离下卦；43÷6 余 1 初爻动，泽火革变咸，互见乾巽。断语以体用生克展开：源L252：`右兑金为体，离火克之。互中巽木，复三起离火，则克体之卦气盛。` → 兑金体受离火克、互巽木生离火助克，故伤；变艮土生兑金，故"不至凶危"。引擎 analyze 的因子链（体用关系→互变生克计数→卦气→综合）即此文的机械展开。
- 牡丹占（端法之外的纯数占）。断语：源L255：`巽木为体，干金克之，互卦又见重干，克体之卦多矣，卦中无生意，固知牡丹必为践毁。` → "卦中无生意"=克体之卦计数压倒生体之卦，与 analyze `_synthesize` 的生体/克体计数修正同构。
- 邻夜扣门借物占（声音数起卦+"推数须明理"总纲）。源L257：`以一声属干为上卦，以五声属巽为下卦` → 一声乾、五声巽，加酉时十数，得姤四爻动；断金短木长为斧。更重要的是方法论：源L258：`推数又须明理，为卜占之切要也。推数不推理，是不得也。` → 数断之外须以事理裁决（夕晚安用锄），这是书内对"纯机械输出"的自我设限，narrate 段落翻译时应保留此精神。
- 今日动静如何（平仄声调占）。源L260：`「今」平声，一数；「日」入声，四数；「动」去声，三数，共八数，得坤为上卦。` → 平1上2去3入4 计数起卦（未实现，OPT-03）。其断语示范互卦用法：源L261：`卦中兑为口，坤为腹，为口腹之事，故知有人相请。` → 类象合成断"有人相请"。
- 西林寺牌额占（字画数起卦+卦断遗论"不拘体用"之源）。以"西"7 画艮上、"林"8 画坤下，得剥三爻动，"寺者纯阳之所居，今卦得重阴之爻，而又有群阴剥阳之兆"。末句归位先天：源L266：`以上并是先得数，以数起卦，所谓先天之数也。` → 此卷二卦断遗论据此立"不拘体用"特断，引擎 `verdicts.json#hexagram_special` 收剥·3爻动一条，原文按铁律二不入库（`disciplines/meihua/references/classics.md` §三有明确取舍记录）。
- 老人有忧色占（端法+数应迟速刻期）。源L268：`以老人属干为上卦，巽方为下卦，是天风姤；又以干一巽五之数，加卯时四数，总十数，除六得四为动爻` → 老人属乾（人品起卦）、巽方（方位）为下卦，正是后天端法活例；引《易》"包无鱼，起凶"参断。刻期规则：源L269：`坐则事应迟，当倍其成卦之数而定之也。立则半迟半速，止以成卦之数定之可也。` → 行取半、立取全、坐卧加倍——`analyze.py` `_numerical_timing` 与此逐字同构（行半/立全/坐倍）。
- 少年有喜色占：艮上离下得贲六五动，"互变俱生"加易辞吉而断聘币。源L271：`断曰：子于十七日内必有聘币之喜。至期，果然定亲。` → 易辞、体用、互变三轨合参的范例。
- 先天/后天两组卦例的总结句。源L281：`以上诸占例，并是先得卦，以卦起数，所谓后天之数也。` → 与 L266 对读：先得数者为先天（观梅、牡丹、西林），先得卦者为后天（老人、少年、牛、鸡、枯枝）——这是《先天后天论》分轨的事实基础。
- 风觉/鸟占/听声音/形物/验色：外应入卦四则。源L285：`凡见风起而欲占之，便是风从何方而来，以之起卦。` → 风方起卦；鸟占数只数/看方所/听声音；听声音辨物声属卦：源L289：`声自口出者属兑。而静物扣击属震，鼓拍槌敲、板木之声是也；金声属干，锺馨钲铎之声是也` → 声源→卦的映射表；形物占：源L291：`物之圆者属干，刚者属兑，方者属坤，柔者属巽，仰者属震，覆者属艮` → 形→卦映射；验色占：源L293：`凡占色之青者属震，红紫赤者属离，黄色者属坤，白色属兑，黑色属坎之类是也。` → 色→五行映射。四者皆"外应→卦/五行"查表，可数据化，引擎均未实现（OPT-04 的数据基础）。

### 卷二·体用生克篇之一（L553-591）：心易玄机与体用总诀——全书断卦总纲

本篇是《梅花易数》的理论核心：先立"心易占卜玄机"（占贵变通），再给占卜总决（四步：爻辞→体用→克应→己身动静）、占卜论理诀（数外论理）、先天后天论（两套起卦与断法分轨）、卦断遗论（不拘体用的反例集）、八卦心易体用诀（体用诀的传承自述），最后以体用总诀收束，并附逐卦"生体/克体"吉凶清单。

核心判据：

- 变通总纲。源L556：`占卜之道，要变通。得变通之道者，在乎心易之妙耳！` → 同类卦兆不可刻舟求剑（今日观梅得革断女子折花，异日再得革未必）。
- 占卜总决四步。第一步看爻辞：源L558：`大抵占卜之法，成卦之后先看《周易》爻辞，以断吉凶。` → 注意：这是总决第一步，而引擎 analyze 未挂《周易》爻辞判语（core 有卦辞爻辞真值源可取），见 OPT-02。第二步体用生克：源L559：`体为主，用为事。应用生及比和，则吉；体生用及克体，则不吉。` → 体用总纲；引擎 `_relation_of` 五关系判定同构。第三步克应、第四步己身动静（行速坐迟）——引擎分别对应外应（未实现）与 motion 数应（已实现）。

- 三要十应体用不可分。源L725：`体用不可无三要，十应不可无体用。` → 合参不可拆。
- 衰旺论总则。源L727：`大抵体之卦宜旺，生体之卦气亦宜旺。克体之卦气宜衰。` → 与 L705 呼应。
- 内外论收束句。源L729：`占卜之精者，无非合内外之道也。` → 全书合参方法论的一句话总结。
- 动静之机（"不动不占"的原理化）。源L731：`不动不占，不因事不占。` → 与观梅占"不动不占"呼应；坐迟行速在此重申。

- 静占（无外应时的降级规则）。源L735：`凡占在静室，无所闻见，则无外卦，即不论外卦。但以全卦年月日值五行衰旺之气，以体用决之。` → 引擎现状（无外应输入）相当于恒按静占口径运行——现状诚实，但应把"外应空缺"显式化（OPT-04）。

诸卦反对性情以歌诀述六十四卦性情（"干刚坤柔反其义…"，即《杂卦》的展开）；占物类例以爻辞断物（干初爻"潜龙勿用"→不可用之物等）；物数为体诀（凡卦多者皆可为体、互卦决物之数目）；观物看变爻为主；观物克应法（成卦之际所见即所断之物兆）；观物趣时诀（四时得卦断物性）；观物用易例（笼盛物/锺覆物两例示范爻辞+互卦断物）；万物戏验（猜手中物的类象总集）。

核心判据：

- 爻辞断物（观物类例总则）。源L936：`凡看物数，看其成卦，观其爻辞。如得干，曰「潜龙勿用」，乃曰不可用之物；` → 以动爻爻辞语义直接映射物性——这是"后天用爻辞"在占物分支的落地，依赖 core 爻辞真值源（OPT-02 的应用面）。
- 互卦决物数。源L938：`互见干、兑，决为一二之数。互见艮、坤，为七八之数也。` → 互卦先天数→物之数目；"物乘旺，物数多，衰而物少"。未实现。
- 趣时断物。源L947：`以春得震、离为花，夏得震为有声之物，秋得兑为毁折成器之物，冬得坤为无用土物也。` → 月令×卦的物性矩阵，与卦气旺衰同源（旺季之卦为"有用成器之物"：源L952：`凡占物，以春震巽、夏离、秋干兑、冬坎皆当以为可用之物，成器之物。`）→ 可由现有卦气旺衰直接推得，属低成本增量判据。

### 卷三·断占总诀篇之四（L954-1019）：占卜十应诀、论事十大应、卦应

本篇把卷二篇四的十应再系统化：先总述十应（正应/互应/变应/方应/日应/刻应/外应/天时应/地理应/人事应——注意总述句列了九应，漏举方应，而下方分节 L957-977 实有十节，方应自成一条），再逐应立义，末附"论事十大应"（一行/二立/三坐…十怒，江湖切口式判语，文义残缺）与"卦应"（八卦广类象，dz 本大幅缩略）。

核心判据：

- 十应总述。源L956：`有正应、互应、变应、日应、刻应、外应、天时应、地理应、人事应、所谓十应也。` → 正/互/变三应即卦内三重，日应引入占日卦气：源L966：`日应者，以体卦为主，看所占属何卦，及体卦与本日衰旺如何。` → 体卦五行×占日地支五行的旺衰——引擎月令旺衰即此理的月尺度版，日尺度未做。
- 外应取卦。源L970：`如见老人、马、金玉圆物，得干。见老妇、牛、土瓦物，得坤之类。` → 外物→卦映射表（与万物属类同源），OPT-04 的数据基础。
- 天时之应。源L973：`天时之应，占卜之际，晴明为离，雨雪为坎，风为巽，雷为震。` → 当下天气→卦，与体卦论生克。
- 人事之应。源L977：`老人为干，老妇为坤，少男为艮，少女为兑。` → 人品→卦。
- 十应合参的收束。源L978：`如占病症，互变中俱有克体之卦，而本卦中又无生体之卦者，断不吉也。` → 内卦判定为基，再"看诸应有生体者，险中有救"——先内后外的合参次序，可直接作为 OPT-04 的合参算法骨架。

## 四、对勘与口径分歧

**抽样对勘结果**（主源=殆知阁简体本，对勘本=维基文库繁体本；对勘统计见 `data/sources/crosscheck_report.json`，containment_primary 0.9323 / secondary 0.9852，verdict 高度一致）：

2. **牡丹占**：主源 L254-255 与对勘本 L214-216 一致（25→余1乾上、29→余5巽下、29÷6余5五爻动、姤变鼎、互见重乾）。对勘本原文：源wikiL214：`以巳年六數，三月三數，十六日十六數，總得二十五數，除三八二十四數，餘一數為乾，為上卦`
3. **邻夜扣门借物占 / 今日动静如何 / 西林寺牌额占**：主源 L257-265 与对勘本对应段一致，连两本共有的讹字（"以乎分"）也一致，说明是共同祖本的缺陷而非殆知阁转录引入。
4. **老人有忧色占**：主源 L268 与对勘本 L238 一致，包括"谓老人虫"讹字与"行则应速，中分取半"刻期规则。对勘本原文：源wikiL238：`巽木為體，乾金克之，互卦又見重乾，俱是克體，並無生氣`

**实质差异（主源与对勘本文本不同处）**：

- **序"先天/后天"一字之讹**：主源序作"以数起卦，故曰后天"（源L3：`以数起卦，故曰后天。`），与本句上文"凡此，皆所谓先天之数也"自相矛盾；对勘本同句作"以數起卦，故曰先天"（源wikiL7：`以數起卦，故曰先天。`）。判：对勘本义长，主源"后"为"先"之形讹。影响：仅序文叙事，不影响任何算法判据，但录文引用时须辨。
- **卦应节结构性缩略**：主源卷三篇四《卦应》仅 L990-1019 约 30 行（乾卦详载天文/天气/凶盗/官贵/身体/性情/声音/信音/事意/疾病/附药十一目，坤至兑仅存《说卦传》原文一行）；对勘本同节（L1109 起）约 414 行，八卦逐卦广载。殆知阁转录本在此节大幅缩略。影响：若将来扩 `bagua_analogies` 取《卦应》语料，必须以维基文库本为准，不能用主源。

**与其他书的口径分歧**：

- **多爻动**：本书本法是"爻以六除"单爻动（源L190），两爻及以上动是后世通行扩展。`disciplines/meihua/data/verdicts.json#multi_move_rules` 已显式声明这是扩展口径并引卷二"生体多者则愈吉"作合参依据，口径诚实，无冒名。
- **先天/后天与《易》辞**：本书主张先天止以卦论、后天用爻辞兼卦辞（源L565），且总决第一步即看爻辞（源L558）——引擎现行判语只走体用生克单轨，未挂《周易》爻辞，与书有一轨之差（OPT-02）。这与六爻科"装卦用纳甲、断卦重用神"的口径完全不同：梅花无六亲六神、不用旬空月破，引书源判据时不可与六爻混同。
- **卦气旺衰**：本书"震巽木旺于春…坤艮土旺于辰戌丑未月"（源L170）与通行月建旺相休囚说同构，且书只分旺/衰两档（源L172），不做休囚死细分；引擎 analyze 现按旺/相/衰处理、lunar 路径按节气定月，与本书"月令定卦气"同源，无分歧。
- **刻期双轨并存**：卦气干支应期（源L842）与卦数应期（"巽五日而坤八日"，源L846；"全卦之成数"刻屋毁之年，源L782）在书中并存且未调和；引擎实现的是前者，引用后者时须注明另一轨。
- **十应总述漏举方应**：源L956 总述列九应，分节（正/互/变/方/日/刻/外/天时/地理/人事）实为十应；对勘本同有方应节（其 L1056），属祖本之误，引用时以分节为准。

## 五、不适用与存疑

**OCR/转录缺陷登记**（引文均为主源原样拷贝；标注"两本同讹"者为共同祖本缺陷，非殆知阁独有）：

2. 源L260：`以乎分「今日动」三字为上卦` —— "乎"为"平"之讹（两本同讹）。
3. 源L268：`谓老人虫：` —— "虫"为"曰"之讹（两本同讹：对勘本 L238 作"謂老人蟲"）。
4. 源L300：`震：竹木、青碧绿色、龙、蛇、` —— 此行"蛇、"后径接"苇"，脱"萑"字（两本此段同脱；主源卷一·篇二 L241 作"萑苇"不误，可互证）。
5. 源L301：`山木之禽鸟、、香` —— 双顿号处脱一字（两本同脱，脱字无考）。
6. 源L764：`牝难司晨鸣咿啼` —— "难"当为"鸡"（对勘本 L1492 同作"牝難"，两本同源讹）。
7. 源L1007：`为＄足、为作足、为的颡` —— "＄"为"馵"之乱码（两本同；主源卷一·篇二 L241 作"馵足"不误）。
8. 源L1015-1016：艮卦《说卦》行"为／坚多节"断作两行，系转录断行，非原文换行。
9. 源L289：`锺馨钲铎之声是也` —— "馨"当为"磬"（形近讹，照录不改）。
10. 源L271 前后"逐占之/逐与客曰"之"逐"均为"遂"之讹，两本同例，通篇如此，不再逐条登记。

**不适用（不进引擎判据库）**：

- **论事十大应**（L979-989）："一行/二立/三坐…十怒"配断语，是江湖切口式联想，文义多处不通（如"问官事，属木，旺木有文书"），无算法结构可提取，存目不采。
- **观物洞玄歌**（L738-778）：宅气观察歌（"门前墙壁缺，家道中渐歇"之类），属望气宅相一路。按 AGENTS.md"相科（面相、手相、堪舆）明确不做"，其法不取；其中个别句与卦占相关者（如雀噪远行至）已由三要十应覆盖。
- **疾病占鬼神说**（L641-643）：书自言"信鬼神之说，虽非《易》道"；祟煞断语按 AGENTS.md 铁律三不进判语，涉医疗的报告必须提示专业意见。
- **拆字之应与叶音**（L678-681）："人傍木为休""见鹿可以问禄"属字形谐音联想，主观性强，不可机械化，不采。
- **性别/身份断语**（"阴人之祸""寡妇之家"等）：时代语境语，引擎只应输出结构信号（兑/坤、重阴），不作性别身份断言——口径改造而非数据改动。

**存疑（不改文、不改判据，记录待考）**：

- **变卦式八则**（L799-815）文本残缺错简：如源L799：`泽火革 体金，互巽木变泽山咸` 与下文"离卦初爻，阳动变阴，变艮卦兑金"（L800）文气不属，八则体例参差。可提取的总则仅一条：源L801：`体用于变爻，作动静取之。动者为用，静者为体。` —— 动者为用、静者为体，正是 verdicts#body_use_general 的口径。八则原文逐字入库有难度，建议只收 L801 总则（现状已收）。
- **"观梅恒卦"之"恒"**：源L821：`例如观梅恒卦，互兑、干，兑为体，互见女子折花。` —— 观梅所得为泽火革非恒，"恒"字疑衍；且革卦互为乾巽，此处"互兑、干"亦与卦不合（对勘本 L857 同文同疑）。该段"体互用之分"的义理可取（兑体取兑互不取乾互），文本不可作逐字判据。
- **"全卦成数"口径未详**：屋宅占断"二十九年者，全卦之成数也"（L782），水风井（6+5=11）与变升（5+5?）如何凑出二十九，书未给出换算式；万物赋"巽五日而坤八日"（L846）又是单卦数刻期。两处刻期口径均存疑，实现前须先考据（OPT-06 只建议立实验通道，不直接进判据）。
- **"乾坤无互，互其变卦"**（L193）按字面是"乾坤互卦仍为本卦，故取变卦之互"，但"变卦之互"取变前还是变后、上下互如何对应，书无例证，实现前需考据确认（OPT-01 建议先立口径再动代码）。
