## 二、逐卷（章）深读

### 卷之一（行 L177-981）——章法基础：装卦、用神、生克旺衰、空破冲合

本卷从点卦装卦教起（八卦章、卦象图、八宫、浑天甲子、六亲歌、世应、动变七章为入门），核心是用神章第八、元神忌神仇神章第九、元神忌神衰旺章第十确立"用神—元神—忌神—仇神"四元分析框架，随后逐章铺开生克（五行相生相克、克处逢生、动静生克、动变生克）、旺衰（四时旺相、月将、日辰）、六神、六合六冲、三刑、暗动、动散、卦变生克墓绝、反伏、旬空、生旺墓绝，末以"各门类题头总注／应期总注"两章给出全书通用的术语表与应期法则，游魂归魂殿后。术语随文白话：**用神**即所占之事所系之爻（占父母取父母爻等）；**元神**生用神之神；**忌神**克用神之神；**仇神**克元神而生忌神之神；**月破**月建所冲之爻；**旬空**旬内无此支；**暗动**静爻旺相被日辰冲。

  - 源L2358：`官父兴隆，文章见用。凡得旺父持世、官动生之，或官星持世、父爻旺动，或官星父爻旺动、生合世爻，或日月作官星、父母生合世，皆主成名之象。` → 功名域四吉构。
  - 源L2378：`凡得子孙持世发动，终非朝廊之贵客。` ＋ 源L2386：`此子孙克官之征验也。` → 子孙克官在功名域的一票否决（野鹤以"皓首无成"例证）。
  - 源L2387：`世静而临旬空月破，官逢月破自空，皆主不得成名。惟世与官星空破而动者，勿以此断。` → 空破而动有救。
- 寿元章（L2396-2431）：
  - 源L2397：`凡占寿元，独以世爻为根本，世爻或旺相、或临日月、或得日月生扶及动爻生扶、或动而化生化旺化回头生者，乃大寿之征也。` → 寿元单核世爻；同段斥"初爻管五年二爻管五年"分段法为"欺人之法，余不为之"（L2405）。
  - 源L2414：`占他事宜元神动者，动则而有力也，占寿元不宜发动，动则已有限期矣，非元神逢绝墓之年，即在元神被冲克之岁。` → 占寿元元神反宜静（动即限期）；L2423 对称：`忌神不动，自是平安，动则已有限期矣。`
- 趋避章（L2432-2543）：
  - 源L2433：`若占得死于水者，莫近河旁，死于刑者，不可违条犯法，未有不化凶而为吉。` → 趋吉避凶可行性总纲（康节临终典作结）。
  - 源L2442：`凡占防患克世者，皆不为吉，独鬼爻克世更凶，火鬼须防火炎，木鬼须防木窖，水鬼克世沉溺之忧，土鬼伤身岩樯之厄，金鬼剑刀斧锹。` → 五行鬼克世取象表；L2443 再以六神/八卦细化（玄武盗贼兵戈、蛇雀官非火厄、勾陈牢狱等）。
  - 源L2498：`克神若在内卦，动而克世，宜出外避之，克神若在外卦，动而克世，宜在家避之。` → 方位避法核心判据（内克宜出、外克宜居）。
  - 源L2516：`凡避兵、避盗、避瘟、养病、避是非、皆宜避于生世之方及子孙为吉。` → 避方＝生世之方/子孙之方；L2532 以火鬼得令生世例驳"子孙属水即北方吉"的死方位。
- 父母寿元、兄弟、夫妇、子嗣（L2544-2674）：
  - 源L2562：`若以古法，阳为父，阴为母，前卦丑戌两现，俱以旺而断者，如天远矣。` → 驳"阳爻为父阴爻为母"，父母各依父母爻分占分断。
  - 源L2610：`占妻财爻为重，应爻次之，财爻旺相，应爻空破，仍以吉断，应爻旺相，财爻空破，即以凶推，应旺财旺，吉而又吉，应破财破，凶而更凶，故以应爻为附和也。` → 夫妇章驳黄金策"应为百岁之妻"：应爻降为附和位，财爻为妻之正用。
  - 源L2644：`福德即子孙爻，若旺遇生扶，或临日月，或帝旺长生于日，或动而化吉，必产贤儿。` → 子嗣域子孙旺衰断；L2654 财化子辨正庶、L2655 子化子辨本宫他宫（`须宜分别化出他宫者，立异姓之子；化出本宫，立族中子。`）。
  - 源L2664：`父占子，止知易养，难断高贵` → 父占子限域声明（占贵须另占），同段斥"禄贵临爻童年拜相"为"信笔妄谈"。
  - 源L2673：`代占六亲，不宜世爻化鬼。占父母、兄弟、妻妾、儿孙，先看世爻，虽占六亲，常有带出自身之凶者` → 代占时世爻化鬼先忧自身。
- 学业、治经、延师、求名至功名品级（L2675-2998）：
  - 源L2741：`父与世爻旺相及得日月动爻生扶及动而化吉，全无破绽者，定考超等。` → 岁科考等第判据（父/世两爻旺衰＋破绽多少列等第）。
  - 源L2774：`所喜者卦中财爻同兴，喜其兄动以制财也。卦中父官两动者，又喜兄爻持世，父动以生世也。` → 兄弟爻在科名域的"有喜有忌"两面性（驳"兄弟乃夺标之恶客"的死断）。
  - 源L2775：`官星父母世爻有一而被动爻克制，或化回头克，若得日月冲制克神，亦许得意，故谓制恶煞将军。` → "日月为制煞之将军"：日月冲制克神即救。
  - 源L2785：`功名无成者不是子孙持世，即是子孙财爻发动，或是世爻破空，或是六爻乱动，功名必无成。` → 科名四凶构清单。
  - 源L2829：`子孙持世，子孙动于卦中，升迁无期。` ＋ 源L2842：`子孙持世值旬空，亦不当升。若占两三日之内者，许之必得，其故何也？子孙尚未出空不克官也。` → 近事空亡窗口效应（三日之内子孙未出空不克官）——高频短应期的细节判据。
  - 源L2851：`古以随官入墓，助鬼伤身，皆以为凶。余屡试之，世旺者竞升，世衰者不吉。` → 随官入墓/助鬼伤身在升迁域的旺衰反转（呼应随鬼入墓章）。
  - 源L2982：`占法：水一火二木三金四土五，官临火者，官居二品，官星属水，一品之尊。` → 功名品级五行数古法被斥（野鹤问"水至二数位至公侯者，何以定之"），立"指占法"（我能公侯否/我能将相否，逐问逐断）。
- 求财章第六十八（L3009-3051）：
  - 源L3011：`公私占卜皆以财为用神，子孙者乃生助财爻之元神也，俱宜旺而化吉，又宜生合世爻，公私皆得如意。` → 求财双核（财＋子）与世爻生合。
  - 源L3012：`兄动生子，故谓之有望。财爻兄爻子孙爻俱动于卦中者，更为可喜，其故何也？兄动生子，子动生财，其利甚厚且有久远源流长之利益也。` → "有福无财兄弟交重偏有望"的条件化：兄动须生子。
  - 源L3015：`父动克福神，兄动克财爻，此二爻动于卦中，凡有所图，水中捞月。` → 父兄爻动的求财凶构。
  - 源L3024：`卦中财临日月，谓之重叠，若许求谋得意之时，须待财爻入墓之日。` → 财太过待墓库（呼应千金赋"用爻重叠喜墓库以收藏"）。
  - 源L3044：`旧注凡遇财爻生世合世克世持世，皆谓之财来就我，若卦中虽有财爻，不来生合世爻亦非我之财也。` ＋ 源L3045 野鹤补充：`总要断卦之灵机应变，彻悟其理，自然触类旁通，不可拘执。`（其前 L3035-3043 兄持世两卦亦得财之例）。

### 卷之四（行 L3054-3696）——商旅财货、婚产、出行行人、讼病医药、宅墓

本卷为最细分的问题域汇编：谒贵/开店/囤货/借贷/六畜/博戏（求财系）、婚姻/胎孕/产期（婚产系）、出行/舟行/行人（旅占系）、防讼/争竞/重罪（讼系）、疾病/痘疹/病源/鬼神/延医/医卜（病系）、家宅/盖造/迁居/修方/马房（宅系）、寻地/形势/点穴/祖茔/修补（墓系）。每章极短，判据高度模板化："某爻旺相宜X／空破不宜X／动而化凶更忌"。

- 求财系：
  - 源L3059：`见贵有两间也，为名者用官，为利者用财，皆宜持世及生合世爻为吉，如逢空破，墓绝及动而变凶者，徒劳奔驰之力耳。` → 谒贵双用神分域（为名用官/为利用财）。
  - 源L3077：`应生世，他益于我。世生应，我益于他。相克相冲而情有变，应爻克世，我被他瞒；世克应爻，他从我愿` → 开店章世应生克直读表（应兼表伙计与顾客，"须在来人之念"决定）。
  - 源L3087：`财衰宜囤，财旺宜脱；如春天占得财爻属木，谓之旺，宜速发卖` → 囤货卖货的四时旺衰决策；L3097：`财化进神不可收积，化退者，其价将落，有货速宜出脱。` 进退神在商占的应用；L3099 应期链：`财爻太旺旺者得利于墓库之月，休囚者出脱于生旺之时，入墓必待冲开，逢绝当逢生旺，月破者填实之，被克者冲去克神之秋，伏藏者得价于出现之时，旬空者冲空实空之月`。
  - 源L3144：`世逢兄，何须开口，应空破，难遂我心，财若空破，休指望。` → 借贷章三忌。
  - 源L3179：`觉子曰：古以青龙财爻为吉，余以此非营生之本，乃丧心之事也。` → 行险求财章：非礼非义之事"不告于神"，全书伦理边界（与博戏章对照：博戏有技力可占）。
- 婚产系：
  - 源L3181：`男家占女，不拘父母亲朋而代占者，无不以财为用。女家占男，皆以官为用。` → 婚姻章取用总纲；L3182 细则：`男家代占女，专以财为用神，以应爻为女家，财宜旺相动而化吉，应爻不宜空破又克世爻`。同章驳"财动丧双亲"（翁姑不睦）旧说（L3181）：`余曰：分占之法也。先要财官旺相，既得吉卦，再占妨克父母，是其法也。`
  - 源L3200：`动而空者实空之月日必成，静而空者终不成也。` → 婚期空亡动静分断；L3203：`兄爻持世，若得财爻动来相合，此婚必成。世兄爻化出财爻，此婚亦能成。` 兄持世的可救条件。
  - 源L3204：`女占男不宜子孙持世发动，子孙乃伤夫之神，未成者不成，已成者伤夫再嫁。` ＋ L3214：`爻逢六合占婚最宜，更要财官旺相为吉，男忌财逢破墓，女防官位克绝，六冲变六合者更吉，眼下不允，日后必成。` → 婚占忌神与卦象组合。
  - 源L3265：`坐草临盆嫌鬼动，胎前产后忌兄摇。财临绝破妻难保，鬼化妻财命不牢。` → 问产妇安否四句诀（财为用、鬼动忧、兄动损财、互化凶）；L3263 男女辨：`六爻静，先看卦包阴包阳……六爻既静若无包，须看子孙值阳为男，值阴为女`，动爻优先：`卦有动爻虽有子包而不用，神兆机于动，先看动爻。`
  - 源L3277：`子孙动者逢合逢值，静者逢值逢冲，空者冲空实空之日，破者实破逢合之期。` → 产期应期表。
- 旅占系：
  - 源L3281：`世为出行人，生旺有气则吉，动而化吉，及化子孙者更吉。如若休囚空破，动而化凶者不宜行也。应为地头，又为傍倚人` → 出行章世应分工（应兼地头与同行）。
  - 源L3283：`六冲卦及动而变冲，世爻休囚被克者，终去不成，有始无终` ＋ `倘两间齐空，若非中途梗阻，定然无伴孤行。` → 出行凶构与间爻象。
  - 源L3287：`出行得子孙发动，子孙持世、世化子孙，程途万里，百祸潜消，子孙克世者亦吉。` → "克去身边之鬼"在出行域的正面表述（与千金赋 L1565 同源）。
  - 源L3298：`世克用兮人未动，用爻克世必然归` → 行人归期速断诀；同章：`用神墓绝空破受伤，谓之有病。`（有病问平安、无病断归期，两问分断）。
- 讼系：
  - 源L3358：`子孙动子孙持世必不成非，鬼持世鬼克世应动克世定然成讼。` → 防非避讼两句诀。
  - 源L3360：`应克世者他胜，世克应者我赢，世空破世动化退我心怯焉，应动应旺化进神他得势耳，卦遇六冲必散，卦逢六合必成` → 斗殴争竞胜负判据链。
  - 源L3364：`子孙持世子孙发动已到法场终必赦免。` → 已定重罪章（"福宜旺相最忌官兴"，子孙制官为赦免结构）。
- 病系（疾病章 L3365-3413、痘疹、病源、鬼神、延医 L3404-3413、医卜往治 L3414-3492）：
  - 源L3366：`余试多年或生或死，全凭用神，余皆不验` → 疾病章总纲：驳以卦名（明夷大过观贲蛊夬丰同人等"断之必死"）、星煞六神断生死。
  - 源L3367：`久病者，卦逢六冲，卦变六冲，不论用神之衰旺，乃不治之疾也，近病逢之，不药而愈。` → 近病久病×六冲四象限（唯一"不论用神"的特例域）；卦变回头克者近病亦危。
  - 源L3368：`觉子曰：余得验者，近病值旬空，若逢三合六合者必成久病而终。` → 近病逢空的例外（合主缠绵）。
  - 源L3380：`自占病，官鬼持世，其病难痊，虽得子动克去身边之鬼，目下虽愈，终不断根` → 官鬼＝忧神/病灶象；代占则官鬼持世只主忧疑（L3388：`若占父母之灾，官鬼为父母之元神，岂宜子动而伤耶？`——用神域反转提示）。
  - 源L3389：`代占六亲之病不必看用神之衰旺，即知其安。何也？子孙乃喜悦之神，只要旺相，若动於卦中者亦为吉庆。` → 子孙＝解忧神（代占病吉凶的简化判据）。
  - 源L3406：`自占代占，鬼虽忧疑之神也，若持世及动于卦中，得子孙动而制之，此医可请，手到成功。若得子孙临应爻者乃明医也` → 延医章：应为医人、子孙为药效，"子孙制鬼"决定医可延。
  - 源L3407：`应爻空破墓绝休囚衰弱，或旺相而被日月动爻冲克，或动而化鬼化绝化回头克，药不见效。` → 医人（应爻）凶构。
  - 源L3411：`子占父宜父爻旺相，占药占医又以子孙为用神，父旺以伤子也，一爻不能两用。` → 占药与占病用神分离（一卦两用之禁）；L3465 觉子注推广：凡卜药"皆以子孙为用神，但得子孙持世，子孙发动，服之立可解忧"。
- 宅墓系（家宅 L3493-3605、墓葬 L3606-3694）：
  - 源L3494：`以卦中之父母爻为屋，又以父母爻为双亲，既为二亲，又以五爻为父，四爻为母，如此悖谬糊涂，尚有刊传为法，余实不解。` → 家宅章总纲：斥爻位六亲分配（初井二灶三床四门等，L3605 李我平汇考诸书异同），立"指其所疑而占之"（L3537：`所以指其所疑之处而占之，无不响应`）。
  - 源L3560：`子孙持世，或动于卦中，或官鬼不动，及六爻安宁，非此处也。` ＋ 源L3561：`官鬼持世克世，官鬼动爻，实因此处有害` → 旧宅"何方有碍"的排查判据（子孙安则非、官鬼动则是）。
  - 源L3578：`鬼临白虎，必有伏尸。鬼临元武，水怪山魑。蛇主虫蛇为妖。雀是官非火盗。` → 崇象六神分类；其后按地支/宫位细列（亥子投河、辰戌丑未墙倒、寅卯悬梁、巳午火伤、申酉刀剑等）。
  - 源L3609：`古以二爻为穴，内卦为穴，腾蛇为穴，屡试不验，所验者，世为穴也` → 寻地章：世爻为穴（又一次"以占验废古法"）。
  - 源L3610：`卦逢六合或世与子孙爻作六合，乃藏风吉穴，代代兴隆。若得六冲卦，或六冲变六冲，或世应相冲，冲者散也，必无气耳。` → 风水吉凶的合冲判据；L3611 六冲变六合"吉地失而复得"等变体。
  - 源L3639：`世爻当令又长生帝旺于日辰，来龙远大。` → 占地形势章的六爻山水分配（世=穴/应=对山/两间=明堂/左右山/朱雀前山/玄武后脉/上爻水口/腾蛇道路）。
  - 源L3649：`世为用神，静者逢冲逢值，动者逢值逢合，世空者冲实之秋，世破者填实之候` → 卜得地于何时的应期表。
  - 源L3673：`先有心地而后得遇阳地` → 谋地偷葬章伦理判（损人利己之事不告于神，与行险求财章同）。
  - 源L3684：`子孙持世，子孙动摇，修之则吉。` → 再占修补吉凶章判据；新亡附葬章（L3686）同构："惟喜世及六亲不逢变克，随卦静六合，必得存亡之安"。

## 四、对勘与口径分歧

**与对勘本（`data/sources/zengshan_buyi.wikitext.txt`，维基文库繁体排版本）的抽样差异**（对勘报告 `data/sources/crosscheck_report.json`：containment 0.7889，判定"基本一致"；差异多为简繁、标点、用字三级）：

1. **"余／予"用字**：主源通篇野鹤自称作"余"（如源L991`野鹤曰：余得其验`），对勘本同处作"予"（wikitext L249`野鶴曰﹕予得其驗`）。全书高频差异，逐字对拍工具须归一化后比对，采信引文以主源为准（铁律：引文逐字可指回主源）。
2. **原神／元神混用**：源L1022（午月癸卯日占后遇功名卦例）`卜书有曰：虽有如无，作原神而无用`，对勘本同处（wikitext L291）作"作元神而無用"。主源另有多处"原神"（源L438 末"谓之元神"处无混；源L1619`原神动于卦中`、源L1725`原神若被伤克者`等），与"元神"并存。引擎术语统一为"元神"，凡引擎采引涉"原神"行文时须换写并登记。
3. **疑似脱字**：源L1033 飞伏神章`则于宫首卦寻之`，对勘本同处（wikitext L309）作"則本宮首卦尋之"——主源疑脱"本"字。同章主源L1040"须在宫首卦，乾为天卦内寻之"不脱，故为孤例讹脱。
4. **标点差异**：源L1006 断曰`今即前卦动官相生`，对勘本（wikitext L269）作"今卽前卦動。官相生"（多一句读，语义略异）；不影响判据本体。
5. **结构缺漏（对勘本侧）**：对勘本卷之一自暗动章第二十二起诸章为子页面转嵌（wikitext L216-233 `{{/22}}`…`{{/26又4}}`），序亦转嵌（L10 `{{/序}}`），单文件内无正文——这解释了 containment 0.79 而非 1.0 的主因；卷之二起（月破章）起正文完整可对勘。对勘方向上：主源卷一无对勘文，卷二至卷四对勘一致性高（本轮抽六处全数命中）。

**与《卜筮正宗》的口径分歧**（本仓库另存其书源，规则注册表多条引之）：

- **卦身**：《卜筮正宗》有安月卦身诀（`rule_registry.json` 条目 liuyao.guashen 所引），本书明断"卦身亦不验，亦用世爻"（源L951、L1457、L2821 觉子以卦身说验例反证其谬）。两书并存于注册表，引擎输出卦身结构标签时应声明"本书判不验"。
- **反吟伏吟**：注册表 liuyao.fanyin_fuyin 引《卜筮正宗》反吟伏吟章；本书反伏章（L859-889）口径基本一致（反复不宁、用神旺相则事可成），但李我平按（源L889）明确批评《易林补遗》"不看用神之衰旺竟以反吟为畏途"，并以两卦例立"反伏须兼用神衰旺"。
- **随官入墓**：注册表 liuyao.muku 引《卜筮正宗》随官入墓歌诀（凶象五情形）；本书同章（L1296-1343）大幅修正——删世身/本命随墓、旺相非真、墓破非真、入墓反主"沉滞昏迷"近理（源L1322：`古法以墓为沉滞昏迷之象，此说近理`）。两书非矛盾而是详略，引擎应以本书条件为强校验。见 OPT-02。

**与《易冒》的口径分歧**（本书转引批驳，未单存书源）：

- 冲散：动散章李我平按（源L852）`黄金策以空亡为重，冲散为轻。易冒最重冲散，细阅占验多因错课。`——野鹤实测"旺相者冲之不散"（源L844）。

## 五、不适用与存疑

5. 家宅以爻位配六亲（五爻为父四爻为母、初井二灶三床四门）斥为悖谬（源L3494、L3605）——不适用；宅占须"指其所疑而占之"。

7. 功名品级五行数法（水一火二）野鹤自承无法定品级，改指占法（源L2982）——不适用。
8. 行险求财、谋地偷葬、强夺婚遂私约"非祥非义，勿告于神"（源L3179、L3250、L3673）——不适用且应作叙事层拒答依据。
