## 一、书目与版本

**作者与成书**：题署"唐 徐道符"，实为明人托名辑录（书首 L2 `奇门源流 唐 徐道符`）。《御定奇门宝鉴》是奇门遁甲的**集大成式汇编**——它把遁甲源流、总论、凡例、四十四则释义、《烟波钓叟歌》注释、《遁甲隐公歌》、《汉阴居士歌》、《神机赋》《指迷赋摘》《专征赋摘》，最后加一部《混合百神》（六仪加十干的格局断语表），合为一编。

**编纂立场**：本书最有价值的一点是**它自己声明了编纂原则**——不是断语汇编，而是"取其生克制伏，近于理者"。源L53： `至于书符诵咒，似属不经，槩不录入。` 即祝由、符咒一类不作采；同时对三氏（李氏／林氏／陶氏）奇门的门户分歧逐条判别是非，这在同类书中罕见。

**版本形态**：单文件、无显式卷目，以篇名分段（篇目前有总目 L5-L14，与正文标题 L17/L43/L56/L81… 逐一对应，可机械对齐）。已知缺陷：① 篇目"释义四十四则"实存 43 则（`grep -c '【释'` = 43，另有一条作 `【辨三氏奇门】` L141）——第 44 则或缺或并入他则；② 《混合百神》条目排列有脱讹（L931 `六辛加卒` 卒应为癸；L877/L879/L881 三条作"六丁**交**辛／交壬／交癸"，与通例"加"不一致）；③ 末条 L973 自注"此句独不叶韵"，为编者自标的疑文。

**对勘本**：无。本篇不设对源，差异登记见 §四（改为"书内三氏口径分歧"与"与现有八科底层口径"两条线）。

## 二、逐卷（章）深读

### 奇门源流与遁甲总论（L17-53）——"尊甲"世界观与编纂原则

首篇考源流，自黄帝经吕望、张良，隋志十三家、唐益倍之，至宋《符应经》亡佚、明代李氏／林氏／陶氏三家分立，末以都天撼龙经九篇考其源。核心命题是**遁甲以兵为设**：源L47： `遁甲为兵而设，兵为阴象，为诡道，故取诸遁。` 由此推出全书的**总纲"尊甲"**——源L49： `甲为至尊之神，宜藏而不宜露，宜和而不宜乘，宜生扶而不宜克制。` 甲喜土（戊随之）、憎金（乙合庚以伺内、丙丁制外）；这条总纲是后面 81 条格局吉凶的**唯一推演公理**。

术语随文解释：**尊甲**＝以甲为至尊而设局；**甲奇配戌（戊随之）**＝六仪为甲之党羽；**三奇为甲之腹心**（源L129：`六甲统仪不统奇者，仪为庚之党羽，奇为甲之腹心也。`）；**戴九履一**＝洛书宫数。

### 释义四十四则（L81-335）——奇门的"辞书"部，也是本书最可机械化的一段

这一篇是全书的术语总纲，把奇门专用名物逐个落地，且大多**给出了可判的规则**而非仅给名字：

- **八门方位与五行**：源L95： `有开必有阖，故对开为杜门。` 开休生为三白（吉），杜景死为三黑，受伤惊为二凶——门吉凶三分是全书判据的地基。
- **九星立义**：源L99： `蓬任冲辅英芮柱心禽，其立义皆本于甲。` 星名与节气绑定（冬至蓬、立春任、春分冲、立夏辅、夏至英、立秋芮、秋分柱、立冬心、中五禽），此即九星＝八节之象。
- **八神及其职司**：源L107： `八神者；天乙、螣蛇、太阴、六合、朱雀、白虎、九地、九天也。` 各有所司——扬兵九天、安营九地、伏兵太阴、匿形六合、间谍朱雀、侦探白虎、惊扰螣蛇；兵占以天乙所在坐击其冲。
- **符头与元局**：源L135： `甲子、己卯、甲午、己酉四日为符头。` 以甲己二干加仲为上元首——这是奇门**置闰／超接**争论的根，也是本书与李氏奇门最大的口径分歧点（见 §四）。
- **直符直使**：源L139： `直符常以加时干，直使逆顺时支去。` 符＝代甲直用者（星），使＝甲巡行之使（门）——**符以时干起、使随时支逆顺**，是排盘算法的骨架。
- **旺衰气应（关键机械化判据）**：源L265： `皆以我生之月为旺，我同之月为相，我克之月为休，克我之月为囚，生我之月为废。` 九星以此论旺相休囚废；八门另有"旺绝胎没死囚休废"环列。此条是奇门版的旺衰表，与命科 `symbols.wangxiangxiuqiusi` 的五行旺相口径**同源不同用**（奇门以九星／八门为主体，命科以日干为主）。
- **时干克日干为五不遇时**：源L185： `五不遇时者；时干克日干也。` 顺数七干名"七杀"、逆数五干名"五不遇"，与六壬"七杀／不入"同构。
- **门迫／宫迫**：源L181： `吉门被迫，吉事成凶。凶门被迫，凶灾愈甚。` 门制其宫为迫；L551 更细分为"宫制其门曰门迫。门制其宫曰宫迫"，并给出开门临三四宫、休门临九宫等**逐门逐宫穷举表**。
- **三奇得使／三奇游六仪／玉女守门**：源L167： `三奇得使者，谓得三吉门、直使加奇也。` 三格本是奇门最常引的吉格，本书却对流行口径逐条纠偏（见 §四）。
- **反吟伏吟**：源L203： `伏吟者；伏匿不能变动而呻吟也。` 星门各加本宫为伏吟、加对冲为反吟——纯几何规则，可完全机械化。
- **六仪击刑**：源L193： `甲子戊仪加三宫，甲戌己仪加二宫，甲申庚仪加八宫，甲午辛仪加九宫` ——甲子戊加三宫、甲戌己加二宫、甲申庚加八宫、甲午辛加九宫、甲辰壬／甲寅癸加四宫，是**干支→宫位硬映射表**。
- **格名（勃／格／刑／破／奇格）辨正**：源L281： `庚加癸为刑，丙加己为刑，盗气同也。` L277/275 明确"勃者乱逆也，格者闭塞也"，并驳"浑言岁月日时干互相加临为飞伏"之说。
- **二吉四凶**：源L285： `丁甲相加，为阴阳化气。丁乙相加，为龙凤呈祥。` 丁甲＝化气、丁乙＝龙凤呈祥为二吉；甲乙二龙战野、庚辛二虎争雄、甲戊青龙困顿、庚壬白虎迍邅为四凶。
- **日干门户神名（可直接查表）**：源L291： `甲为天辅青龙，乙为天德蓬星，丙为明堂天威，丁为太阴玉女` ——甲天辅青龙、乙天德蓬星、丙明堂天威、丁太阴玉女、戊天武天门、己地户六合、庚天狱天伐、辛天庭天尉、壬天牢天廪、癸天藏华盖。
- **直辰（十二建除）**：源L241： `直辰者；建、除、满、平、定、执、破、危、成、收、开、闭也。` 与择吉 core 的 `JIAN_CHU_ORDER` 完全同序——**这是本书与现有择吉科共用底层的确证**。
- **战关背向七条**：源L317： `第一宜背太岁大将军。` 加背月建、背孤击虚、背游都击鲁都、背天雄击地雌、背生神击死神、背干游击干鲁。其中"甲己日：游在丑、鲁在未"一类是干日→方位硬映射。

### 注释烟波钓叟歌（L337-557）——从歌诀到可执行规则的转换层

此篇把《烟波钓叟歌》逐句翻成规则，是奇门**由术入法的转换层**：

- 九宫先天数与纵横十五：源L343： `九宫者：一坎、二坤、三震、四巽、五中、六干、七兑、八艮、九离，乃先天之数，纵横数之，皆十五也。`
- 三元与顺逆：源L347 阳遁顺（五日一换）、源L371： `阳遁顺仪奇逆布，阴遁逆仪奇顺行。` ——六仪顺、三奇逆（阳）／六仪逆、三奇顺（阴），是布盘第一动作。
- 超神接气与置闰：源L349： `五日都来换一元，超神接气为准的。二至之前有闰奇，此时叠节累乘之。` 源L351 给出可判阈值： `超不过十，接不过五。若符头先到七日，便当作闰。` 这三条是**元局起算的量化规则**，可直接写成函数。
- 太冲天马：源L403： `太冲天马最为贵，卒然有难宜逃避。` 天马＝房日兔，以月将加月建视太冲所临之方。
- 三门四户与地私门：源L399： `六合太阴太常君，三辰元是地私门。` 太冲／小吉／从魁为天三门，除危定开为地四户——皆以月将加正时求方。
- 白入荧／荧入白：源L469： `白入荧兮贼即来，荧入白兮贼即灭。` 庚加丙（金入火乡）／丙加庚（火入金乡），结构上是"失物／盗来"的领域信号标签。
- 两大吉格：源L513： `丙加甲兮鸟跌穴格，甲加丙兮龙返首。` L519 释"鸟跌穴龙返首二局，万事大吉"，且**不须另加奇门**——吉格层独立于奇门层。

### 遁甲隐公歌·汉阴居士歌（L561-777）——歌诀注与三元次第总论

《遁甲隐公歌》逐句下注，把六仪六甲的职分讲全：源L577： `二遁三元当周局，顺逆三奇与六仪。` 六仪各有个职分（天门戊、地户己、天狱庚、天庭辛、天牢壬、天网癸），并各宜忌（如源L649： `六庚之时杀气横，若当攻击祸先逢` ——结构上庚时于用兵有凶象信号，宜安禁狱）。《汉阴居士歌》（L777）是长歌合韵，把**三元次第与正受／超接**讲成体系，其末"认取兹为尊甲法，勿胶拆补缪搜求"是全书方法论的收束——**明确站古法（符头为本、节气为用）立场，反对李氏拆补**。

### 神机赋·指迷赋摘·专征赋摘（L781-801）——三赋速查

三赋是给已经会排盘的人用的"翻牌"文本。源L793 指迷赋给出最短的生克总纲： `星克宫而客利，宫克星而主胜。` ——**星宫生克定主客胜负**（与六爻"克出为克"同一底层，但判的是"客／主"而非六亲）。源L801 专征赋给出分兵法： `分兵三部、一居月建上、一居生辰上、一居亭亭方上、用之克敌大胜。` 源L785 神机赋把格名串成一句总纲： `按格所向既凶，百事营为不喜。` 即**凡遇格即减分**——先判格局层、再判奇门层，是本书判读的固定次序。

### 混合百神（L805-973）——81 条格局断语表，本书最"结构化"的一段

末篇把六甲、六仪、三奇共十干两两相加，按天盘干→地盘干的固定次序给出 81 条断语，每条形如"格局名；四句断语"，且**断语内自带条件分支**（星／门／奇／阴人阳人／主客／方向）。样例：源L811： `六甲加甲；青龙出地，喜信必来，门合则美，门塞星凶，空有财至。` 同类：六癸加癸（L971）作 `六癸加癸：天网高张，行旅失约，游去四方，合处相得，逆处相伤。`

这条篇的结构价值在于：它是**一张十干×十干的格局矩阵**，每格自带"吉／凶倾向＋成立条件"。其中"吉凶"多为 narrative 断语（"失财破家""人口死亡"），条件分支（门吉星顺／门逆星凶、阴人／阳人）却是结构化的——**条件可机械化、断语须留作 narrative**。

## 四、对勘与口径分歧

**无对勘本**，本篇的对勘改作两条线：书内三氏奇门的门户之争、与现有八科底层的一致性。

**（一）书内三氏口径分歧（本书亲自裁断）**——《辨三氏奇门》（L141-153）＋《释三奇游六仪》《释玉女守门》（L177）是本书最有价值的一节：它逐条判李氏／林氏／陶氏之非。

1. **李氏奇门（李成吾）**：源L143 `盖以接气为拆补，谓拆补宁多二三时，起超不可过九日，如过九日，即当置闰也。`——李氏**用节气定元、用拆补接气**。本书立场相反：源L145 `考古法以甲子、己卯、甲午、己酉为符头者，缘尊甲以制奇门，故立符以定元首也。是以符头为体，节气为用。` 即**符头为体、节气为用**，并斥李氏"用残局补合三元"是"下元返用于上元之先"，违尊甲之旨。
2. **林氏奇门（林士徵）**：源L147 `一林氏奇门，以周天三百六十五度四分度之一`——以周天度数为节候标准、二十年闰二十一候。本书斥其"三元次第不分，四仲符头无用"，语出 L149。
3. **陶氏奇门（陶仲文）**：创阴阳一百六十二图（飞掌加临）、禽芮同宫。本书判其"使九星可入中宫""颠倒星宫，殊违尊甲之旨"。
4. **三奇得使／游仪／守门的名实之争**：源L177 `若从三氏以游仪为得使，以守门为游仪，则于歌义大相戾矣。`——本书据《钓叟歌》文义定"得使"须**吉门直使加奇**且遇直符之甲（与 L167 一致），"游六仪"与"玉女守门"另立二格。
5. **三奇得使遇甲的时刻表**：本书逐一排出（阳一／三／五／七局与阴二／四／六／九局各几见），与三氏"三时／七时"说不同。

**本项目以哪本为准**：本书以**古法（符头为本／尊甲）为准**。理由：① 本书自设凡例，明言"不敢私心去取"，但对三氏逐条给了**可核的理由**（符头体用不合、三元次第乱、飞掌非古法），非仅罗列；② 本书是三氏的直接批评者，立场自洽；③ 机械上"符头＝甲己加仲"（L135）可确定性计算，而陶氏一百六十二图与林氏闰候需额外参数表。本篇不作实现，故只登记口径：**将来扩科时采古法（本书）为主口径，李／林／陶三说作可选开关**。

## 五、不适用与存疑

**一、本书不在现行八科范围，价值在为将来扩奇门科留底。** 奇门遁甲（none-qimen）不在六爻／梅花／八字／大六壬／择吉／紫微／灵棋经／小六壬之列，本项目无对应学科。因此：

- 本篇**不主张**把奇门判据塞进任何现有八科引擎。奇门的排盘对象（九宫／八门／九星／奇仪／符使）与六爻的六亲卦爻、大六壬的三传四课、择吉的方事类别**均不同构**，硬塞会污染既有结构层。
- 本篇**不主张**把本书的吉凶断语（如"失财破家""人口死亡"）当作任何引擎的结构层输出。它们是 narrative 候选，且多为兵占语境（用兵、埋伏、逃亡），与民用八字／择吉场景不同。
- 唯一可安全共享的是 §四（二）表中的**底层共用项**（干支、节气、十二建除、天乙贵人、旺衰五行），且已入 core，无需改动。

**二、书源自陈的取舍（不适用登记）**：

1. **祝由符咒不录**：源L53 `至于书符诵咒，似属不经，槩不录入。` 本书主动排除符咒一路。项目若将来扩科，**照此不采**——本项目一律不实现咒法／符法，此为书源与项目口径一致处，登记为"确认不适用"而非缺口。
2. **兵事避忌随岁月太阳查算、书中未预载**：源L64 `旺气所在，亦宜避之。所谓春不东伐，秋不西征者是也。` 自认"亭亭白奸、三门四户、天马方之类，须从岁月太阳查筭，书中未能预载"——即本书**自承 incompleteness**，某些神煞算法须求诸他书（历法与择吉类书）。

**三、存疑／脱字登记（机械采信前须复核）**：

1. **"释义四十四则"实存 43 则**（`grep -c '【释'` = 43；另有一条作 L141 `【辨三氏奇门】`）。第四十四则或脱页、或并入他则，未敢补。
2. **《止宿闭戊》则内容为空**：源L309 `皆同` ——L307 标题 `【释止宿闭戊】` 下仅此二字，实为残缺，本篇未敢据他本补。
3. **《混合百神》脱讹**：L931 `六辛加卒` 卒应为癸；L877/L879/L881 三条作"六丁**交**辛／交壬／交癸"，与通例"加"不一致。81 条矩阵按天盘干→地盘干应有 90 格位，现存 88 条，**缺 2 格**（己加辛/己加壬类位置须逐条核）。采信前须逐条校。
4. **末条自标疑文**：L973 `此句独不叶韵` ——编者自注，说明该句文本有异文。
5. **字形讹**：源L39 `【天芮汉书作内、天蓬唐书作逢。】` 存"天芮／天内""天蓬／天逢"的古今字异；L407 作 `三为生炁` （炁＝气）；这两类是通用形讹，非脱字。
6. **未读懂／无法机械化**：① 《混合百神》四句断语中的文学取象（如"春草秋叶落"类意象）不可作判据；② 《专征赋》"孤雄健旺属他，奇门又不相比"的比喻；③ 运筹／闭戊（L297-L305）的**物理画地成局法**——书源明载以刀画地、取土成堆，属仪轨操作而非历法推算，无数字化路径。
