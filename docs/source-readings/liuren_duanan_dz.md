## 一、书目与版本

《六壬断案》是宋·邵彦和（字叔原，浙江太末人，生于宋英宗治平二年乙巳、殁于高宗绍兴三年癸丑）的占验课例集，源L5 自述「据其自占动静一数而推之」。全书体例为**编号课例＋课体标签＋占断＋先生析曰**四段：每则先记干支起课（如「戊申年正月辛卯日子将未时」）、旬空落空，再列一串课体名，随后是占断（分事：宅/婚/讼/病/仕宦/求财等），最后由「先生析曰」逐层拆解取象。

## 二、逐卷（章）深读

### 序：撰者与占例性质（源L3–L5）

开篇即坐实本书性质——**自占课例实录**，而非理论著作。这一点决定了它的引擎价值：不是提供规则，而是提供**规则的实际取值分布与断语措辞样本**。

- 撰者小传，源L5：`邵彦和先生，宋人也。据其自占动静一数而推之，生于英宗治平二年乙巳，殁于高宗绍兴三年癸丑，似浙江之太末人。` → 自述"自占动静一数而推之"，即**己身起课、依课体占断**，是课例集的自我定位。现状：叙述层，不入引擎。

### 课体取象与发用规则之辨（源L75、源L198 等学者按语）

本书最有价值处不在断语，而在**辨正**：多位学者按语明确指出"取用"与"课体"是两个层级，不可混为一谈。这直接关系引擎该在哪一层落规则。

- 取用不重复，源L75：`凡传用，若干支阴阳已先据其位，只以不备推测，不可重复取用。` → 明确**发用（传用）只在无克处取一次**，已得则不再重取；余者以"不备"论之。这是九宗门「元首/不备」层级的书源表述，对应 `kemu.json` 的取用判定。
- 课体与取用分层，源L198：`此课利宅不利人，若占病讼，真闭口卦也。` → 同一课体因占事不同而吉凶反转（利宅不利人），是"课体为结构、吉凶随占事"的直接证据。现状：引擎须保持课体为结构标签、吉凶分离（铁律三）。

### 占宅类课例群（源L38–L230，节选）

占宅是本书最大课例群（宅基、宅居、移徙）。结构判据集中于**人宅关系**（以日为人、辰为宅）、**空亡**（合支上空亡则宅不可得）、**初传脱气**等。

- 人宅取象，源L105：`大凡占求宅基，以日为人，辰为宅，须看支辰，合支上空亡，是宅不可得而图也。` → 「日为人、辰为宅」是宅占的固定取象；「合支上空亡→宅不可得」是机械结构条件（支与宅相合而落空则事不成），属可判定的结构标签。
- 墓神迟滞，源L198：`日上墓作天后，主迟滞，时运未通。` → 墓＋迟滞神（天后）为结构性迟滞标签；吉凶措辞（"主迟滞"）属叙事层，按铁律三转"结构上偏向迟滞"。

### 疾病、讼事与命限类课例（源L19–L61、源L136 等）

分事占断覆盖疾病（占病多主饮食/翻胃/痈疽）、讼事（主是非牵连）、命限（以行年与墓库推寿）。命限类尤其体现"课传中旺气计数"的机械推法。

- 疾病取象，源L19：`此课，火伏于下，水升乎上，不拘占雪占雨，皆当日有。` → 课体（铸印）加火伏水升的取象，定"当日有雪"；这是**课体象＋天地象合成**的推断，属结构标签＋叙事解释两层。
- 命限推法，源L136：`此非先生意，乃及门诸子增入之辞也。` → 学者明确辨正"四四一十六年"系门人增入之辞，非邵公原意；反映课例传承中的增窜问题，是**案例使用须辨源**的实证（与铁律二相关）。

### 学者按语的辨正价值（贯穿全书）

全书中"邵先生曰""爱圅曰"等按语多处纠正前人占法误解，尤其涉及**间传、不备、遥克、六仪**等课体的取用边界。这类辨正对引擎规则的边界定义价值极高。

- 爱圅改字，源L201：`一作辛丑生，爱圅曰：古本作辛丑生，六十九岁二月二十四日卯时生。` → 学者校订生辰原文（爱圅即顾野王，校书者），说明课例文本存在异文，引用生辰须注明底本。现状：转录异文，登记于 §五。

## 四、对勘与口径分歧

**与《壬归》的口径异同**：本书与《壬归》同属**课体取象派**——两者都极少言"九宗门"发用规则（本书涉害仅 1 见、《壬归》全篇零见"月将"与九宗门门名），而以课体格局（三传结构格）取象为主。**层级不同**：九宗门是**发用规则**（定三传怎么取），课体格是**成象命名**（取定之后叫什么）。故本书与《壬归》的课体名（重审/励德/不备/斩关/间传…）应作为 `kemu.json` 各课体条的**第二书源**（继《六壬大全》之后），而非另立一表。

**与《六壬大全》的关系**：《六壬大全》是发用规则与九宗门的**唯一真值源**（起课层、月将、天将皆出大全）；本书提供课体取象的实际用例与断语措辞。两书互补不冲突：大全定规则，本书证规则的实际分布。

**与《六壬粹言》《六壬指南》的关系**：粹言讲体用格局理论、指南讲心印指掌，本书纯为课例集。本书的价值在**断语措辞样本**与**课体频次实证**，不提供新的规则体系。

**本批内无口径冲突。**

## 五、不适用与存疑

**不采内容及理由**：

1. **占断吉凶断语（主体，占全书绝大篇幅）**：如源L19 `占病遇之，十占九死` 类，以及各课例「主百事」「必主破耗」等断语，**属叙事候选/超出骨架**，一律不入结构层。理由：大六壬学科定位为机械结构标签（AGENTS.md），吉凶须按铁律三转措（结构上偏向…），且课例断语受时代价值观染（如"封侯拜相"），不可作机械判据。
2. **课例作为案例库**：216 则课例属古籍验案，按铁律二与交付过程物理隔离，仅可作 `data/cases/` 参考与事后校验，不作实时推理依据，不作对齐分调参。
3. **命限/寿数推断**：「四四一十六年」类推算（源L136）不仅属断语，且已被学者辨正为门人增窜之辞，绝不可作数据用。

**转录/异文登记**：

1. 源L201 `一作辛丑生，爱圅曰：古本作辛丑生，六十九岁二月二十四日卯时生。` ——生辰异文，底本两说并存；引用生辰须注明底本，不宜径取。
2. 源L136 `四四一十六年也` ——"一十六"为"十六"之衍；系门人增辞，已辨正，照录不据以改判。
3. 课例编号 01–216，编号与行号无固定对应，引用须以"N课"定位，勿以编号推行号。

**存疑**：

- 本书未言起课法（月将加时、天将乘临的推法），起课层仍须以《六壬大全》为唯一真值源；本书"昼贵/夜贵"仅见于占断语境（如课例首行的昼夜空亡），非贵人起法定义，不可作贵人表书源。
- 课体名有一名多义（如"不备"在本书常与发用相关，而《大全》体系下"不备"是九宗门之一课体），跨书引用须确认所指为"取用层"还是"课体层"。
