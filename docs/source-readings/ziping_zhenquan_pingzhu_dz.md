## 二、逐卷（章）深读

### 基础篇（一～七，L62-120）——干支阴阳／合化／刑冲

沈孝瞻开篇次序"先明干支阴阳→五行阴阳→生死→配合性情→合与不合→得时不旺失时不弱→刑冲会合"，从最基础知识逐步递进到格局分析。术语随文白话：**气＝甲＝生气流行于天；质＝乙＝形质凝聚于地**；**阳主聚以进为进故主顺；阴主散以退为退故主逆**——十二长生阳顺阴逆的原理。

核心判据：

- 源L63：`天地之间，一气而已。惟有动静，遂分阴阳。有老少，遂分四象。` → 开篇定论：天地一气→分阴阳→分四象→五行具于其中。
- 源L63：`水者，太阴也；火者，太阳也；木者，少阳也；金者，少阴也；土者，阴阳老少、木火金水冲气所结也。` → 五行与四象对应——十干取象的哲学基础。
- 源L79：`阳主聚，以进为进，故主顺；阴主散，以退为退，故主逆。` → 阳顺阴逆的哲学正当化。

### 格局核心篇（八～十五，L121-266）——用神／成败救应／相神／格局高低

本卷是全书核心分析框架：用神专求月令→用神变化→格局成败→成中有败／败中有成→格局高低在有情有力之间→相神为格局所赖之一字。术语：**用神**＝月令所透所会之字；**格局**＝月令地支与日干的生克关系所分（财官印食／煞伤劫刃）；**相神**＝辅用神之字（"若君之有相"）；**有情**＝顺而相成；**有力**＝旺而有根。

核心判据：

- 源L121：`八字用神，专求月令，以日干配月令地支，而生克不同，格局分焉。财官印食，此用神之善而顺用之者也；煞伤劫刃，用神之不善而逆用之者也。当顺而顺，当逆而逆，配合得宜，皆为贵格。` → 格局分析第一总纲：四吉神顺用＋四凶神逆用。
- 源L123：`取用之法不一，约略归纳，可分为下列五种：` → 取用五法总起——源L124-128分述扶抑／病药／调候／专旺／通关。engine evaluate.py 的用神分类框架源。
- 源L191：`论命惟以月令用神为主，然亦须配气候而互参之。譬如英雄豪杰，生得其时，自然事半功倍；遭时不顺，虽有奇才，成功不易。` → 用神配气候得失：月令用神为主、气候调候为辅。
- 源L209：`月令既得用神，则别位亦必有相，若君之有相，辅者是也。如官逢财生，则官为用，财为相` → 相神紧要：格局赖辅"相神"一字而成。
- 源L265：`八字格局，专以月令配四柱，至于星辰好歹，既不能为生克之用，又何以操成败之权？` → 星辰无关格局：神煞不能操格局成败。

### 行运篇（廿五～廿八，L267-369）——行运成格变格／喜忌干支有别

本卷论"运"——以运之干配命中干支统观喜忌；以运评定格局成立／破坏／变化。术语：**成格**＝运来成全不全之格；**变格**＝运来改变原有格局；**透清**＝支中藏干逢运透出。

核心判据：

- 源L299：`看命以四柱干支，配月令之喜忌，而取运则又以运之干，配八字之喜忌。故运中每运行一字，即必以此一字，配命中干支而统观之` → 行运原则：岁运每字配命中干支统观。
- 源L325：`命之格局，成于八字，然配之以运，亦有成格变格之要权。其成格变格，较之喜忌祸福尤重。` → 行运成格变格的定位：比喜忌祸福尤重。
- 源L337：`命中喜忌，虽支干俱有，而干主天，动而有为，支主地，静以待用，且干主一而支藏多，为福为祸，安不得殊？` → 干支喜忌有别论。

### 卅一～四十八（L347-500+）——各格局细节＋取运

逐格给出"格局定义＋喜忌＋取运细则"。每格结构：①格局定义；②成格条件；③败格条件；④救应之道；⑤取运细则。术语随各格而异（正官格：官喜财印／忌伤煞）／（财格：财喜食伤／忌比劫）。

核心判据（以正官格为例）：

- 源L371：`官以克身，虽与七煞有别，终受彼制，何以切忌刑冲破害，尊之若是乎？岂知人生天地间` → 正官格喜忌立场：官乃"分所当尊"故忌刑冲破害。

## 附录：沈孝瞻格局分析七段式与 engine 实现对应

> 不属于六节验收范围。七段式：①用神专求月令 → ②用神变化 → ③格局成败 → ④因成得败因败得成＋救应 → ⑤格局高低（有情无情／有力无力） → ⑥相神紧要 → ⑦行运成格变格。engine pattern.py＋evaluate.py 整体架构与七段式一一对照（pattern.py 管①-⑥格局识别，evaluate.py 管⑦行运与喜忌评价）——此为 project 格局引擎的顶层设计来源。
