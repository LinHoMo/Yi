## 一、书目与版本

**题署**：《大六壬心镜》八卷，唐 徐道符（号不欲子，一作徐元道符）撰。
源L164：`计备格一百八十一篇，分为八卷，排门定类，条节昭然。` → 自序称一百八十一篇、八卷，
是本书的**课体总数权威自述**（项目课目表条数须与此对账，见 §六 OPT-01）。

**版本链**（本书最大的版本学价值）：
- 现行底本为清嘉庆间程树勋（伟堂）手录本，源L3：`兵占一门，全未集入。` → 郑天民校记明言
  兵占门在所据写本中全缺，后由程君据《六壬兵机三十占》补入，故卷八为后人补辑，非徐道符原书。
- 源L11：`实则《心镜》内杂占歌诀，不知何人手录而托名邵子焉。` → 另一支脉误题"邵康节撰"，
  是托名现象的实录。
- 书中"经云"为原注，"郇注"为清 郇应清注，"郑按／伟堂按"为校者按——**注家分层本身就是版本证据**。
- 三序（郑天民、张维桢、程树勋自识）俱在，行3~23，为版本流变的第一手材料。

**结构总貌**：卷一释课元微门（九宗门）+宗首九科门；卷二~卷三为课体门（淫泆/新孕/隐匿/乖别/十杂卦/凶否/吉泰）；
卷四杂神门（十二神）+杂将门（十二天将）+三宫时门；卷五~卷七为占验各门；卷八兵占门 + 今附四歌。
- 全书卷章清单：卷一（L172）释课元微门·宗首九科门／卷二（L270）新孕·隐匿·乖别·十杂卦／
  卷三（L412）凶否·吉泰／卷四（L514）杂神·杂将·三宫时／卷五（L818）占宅·修造·黄黑道·婚姻·产育·田蚕／

## 二、逐卷（章）深读

### 卷一·释课元微门（九宗门）与宗首九科门

九宗门是本书唯一与项目结构层完全对齐的部分。九门次序与《六壬大全》同，但**本书逐门给的是"条件＋歌诀"双层**：
条件层可落地，歌诀层是 narrative。

- **克贼**：源L178：`四课之中一克下，便是初传立用` → 一上克下即用；无下贼则取上克。
- **比用**：源L182：`择其比者作均分`；源L182：`阳日以阳神为比，阴日以阴神为比` → 多课相克时按阴阳同类比和取用。
  结构条件完整（引擎 `disciplines/liuren/data/verdicts.json#men.比用` 已入库）。
- **涉害**：源L186：`以其受克、克害日最深者用之。` → 俱比俱不比时按受克深浅取深者；
  "刚日以日上、柔日以辰上"为端点歧义（SKILL.md 已标 `verified=False`）。
- **遥克**：源L190 以"日遥克神名克，神遥克日名贼"分二名——**结构名分立，不涉吉凶**。
- **昴星**：源L194：`刚日仰视酉上神为用，柔日年从魁所临神为用` → 刚柔分端点，与大全口径同，歧义已登记。
- **别责**：源L198：`刚三柔六共九课` → **给出课数公式（刚 3 / 柔 6 / 共 9）**，是可直接机检的计数判据，
  《六壬大全》此处只有歌诀，本书更优。
- **伏吟**：源L206：`先刑后冲为传` → 自刑/刑冲的取用次序规则化。
- **返吟**：源L212：`六个阴柔何日是？丑未配于丁己辛` → **列出丁丑丁未己丑己未辛丑辛未六个日干支**，
  是纯枚举型结构条件，可作返吟井栏射的判定表。
- **八专**：源L216：`八专之课号芜淫丁未、癸丑、甲寅、己未、庚申，皆两课也` → 五个日干支枚举＋只有两课。

**宗首九科门**：源L220：`八局之列，分为九科。每科成一卦，是九科之宗首。此九卦外皆独类于枝叶也。详卦名义，六十四卦。`
→ 九卦为纲、其余归枝叶，总数六十四。本书九科门恰为九卦（元首/重审/知一/见机/蒿矢弹射/虎视/信任/无依/帷薄不修），
与引擎 `disciplines/liuren/scripts/jiuzongmen.py::MEN_ORDER` 的九门同名不同类（门类 vs 课体），
**须防同名混淆**（见 §四）。

### 卷二·新孕门／隐匿门／乖别门／十杂卦

- 新孕门元胎卦：源L276：`三传俱孟是元胎` → **"三传俱孟"是纯结构条件**（孟=寅申巳亥），
  项目可据此机械识别"三传同孟"课体。
- 乖别门末"始终卦"：源L376 一句给出三传相生/相克的结构分支（`三传相生，万事尽成。忽若相克，为鬼为贼`）——
  条件可采，判语为 narrative。
- 十杂卦中"润下卦"源L410：`立用传中申子辰，卦名润下水之因。` → 用传见申子辰三合即润下，
  与"曲直（亥卯未）／稼穑（辰戌丑未）／从革（巳酉丑）"同构：**三传三合局定课体**是一类可机械化的课体判据。
  注意这与 `data/kemu.json#rules` 的旬奇/日奇参数不是同一层，勿混。

### 卷三·凶否门／吉泰门（课体条件最密集的一卷）

本卷 24 卦几乎每卦都是"条件句＋断语"两段式，条件句密度全书最高：

- **九丑卦**：源L418：`乃乙卯、己卯、辛卯、乙酉、己酉、辛酉、戊子、壬子、戊午、壬午十日也`
  → 十个日干支枚举＋"遇大吉加在支辰上"，**纯条件**。（但正文自称"五干…十日"自相矛盾，见 §五。）
- **二烦卦**：源L422：`日宿者，月将是也` → 日宿即月将、月宿为太阴四正（十二宫月宿名目齐全），
  是**月宿查表法**；条件为"月宿加四仲"，结构可机械化，判语"主盗贼，不利出行"为 narrative。
- **天网卦**：条件"用起并时同克日"（庚辛日午时火克金之例），纯结构。
- **天狱卦**：四凶条件（用神死囚／仰见其丘／俯见仇／斗罡加日本），"日本"=今日生处。
- **天罗地网卦**：源L466：`日前一辰天罗杀，对冲名为地网神` → **"日前一辰"与"对冲"是两条机械定位规则**，
  无需天将即可判；断语"官灾病厄是其迍"为 narrative。
- **丧门卦**：源L458：`丧门正月未为之正月未，二月辰，三月丑，四月戌` → 十二月逐月支序，
  与《六壬大全》神煞总表同源，属**神煞名/序表**可复用为补遗（不是断语）。
- **三阴卦**：元白居日前为一阴／用终囚死又相克为二阴／占时克行年为三阴——**三条机械条件**，
  是本卷最适合落地的一条。

### 卷四·杂神门／杂将门／三宫时门

- **杂神门**：登明→河魁→从魁→传送→小吉→胜光→太乙→天罡→太冲→功曹→大吉→神后十二神，
  每神给"音／月将／人身部位／星宿／禽兽"五类属性。这些是**类神映射表**（占门取类用），
  机械层可复用为"类神字典"，但各门"主什么"仍是 narrative。
- **杂将门·贵人旦暮**：源L640：`甲戊庚日量用大吉丑作贵人，墓用小吉未作贵人。`
  → **昼用丑暮用未**；乙己昼子暮申、丙丁昼亥暮酉、辛昼午暮寅、壬癸昼巳暮卯。
  与项目 `core/yishu_core/liuren_tables.py` 的 `NOBLE_DAY`／`NOBLE_NIGHT` 同口径，
  本书另给出"每以星落地盘宫位顺逆行之"的分宿法，可作 `noble_of` 的交叉校验源。
- **十二天将发用日干来意诀**（源L752 为标题行，源L754 为诀文）：逐将发用所主，
  条件为"某将发用＋某类神"，断语全为 narrative。
- **杂将门驳异说**：源L750 驳"青龙吉将、白虎凶神"一刀切口诀，以青龙折角、白虎登山、
  太常子上、勾陈巳上为反例——**方法论上强调"同将随所乘之地而异"**，
  这条对项目很有价值：提醒结构层报"天将乘临"时必须连同所乘神一起报，不可只报将名。
- **三宫时门**：源L792：`三宫时门三首，此三宫进，视课传神将吉凶之意而再用此详之`；
  绛宫时条件源L796：`登明加四仲，名绛宫时`；明堂时源L800：`神后加仲为明堂时`；
  玉堂时源L804：`大吉加四仲，名玉堂时`。三条判定条件皆为"某神加某位"，**结构条件极干净**。

### 卷五·占宅／修造／黄黑道／婚姻／产育／田蚕

- **占宅**：以月将加家长行年、视宅神上得何神——"月将加时＋行年"是标准起课骨架。
- **黄黑道门**：源L854：`正七月以天罡加子，二八月以天罡加寅，三九月以天罡加辰`
  → **黄道方起法为"天罡加月建"十二 month 表**，逐月可查；
  源L858：`天罡黄道建青龙辰下为青龙` → 黄道六神青龙/明堂/金匮/天德/玉堂/司命各定位；
  源L866：`以上六神名黑道，修宅犯之人祸殃。` → 黑道六神定位表（午未戌子丑卯）。
  这三张表是**择吉类方位结构表**，归属上更近 `zeji` 科，但**结构部分（六神＋方位）可复用**，
  断语部分（宜修造/主狱/主口舌）一律 narrative。
- **婚姻门**：源L884 以"日为夫、辰为妇"配天后神后，条件为日辰上神刑克破害，判语为成/不成——条件可采。
- **产育门**：源L930 以"四孟月用功曹、四仲月用神后、四季月用天罡加月建上"定产妇方位，
  丙下月德、壬下月空，**方位查表法**。

### 卷六·商贾／假借／奴婢／官职／凶盗／官讼

- **官职门**：源L992：`日干顺灵敏至龙常所乘之神为年限，一位为一年`
  → **文看青龙、武看太常；干顺数至所乘神为年限、支顺数至所乘神为月限**。
  这是**可算的年限／月限推法**（计数规则是机械的，落官＝吉凶则不是），项目若做"应期"骨架可采其计数法。
- **凶盗门**：源L1020 以元武为盗、元武之阴为盗神，日干为失主；
  "元武顺行贼已行、逆行贼未行"（源L1020 注）为**方向判定**，
  里数法"甲己子午九，丑未八，寅申七，卯酉六，辰戌五，巳亥四"为**查表乘法**（源L1020）。
  这些计数/方向条件属结构层，"贼必败露""易获"属 narrative。

### 卷七·疾病／行人／天时／杂课

- **疾病门**：源L1088：`以日干为病人，以支辰为病及寝宅，以鬼为病，以折虎为病神`
  → **四课角色分配表（病人/病所/病/病神）是纯结构映射**；同小注给出"入墓"六条（身入墓/魂入墓/
  鬼入墓/日入墓/支入墓/行年入墓），每条都是可判条件；而"必死""难痊"属 narrative。
- **行人门**：源L1150：`来人问信知时辰，对宫起子顺排轮。` → **"对宫起子顺排轮数至天罡"是纯计数法**；
  源L1142：`将军三年移一宫，如寅卯辰年在子，巳午未年在卯，申酉戌年在午，亥子丑年在酉。`
  → 大将军煞四组三年一迁的**枚举表**，与项目神煞表同源。
- 源L1154：`拟出门时定行否，须看行年与日辰。` → 定行止以行年＋日辰为条件骨架。

### 卷八·兵占门与今附四歌（**版本存疑最重的一卷**）

- 兵占门是后补（见 §一），十六占全部是兵事占候——**兵占非本项目八科范畴，整体不适用**。
  但其中"月将加时＋某神加减定方"的路数是通用的：
  源L1332：`此论专看天盘上子丑卯酉四处` → 藏形遁迹只看天盘子丑卯酉四位。
- 今附"六十花甲纳音"：源L1336：`甲子乙丑海中金，丙寅丁卯炉中火。` → 六十甲子纳音表。
  属**历表数据**，可作择吉/纳音备用表；与结构层无关，登记为不适用（超出骨架）。

## 四、对勘与口径分歧

- **无对勘本**：登记表 `crosscheck` 为空，本篇不设对勘结论。但本书自附**异书异说**，可作间接对勘：
  - 九宗门各门注文大量引《六壬入式》（明 徐华胥）、《神枢经》、《龙首经》、《玉历》、
    郇应清注——**本书是《六壬大全》的上游旁证之一**，两书同门不同辞处应回到《心镜》原句。
  - 源L3 郑天民校记明列《心镜》与《通神集》《六壬兵机三十占》《百炼金》的异同，
    说明卷八及部分歌诀实为**辑佚补入**，非本书原生。
- **同名不同类（重要口径分歧）**：《六壬大全》「九宗门」与本书「九科门」**门名重叠但层级不同**：
  九宗门是**排三传取用之法**（九种方法），九科门是其上笼罩的**九种课体总纲**（元首/重审/知一/见机/
  蒿矢/虎视/信任/无依/帷薄不修）。引擎 `jiuzongmen.py::MEN_ORDER` 是**法**的名单，
  `kemu.json` 是**课体**的名单，两表各有九项、名称部分重叠。
  **本项目以「法」与「课体」分表为口径，不合并**；若将来合并必先解决"元首/重审"双表同名歧义。
- **与《六壬大全》口径一致处**（可互相印证）：十干寄宫、九宗门次序、贵人旦暮昼暮分宿、
  大将军四组三年一迁、天罗地网＝日前一辰＋对冲。本书在这些处**提供了《大全》没有的枚举细节**
  （返吟六日、八专五日、别责刚三柔六），属可补遗方向。
- **本书独有的「一法两断」结构**：每条歌诀实为「条件句 + 断语句」两段拼接（歌体限制）。
  本项目一律只取条件段，断语段标 narrative；**不得因两段同处一行而把断语当成判据**。

## 五、不适用与存疑

**不适用（超出骨架，按铁律不采）**：

1. **卷五~卷八全部占验断语**：占宅/修造/婚姻/产育/田蚕/商贾/官职/凶盗/官讼/疾病/行人/天时/杂课
   的"主吉/主凶/宜/不利"一律 narrative 候选，登记不采——骨架层不输出方向。
2. **黄黑道门（卷五 L850-876）**：源L866：`以上六神名黑道，修宅犯之人祸殃。` 等六神定位属择吉方位表，
   与 liuren 骨架层无涉；其"所主"（主狱/主口舌/主财亡）为 narrative。
3. **兵占门（卷八）**：兵法占候不在八科范畴；且该门系后补（见 §一），即便采信亦须先解决版本问题。
4. **六十花甲纳音（卷八 今附）**：源L1336：`甲子乙丑海中金，丙寅丁卯炉中火。` 属历表，
   与结构层无关，登记不适用。
5. **杂神门各类神"主什么"**：音/月将/部位/禽兽等**类神字典可留底**，
   但"主猪""主狱""主盗贼"是断语，不采。
6. **卷三凶否门/吉泰门的卦名吉凶倾向**（九丑"凶灾将及"、三光/富贵/官爵等）：
   卦名与条件可入库，断语不采；「吉泰门」诸卦（富贵/官爵/高盖乘轩/斫轮/铸印）纯为吉名，
   在骨架层无对应物，登记不适用。

**存疑 / 未读懂（如实登记，不脑补）**：

- **九丑卦日数自相矛盾**：源L418：`乃乙卯、己卯、辛卯、乙酉、己酉、辛酉、戊子、壬子、戊午、壬午十日也`
  句末自云"十日"，实际列出 10 个日；但同句上文又云「乙戊己辛壬五日此五干为日也」，
  与所列日干支（含戊午壬子而非戊子乙卯）不合。**属转写讹误，不臆补**，登记待校。
- **九宗门编号缺「八专」位次说明**：目录（源L31）作「克贼一…八专九」，正文（源L216）亦标第九，
  但**「八专」在《大全》体系中位次与他书有异说**，本书此处只言"皆两课也"，未申说理。
- **卷二「夭姶卦」名与字形**：源L39 作「泆女卦」，源L266 又作「泆女卦亦名失友，传见六合，名曰狡童」，
  「泆／淫」字形在传抄中混用（目录源L39 亦见「芜淫卦」）。**不归一，照录原样**。
- **三宫时门与斗孟/斗仲/斗季关系不明**：源L806 自注「《续编》斗孟仲季本是三宫门，己前十干神后集定」，
  提示斗孟仲季本属三宫门而后分出，然其分判规则在本书中**未明写**，仅存一句自指。
- **「杂将门」驳异说段（源L750）与 tianjiang 口径的张力**：该段以青龙折角、白虎登山等
  反驳"青龙吉白虎凶"，与项目 `data/verdicts.json#tianjiang` 逐将乘临歌的
  "旺相比和则吉、休囚则凶"框架**层级不同**（本书讲同将随乘地而异，歌诀讲同将随旺衰而异）。
  本项目以歌诀层为断语出处、以本书段为"报告须带乘神"的方法论约束，两者不冲突但须分行登记。
- **「一百八十一篇」与实收六十四课不对账**：源L164 自序称 181 篇，源L220 称六十四卦，
  而项目 `data/kemu.json` 实收 64 条。181 为全书篇数（含占门杂占），64 为课经课体数，
  两者口径不同，**不可互相校正**，登记备查。
- **版本脱字登记**（照录原样，不改字）：源L1090 附近「若白牙乘浴盆」作「白牙」（白虎讹字）、
  源L1132「若无类刘在上」（疑脱「神」字）、源L1150「保住副」「分胆」等讹字，均属转写之误，
  本文档一律照录原样并在此登记。
