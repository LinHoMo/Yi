## 二、逐卷（章）深读（占法逐句全读；签文按段抽层）

### 占法（L6-33）：报字 → 笔画 → 三百八十四数 → 查签

占法是全书唯一机制层，构成完整机械闭环，三条规则环环相扣：

- **甲·报字**：源L8：`凡占卦者。必先报字。报字不拘何字。必先以三字为度。不可报四字。亦不可报二字。` → 输入侧硬约束：**恒三字**，多一字少一字都不受理。三字是后续位值制（百十个位）的前提。
- **乙·计算其一（位值）**：源L11：`将所报之字。先写于纸上。数其笔画。以便查字。其法有三。` 与源L13：`第一字作百数。第二字作十数。第三字作个数。` → 三字笔画按**百、十、个位**拼成一个三位数——不是求和，是位值拼接（如 7/9/12→792）。
- **乙·计算其二（折笔）**：源L18：`凡字笔画。在九笔以内者照算。在十笔以外者。减十笔算。(二十笔同)若恰在十笔或二十笔。俱照零笔计算。` → 每字笔画取模 10（恰 10/20 记 0），保证每字折为 0-9 的位值数字。算例：源L23：`假如佑咱统三字。为七百九十二数。减去三百八十四为四百零八数。` —— 佑7画/咱9画/统12画→折 7/9/2→792。
- **乙·计算其三（归签）**：源L23：`此书照大易三百八十四爻。作为三百八十四签。所报之字笔画以三百八十四为度。过于三百八十四。则须减去三百八十四计算。` → 总数对 **384 取模**（减至不过 384 为止），即把三字哈希到 1-384 的签位空间。384=64卦×6爻，签制自挂《周易》爻数以立权威。
- **丙·查签**：源L33：`数已计定。即可查签。` → 数到签的映射是**直查表**，无任何中间推演。

评：这是与《灵棋经》（掷数→124 课表→书源断语，已实现于 `disciplines/lingqi/`）完全同构的「数应机制」——输入编码（掷棋 vs 报字笔画）、取模归槽、直查断语表三段一一对应。差别仅在编码函数与表容量（124 vs 384）。若将来扩签占科，lingqi 的四段契约（chart→analyze→narrate→render）可直接平移；本批只登记，见 OPT-zhuge_shenshu_dz-02。

### 签文抽层解读（L35-264，签 1-230）

**抽样覆盖段声明**：占法（L6-33）逐句全读；签文按五个连续段各抽代表签细读——签 1-50（L35-84）、签 51-100（L85-134）、签 101-150（L135-184）、签 151-200（L185-234）、签 201-230（L235-264）——余签按主题层归纳，不逐签誊录；签 231-384 主源缺失，无法覆盖。

- **签 1（L35，上上格样板）**：源L35：`天门一挂榜，预定夺标人；马嘶芳草地，秋高听鹿鸣` → 开卷第一签立全库基调：意象（挂榜/鹿鸣=科举语汇）直出吉断，无条件项。
- **签 5（L39，八卦语汇入签）**：源L39：`春雷震，夏风巽，卧龙起，猛虎惊，风云会合，救济苍生。` → 震/巽两卦名嵌入季节语，是 384 签中《易》语最外显的一条。
- **签 32（L66，卦理直用）**：源L66：`乐之极矣忧将至，巽兑分明吉与凶；未能光大终幽暗，日落西山返照中。` → 「乐极生衰」义理+巽兑卦名，断语自带哲理框架。
- **签 50（L84，禄马语汇）**：源L84：`财马两匆忙，官禄有定方；猪羊牛犬，自去主张。` → 「财马」（禄命语汇）+生肖罗列收尾，民俗口径。
- **签 96（L130，经语句入签）**：源L130：`可以寄百里之命，可以托六尺之孤，锺期既遇毋迟误，笑呼呼，他乡聚首，各自乐康和。` → 《论语·泰伯》原句直入签文。
- **签 102（L136，否泰框架）**：源L136：`泰来否已极，诸事莫忧心，但须培养元福，做些好事，行些方便，一点丹灵独得真。` → 否极泰来（《易》序卦语）+劝善条款（「行些方便」），签占与功过格合流。
- **签 213（L247，用舍行藏）**：源L247：`用之则行，舍之则藏；一骑出重关，佳音咫尺间。` → 《论语·述而》句入签。
- **签 214（L248，易句入签）**：源L248：`积德施功有子孙，杀牛祭神及西邻，功名两字成全日，回首山河万物新。` → 化用《易》既济九五「东邻杀牛，不如西邻之禴祭」。
- **签 230（L264，末签）**：源L264：`玉出昆冈石，舟离古渡滩；行藏终有望，用舍不为难。` → 主源所存最后一签；「用舍」再应《论语》语，与签 213 呼应。

**主题层归纳**（覆盖全部 230 签的粗分）：功名仕途（1/28/97/121/142/157/181 等）、财利经营（50/84/126/147/214 等）、婚姻家宅（13/123/124/136/184 等）、疾病讼灾（49/113/175/220/227 等）、行旅音信（9/15/55/191/195 等）、出世修行（37/39/42/44/45/47/143 等）、吉凶两可戒惧类（25/74/100/128/154 等）。断语形态全部为「意象直断」，无一条给条件分支或推演链；同主题各签吉凶光谱连续（如婚姻从「百年好合」到「镜破钗分」均有），说明表是**设计出来的全谱系断语库**，非验案汇编。

## 四、对勘与口径分歧

- **本批内无直接冲突**。与《灵棋经》（`lingqijing_dz.md`）是机制亲缘而非口径冲突：同为「数→槽→断语直查」，差异只在输入编码（12 棋掷数 vs 三字笔画）与表容量（124 vs 384）；两书断语均书源逐字，路线一致。
- **内部重文**：签 49（源L83：`沉沉屙染，不见天心；雷门一震，体健身轻。`）与签 113（源L147：`屙染沉沉，终日昏昏；雷门一震，体健身轻。`）语句高度雷同且后句全同——或为传抄重文，或为异本并收，本源无从判分，登记 §五。
- **经义口径**：签 214 用既济九五「西邻」祭薄而受福义，与《周易》原文相合；签 102「泰来否已极」倒装通行「否极泰来」，义同。无与内核数据的冲突面。

## 五、不适用与存疑

**不适用理由**：

1. **无对应学科**：八科无签占科；lingqi（灵棋经）是已建科的近亲，但学科间禁互相 import，更不允许以本书源新增目录。
2. **签断语无推演结构**：230 签全部为意象直断，无常量参数、无条件分支；「数应机制」虽机械，但只是**哈希函数**，输出与输入无义理关联（笔画数与吉凶无因果），与铁律一「机械推演」的内涵（排盘/装卦/旺衰等结构运算）不同层。
3. **铁律三口径**：凶签（如签 175「乘病马，上危坡，防失跌」、签 11「平地起风波」）若经任何出口转述，必须按「有信号/偏向」软化，且本批无出口路径。

**完整性缺陷**：签 231-384 缺失（§一已列）——书源缺陷级，非 OCR 可修复，需换源补抓。
