## 二、逐卷（章）深读

### 卷之一·提纲例约（全书的机械结构总纲）

L62 一句定全纲领，是本书**唯一可整段机械化**的纲文：

源L62：`壬之有纲，犹裘之有领；振裘者必挈其领，言壬者当提其纲。维纲云何？曰四课也，用神也，三传也，天官也，八煞也，如斯而已。`

→ 五纲＝四课／用神／三传／天官／八煞。后文即按此五节展开（节名与 L4-L8 目录逐字对应：
观四课之加临、察用神之生克、明三传始终、定贵神吉凶、判八杀吉凶）。
注意「知四课而不知加临之变，不知四课者也」——本书立场是**结构必须落到加临**，与
本项目「课体标签 + 日辰关系」的骨架口径同向。

**观四课之加临（L65-L105）**：把日辰与上神（及辰上神）的生克关系逐条命名，
是本书**最密集的结构标签群**（全部为机械条件，可落）：

- 益气（上神生日）源L65：`凡日上神生日，谓之益气。益气者，有益于我之气也` →
  「益气」为纯结构名，后半「遇灾不凶，凡事皆吉」是断语，narrative 候选。
- 脱气（日生上神）源L66：`我生上神，为脱气劳心劳力。` → 名词「脱气」可采。
- 损气（上神克日）源L67：`凡日上神克日，谓之损气` → 结构名。
- 制气（日克上神，即六亲之财）源L68：`我克者为财，然而得吉神旺相，方可言财` →
  **「日克上神＝我克者为财」是六亲财的取法定义**，与项目六亲取用一致；
  「得吉神旺相方可言财」为条件性断语，属 narrative。
- 日／辰主客定位（L102）源L102：`凡日课为主，为尊，为人，为动，为远，为高；辰课为彼，为卑，为地，为静，为近，为小。上生下则利，我生彼则不利。` →
  **日课＝我（主、动、近、高）／辰课＝彼（客、静、远、卑）** 是全书的对待轴，
  与项目「日为我、辰为彼」口径同，属可落地结构条件；末句「上生下则利」是断语，narrative。
- 月宿（L104）源L104：`凡辰上见月宿，为凶神入宅。月宿，太阴也。正月起危，二月起奎` →
  月宿十二次按月建顺推（危奎胃毕井柳张翼角房箕斗），是**纯数据表**；
  「为凶神入宅」是断语。书源此行「三胃」当为「三毕」（衍字，见 §五 存疑）。

**察用神之生克（L108-L138）**：用神取法与应期分层。

- 内外事定位（L109）源L109：`凡用在日上两课，为外事，主远，主去；用在辰上两课，为内事，主近，主来。` →
  **用神落在日上两课＝外事（远、去）／辰上两课＝内事（近、来）**，纯机械条件，优先级高。
- 应期分层（L112）源L112：`凡用得太岁，事在年中；用得月建，事在本月；用得旬首，事在本旬；用得节气中立之首，事在半月之内；用得本日之干，事在本日之内；用得气首，事在五日之内。` →
  六级应期刻度（年/月/旬/半月/日/五日），是**机械时间映射表**，可直接落为「应期层级」标签。
- 五气断语汇总（L123）源L123：`故曰：旺发言官事，妻财相气论，死言丧祸至，囚动见官刑，休来忧疾病，诸家卦备陈。` →
  旺相死休囚五气对应六亲的结构部分可采（五气→六亲），
  「发言官事／论／丧祸至／见官刑／忧疾病」全为断语，**narrative 候选，超出骨架**。
- 夹克／内战／外战（L131-L133）源L131：`凡用神下临克地，而天官又下克之，则为夹克`、
  源L133：`凡地盘克用神，用神克天官，为内战` → 夹克／内战／外战是**纯结构名**
  （用神下临受克地 + 天官同向下克 → 夹克；地盘克用神且用神克天官 → 内战，反之为外战），
  「吉不成吉，凶则大凶」是断语。

**明三传始终（L140-L182）**：全书三传结构格最密集的一段，**几乎全是可落地的机械条件**：

- 源L145：`凡三传不离四课者，谓之课内藏` → 三传全部落在四课之上＝课内藏（结构名）。
- 源L152：`凡三传俱阳，事必显著；三传俱阴，事必隐秘。子寅辰午申戌为阳，丑卯巳未酉亥为阴。` →
  **三传阴阳＝按地支奇偶定（子寅辰午申戌为阳／丑卯巳未酉亥为阴）**，纯规则，可落。
- 源L155：`凡三传自干上发用，传归支上者，必是我托人干事；自支上发用，传归干上者，必是人托我干事。` →
  发用起点与归宿定「我托人／人托我」，机械可判（吉凶措辞除外）。
- 源L162：`凡三传不在四课之上者，事必难成。` → 与课内藏互为镜像的判据。
- 源L166：`凡三传见于日辰之中，谓之夹定三传。` → 三传被日辰夹住＝夹定三传。
- 源L168：`凡日辰夹住三传，前后尚虚一位者，谓之虚一` → 夹定而首尾尚虚一位＝虚一。
- 源L169：`若日辰之中止有两传，而有一传透出在外，则为透关之格` →
  日辰中仅二传＋一传外透＝透关之格；「须观所透者于日干何等亲属」是取象步骤。
- 源L172：`中见日害，谓之折腰，事当中阻；中见日空，谓之断桥，事主中断。` →
  **中传见日害＝折腰、中传见日空＝断桥**，两个纯结构名（并列的「中见日墓＝事当中止、
  中见日破日冲＝事必中坏」同在 L172）。
- 源L173：`凡末见中传之鬼，谓之传中藏鬼` → 末传见中传之鬼＝传中藏鬼。
- 六亲取法（L180）源L180：`凡三传所属五行，皆当与日干较取六亲，如甲日见太乙为子孙，见大吉为妻财，见登明为父母，见从魁为官星，见太冲为兄弟之类。` →
  **十二将按五行配六亲**（太乙火＝子孙、大吉土＝妻财、登明水＝父母、从魁金＝官星、
  太冲木＝兄弟），是纯数据表，与项目六亲取用同口径，可作交叉校验。

**定贵神吉凶（L184-L187）**：类将分工表。源L185：`凡占必以天官为万类之主。如占盗贼，视元武，求财视青龙，文书视朱雀，干贵视天乙` →
十二天官对占类的映射（元武盗／青龙财／朱雀文／天乙贵），**结构映射可采**，
后半「触类而长」之类断语不采。源L186：`如巳为天乙，加临寅上，寅刑巳也。` →
天乙乘神受刑之例（巳为天乙加寅为刑），是「天将乘临」结构的书源例证。

**判八杀吉凶（L189-L193）**：源L190：`干有德合鬼墓，支藏破害刑冲，看其旺相空亡，定其往来生克。` →
**八煞＝干上德合鬼墓四字＋支上破害刑冲四字，共八**，命名清晰，是**纯结构标签群**，
与项目神煞表可对接；同行的「合乃完成，德为庆会，鬼主伤残……」八句是断语，narrative。

### 卷之二·壬占易简例约（理气象类说＋三则琐占例）

**理气象类说（L200-L201）**：本书哲学总纲。源L201：`曰五气，旺相死休囚是也` →
五气（天上的）＋十二气（地上的）为全书气论二分；「得气则吉，不得气则凶」是断语。

**占例一 求财（L204-L238）**：源L206：`故凡类神所临之地，有十二气，而神与其地较旺衰。盖凡下临有气之地，则财强。长生、冠带、临官、帝旺是也，谓之四吉。` 与
源L206：`下临无气之地，则财弱，沐浴、衰、病 、死、墓、绝、胎、养是也，谓之八凶。` →
**十二气四吉（长生／冠带／临官／帝旺）／八凶（沐浴／衰／病／死／墓／绝／胎／养）**，
是纯分组表，可落。注意此处书源把「衰」列入八凶、「病」后有多余空格（见 §五 存疑）。
财类神取法（L249）源L249：`财神有五，而年上不与焉，五财者，时用日辰命也。` →
**五财＝时／用／日／辰／命（年上不取）**，纯结构条件，与项目六亲定位互补。

**占例二 琐占约云（L240-L253）**：L241 一段七字诀是全书最短的判纲：
「求财视龙，旺相相逢。日辰年用，此外难同。财神虽现，财阴须善。龙财旺方，往来诚便。」
——「求财视龙（青龙为财将）＋旺相＋见于日辰年用」为机械入式条件，
「往来诚便／须善」为断语。

**占例三 扣门占（L255-L258）**：以日干为扣门之人、行年为我，日上神与年上神较论休咎，
是「日／年两维对照」结构，不涉门类，无新增机械条件。

### 卷之三·谋望门（成象／通象／推类／引伸）

- **成象第二（L270-L274）**：源L271 段内「日动为我，辰静为人；辰上神以之观人，日上神爰以观我」——
  与卷一 L102 同口径（我／彼轴）。干人两象的对待条件为「生合／战克／刑／冲／害／破」六种，
  **六种关系本身是机械的**，可与项目日辰 10 条判据互补。
- **通象第三（L276-L288）**：休咎关于发用、转移属中传、末为底止之乡；三传递生/递克方向定成败。
- **推类第四（L290-L295）／引伸第五（L297-L306）**：类将类神的细分取法。源L298：`有珠玉之求者，视从魁 ，有弓矢剑戟之求者，视传送` →
  按所求物类分配十二将（珠玉→从魁、弓矢剑戟→传送、图书伞盖→登明、书籍→功曹、
  雁羊酒食→小吉、墓田→大吉、鱼盐→天罡、犬马→天魁胜光），**纯物类→天官映射表**。
- L308 归约段自述四课定人我、三传决始终、类神类将指事、本命行年相参——可作卷三结构小结。

### 卷之四·婚姻门（例约＋正象＋占验五则）

- **例约第一（L315）**：四立：分男女、视三传、以天官察类神、从五气辨休旺。
- **干支正象第二（L317-L324）**：日干＝夫星（阳／天）、日支＝妇位（阴／地），
  「喜其互合交生，恶其明刑暗克」——性别与取象轴**机械可判**，
  然「姻缘之吉庆可知，投求亦易」等断语 narrative。
- **用传变象第三（L326-L332）**：L327 段「以三传之变象而言，则初男末女，亦喜相生」——
  **初传＝男、末传＝女**，是纯位置映射；同段列「初见虎勾／妇女不良，末乘元合」等为断语。
- **成改迟速始终琐象第七（L363-L372）**：源L367 段内
  「成不成，莫相刑……得不得，制其物」——**成＝不刑、得＝上神制支上神**，
  是两条可机械判定的条件句（吉凶语在外）。L369 段内孟＝事始虚、仲＝骑墙、季＝事终实，
  **孟仲季三阶段判定**可复用为应期结构。
- **古今占验第八（L374-L437）**：五则占验（占验一至五）。属**案例库**候选——
  可入 `disciplines/liuren/data/cases/`，但按铁律二与交付过程物理隔离，
  **不作推理依据**，且断语（媒妁、私通、二夫、断讼等）一律不采。

### 卷之五·农事门（农桑＋蚕桑）

- 源L452：`凡以登明神后为稻者，水谷也。` → 登明（亥）神后（子）＝水谷类；
  功曹太冲＝木谷、太乙胜光＝火黍豆、传送从魁＝金二麦、四土＝百谷（大吉＝田）。
  **五行→作物类神映射表，纯结构**。
- 源L455：`申酉者，金之类神也。` → 金类二麦；其条件句统一为
  「乘吉旺相＋与辰上神生合＋不与日年上神往来相伤」，三项皆为机械条件。
- L462 段内「日为农人，辰为畎亩，辰上神将为所树艺之物，日上神将为所仰望之天」
  ——日月辰的类义分工，机械可登记。
- 蚕桑象类（L471-L492）：午＝蚕命、未＝桑、寅＝茧、卯＝丝、辰＝薄、巳＝筐、申＝绵、
  酉＝僵、戌＝黄、亥＝厄绝、子＝鼠耗、丑＝眠化——**十二辰物象映射表，纯结构**，
  条件句统一为「加临乘带俱吉」。
- 吉凶琐象（L501-L509）全为断语，narrative。

### 卷之六·出行门（十四占法）

十四篇目中可落地的机械条件集中在三处：
- 源L534：`盖凡关墓临干，身则难动。` → **关墓临干＝静象难动**，与「旺相发用则动」
  构成动静占法的二元判定，纯结构。
- 源L574：`故凡传得纯阳，则主晴朗，而木旺乘阳者多风。传得纯阴，则主阴晦，而金旺乘阴者多雨。` →
  三传纯阳／纯阴＋所乘五行→晴雨，规则机械；晴雨断语 narrative。
- 期会良法第十三（L628-L629）：以天罡／胜光在日辰前后来定「得会／已去／未来」，
  属位置机械条件。

余下（伴侣、赀本行李、投宿、启行、见闻有疑、家内吉凶）皆叙事性断语，不采。

### 卷之七·三才门（类神之三传，本书最独特的结构层）

- 三才易简例约第一（L646-L663）源L649：`乘即天后所乘之神也。临即乘神所临之宫也。后所乘神，即为初传，初之阴神即为中传，中再传之神，即为末传，是即所谓类神之三传。` →
  **类神之三传＝由类将所乘之神起，依次取其阴神递推**（乘神＝初传、初之阴神＝中传、
  中再传之神＝末传）。这是一条**纯机械的取传算法**，且与本项目三传（九宗门发用）不同源，
  可作为「类神三传」独立标签组落地的算法依据。
- 源L663：`然神与将又有变通之法，将即神，神即将。` → **变通法：无天乙则取大吉、无青龙则取功曹，
  再无则取太常**（L651-L662 逐将给出类将→类神的替代表），纯替换规则。
- 类神三传变通法引证第二（L665-L679）源L676：`凡在二三则为近，在五六则为远。` →
  六合之气「前后凡七」中，前二三分判近、后五六分判远，是**纯距离分级条件**。
  源L678：`一不宜落空，二不宜投墓，三不宜传见官鬼，四不宜煞带二死，五不宜蛇虎魁罡加临年命，六不宜气乘囚死。` →
  **占子孙六条机械否决条件**（编号化，可直接落为「结构否决项」清单）；
  后半「若全见者，必有死亡之事」为断语，narrative。

## 四、对勘与口径分歧

- **对勘本**：本批内无对勘本（`crosscheck` 为空），故无逐字对勘。
- **与《六壬大全》的最大口径分歧——起课层缺席**：本书**全文零次出现「月将」**，
  也不列贼克／重审／比用／涉害／遥克／昴星／别责／八专／伏吟／返吟九门名，
  且在卷七明言「不必徒求课体」式的取向。本项目以**《六壬大全》九宗门为准**作为三传唯一真值源
  （`disciplines/liuren/data/verdicts.json#men` 九门已在库）；本书三传相关条文
  （三传阴阳／课内藏／夹定／虚一／透关／折腰／断桥）**只作旁证标签**，不改九宗门判定。
  理由：九宗门是**发用规则**（机械可复算），本书三传诸格是**成象命名**（描述既有课的形态），
  层级不同，不可混作一路。
- **与《六壬大全》的第二分歧——六亲取法**：大全以日干对四课取六亲；本书 L180
  另给出「三传五行亦当与日干较取六亲」的扩展口径，并以十二将五行配六亲为实例。
  二者不冲突（对象不同：四课 vs 三传），本项目取「四课为主、三传为辅」，已入库实现不动。
- **与《六壬大全》的第三分歧——日辰关系的命名**：大全作「日上生干／干生上神」等
  直陈式十句（已入库 `verdicts.json#richen`）；本书加**四气别名**（益气／脱气／损气／制气）。
  本项目以大全直陈式为判定键、以本书别名为显示标签，二者指向同一批结构，**不新增判定分支**。
- **与《六壬指南》的分歧**：指南重日辰六亲与毕法，本书重类神取象；本项目取其交集，
  凡本书独有的类神层一律标 narrative 或 P2 备表，不进骨架主线。
- **口径纪律**：本书材料若与既有唯一真值源冲突，**按 AGENTS.md §数据缺陷**报缺陷，
  不得按读数改数据。
