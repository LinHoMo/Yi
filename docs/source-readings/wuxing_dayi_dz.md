## 一、书目与版本

## 二、逐卷（章）深读

### 五行之总纲与体性（源L6、源L80、源L88）

开篇总纲即以五行配天地万物、阴阳为体。「夫五行者。盖造化之根源。人伦之资始」（源L6）把五行定位为**本体论**层面的生成本原，是理解全书义理的起点。第二论辨体性（源L80）以「体者以形质为名，性者以功用为义」区分体/性，并以少阳/少阴/太阴/太阳/中和配五行——这套**体性框架**是汉晋易学的通行义理，与 core 的五行阴阳表（只取生克）属不同层次。

- 本体论总纲，源L6：`夫五行者。盖造化之根源。人伦之资始。` → 五行为天地万物本原，是全书义理总纲；对项目：五行属"本体/义理层"，与机械推演的生克表不可混同，属叙述层。
- 体性之分，源L80：`体者。以形质为名。性者。以功用为义。以五行体性。资益万物。` → **体/性二分**的哲学框架（体=形质、性=功用），是本书区别于纯生克表的理论深度所在；现状：core 只取生克阴阳，体性义理不入引擎（合理）。
- 五行之数，源L88：`行言五者。明万物虽多。数不过五。故在天为五星。其神为五帝。` → 五行之"五"的数源（天数五），并引孔子、老聃"天有五行……其神谓之五帝"；属义理/神祀层，非机械判据。

### 数理：生成数与大衍、九宫（源L82–L100、源L118、源L100）

第三论数是本书数理核心。**河图生成数**（天一生水、地六成之……五行生五，五行克十）把五行与先天数相配，是"五行＋数理"的关键桥梁。第三论九宫（源L100）以"上分于天、下别于地"分九宫，为遁甲九宫的义理先声。源L118 引"天生一，始于北方水……五行生五，始于中央土"，是生成数的经典表述。

- 生成数起例，源L118：`经云。天生一。始于北方水。地生二。始于南方火。人生三。始于东方木。时生四。始于西方金。五行生五。始于中央土` → 河图生成数配五行方位，**是 core 纳音/生成数的义理先声**；现状：core 取其用（纳音/五行），此段为义理旁证。
- 九宫之义，源L100：`九宫者。上分于天。下别于地。各以九位。天则二十八宿。北斗九星。地则四方四维。及中央。分配九有。` → 九宫＝上天（二十八宿/北斗九星）＋下地（四方四维＋中央）的空间划分；与遁甲九宫同源（奇门无学科，留底）。

### 相生相克与刑冲合害（源L140–L170）

第四论相生至第十三论冲破，构成五行的**动态关系网**：相生（递养）、相克（制罚）、合（和）、扶抑（强弱）、刑害冲破（攻讦）。相克一段定义尤清，源L158 明言"克者。制罚为义。以其力强能制弱"，并给出木克土、土克水、水克火、火克金、金克木的序列。

- 相克之义，源L158：`五行虽为君臣父子。生王不同。逐忌相克。克者。制罚为义。以其力强能制弱。故木克土。土克水。水克火。火克金。金克木。` → **相克序列与义理**（制罚义、力强制弱），其中"木克土，土克水，水克火，火克金，金克木"即 core 相克表；现状：**序列已入 core**（五行相克），"制罚为义"为义理旁证，登记对源。

### 八卦、五事与性情治政（源L198、源L218、源L214）

第十七论八卦（源L218）引《周易》包牺氏"仰则观象于天，俯则观法于地"以释八卦起源；第十八论性情引《洪范》五事配五行（源L198：貌配木、言配金、视配火、听配水、思配土）；第十九论治政、第十六论七政（源L214：七政日月五星）则把五行用于天文与政事。这些是五行**向人事、天文延伸**的义理内容，与项目机械层无涉。

- 五事配五行，源L198：`五事者。尚书洪范云。敬用五事。盖以人事配五行也。一曰貌。以配木。二曰言。以配金。三曰视。以配火。四曰听。以配水。` → 洪范五事配五行（貌木言金视火听水思土），是五行配五常的源头；现状：叙述层，无对应引擎（合理）。
- 八卦起源，源L218：`八卦者。周易云。古者庖羲氏之王天下也。仰则观象于天。俯则观法于地。` → 八卦起源的义理（观象法地/近取诸身远取诸物），属先天卦义的解释层；现状：core 六十四卦表为占筮用，本段为义理旁证。

### 纳音数与支干配数（源L90、L94、源L158）

第三论数的第四段专论**纳音数**（源L94「第四论纳音数」），是把六十甲子与五行阴阳相配的数理依据——这正是 core 纳音表（`NAYIN`）的义理母题。相克一段（源L158）给出与core 完全一致的相克序列，可作对源。

- 纳音数之立，源L94：`第四论纳音数` → 纳音数列专论，是六十甲子纳音配五行的数理出处；**core `symbols.py` NAYIN 表已入，本书为其书源之一**（对照《三命通会》《五行精纪》两书同载纳音，为三源互证，见 OPT-02）。
- 相克序列对源，源L158：`故木克土。土克水。水克火。火克金。金克木。` → 与 core 五行相克表**逐字全等**，属最可靠的对源之一。

### 数理与九宫（承前补其用）

core 的纳音表（NANYIN）与九宫数均取此类数理。本书提供的是**义理母题**（生成数配五行、九宫配天地），engine 只取其最终数值表，不实现其推导过程——符合"机械运算归代码"。

## 四、对勘与口径分歧

**与项目 core 五行表的关系（对源，非冲突）**：本书第四论相生、第十论相克所给的生克序列（源L158 相克、L118 生成数）与core `symbols.py` 五行相生相克表**一致**，属**同一底层_tables 的不同书源**。本书是**类书义理**源，core 取其机械层；二者层级不同、无口径冲突。唯一需注意的是：本书相克附有"制罚为义"的义理，**入引擎时只取序列、弃义理**（铁律三：机械运算与象数解读分离）。

**与《命理探源》《穷通宝鉴》的关系**：三书均涉五行，但《命理探源》以五行配干支/纳音（引《五行大义》），《穷通宝鉴》以五行配调候，《五行大义》本身是五行义理总汇、不涉命理调候。三书在"五行→纳音"一层可互为对源，无冲突。

## 五、不适用与存疑

1. **性情、治政、五帝、诸官、诸人配五行**（源L198、L214、L222–L230）：以五行论人臣配职、治政、五帝祭祀，属**义理/人事/神祀层**，与项目八科（占筮/命理）无涉，且带古代神祀色彩，不入引擎。理由：机械层无关、义理层叙述过远、价值观需谨慎。
2. **大衍数、河图九数推算**（源L82–L100）：属数理象数，与项目历法/命理机械层无直接对应；core 取其用（如纳音），推算过程不入引擎。
