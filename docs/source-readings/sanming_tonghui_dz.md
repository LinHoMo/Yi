## 一、书目与版本

《三命通会》十二卷，明代万民英（育吾山人）编，是子平法神煞、纳音、十神、格局的集大成之作。四库提要（主源 L1-10）考其"自明以来二百余年谈星命者皆以此本为总汇……于官印财禄食伤之名义用神之轻重诸神煞所系之吉凶皆能采撮群言得其精要"，并指其"立论多取正官正印正财而不知偏官偏印偏财亦能得力"的偏执。本书对命科引擎的价值集中在三点：**神煞表**（`core/yishu_core/shensha.py`）、**纳音表**（`symbols.py` 的 `NAYIN`/`NAYIN_TO_ELEMENT`）、**格局/从格判据**（概念同源于 `disciplines/ming/data/verdicts.json` 的格局诸分支）。其中神煞、纳音二表的算法已入库但书源出处未登记，格局判据现引《子平真诠》《滴天髓》而未引本书，详见 §三、§六。

**主源形态**：殆知阁本无刻本目录，正文以 `论 X` / `释 X` / `总论 X` 标题 + 大段注按（多引珞琭子、阎东叟、玉霄宝鉴、广信集等）展开；神煞章末每煞附"吉则/凶则"十六般细分；格局章每格附大量七言古歌。转录本有少量异文（如"防命口诀"当作"看命口诀"、"邜"代"卯"、""等缺字），引文照录原样。

## 二、逐卷（章）深读

### 论天乙贵人与诸神煞（源L456、L525-566、L584、L588）

神煞章群是本书最系统的部分，也是命科 `shensha.py` 的直接概念来源。天乙贵人歌诀（L551）与引擎 `TIAN_YI_GUI_REN`（甲戊庚牛羊、乙己鼠猴乡、丙丁猪鸡位）逐字对应；文昌贵（L584）、学堂词馆（L589）、驿马（L525-530）、咸池（L456）均能在 `shensha.py` 找到同名机械表，但引擎未登记书源出处。

- 天乙贵人歌诀，源L552：`甲戊庚牛羊六辛逢马虎明矣` → 与 `shensha.py` 的 `TIAN_YI_GUI_REN` 逐字相合，是神煞表已入库但书源未登记（见 §三/§六）。
- 天乙最吉，源L566：`天乙贵三命中最吉之神若人遇之则荣功名早达官禄亦易进` → 书源对天乙的定位；引擎只取地支落点，未收录"最吉之神"的吉凶定性（叙述层）。
- 驿马定义，源L527：`寅午戌生人马在申` → 三合局驿马落点，与 `symbols.SAN_HE_GROUPS` 派生出的驿马表同源。
- 驿马与贵人同宫，源L530：`凡柱中带马若不値空亡破败交退伏神须荣贵` → 驿马喜生旺忌空亡，与引擎驿马判据口径一致。
- 咸池，源L456：`论咸池【按此煞须天干纳音于地同类方是` → 桃花须天干纳音同类方真，是"神煞须辨真假"的口径注脚；引擎桃花表未做此真假判别。
- 文昌贵，源L584：`有文昌贵甲人蛇口乙猪头丙狗丁龙戊向猴己午庚寅辛未贵六壬卯位癸逢牛` → 与 `shensha.py` 的 `WEN_CHANG` 逐字对应，已入库但书源未登记。
- 学堂词馆，源L589：`夫学堂者如人读书之在学堂词馆者如今官翰林谓之词馆取其学业精专文章出类长生乃学堂之正位` → 学堂取长生、词馆取临官，引擎有同名表未登记书源。

### 纳音体系（源L30-135）

纳音是本书不同于一般子平书的特色。"总论纳音"（L30-33）讲纳音本六十律旋相为宫；"论纳音取象"（L34-89）逐对解释六十甲子为何取某象（海中金、炉中火……）；"释六十甲子性质吉凶"（L90-135）给出每纳音干支的性质短语与所带神煞。引擎 `symbols.py` 的 `NAYIN`/`NAYIN_TO_ELEMENT` 正是此六十甲子纳音表，已入库但书源未登记。

- 纳音立法，源L31：`尝观笔谈论六十甲子纳音本六十律旋相为宫法也一律含五音凡气始于东方而右行音起于西方而左行阴阳相错而生变化` → 纳音取象的哲学依据，与 `symbols.py` 注释口径同源。
- 纳音取象，源L35：`昔者黄帝将甲子分轻重而配成六十号曰花甲子其花字诚为奥妙圣人借意而喻之不可着意执泥` → "借意而喻不可执泥"是纳音取象的叙述层基调。
- 六十甲子性质，源L37：`甲子金【为宝物喜金木旺地进神喜福星平头悬针破字】` → 纳音性质+神煞批注，属叙述层素材；引擎只取纳音五行，不取"喜神/平头悬针"等吉凶批注（§五 不适用）。

### 论正官与偏官（七杀）格局（源L1600-1668）

正官为"六格之首"（L1603），偏官（七杀）重在制化（L1659）。这两章的格局判据与 `verdicts.json` 的"格局成败引文"高度同构，但 verdicts 现引《子平真诠》而未引本书，是本书最值得补引的书源缺口之一。

- 正官定义，源L1603：`正官者乃甲见辛乙见庚之例隂阳配合相制有用成其道也故正官为六格之首止许一位多则不宜` → 正官喜纯一、只许一位，与 `verdicts.json` 格局成败引文"官星纯一"同义；现状：verdicts 未引本书。
- 偏官/七杀定义，源L1660：`偏官者乃甲见庚乙见辛之例犹二男不同处二女不同居不成配偶故谓之偏以其隔七位而相克战故谓之七煞` → 七杀"隔七相克"与"无制为煞、有制为偏官"的转化，与 `verdicts.json` 七杀分支同源。
- 弃命从煞，源L1668：`弃命从煞须要防煞从财忌煞从煞喜财防逄根气命损无猜` → 从煞格"煞重身无所归"的书源句，正是 `verdicts.json`"从格引文"的同类判据，但现引《滴天髓·从化论》（见 §三）。

### 论财、印、伤官、食神、杂气（源L1683-1746、L1734）

正财（L1683）重"财要得时乘旺不偏正混乱"；偏财（L1697）为"众人之财"忌分夺；印绶（L1718）"乃五行生我之名"忌财破；伤官（L1742）"务要伤尽方作贵看"；食神（L1745）"胜似财官"；杂气（L1734）为辰戌丑未库藏官印财。这些与 `verdicts.json` 的"格局成败引文"（现引《子平真诠》）构成平行书源。

- 杂气定义，源L1735：`杂气者乃辰戌丑未辰中有乙戊癸为水土库戌中有辛戊丁为火库丑中有癸辛巳为金库未中有丁巳乙为木库` → 四库藏三物，引擎未单独建"杂气格"机械层（归 `不适用` 见 §五）。
- 伤官定义，源L1744：`伤官者我生彼之谓乃甲见丁乙见丙之类甲用辛为官丁火乗旺盗我之气尅制辛金使不辅甲为贵故名伤官` → 与 verdicts"伤官带煞而透印格之成"同构，未引本书。
- 食神定义，源L1746：`食神者日干所生顺数第三位乃甲食丙乙食丁之例` → 食神"胜似财官"的喜忌与 verdicts 食神分支同源。
- 印绶定义，源L1721：`印绶者乃五行生我之名如甲乙在亥子月丙丁在寅卯月之类乃我气之源为生气为父母能防我官星使无伤尅` → 印赖官生、忌财破印，与 verdicts 印绶分支同源。

### 论偏财与弃命从财（源L1697-1704）

偏财为"众人之财"（L1697），弃命从财（L1703-1704）是从格的一种，与弃命从煞并列，是 `verdicts.json`"从格引文"的另一直接书源句。

- 偏财，源L1698：`何谓偏财乃甲见戊乙见巳之例非妻所带乃众人之财也切忌有姊妹兄弟分夺柱无官星祸患百出` → 偏财忌分夺，与 verdicts 偏财分支同源。
- 弃命从财，源L1704：`弃命从财须要防财若逢根气命损无猜` → 从财格"日干无气只得弃命相从"的书源句，verdicts"从格引文"现引《滴天髓》未引本书。

### 看命口诀（防命口诀）与方法论（源L5114-5140）

"看命口诀"是全书方法论总纲，以"日干为主、月令为提纲、以四柱配合"统摄一切（L5115），并反复强调"五行贵中和""神煞以五行为本"（L5137）。这部分是命科"日干定位 + 月令定格 + 强弱评分"的总原则书源，属叙述层/方法论，未进单格机械表，但应作为强引用依据登记。

- 看命总纲，源L5115：`大凡防命先防月支有无财官方防其他月令为命也` → "月令为命"与引擎"月令定格"同源（"防命"即"看命"，转录本异文）。
- 神煞以五行为本，源L5137：`命中用煞以五行为本如五行得地无贵煞而亦贵虽有恶煞无害于事若五行不得地纵有吉煞亦发不久` → 神煞吉凶最终取决于五行得地与否，是引擎"神煞为辅助层、五行为本"取向的书源依据（铁律三口径）。

## 四、对勘与口径分歧
