# 书源深度解读 · 格式规范与总索引

> 本文规定 `data/sources/` 内 76 份抓取物（去重 54 部著作）的**深度解读文档**怎么写、
> 怎么机械验收。登记表：`data/sources/works_registry.json`；验收门：
> `python tools/check_source_readings.py`（`--doc` 单篇自检 / `--index` 重建本文 /
> `--selftest` 负例自证）。
>
> 背景：2026-10-07 前完成殆知阁/维基文库书源批量抓取（`tools/fetch_source.py`，
> provenance 齐备）。本轮任务 = **每一部都做完整深度解读**，产出可用于项目优化的
> 判据清单与优化项；引文一律逐字可指回原文（铁律"引文可指回原文"的文档版）。

## 一、写作规范

每部著作一个文档：`docs/source-readings/<work_key>.md`，骨架（六节名称逐字固定，
机械门按节名验收）：

```markdown
# 《书名》深度解读

## 一、书目与版本
- 朝代/作者/卷帙；主源 `data/sources/<key>.dz.txt`（N 行 / M 字）；对勘本有无与差异。
- 全书卷章清单（逐卷一行）。

## 二、逐卷（章）深读
### <卷/章名>
- 本卷讲什么（2-5 句，术语随文解释）。
- 核心判据/口诀：源L123：`逐字引文` → 白话释义。
（逐卷推进，不许跳卷；大部头合并稿按卷分 ### 小节。）

## 三、可用判据清单
| # | 判据 | 书源引文（逐字） | 位置 | 本项目现状 | 建议 |
|---|---|---|---|---|---|

现状取值：`已入库(指到文件/表)` / `部分` / `缺失` / `不适用(无对应学科)` / `未核`。
引文列的写法同 §二：源L45：`……`。

## 四、对勘与口径分歧
- 与对勘本/其他书的分歧（如子平 vs 滴天口径）；本项目以哪本为准、为什么。
- 无则写"本批内无直接冲突"。

## 五、不适用与存疑
- 书源明写否定（"不宜用X"）→ 本项目留空是正确行为，登记为不适用；
- 存疑/未读懂处如实登记，禁止脑补填充。

## 六、优化建议
| ID | 目标 | 现状 | 建议 | 验收方式 | 优先级 |
|---|---|---|---|---|---|
| OPT-<work_key>-01 | <学科/文件> | 缺失 | … | 单测+对齐分不回归 | P1 |
```

**硬性规则**（机械门逐条验收）：

1. **引文逐字**：`源L行号：`反引号引文``——引文必须是该书源**被引那一行**的逐字
   子串（含标点原样拷贝，不许增删改字、不许跨行拼接）。行号以编辑器 `cat -n` 口径
   为准。写完必跑 `python tools/check_source_readings.py --doc <文档路径>` 自检到 EXIT=0。
   - **跨行表格行（2026-10-07 补注，源 `OPT-qimen_tongzong_dz-08`）**：空格对齐的
     表格排版转录成 `.dz.txt` 后**极易错行**——同一张表被拆成多行（如
     `qimen_tongzong_dz` 源 L113-114 六仪击刑、L28-39 目录、L151-154 值符值使图）。
     这类行的引文必须 ①**单行取、绝不跨行拼接**；② 逐行用 `cat -n` 复核，
     确认行号落在预期那一行；③ 若一条内容横跨两行，**分两条引文写**（各带各的行号），
     不得拼成一条。已知跨行表格行须在 §五 登记（性质 + 行号范围 + 影响面）。
     逐字门 `check_source_readings.py` 已覆盖此类行——它按 `源L<num>` 精确回该行取子串，
     拼行或错行都会被判红。
2. **多文件著作**（如六壬大全 11 份卷文件）须在 §一 给图例：`- J3 = liu-ren-da-quan-juan3.wikitext.txt`，
   引文写作 `源J3L45：`……``。
3. **深度下限**：整部书 ≥120 行 / ≥8 条引文 / ≥3 个 `###` 小节 / §三 ≥5 行判据；
   tiny 著作（登记表 `tiny:true`）减半。引文上限 200 字。
4. **OPT 行 ID 挂著作**：`OPT-<work_key>-NN`，六列固定，P0=数据缺陷级 / P1=高价值可落地 /
   P2=锦上添花 / P3=登记不动（超范围或证据不足）。至少 2 条——**确无新增判据的书**，
   把"对勘差异/版本提醒/不动手理由"本身写成 P3 条目，不得空表。
5. 文档内**不要**出现示例假路径；引用仓库文件一律真实路径（死链门会扫 docs/）。
6. 学科归属（现行两科在册，其余为历史归档文本）：六爻`liuyao`、梅花`meihua`、八字`ming`、大六壬`liuren`（骨架无吉凶断语——
   书源吉凶断语一律标"narrative 候选/超出骨架"，不得建议塞进结构层）、择吉`zeji`、
   紫微`ziwei`、灵棋经`lingqi`（124 课表逐字书源）、小六壬`xiaoliuren`。
   无对应学科（奇门/太乙/易占/通纲/杂占）：现状标 `不适用`，判据照录，
   价值在"为将来扩科留底"。
   > 注：太乙/大六壬相关文档已移至 archive/（随学科收缩一并归档）。
