## 一、书目与版本

元·李清庵（号莹蟾子）撰。卷首保八序署「大德丁未 五月望日 洛阳后学保八序」
（源L13：`大德丁未 五月望日 洛阳后学保八序`），即元大德十一年（1307）。李清庵
即元代道士李道纯（都梁人，南宗白玉蟾一系丹道家，《中和集》作者），此书是他
以理学「明本体用」框架整理市肆卜筮法的通俗筮书；序言自评其旨：
「旨趣与市肆间卜筮之书大同小异」，而方法主张
源L11：`必先明本，次当明体，变通明用`，定位为
源L11：`尚占者，学易之枢机也`。

主源形态：三卷十八部（部下称「凡某章」），总目 L16-172 与正文一一对应，
每部一章至十二章不等。体例三式：卷上「图局部」「旁通部」以图表横列取象；
「发端部」「决断部」以短诀+例说立装卦与断卦骨架；卷中九部与卷下断例全是
七言歌诀体（逐句一断）；卷下八宫「立成章」是表格化纳甲排盘。歌诀体意味着
判据密度极高，但断语多为定性联句，抽取时须区分「结构判据」与「事类联想」。

## 二、逐卷（章）深读

### 卷上·图局部与旁通部（L179-438）

图局部把周敦颐太极图说改写成占筮导论（无极→太极→两仪→四象→八卦→乾坤六子→
纳甲→纳音→五子归元），其中「天干纳甲图」与京房纳甲全同（乾纳甲、坤纳乙、
艮纳丙、兑纳丁、坎纳戊、离纳己、震纳庚、巽纳辛，乾又纳壬、坤又纳癸）。
旁通部是全书判据密度最高的表区：「六位例」用一张横表把六爻位次在三十余个
占类下的取象一次列尽（占雨六位=雷电风雨云雨、身命六位=足腓股腹心首、
住居六位=井灶房屋仓库廊厅门户……）；「月建六神例」按月起六神、「日建六神例」
按日干起六神（与通行一致）；「八节休旺例」给出旺相胎没死囚休废**八态**轮转表，
比通行五行五态（旺相休囚死）多出胎、没、废三态；余四表为逐月/逐日神杀、
合刑杀、四时神杀。这些表是元人把市肆筮法「标准化」的直接证据。

### 卷上·发端部（L440-518）

装卦十二法是全书机械骨架。一、以钱代蓍：源L445：`以钱三文，熏于炉上`，记祝辞
与掷法，「一背为单画，二背为拆画，三背为重画0，纯字为交画╳」，成卦次序
源L445：`自下而上，三掷内卦成。再将钱炉上熏过，复求外卦，圆成一卦，而断吉凶`——
与《京氏易传》四库提要记三钱法及引擎铜钱摇卦口径完全一致。三、上手法以
源L455：`单单单乾为天，拆单拆坎为水` 八句尽纳八卦；四、重卦例列八宫各八卦
（八纯上世、一世~五世、游魂四世、归魂三世）；六、起世应：
源L484：`八纯卦，世上；初爻变，一世卦`，应爻位次口诀齐全，并立立场
源L485：`彼为应，世为我。应为晦，世为贞`；七、飞伏例明两系并用：
源L490：`持世纳甲为飞神，本宫纳甲为伏神`，八纯与归魂则「以本宫持世为飞神，
相配卦持世为伏神」，配对四组
源L490：`乾与坤，坎与离，震与巽，艮与兑，皆相配也`——这是京房对宫系与后世
本宫系的过渡形态；八、身命例立世身法：
源L495：`子午持世初为身，丑未持世二为身`，六句按世爻地支定位身爻，末句
「占卦人本肖属（注1）为命」以生肖为命（注号残留，见 §五）；十、定六亲以
「本宫所属为我」，源L504：`生我为父母，我生为子孙，克我为官鬼，我克为妻财，比和为兄弟`，
并补定位细则
源L505：`常以本宫所属为我，纳甲所属为彼`——与引擎六亲算法同构；十一、定六神：
源L511：`甲乙日起青龙，丙丁日起朱雀`，与引擎 get_six_spirit 一致；十二、论四直：
源L516：`年建天符太岁居，月建青龙为直符，日建传符宜发动，时辰直事次传符`——
把年月日时四值全部请进卦中，是本书最具特色的扩展（火珠林只用日月）。

### 卷上·决断部（L520-579）

六章断例全部歌诀化：六亲断例逐亲给「持世吉凶+化出六义」两层（如
源L525：`父母持世及身宫，旺相文书喜信通`，父母化子进人丁、化财宅长忧；
源L526：`子孙持世为福神，事成忧散谷财荣`，谒贵求官反不亨——子孙持世的
双面性在此定调）；六神断例逐神给「发动+持五行+落空」三因子组合
（源L534：`发动青龙万事通，进财进禄福无穷`，惟忌临金与落空）；天符/直符/
传符三章是四直体系的断语落地（年建动爻为天符、月建为直符、日建为传符，
各有五行六神组合歌诀）；神杀断例把旁通部神杀表串成口诀（问喜宜天喜、
病遇天医瘥、往亡休出入、三丘并五墓飞廉及浴盆四般休问病）。

### 卷中·三材部（L582-668）

五部天时地利歌诀。阴晴雨晦章以八卦+六神+卦名断晴雨，开篇
源L587：`乾为天象震雷龙，坎兑为阴巽起风`，结以应期（水旺龙生身对冲日）。
禾苗田地章立「应为种子世为田」的对位模型，源L607：`应为种子世为田，世应相生获十全`，
以财爻旺衰定丰歉、子孙+青龙为大福。住居宅地章按卦取宅象
（源L622：`住宅休占火泽睽，鬼临人口定分离`），移徙章以动爻定迁，
源L637：`迁居先以动爻求，动爻旺相决无忧`，安静与乱动的对断
源L641：`六爻安静休搬动，乱动移居又不休`，并有化出爻定迁后吉凶
源L644：`鬼化子孙移富贵，财爻化鬼住安康`。坟塚章分未葬/既葬两截断
（未葬亡在外、既葬内是亡），源L648：`若占坟塚静为强，发动之时便反常`，
穴色按五行取、六神持世定地形，末句有脱文（§五）。

### 卷中·人事、三教、营生、疾厄四部（L671-913）

人事部：身命章立「卦内为身外为命」「世为身兮应为命」的双身框架；
六亲章逐亲配六神吉凶（两重父母过亲房、玄武子孙男盗女猖）；婚姻章以
「内身阳鬼丈夫持，外应财阴总是妻」取用并按卦论性情容貌；胎孕章以子孙为用，
结以源L729：`欲扣孩儿分娩日，胎神冲破子生方`。三教部四类（僧道儒蒙教）占法
自成体系，属占域扩展。营生部：求财买卖章总纲
源L789：`求财交易财为主，发动临身财必取`，应期法
源L803：`应在身财生旺日`；行人章以「身爻发动是行人」为纲，逐爻位定行程，
结「子落空亡身入墓，行人准定不回乡」。疾厄部：疾病章总纲
源L853：`疾病先将身命看，逢龙见子放心宽`，并录「两重官鬼因劳复，鬼化为兄病不宜」
等化出断；医药章以子孙为药为医，源L867：`子孙出现是医人，生世生身药必灵`，
五行子孙定剂型；盗贼捕盗两章一反一正：占盗
源L877：`占盗先推财鬼乡，财爻安静便无妨`，世次定远近
源L881：`一世二世亲邻盗，三世四世不离乡，五世六世他方鬼`，捕盗独用飞伏对冲
源L891：`捕盗先推飞伏神，飞伏相生贼不真`——飞伏在此被用作捕盗成败判据，
是全书飞伏最「实用」的一处；公讼章以身杀（劫杀）旺衰定曲直输赢。

### 卷下·八宫立成与八卦断例（L919-1396）

八宫各二章：立成章逐卦给「上爻→初爻」纳甲干支、六亲、世应身位、飞神、
伏神、月卦（如乾为天「四月卦」）；断例章每卦四句象赞+八句断辞。立成表
是本书对六爻引擎最有工程价值的部分：它与 core/yishu_core/symbols.py 的
NAJIA_BRANCHES/NAJIA_STEMS/EIGHT_PALACES 构成**两个独立真值源**——
例如天风姤立成初二三爻辛丑辛亥辛酉、上三爻壬午壬申壬戌，与 NAJIA_BRANCHES
巽「丑亥酉」+乾「午申戌」逐位一致；八宫序、游魂归魂位次亦与 EIGHT_PALACES
全同（乾宫：姤遁否观剥晋大有）。八百年来两个传承体系的纳甲逐格可互校，
这是防内核表漂移的现成外部证据（OPT-01）。断例章断辞则属叙述层素材，
不宜直接入机械判据。

### 卷下·通变部（L1398-1478）

极变、单卦变通、重卦变通、六十四卦变通、时变、事变六章。单卦变通演乾
八变反本；重卦变通演乾宫**十六变**全序列（一世~五世、游魂晋、
「伏藏」火山旅/火风鼎、归魂大有，再变出离/噬嗑/颐/益/无妄/同人，
共九升七降十六变反本），并注明本书取用范围：
源L1442：`尚占只用八卦，自一世至五世，游魂便到归魂也`——即占筮只用八宫正变
八卦，十六变属义理推演；六十四卦变通则枚举乾一卦变六十四卦、
源L1447：`八卦升降变六十四卦，每卦各有六十四变，计四千九十六卦`，纯数学
完备性展示。时变章把十二消息卦配月配日（复十一月~坤十月）。收束句
源L1478：`卦者，事也。爻者，事之时也`——「卦主事、爻主时」是通变部的方法论
总纲，与六爻应期体系（事类由用神、时点由生旺冲合）同构。

## 四、对勘与口径分歧

无对勘本（登记表 crosscheck 为空）。本节录三书互证与一处核心分歧：

1. 身的定义三说并立，不可混用：火珠林占身命章「世爻为命，月卦为身」
   （huozhulin_dz.dz.txt L134）；本书发端部世身法（L495）+人事部「卦内为身外
   为命」「世为身兮应为命」（L679-680）；《卜筮正宗》安月卦身诀（引擎现行，
   effects.py:1052）。月卦身按世爻阴阳从子/午月起数，世身按世爻地支定位——
   两者同一卦可给出不同身爻。引擎只实现月卦身一套，读古籍案例时凡遇「身」
   须先辨系，防止跨系误判（OPT-02）。
2. 钱法互证：本书「一背为单、二背为拆、三背为重、纯字为交」与《京氏易传》
   四库提要「两背一面为坼、两面一背为单、俱面为交、俱背为重」按计数基准
   换算后完全一致，亦与引擎铜钱摇卦一致——祖源、近源、今法三点一线。
3. 飞伏系别：本书是京房对宫系（八纯/归魂配相合卦）与后世本宫系（余卦配本宫
   首卦纳甲）的**混合态**；与《京氏易传》纯对宫系、《卜筮正宗》纯本宫系均
   不同。引擎采本宫系，三书口径差异已并入京氏篇 OPT-03 登记。
4. 立成表与 core 表逐格抽查一致（姤、复、乾、坤四卦纳甲干支；八宫序与
   游魂归魂位次全同）——支持把立成表固化为 core 表的外部对拍源（OPT-01）。
