## 一、书目与版本

**作者与成书**：相传为宋代徐子平（徐升／徐大升）所撰，后世托名。《渊海子平》是现存最早以"日干为主"论命的八字专著——此前李虚中推命以年为主，至徐子平转为以日干为命主（"子平之法"因此得名）。全书收录大量歌诀（《天干地支暗藏总诀》《又地支藏遁歌》《论天干地支暗藏总诀》《性情》《疾病》等），奠定了"子平八字"的全部基础框架。

**全书性质**：子平八字的总源头——定下"日干为主、月令为提纲、生克定十神、大运看支岁君看干"的可执行框架。与《穷通宝鉴》（调候细则）、《滴天髓》（原理总纲）、《子平真诠》（格局层次）构成命科四大部。本项目 chart.py／pattern.py／evaluate.py 的整体结构渊源即出于此书。

**主源形态**：殆知阁转录单文件，无显式卷目（以篇名分段）。主要篇目：基础篇（五干属阳／属阴／天干地支暗藏总诀／又地支藏遁歌／论五行生克制化／论日为主／论月令／论太岁吉凶／论大运／论疾病／论性情／干支体象天干／干支体象地支）＋十神篇（论伤官／论食神／论正财／论偏财／论正官／论偏官／论七杀／论官星太过／论官杀混杂要制伏／论印绶）。已知缺陷：① 部分歌诀 OCR 讹字密集；② 十神名有古今差异（倒食＝枭神／败财＝劫财）；③ 条文有错简。

## 二、逐卷（章）深读

### 基础篇（L1-145）——子平基础框架：日干／月令／十神／大运

本卷起首"五干属阳／属阴"逐干给出十神对应（甲见甲为比肩、见乙为劫财……），次以"地支藏遁歌"定藏干，再以"论日为主／论月令／论太岁吉凶／论大运"定下"以日干为命主、月令为提纲、大运看支岁君看干"的子平分析框架，末以"论疾病／论性情"将五行生克映射到身体与性格，再殿以"干支体象"十二首地支诗给出各地支的性情取象。术语随文白话：**日干为身主**、**月令为提纲**、**大运看支（以地支落宫）、岁君看干（以太岁天干落宫）**、**日干强弱以月令分旺衰**。

核心判据：

- 源L53：`予尝观唐书所载，有李虚中者，取人所生年月日时干支生剋，论命之贵贱寿夭之说` → 追溯推命术史：李虚中以年为主论命已见于唐书；子平之法到宋代方才出现。
- 源L55：`以日为主，年为本，月为提纲，时为辅佐。` → 四柱分工：年＝根、月＝提纲、日＝身主、时＝辅佐——engine 取用层的基础架构。
- 源L42：`子宫癸水在其中，丑癸辛金己土同；寅宫甲木兼丙戊，卯宫乙木独相逢。` → 地支藏遁歌（上四句）：子丑寅卯藏干——engine CANG_GAN 表的源。
- 源L69：`太岁乃年中天子，故不可犯，犯之则凶。经云：『日犯岁君，灾殃必重；五行有救，其年反必招财。』` → 太岁章总纲："犯岁君"＝日干克流年干；有救则反招财，无救则凶。
- 源L84：`子平之法，大运看支，岁君看干，交运同接木。` → 大运起法核心口诀：大运以地支定吉凶、岁君以天干论——engine 大运流年的算法基础。

### 十神篇（L148-333）——伤官／食神／正财／偏财／正官／偏官／七杀／印绶

本卷逐十神给出定义、喜忌、诗诀。每神先立"我生为伤食、我克为财、克我为官杀、生我为印"的关系，再以"诗诀"给快速判据。术语随文白话：**伤官**＝我生彼（阳见阴／阴见阳）；**食神**＝我生彼（阳见阳／阴见阴）；**比肩劫财**（劫财＝败财）；**正官**＝阴见阳／阳见阴＝制我身；**偏官**（七杀）＝阳见阳／阴见阴＝杀身之物。

核心判据：

- 源L149：`伤官者，其验如神。` → 伤官章开篇定位——源L150续：伤官务要伤尽；伤之不尽，官来乘旺，其祸不可胜言；伤官见官，为祸百端。
- 源L150：`伤官务要伤尽；伤之不尽，官来乘旺，其祸不可胜言。伤官见官，为祸百端。` → 伤官总则。
- 源L179：`火土伤官宜伤尽；金水伤官要见官` → 伤官"伤尽"的五行差异：火土宜伤尽、金水反喜见官。
- 源L213：`食神者，生我财神之谓也；如甲属木，丙属火，名盗气，故谓之『食神』。` → 食神定义：食神＝财源。
- 源L229：`何谓之正财？犹如正官之意；是阴见阳财，阳见阴财。大抵正财，吾妻之财也。` → 正财定义：阴见阳／阳见阴为正财＝妻财。
- 源L254：`然而偏财者，乃众人之财也，只恐兄弟姊妹有夺之，则福不全；若有官星，祸患百出。` → 偏财定性（众人之财）；兄弟夺之则福不全。
- 源L268：`夫正官者，甲见辛之类；乃阴见阳为官，阳见阴为鬼，阴阳配合成其道也。` → 正官定义。
- 源L293：`夫偏官者，盖甲木见庚金之类；阳见阳，阴见阴，乃谓之偏官，不成配偶` → 偏官定义：阳见阳／阴见阴＝不成配偶＝偏官。
- 源L344：`所谓印？生我者，即印綬也，经曰：『有官无印，即非真官；有印无官，反成其福。』何以言之？` → 印绶定义。

### 十神格局与神煞（L315-342）——制伏论／官杀混杂辨正

本节论"七杀须制伏""官杀混杂要制伏"，再以诗诀给七杀格各日干细则。术语：**七杀有制则为偏官、无制则为七杀**——经典的"有制／无制"判据模式。

核心判据：

- 源L316：`夫七杀者，亦名偏官，喜身旺合杀、喜制伏、喜阳刃；忌身弱、忌见财` → 七杀总原则。
- 源L340：`官星要纯，不要杂。` → 官杀混杂章定论——源L341续：若有金或庚申，则混杂为杀；须行火乡制伏，则发福。

## 四、对勘与口径分歧

**与对勘本（wikisource）的差异**：

1. **藏干表**：主源 L42-43 地支藏遁歌与 wikitext 版逐字一致。engine CANG_GAN 表取值与歌诀一致——"同一批表曾在三个文件里各存一份且取值不一致"的技术债务已通过与 symbols.py 迁入基本解决。
