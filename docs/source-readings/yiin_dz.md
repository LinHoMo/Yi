## 一、书目与版本

**作者与成书**：卷首谢三宝序称曹氏父子之书源出"其家君游南子之传"，源L6：`上究连藏，下逮京焦，傍通壬甲，广采占歌，作为易隐，凡十万余言`——即上探《连山》《归藏》，下及京房、焦赣，旁通六壬遁甲（壬甲），集占歌诀而成。成书当在明清之际，通行题为清初辑本；本转录本每卷题"东粤游南子曹九锡辑 男横琴居士璿演"（源L685，卷五作"睿演"）。

**卷帙结构**：卷首 + 八卷，共十八类高层占法。卷首为总纲（图式、总断、起例、神煞表，L1-683）；卷一、卷二身命占；卷三、卷四家宅占（续迁移、树艺、育蚕、六畜、奴婢、脱祸、征战）；卷五坟茔、晴雨、朝廷、年时；卷六婚姻、胎产、痘疹、求嗣、延师、觅馆、投师、小试、乡会试、殿试、武试、官禄、文书、谒贵；卷七行人、出行、舟行、谋望、求财、贸易、开店、寄物；卷八疾病、讼狱、逃亡、遗失、盗贼。卷首目录（L9-51）末自注："卜筮之道惟身命，家宅坟茔婚姻行人疾病数者尤难，故弁之于首，以示所重"（源L52）。

**参引源流**：易隐参引书目（L54-92）列约百种，四大源流清晰可见：京房系（《京氏易传》《火珠林》《海底眼》）、管辂系（《照心神鉴经》《管公问答口诀》——书中大量"管公口诀"皆出此）、耶律氏/刘伯温系（《锦囊集》《黄金策》《毕法赋》）、及郭璞（《洞林》《八神筮法》）、袁天罡、李淳风（《占灯法》）等。张星元《易林补遗》两篇总断全文收录。

**体例**：全书以"鬼谷分爻"（六爻逐位配事象）+ 分节短断 + 附断例为骨架。断例 30 余例皆标干支四柱（多为"庚寅年""己丑年"）、卦名与逐爻推理，是书内自带的"回归样本"；其推演路径（伏神、墓绝、六神、应期）与本仓库 `disciplines/liuyao/scripts/` 的五步推演高度同构，但占法分层（身命/家宅/坟茔逐物取象）远超本项目"一卦一事"契约（详见 §五）。

## 二、逐卷（章）深读

### 卷首（L1-683）：总纲——图式、总断、起例、神煞

本卷四层：①基础图式（八卦象例、五行生克、干支所属、六神六亲生克，L94-137）；②三篇总断（刘伯温总断 L139-140、张星元总断 L142-143、京房《海底眼》一爻动变断 L145-151）——三断分别立"日月岁权柄"总纲、"飞伏变冲"纲要与"六亲动变"断语库，且海底眼后明言适用边界；③断法集成（期日捷诀、习卜先读易说、取易辞断法、身命凶卦、化墓绝卦、反吟卦、十六变卦，L153-184）；④排盘起例与神煞总表（纳甲、安世应、日辰伤世应卦、安身诀、月卦身、飞伏神、六神起法、纳音、气候辅卦、阴阳升降、长生定局、年月日时神煞百余项、进神退神、太岁歌、天中煞、刃星辨、贵马德合辨、刑害破空辨、以钱代蓍、太极丸、占戒，L186-682）。

核心判据：

- 源L140：`日辰为六爻之主宰，喜其灭项以安刘。月建乃万卦之提纲，岂可助桀而为虐。最恶者岁君，宜静不宜动。` → 日辰主宰、月建提纲为六爻通则（引擎已内置日月权重）；"太岁宜静不宜动"是把岁君列为第三层权柄、且以动静先分吉凶——引擎无太岁规则，见 OPT-yiin_dz-04。
- 源L143：`太岁主历年之事，时辰掌即日之权。` → 四直分权：太岁管年、月将管月、日主管日、时辰管时；这是"占事时间跨度决定何直为主"的明确表述，对应 `disciplines/liuyao/scripts/liuyao_timing.py` 的应期分域，未核其是否已分层。
- 源L143：`爻有伏吟不吉，卦有反吟最凶。归妹变随为例，小畜之姤皆同。` → 张星元口径的反吟是**狭义卦名倒置**（归妹变随、小畜变姤、谦剥互变、既济未济互变），与通行"支神往复"反吟不同（详见 §四）。引擎 `disciplines/liuyao/scripts/effects.py` 有 liuyao.fanyin_fuyin 规则，采用何口径未核。
- 源L151：`此京房断法，试罔不验，若卦有两爻动，便不准矣。` → 《海底眼》六亲动变断的**适用边界自限**：仅一爻动可用。引擎若引入此断语库必须带"独发"前置条件（与 liuyao.dufa_dujing 独发/独静规则天然衔接）。
- 源L154：`金喜巳酉忌在寅，木喜亥子忌在巳，水喜申酉忌在午，火喜寅卯忌在申，土喜午申忌在亥。` → 周仲高期日捷诀：五行用神各自的喜忌日支，属"用神五行 → 喜忌支"的直接映射表，可核 `liuyao_timing.py` 有无同类判据（未核）。
- 源L162：`六爻安静者，以本卦彖辞断之。一爻动，以动爻之辞断。两爻动，取阴爻为断，阴主未来故也。` → 取易辞断法：动爻数决定取辞位（两爻取阴、三爻取中、四爻取下静、五爻取静爻、六爻乾坤用九用六余取变卦彖辞）。这是机械可实现的"动爻数→辞位"映射，项目无对应规则（未核）。
- 源L171：`变卦与本卦倒置` → 反吟的本书定义：本卦与变卦卦名互倒。
- 源L172：`反吟谦(地山)共剥(山地)，归妹(雷泽)与随(泽雷)同，小畜(风天)之为姤(天风)，既(水火)之未济(火水)宫。` → 反吟四组实例（谦/剥、归妹/随、小畜/姤、既济/未济），窄于通行口径，见 §四。
- 源L168：`墓绝离化乾，坎艮坤之巽，乾兑变入艮，震巽化为坤。` → 化墓绝卦歌：四组"化出墓绝"的宫变组合（离化乾、坎艮坤化巽、乾兑化艮、震巽化坤），可与 liuyao.muku 墓库规则互参（未核引擎是否有"卦化墓绝"层级）。
- 源L175：`外戒卦，吉凶从外来。内戒卦，祸福从内起。骸骨卦，生则赢瘦，死不葬埋。棺槨卦，病必死亡。` → 京房十六变卦的断语：八宫各自十六变中外戒/内戒/骸骨/棺槨/血脉/绝命/坟墓等变卦各有定断（L176-184 给出八宫对照表）。纯京房遗法，本项目一卦一事不适用，但"棺槨卦病必死亡"类凶格与疾病占 L2361 死格同一系统。
- 源L216：`子午持世身居初，丑未持世身居二，寅申持世身居三，卯酉持世身居四，辰戌持世身居五，巳亥持世身居六。` → 安身诀：世爻地支定身爻位置，机械映射，registry 的 liuyao.guashen（卦身）规则未核是否含世身起法。
- 源L217：`世若不空不破，不须论身，世或空破，祸福方凭身象` → **身爻启用条件**：世爻不空不破时身爻不参与判断，唯世空破才凭身象断——这是身爻在断卦流程中的条件开关，比"无条件安身"更精细，见 OPT-yiin_dz-01。
- 源L220：`阴世则从五月起阳世则从十一月起，俱从初爻上，数至世便知何月卦，即是卦身也。` → 月卦身起法（阴世自五月、阳世自十一月起数至世爻），与安身诀是两套；并给出"进则诸事进益，退则百事退沮"的月卦进退断。
- 源L224：`飞伏者往来隐显之神也。飞为巳往，伏为将来。若卦内用神不空不破，不必更取伏神。惟六爻不见用象者方取伏神推之，伏克飞为出暴，飞克伏则伤身。` → 飞伏总纲：取伏的前提（用神不上卦）+ 伏飞生克四态（出暴/伤身/泄气/叨生，后文"伏生飞曰泄气，飞生伏而叨生。飞伏比和，则相助而吉也"）。registry 的 liuyao.fucang 已有伏藏/飞伏，四态标签未核，见 OPT-yiin_dz-02。
- 源L245：`雨水正月中寅木用事` → 逐月气候辅卦表（L244-252）按**节气**而非整月定用事干支与辅卦旺相（立春艮旺震相、雨水寅木用事、惊蛰甲木用事……）。月令分野细到中气，是旺衰判定的校准点，见 OPT-yiin_dz-07。
- 源L343：`长生诀，亦分衰旺。如旺静方可言之，若为日月动爻所伤，不可断为生旺也。` → 黄士琣长生诀使用限制：长生只论旺静之爻，受日月动爻伤者不得径断生旺——对十二长生判据（liuyao.shierchangsheng）附加前提；同行汤通玄曰"长生诀，以六爻自变出者为真"，即长生以本爻自化出为准、傍爻长生不可泥。
- 源L404：`今人只用四马，非也，马即冲破是也。` → 驿马口径自陈：主张马前十二神、马即冲破，斥通行四马为非；另 L630 分马之牡牝（寅申阳马力健、巳亥阴马驽钝）。少数派口径，引入须声明。
- 源L610：`卦中吉凶神煞，有气叠带者，若不犯旬空灾福应重，只一重者，灾福应轻，而无气空亡者不应。` → 神煞总表（L345-610）的总纲：神煞须"有气+叠带+不犯空"才重应。引入任何神煞前应先实现此权重规则，否则单神煞无从落断。
- 源L617：`甲子甲午为阳进神，巳卯巳酉为阴进神。又亥化子，丑化辰，寅化卯，巳化午，未化戌，申化酉，俱是。遇进神，则吉盛凶多也。` → 进神三组来源：干支组合（甲子甲午、〔己〕卯巳酉）与六组支化（亥化子等）皆为进神，功效"吉盛凶多"；退神同法（壬辰壬戌、丁丑丁未及六组支退）"凶衰吉灭"。注意"巳卯巳酉"当为"己卯己酉"之讹（L1865 互证，见 §四）。registry 的 liuyao.jintui_shen 未核是否含六组支化。

- 源L626：`悮作羊刃，又说无阴刃，错以禄前一位用之，刃星所以不验也。` → 刃星辨自陈门户：阳刃阴刃分阴阳干各取禄位所藏同类（乙刃在寅等），明斥通行"禄前一位"说为误。命理通行与本书互斥，见 §四。
- 源L632：`三合以中一字为主，前一字生而主发，后一字墓而主藏，三字俱全，为真三合。` → 三合结构学：中字为主、前字主发、后字主藏，三字俱全方真；缺一各有"有始无终/先难后易"的降格断。registry 的 liuyao.sanhe 未核是否有此真/假三合分层。
- 源L635：`三刑者，寅刑巳，巳刑 申，不逊之刑也。丑刑戌，戌刑未，恃势之刑也。` → 三刑分类学：不逊之刑/恃势之刑/无礼之刑/自刑（辰午酉亥），且"(三字不全者不成刑)"——三刑成立条件有明确前置（引文含原样衍空格，OCR 照录）。registry 的 liuyao.sanxing 未核是否判"三字不全不成刑"。
- 源L637：`冲破之爻，岁破之祸大于月，月破之祸大于日，日破之祸大于时。逢生不受，遇祸能招。又静逢冲为动，动逢冲为破。` → 破的层级与二义：岁>月>日>时；静冲为动、动冲为破。又引《黄金策》注立"多字眼"规则：两午则子不能冲、二丑则子不能合——与通行"一冲一不冲"的邻爻处理直接相关，registry 无对应规则（liuyao.yuepo/liupo 未核层级）。

### 卷一 身命占（上）（L684-871）

本卷立身命占总纲："凡占身命，有三重焉，世爻，身爻(月卦)，与本命爻"（L687），先看命爻（生年支/纳音）与世身命的生合刑冲，继以"身命八要"（祖业看大象、高卑看世位、刚柔看阴阳、六亲看用神、贵贱贫富看神煞、祸福看六神、吉凶看三限、发用看流年太岁，L696）分领后文。主体是**六亲逐类推命**：立"六亲真假"（本宫出现为真、他宫为假、真中假/假中假，L716）与"六亲取飞宫法"（以世为原点按生克关系飞定远亲，L728），然后逐节断祖业、高曾祖、父母、兄弟、妻妾、子孙、女婿、丈夫，卷末以六神入宫分断贵贱百业（L865-870）。

- 源L165：`遁卦刑伤多，姤咸贫贱老。` → 身命凶卦歌：以卦名直接断身命之凶（遁多刑伤、姤咸贫贱老、秋蛊冬蒙凶、八纯与壮妄图谋百不安等，全歌 L165）。卦名级凶格表，机械可查但属断语库性质。
- 源L719：`内亲以内卦本宫出现者为真，如内卦不现，则看内卦之伏神。如不现，又无伏者，则取飞宫论之。` → 六亲取用三层递进：本宫出现 → 伏神 → 飞宫。与引擎用神不现取伏的路径一致，但"飞宫"一层（按世爻生克飞定六亲）未核。
- 源L728：`飞位以世为主而推之。生世为父，父克为母。` → 飞宫六亲法的映射规则：生世为父、父克为母、世比为兄弟、世克为妻、世生为子……"大问小从世前一位数上去，小问大从世下一位数下去"，以一水二火三木四金五土之数定爻。这是把用神缺失场景补全的机械算法，引擎无对应实现（未核）。

**与本项目四段契约的对应**：六亲真假与飞宫法是 analyze 段"用神多现/用神不现"分支的扩展路径（liuyao.use_god_multi 之外的第二层补位）；断父母/兄弟/妻妾/子孙各节的"阴阳真假"分爻（阳宫阳爻为真父等，L828/L832/L839）机械可查，但断语本身属人物象意，只可作分题素材；六神断贵贱百业（L865-870）属职业断言，超出用神覆盖域，照录不实现。

### 卷二 身命占（下）·僧道占（L872-1086）

本卷续身命占的定量化与动态化：断贫富以纳甲积算给出数量级（L875）；六祸福以六神临太岁/月建/日辰分内外动断吉凶（L879-885）；三限法把一生分九十年配正/变/互卦逐爻行限（L891-917）；八岁君立"流年触发"观（L920）；断带疾延年、辩性情、辨身体容貌（鬼谷分爻配二十四部位逐格取象，L933-1011）；占断寿数并附四例（L1013-1047）；末附陈希夷安命宫十二宫法（L1049-1083）与僧道占七场景（L1086）。整卷是本书"占法分层"最重的部分。

- 源L875：`若乃家资之多少，则取财爻之纳甲，周先天甲己子午九，乙庚丑未八，丙辛寅申七，丁壬卯酉六，戊癸辰戌五，巳亥常加四之数推之。` → 纳甲积算定量法：财爻干支取数相乘、按大/中/小富换算进位，旺相加倍休如数囚死减半，太岁贵马益一倍月建益半。同法用于六畜（L1287）、田亩（L1240）、行人里数（L2048）、逃亡里数（L2579）、杖责数（L2491）、科甲名次（L1794）——本书全篇共用两套数字系统（纳甲积算+五行生数）。**口径警示**：输出"精确数额"违反铁律三的诚实口径，只可作量级素材（见 §五）。
- 源L879：`何谓逢恩，龙入水，雀入木，勾入火，蛇入木，虎入土，武入金，是也。` → 六神"逢恩"（六神得所临爻五行之生助）与"归垣"（源L879：`何谓归垣，春龙，夏雀，秋虎，冬武，三九月勾，六十二月蛇，为当权之归垣。`——六神按季节与爻宫两套旺衰）。引擎无六神旺衰规则（registry 20 条无），这是六神判据的唯一增量点，见 OPT-yiin_dz-05。
- 源L891：`正卦管三十年，变卦管三十年，互卦管三十年。每爻五年为一限，共九十年。` → 三限法总纲；大限五年一度从世爻天干起数、阳顺阴逆（L895），小限一载一宫（L898）。占法分层，照录不适用。
- 源L920：`福伏于吉爻之中，祸伏于凶爻之中，伏者不触则不发，故知祸福之发触，以流年之太岁也。` → 岁君触发观：卦限内伏藏的吉凶由流年太岁"触而发之"——把应期推到"限爻吉凶 × 太岁生克"的二维判定上，与 liuyao_timing 的应期思路同构，但以年为尺度。
- 源L1086：`若子财旺动者，卦六冲者，今虽出家，后必还俗也。` → 僧道占例：以子孙妻财旺动、卦六冲断还俗；同节立出家/在俗/建宫观/招徒/云游/修证/还俗七场景各取用神（出家看华盖孤辰临世身命而子空财绝，已出家以子孙为用等）。

**与本项目四段契约的对应**：本卷的"寿数断例"四例（L1017-1047）是书内唯一成组、带完整干支与终验结果的回归样本，其推演链（用爻旺衰→岁旬空→天克地冲→会局克用）可作 `liuyao_timing.py` 的测试素材；三限/十二宫/容貌二十四节属占法分层，照录判"不适用"；六神逢恩归垣是本卷唯一可直接进 analyze 的通则增量。

### 卷三 家宅占（上）（L1088-1154）

本卷立家宅占总则并逐物取象十节。总则分"安居来卜"与"临事来卜"两途：前者先看内外卦（内宅外人）、次看二爻宅五爻人（人克宅吉、宅克人凶）、再按六亲定宅中之人，最后逐位察窗床厕门户道路香火栋梁坟墓六畜；后者直接以六神持克断目下吉凶。十节各立用爻：宅基（卦身）、井（初爻/申金）、住宅（二爻/父母）、厨灶（二爻/妻财）、床（三爻逢交折者）、碓、门户（三爻单重正门/四爻外户）、坑厕（四爻玄武水兄）、香火（五爻福德），逐节以旺衰空破、六神、神煞、飞伏化爻推宅之形制与灾祥。

- 源L1147：`鬼临门户动，为门户鬼，占家宅大忌。` → 分爻定位+用神动克的标准格式示例：三爻门四爻户各临六神鬼动分断（雀鬼官讼、蛇鬼牵连、虎鬼疾病丧亡、勾鬼户婚田讼、玄武鬼穿窬）。分爻定位本身（二爻宅、三爻门四爻户、五爻人）是家宅占的机械骨架。

**与本项目四段契约的对应**：家宅占的"临事来卜"半途（L1091 末段：父动子伤畜损、兄动妻伤财损等六神持克断）与一卦一事的六爻通则同构，是逐物取象中唯一可并入 analyze 通则的部分；井/灶/床/门户等节的一物一断属 render 素材层，若做家宅分题可按分爻定位生成结构标签，叙述由 LLM 承担。

### 卷五 坟茔·晴雨·朝廷·年时（L1398-1639）

坟茔占三十节，为全书阴宅集大成：先以世爻身爻定买地成否，鬼谷分爻定各代坟位（L1407-1414），再以"山局山运"（三合局配本命行运）、形势（卦身取形）、坐山（世爻）、穴向（世冲者为向、墓合者为墓向）、前后妨害、人地论（内卦为地外卦为人）层层展开，续以已葬/未葬之穴、穴高低、案山（应爻朱雀）、明堂（间爻）、龙虎（青龙白虎爻）、后山（玄武）、龙祖（勾陈）、水口（六爻）、辨土色、辨穴中物、辨棺椁、辨葬法、辨坟多少（何房发何房绝）、侵地为坟、出殡、迁坟、客死客葬、辨凶亡、劫塚开棺，末为补遗与耶律氏断例（睽之归妹）。

晴雨占七法互参（五行：水动雨火动晴；六亲：占晴以子孙为用、占雨以父母为用；六神；天干；内外世应；八卦；期日），附鬼谷分爻占雨占晴两张与神杀表。朝廷占以"世爻所居之卦为国"，五爻天子六爻宗庙，初爻民二爻士三爻大夫四爻公卿逐级取象，立大象/国君/后妃/青宫/谏官/城池/帑藏/奸贼/分官/爻象十节，末立卜世卜年法。年时占以太岁为用断一岁灾祥（兄鬼蛇虎动伤世则九围灾变等），附咸卦一方年时断例。

- 源L1414：`巳葬之穴，以鬼为尸，鬼旺生合身世者吉，冲伤身世者凶。` → 已葬之穴的用神结构：鬼为亡人、父为家长、兄为卑幼、财为家业、子为祭主（L1438）；鬼旺生合身世吉、冲伤凶；又"鬼无气而世有气，巳非此地所荫也"——把坟地的"荫不荫"化为鬼与世的生克关系。
- 源L1566：`初爻民，二爻士，三爻大夫，四爻公卿，五爻天子，六爻宗庙朝廷也。` → 朝廷占爻位分层；配套"世爻为君，五爻亦为君""主上自占以世为用，臣庶代卜以五爻为用"的双取法。纯占法分层，不适用。
- 源L1599：`如世爻动变者，则日世爻数至变爻，以定其世与年也。` → 卜世卜年法：世动则自世爻数至变爻之数为世数与年数；卦变世不动则以正变二世爻数之；六爻安静则自所卜之年数至世爻。"则日"疑为"则自"之讹（OCR，见 §五）。

**与本项目四段契约的对应**：晴雨占七法（五行/六亲/六神/天干/内外世应/八卦/期日）是同一问题多法互参的典范，其"期日"节即应期通则；朝廷/年时属占法分层不实现；坟茔占中"辨坟多少、何房发何房绝"（L1480/L1435）的分房法是六亲分域判据，超出用神覆盖域，照录不实现。

### 卷七 行人·出行·舟行·谋望·求财·贸易·开店·寄物（L2024-2342）

行人占七节+四断例：来情（用爻应爻生合克世欲归、刑冲不欲归）、安危（空死墓绝胎重则死轻则病、六神分断途中之事）、囊橐（应爻用爻临青龙财福动获利而归）、所在（以支神定方位、卦身所生定何家、纳甲数定程途远近）、归期（动者三合六合日到、静取冲动月日、旺取墓日、伏藏取临值）、音信（应爻父母为用，父化空遗失化胎墓沉匿）、在外占家人来否。出行占四节（向方以世爻五行化受克定方向、行否、通塞、图谋）；舟行占六节（行否/舟具以父为船蓬六神配船位/舟子/风色以兄弟日辰为用/舟居安否/财利）。谋望占两节：可否成败（内克外世克应事可图、凡事嫌兄动喜福动、卦中无官诸事不成）；迟速（动速静迟、临卯酉速临辰戌迟、初二爻动速五动迟六动更迟），引尹逢头应期四诀。求财占七节+九种专占（空手/借贷/纠会/摇会/赌博/捕鱼/畋猎/开矿/索债）+八断例；贸易占三节（买卖时价/牙行应爻官爻/脱货以财爻生旺月日为脱卸之期）；开店占五节（可开否/本利/合伙/店面货物/收放）；寄物占以世应财爻定可寄与否。

- 源L2051：`凡用爻应爻动者，三合日到，或六合日到也。静取冲动月日起程，旺生月日到也。` → 行人归期法（卷七行人占五节）；与源L1556：`用动，则以六合之日为期也。用静，则以冲动之日为期也。`（晴雨占期日法）同一套"动合日/静冲日/伏值日"骨架——应期通用判据，registry 的 liuyao.yingqi_rules 未核覆盖差异，见 OPT-yiin_dz-03。
- 源L2168：`用旺还须墓日定，用休生旺日当成，用伏但看用值日，动逢合住待冲辰。` → 尹逢头断法四诀：用旺取墓日、用休取生旺日、用伏取值日、动而合住待冲——把用神状态（旺/休/伏/合）映射到应期取法，是应期判据最凝练的表述之一。
- 求财"得于何人"节（L2190）按本宫内外卦×他宫×六亲定财源之人，"得何财"节（L2193）按八卦十二支列财物清单（出燃犀集）；九种专占各有用神（借贷看财爻持世父空无券、赌博看内克外世克应、捕鱼看演禽癸亥为鱼等），是同类分题中结构最完整的。

**与本项目四段契约的对应**：求财占七节+应期四诀是本书与 `liuyao_timing.py` 对拍价值最高的部分；"多少"节的纳甲积算只可做量级素材（铁律三）；谋望"迟速"节的爻位迟速（初二动速、五动迟六动更迟、临卯酉速临辰戌迟）是机械映射，registry 无对应（未核）。

### 卷八 疾病·讼狱·逃亡·遗失·盗贼（L2344-2673）

疾病占九节+八断例：用爻（自占世身命、代占应、家亲按六亲、奴丁占家主以五爻）；生死（收凶格最全：随官入墓、财动助鬼、世应双空、财旺用空、世坐本宫墓/鬼墓/财墓、卦化墓绝、月破、忌神长生之日、黄泉杀、四灭卦、四没卦、棺椁杀恒益诸卦，并引僧一行按年龄取八卦用卦法）；病症（官鬼阴阳内外五行八卦逐层定位）；病因（六神鬼动定起病之由）；饮食（忌口按鬼支）；医药（应爻子孙为医药，脉象按月卦五行，治法按鬼五行宜灸宜针宜汤药，"治此经可治彼"五行克法）；鬼崇（阳神阴鬼、按宫与神煞定何鬼、十干鬼按食神禄位定祭品）；病起何方/何年月日（鬼长生之支定起病时地）。讼狱占七节+六断例：讼因（雀临六亲动分诉由）、准否（文书官鬼旺动可告）、胜负（内外世应生克定两造、鬼克世我输）、和息（六合易息六冲难和）、罪责（杖责数按五行数、六爻配枷杖徒流死罪、噬嗑明夷杖责屯蒙大壮囚击涣解事散）、审问、批评（官爻父爻动静定依拟驳回）。逃亡占六节（远近/向方/里数/匿何家/匿何地/见否）；遗失占五节（取用按财支与分爻、遗处、拾者、知情以福德动定问何人、见否）；盗贼占八节+断例（贼来日/贼进处/惊觉/何贼/何方去/知情/财藏贼隐/何日追获）。

- 源L2361：`用爻随鬼入墓者死。财动助鬼伤用者死。世应双空者死。财旺用空者死。` → 疾病生死凶格系列（同行连续十余格："鬼生命绝者死。鬼动化墓者死。月卦化墓者死。用化墓绝者死。用逢月绝者死。卦身墓于世者死也(损卦)……"并列明各格所属卦名）。**铁律三警示**：此类只能以"有…信号/偏向"口径进入叙述，且医疗事项必须提示专业意见；引擎只宜输出结构标签，不做死亡断言。
- 源L2361：`一岁至二十，男用艮，女用兑也。二十一岁至四十，男用坎，女用离也。` → 僧一行占病法：用卦不上卦或代占时按年龄段取八卦为用（21-40 男坎女离、41-60 男震女巽、60 以上男乾女坤）——机械可实现的取用补位规则，registry 无对应（未核）。
- 源L2376：`问祈禳是何神鬼，则阳鬼为神，阴官为鬼也。` → 鬼崇判据：阳官为神、阴官为鬼；再按宫与神煞细分何鬼（阳金鬼庵堂关圣、阴木鬼自缢疯疾之魂等），末按十干鬼之食神禄位定祭品方位（曹子虚法）。民俗断法层，结构可照录、祭礼不适用。
- 讼狱"罪责"节（L2491）把刑罚种类映射到爻位与五行（六爻枷号、三爻杖责、初爻夹棍、五爻徒罪、六爻流罪、金虎刑刃大杀死罪），并引《鬼谷百问篇》以亡神个数分徒流死——与"杖责数按一水二火三木四金五土之数"同属数量断法，口径警示同 §五。

**与本项目四段契约的对应**：疾病占的取用规则（自占世身命/代占应/家亲按六亲/奴丁占家主五爻，L2358）与病因六神断（L2367）是可复用通则；讼狱"胜负"节（L2485）的世应生克+日辰向背判据是纯结构判据，可直接对拍；鬼崇十干祭礼与病症忌口属民俗断法，只可作叙述素材且必须挂"仅供参考"口径。

## 四、对勘与口径分歧

本书**无对勘本**（registry `crosscheck` 为空），以下分歧皆凭书内自陈或与通行常识比对，结论均标"待对勘"，不得直接当仓库事实引用：

1. **反吟口径（重要）**：本书反吟为窄义"变卦与本卦倒置"四组（谦/剥、归妹/随、小畜/姤、既济/未济，L171-172；张星元总断 L143 同口径）。通行六爻（增删卜易一系）反吟为卦变支神往复（如乾变震、坤变巽等），覆盖远宽。引擎 liuyao.fanyin_fuyin 采何口径未核：若采通行口径，则本书四组是其子集，无冲突；若两口径并存，须在规则输出中注明所据。
2. **阴刃异说**：L626 自陈反对通行"禄前一位"刃法，主张阴阳干各以禄位所藏同类为刃（乙刃在寅、丁刃在巳等）。与命理通行互斥。引擎如引入刃星（用于身命/疾病），须声明采本书口径或通行口径，混用即口径事故。
3. **书内自相矛盾：进神"己/巳"**：L617 作"巳卯巳酉为阴进神"，L1865 作"鬼化鬼逢进神(甲子甲午己卯己酉)"。通行当为"己卯己酉"，L617 判为 OCR 之讹，引数据须以 L1865 与通行互证。
4. **纳甲表 OCR**：L202 离卦六爻作"巳巳/巳未/巳酉/巳亥/巳丑/巳卯"，"巳"皆当作"己"（离宫纳己）。本书**不能作纳甲依据**，以 `core/yishu_core/symbols.py` 纳甲支表为唯一真值源。
5. **长生口径**：L341 长生定局采"水土同宫"（水土俱申长生），与"火土同宫"派异。引擎十二长生取哪派未核，对拍时注意本书立场。
6. **驿马**：L404 主张马前十二神（"马即冲破"）、斥通行四马为非，L630 更分牡牝（寅申阳马、巳亥阴马）与"宜在世后"等细则。少数派，引入须声明。
7. **身/命两套起法并存**：安身诀（L216，子午持世身居初）与卦命诀（L644-646，卯酉持世命居初）起法不同，书内并存且注明"有命限或空亡死绝，十中难逃一二，占病者最要看也"（L647）。引用时须先辨"世身"与"卦命"两词，不可混同。
8. **文字讹误型**：L1599"则日世爻数至变爻"之"日"疑为"自"；L620"出唐一行子房筮法"疑为"唐一行、张子房筮法"两家；L869/L870 白虎玄武二段各有"(此处空一字)"脱字。此类只作校勘注记，不作判据。
9. **断例历法存疑**：全书断例皆标干支四柱，个别年份月日间的旬名标注或缺（如 L1930"庚寅年壬午月甲戌日"无旬名）或与月建序疑似不合，未逐例核历。断例可作推演路径参考，不可作历法依据。
10. **鬼谷分爻表逐占自带、版式不一**：家宅（L1093-1099）、六畜（L1286-1287）、晴雨（L1518-1535）、婚姻（L1646-1652）、胎产（L1717-1724）、考试/官禄（L1775-1781/L1799-1806/L1818-1825）、行人（L2029-2036）、出行（L2104-2110）等各有分爻表，且六畜表在转录中行序错位；引用"几爻为何事"必须取**该占自带**的分爻表，不可混用卷首或他占的表。

## 五、不适用与存疑

**占法分层（照录，判"不适用"）**：超出本项目"一卦一事"契约者一律照录不实现——身命三限九十年（L891-917）、大限小限行运（L895/L898）、安命宫十二宫（L1049-1083）、卜世卜年（L1599）、流年太岁推运（L709"若问一年之灾福……"分段法）。其价值在于"应期以什么时间尺度为主"的思想可被应期层借用。

**逐物取象（判"不适用"，分爻定位除外）**：家宅 22 节（宅基/井/住宅/厨灶/床/碓/门户/坑厕/香火/人口/道路/栋梁/墙垣/篱落/明堂/窗户/巷/仓廒/比邻/坟墓）、坟茔 30 节、身体二十四部位、性情容貌、晴雨鬼谷分爻——皆象意层断语。仅其中**取用爻定位**可作分题骨架出处（二爻宅五爻人、三爻门四爻户、间爻为媒为明堂、初爻足六爻头脑等）。

**神煞总表（L345-610，百余项，判"部分适用"）**：多数不适用；少数（太岁、天乙贵人、驿马、咸池、孤寡、天医、天赦、丧门吊客、天贼天盗）或可入神煞层，且必须先实现 L610 总纲（有气叠带/犯空不应）作为统一权重前提，单点引入无意义。

**铁律三约束类**：疾病生死死期（L2361）、寿数终寿之年（L1014）、数量断言（家资、亩数、里数、杖责数）——引擎只可输出"偏向/有…信号/结构上"口径的标签；医疗与重大决策必须提示以专业意见为准；数量一律不输出"精确数值"，只可给量级叙述并注明为古籍对齐语境。
