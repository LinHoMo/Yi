## 二、逐卷（章）深读

### 卷一·象数本要（L26-247）：择日的历法与符号底座

本卷不讲吉凶，只立「算得出来」的底座：天地形运、洪范五纪（嵗/月/日/星辰/厯数）、先天后天八卦、五行生克、甲历十干十二支、正月建寅的十二月辟卦、二十四方位与二十四气、节气时刻与晨昏朦景、五行用事与七十二候、闰月气盈朔虚、五行生旺、干支五行、纳音与纳甲、十二辰禽象、五虎遁五鼠遁、三合五合六合。

**辟卦—月建对应**（源L45-67 逐月）：正月建寅配泰卦、二月建卯配大壮……十一月建子配复、十二月建丑配临。这是「月建」的历法定义层，与卷四「月建＝阳建之神」（源L486）互为表里。

**五行长生以「土寄生于寅」立论**（源L126）：`木长生于亥火长生于寅金长生于已水长生于申土则亦长生于申寄生于寅` → 土长生于申而寄生于寅（与 `core/yishu_core.symbols` 现用「火土同长生（寅起）」不同——本书走「土从水」一路）。这是本项目已识别的**一处真实口径分歧**，登记于 §四。

**三合/五合/六合起例**（源L229）：`申子辰合水局亥卯未合木局寅午戌合火局巳酉丑合金局` → 与 `core/yishu_core.symbols.SAN_HE_GROUPS` 完全一致（唯一真值源已入库）。六合（源L234-235）以「月建与月将相合」立论，非干支相合，须与择日应用区分。

### 卷二·年神方位（L251-247 校：L251-347）：年层神煞与方位

本卷是**年层**神煞＋方位神，是择日盘的年背景。三层结构：

1. **三元九星层**（L253-265）：九星配九宫（休门一白、伤门三碧…），三元各 180 年一周期，「上元甲子中宫起一白，中元甲子起四绿，下元甲子起七赤」，年九星逆转、月九星顺行。
2. **年德岁破层**（L266-297）：岁德、岁干合、岁德合、岁枝德、太岁、奏书、博士、力士、蚕室、蚕官、蚕命、太阴、大将军、岁刑、岁破、岁杀、劫杀、灾杀。
3. **方位凶煞层**（L300-345）：伏兵大祸、官符、畜官、大杀、病符、死符、五鬼、大耗、小耗、黄幡、豹尾、飞廉、白虎、丧门、吊客、金神、破败五鬼、太岁巳下神杀出游日、五姓修宅。

**岁破定义**（源L297）：`明时总要曰嵗破者子年在午顺行十二辰是也` → 岁破＝太岁所冲之辰（与卷四「月破者月建所冲之日也与歳破义同」源L488 同构）。项目 `analyze.py` 的日支冲煞用的是 `core.symbols.CHONG_PAIRS`，年层岁破未落地。

**本卷的书写体例值得项目注意**：每条神煞都是「某家曰（定义＋宜忌）○厯例曰（逐月支表）○曹震圭曰（推衍原理）」三层。**「厯例曰」的逐月表是可机读的起例层，「曹震圭曰」是解读层**——项目若要落地年层神煞，须走「厯例曰」逐月表而非径取断语。

### 卷三·月事吉神（L350-479）：择吉第一权（吉神与黄道）

本卷是**月建层的吉神总表**，约 60 条，是《协纪辨方书》「义例」的前身。

**天德月德是全书最有 mechanical 价值的吉神**（源L356-365）。天德逐月（源L356）：正月丁、二月坤、三月壬、四月辛、五月干（亥）、六月甲、七月癸、八月艮（寅）、九月丙、十月乙、十一月巽（巳）、十二月庚——即正月至十二月对应 丁申壬辛亥甲癸寅丙乙巳庚。**此表与 `core/yishu_core/shensha.py` 的 `TIAN_DE`（寅丁/卯申/辰壬/巳辛/午亥/未甲/申癸/酉寅/戌丙/亥乙/子巳/丑庚）逐格相同**：项目已入库，且本书可作其**可核书证**（此前 `data/citations.json#gap` 记为「维基文库无公版可抓」的《协纪辨方书》在本书中已有对应条文）。

**天德的地支/四维口径是本书独有贡献**（源L358）：`按天德者三合之气也如正五九月建寅午戌合火局故以火为德正月丁九月丙五月干戌火墓在干宫也` → 四孟之月以阴干为德（天道惠其未生）、四季之月以阳干为德（惠其自墓）、四仲之月以四维之卦为德（变化成功）。此说与《协纪》源L40「天德乃月建三合五行中和之气…孟月用阴干季月用阳干仲月用库宫」**口径一致但论证更细**——两者可互注。

**黄道六神与月将黄道是同一套的两种叫法**（源L447）：`神枢经曰青龙明堂金柜天德玉堂司命皆月内天黄道之神也所直之日皆宜兴众务不避太嵗将军月刑一切凶恶自然避之` → 关键在「**不避太嵗将军月刑，一切凶恶自然避之**」：黄道是**结构上的压倒性权重**，不是逐项吉凶清单。这与铁律三精神相合，也与协纪源L4825「六黄道以位置得宜为吉…诸事皆宜而无专宜之事」互证。

**王日/官日/相日/民日/守日**（源L442）含一条**版本改名记录**：`王日者春寅夏巳秋申冬亥【今易为官日】` → 今本已互换名目，项目若录此条须注明用的是哪一套名（此即 §五存疑项之一）。

**三处「不采/ 有误」的自校**（本书的辨伪层，价值很高）：

- 源L463 阴阳不将：给出完整定义与「春冬巳不将秋夏戊不将」口诀，并明谓「阳将伤夫隂将伤妇隂阳俱将夫妇俱伤隂阳不将夫妇荣昌」——**以「伤夫／伤妇／荣昌」为断语，属解读层**。
- 源L471 鸣吠对日校勘：`惟甲午疑应作甲子葢甲子本与庚午对冲且既用庚子不宜幷用甲午也恐传者有悮` → **本书自己指出传写有误**，登记为存疑，项目不得径取甲午。
- 源L490 天罡河魁定义「魁罡者乃月建四杀之辰平收之日也」与洞源经「对七为冲隔三为破」的推衍。

### 卷四·月事凶神（L483-629）：择吉第二权（凶神与黑道）

本卷与卷三对读，是**月建层的凶神总表**，约 55 条。项目处置原则见 §五：凶神**只入结构标签与避方提示**，不作绝对断语。

**九空的口径在本书即已驳通书**（源L530）：`九空者墓库破散之神也库破则空冲则散假令寅午戌月火库在戌辰能冲散也亥卯未月木墓在未丑能冲散也申子辰月水墓在辰戌能冲散也己酉丑月金墓在丑未能冲散也` → 与《协纪》源L44「九空乃月建三合库地对冲之日…寅午戌月合火局火库在戌故以辰日为九空」**完全一致**，且本书明斥「今厯家所[传/与九坎九焦同行者非」（该句含一个私用区字符 U+EA5B，疑脱字，登记 §五），并于同句末补正「纪歳厯亦止是逆行四季」。**这是两书对同一规则的双重独立书证**——项目「九空＝三合库地对冲」这条口径同时有两部官书背书。

**独火即月害（六害）异名**（源L501）：`按独火与月害同亦名游祸又名六害` → 一名三神，同一物。这是项目**必须做异名归并**的典型条目（若分别立判据会重复计凶）。

**黑道六神与月建十二神同律**（源L590）：`神枢经曰天刑朱雀白虎天牢元武勾陈者月中黑道也所理之方所直之日皆不可兴土功营屋舍移徙逺行嫁娶出军` → 黑道六神与黄道六神在同一层级，只是权重方向相反；两卷六神（卷三黄道 + 卷四黑道）与卷五「黄黑二道」条三处重复，是本书的体例冗余，也是校验一致性的好材料。

### 卷五·日时总类（L633-797）：日层裁决总表

本卷是择吉的**算法层**，把年月日时四层与黄黑道、建除、二十八宿、空亡、防类总目收在一卷。

**月建十二神＝建除十二神，两名同实**（源L636）：`厯家以建除满平定执破危成收开闭凡十二日周而复始观所值以定吉凶每月交节则叠两值日其法从月建上起建与斗杓所指相应` → 与 `core/yishu_core.zeji_tables.jian_chu_of()` 的算法（月支起建、日支顺行）完全一致，项目已入库。

**吉凶四档的总判词是本书最重要的口径声明**（源L638）：`大抵凡日吉神多则吉凶神多则凶又各视其神之宜忌以为趋避亦未可以执一而论也` → 「未可执一而论」正是铁律三的古典表述：**吉凶随所遇诸神增减，不作绝对断言**。这条应作为项目择吉裁决哲学的书证。

**十二神吉凶档位**（源L638）：`按月建十二神除危定执成开为吉建破平收满闭为凶` → 除危定执成开为吉六神，建破平收满闭为凶六神。项目 `data/verdicts.json#jian_chu` 采的是**《协纪》+ 通行通书的事类宜忌口径**（每神各有宜/忌事类清单），与本书的**六吉六凶二档**不是同一层：前者可直接查表计分，后者只作粗判。**这是本项目与本书口径的真实差异，须登记 §四并给出取舍理由。**

**黄黑道起例以「寅申起子」立枢**（源L642）：`其法则寅申青龙起子卯酉起寅辰戌起辰巳亥起午子午起申丑未起戌顺行十二辰` → 与 `core/yishu_core.zeji_tables.qinglong_start_index()` 的 `(m-2)*2 % 12` **完全等价**（寅月→0=子，卯→2=寅…），项目已入库且本书提供了算法级书证。同行给出时辰值神口径（源L642）：`日起时则子日申时起青龙酉时为明堂依次顺数` → 子日申时起青龙，即时位偏移 +8；项目现用 `(h + start) % 12`（子时即青龙）。**此处与书源不合，须核**（登记 §四、§五）。

**二十八宿值日以「七元」起例**（源L660）：`故有七元之説一元甲子日起虚以子象鼠而虚为日鼠也二元甲子起奎三元甲子起毕四元甲子起鬼五元甲子起翼六元甲子起氐七元甲子起箕` → 一元甲子起虚（虚宿），二起奎，三起毕，四起鬼，五起翼，六起氐，七起箕；420 日一周，七元尽而甲子又起虚。**本书自陈锚点不可考**：源L660：`但一元起于何年月日则不可得而考矣` → 这直接支持项目改用**现代日期锚点**（`_XIU_ANCHOR = 2007-09-13 = 角`）的做法，而非硬套七元起点——本书自己都说不可考，项目更不该臆造。登记为 OPT。

### 卷六·用事宜忌（L799-911）：事类宜忌的落地层

本卷是**事类 × 吉神/凶神**的对照表，是《协纪辨方书》「宜忌」卷的直接前身，条目约 45 项。体例极稳定：「厯例曰凡某事宜〈吉神〉忌〈凶神〉○曹震圭曰正月宜…二月宜…」。

**出师条**（源L817）示范了兵事的多神叠加与长忌串：`宜天徳合月徳合吉期兵吉兵福兵宝宝日义日制日天马` → 宜七神并列（天德合、月德合、吉期、兵吉、兵福、兵宝、宝日、义日、制日、天马），同条忌「月虚大时大败大杀劫杀死气死神天狱天火兵禁五墓往亡四废四离四絶四穷四耗四击八专九丑月刑月害伐日专日及四杀日」等 24 项。**这种「宜/忌神名串」是可直接机读的结构化数据**，但项目 `data/verdicts.json` 目前只对建除十二神做了事类宜忌映射，尚未落地吉凶神串。

**嫁娶条**（源L872）：`宜不将日周堂值第堂厨灶日如遇翁姑而无翁姑者亦可用之` → 「不将日」＋「周堂值第堂厨灶日」双因子，且**含一条现代已废的判断**：值翁姑日则凶、无翁姑者可用。项目不涉合婚、且「周堂」为旧式嫁娶法，宜作文本参考不作判据（§五）。

**安葬条**（源L908）：`宜鸣吠日忌宻日重日复日建破平收日开日` → 鸣吠日（卷三源L468 已给全 14 日）与破土用的鸣吠对日（卷三源L470 给 10 日）**在本书卷六即可串成完整的安葬/破土判据链**。这正是 `docs/source-readings/xieji_bianfang_dz.md` 中 OPT-xieji_bianfang_dz-01（鸣吠日表全录入）在本书里可以直接解决的——**本书卷三已给出鸣吠日与鸣吠对日的完整日表**，无需再去协纪书源里挖。

**用事宜忌的哲学收束**（源L802）：`夫神煞之名不过即五行之生旺休囚干支之刑冲合防以为断耳` → 神煞只是五行生旺休囚 + 干支刑冲合防的**符号化别名**，其吉凶须还原到生克本原。这一句是官方对择吉神煞的定性总结，也是项目「神煞不加解释层权重过多」的最强书证；同段的批判性表述（源L802）：`术数之徒乃甚言其吉凶以骇众而震俗偶有所验羣焉信之` 更须如实登记——**官修本自身就带着对神煞滥用的警惕**。

## 四、对勘与口径分歧

**总原则**：本书（康熙五十二年，1713）早于《钦定协纪辨方书》（乾隆四年敕修，1739）。协纪正文多处回引本书（「考原曰」），故**冲突时以协纪为定本，本书作蓝本互注**——与 `docs/source-readings/xieji_bianfang_dz.md` §四「若有口径冲突，从《协纪辨方书》定本」一致。

**已确认的双书一致（可作对源互证）**：

| 规则 | 本书 | 《协纪辨方书》 | 判定 |
|---|---|---|---|
| 天德起例 | 三合之气＋四孟阴干/四季阳干/四仲四维（L356-L358） | 月建三合五行中和之气，孟月阴干季月阳干仲月库宫（L40） | 一致，书本论证更细，互注 |
| 九空 | 月建三合库地对冲之日，并驳通书（L530） | 同（L44） | 一致，本书与协纪各驳一次 |
| 阴阳大防压神 | 诸日虽遇天德月德黄道亦不可用（L786） | 同（L2306，逐字相同） | 一致 |
| 黄道六神权重 | 不避太岁将军月刑（L447） | 无专宜之事、当以时例为断（L4825） | 一致，措辞不同 |
| 鸣吠／鸣吠对 | 安葬用鸣吠日、破土用鸣吠对日（L907-L908） | 鸣吠宜破土安葬、鸣吠对宜破土启攒（L4826-L4829） | 一致；**本书已给完整日表，可直接补齐协纪 OPT-01** |

**真实口径分歧（须择一，登记在案）**：

1. **五行长生之土**：本书「土则亦长生于申寄生于寅」（L126，走土从水）；`core/yishu_core/symbols.py` 的 `TWELVE_GROWTH` 默认「火土同长生（寅起）」，注释已自承「与上表『土从水（申起）』并存是流派差异」。**本项目不裁决**：十二长生是命科资产，择吉不消费，改动会外溢到命科/八字，风险大于收益。仅登记（OPT P3）。
2. **建除十二神的是「事类宜忌」还是「六吉六凶二档」**：本书 L638 给二档粗判；《协纪》与项目 `verdicts.json` 采事类宜忌表（每神各有宜/忌事类）。**本项目以《协纪》事类表为准**（粒度更细、可直接对应用户诉求），本书二档降为交叉校验项——书源自身也说了「又各视其神之宜忌以为趋避亦未可以执一而论也」（L638），两套并存不冲突。
3. **黄黑道时辰值神起点**：本书 L642「子日申时起青龙」（时位 +8）；项目 `hour_god_index()` 用 `(h + start) % 12`（子时起青龙）。**这是代码与书源的不一致，须核**：本书是「子日起时」的另一种排法，协纪源L3528 回引本书同一句，未见另解。核现代通书黄历时须实测再定，**不在本稿擅改代码**（OPT P1）。
4. **独火的两种定义**：本书卷四 L501 判「独火＝月害＝六害」；而协纪源L4034-L4035 以「独火」为盖山黄道内的独火（另一套体系）。**本书是月建层、协纪引的是盖山黄道层，不同体系不可混用**；项目若录「独火」须标明取哪一层。

## 五、不适用与存疑

**不适用（项目留空是正确行为）**：

1. **五等用卦**：本书自陈「今厯无之姑存于此」（源L673）——卦气纳甲层级，通书正法不用，项目留空正确。
2. **灭日没日**：本书自陈「见于汉书详载于授时厯今厯无之」（源L690），项目无历表层，正确留空。
3. **男女九宫（合婚）**：本书自「男女九宫」（L346-L347）已明贬其说：源L347：`今隂阳家以为合婚之用殊无理解`；且《协纪》源L46 将男女合婚作「牵合非伦」请删。**两部官书同贬，项目择日不涉合婚是正确口径**（`data/citations.json#gap` 已按此登记）。
4. **用事宜忌中的旧式礼法条目**：「周堂值第堂厨灶日」「值翁姑日而无翁姑者亦可用」（L872）——旧婚俗，现代无对应；本书已给退路（无翁姑亦可用），项目作文本参考不作判据。
5. **兵事细则与官阶礼仪**（上册受封 L805、招贤举正直 L815、纳表上章 L818、覃恩 L809）——属官修礼制事务，非个人日常择日需求；**超出骨架**，不在八科任一科的判据层落地。
6. **三伏／二社／得辛龙治水**（L674-L679）——历法置闰与参考日，择日盘不消费，登记备查。

**存疑／未读懂处（如实登记，禁止脑补）**：

1. **L530 有一处私用区字符**：源L530 中「今厯家所<U+EA5B>与九坎九焦同行者非」一句，`所` 与 `与` 之间是私用区码位 U+EA5B（疑为「传」字残缺或「传」与后字「与」串行）。**本稿只引该行无此字符的前后两段（九空定义段与「纪歳厯亦止是逆行四季」段），不臆补该字**。
2. **「宻日」疑为「密日」**：源L908/L906 作「忌宻日重日复日」，《协纪》亦斥「密日」为荒诞不经。本书此字形为「宻」（宀+必），脱字/异体，**照录不校**。
3. **王日／官日名目已互换**：源L442 `王日者春寅夏巳秋申冬亥【今易为官日】` ——本书已自注今本名目与古本相反。项目录此条须标明取哪一套；本项目 `activity_names` 无此神，暂不消费。
4. **甲午疑为甲子之讹**：源L471 `惟甲午疑应作甲子葢甲子本与庚午对冲且既用庚子不宜幷用甲午也恐传者有悮` ——鸣吠对日表所含甲午日，本书自疑有误。**本项目按「照录原样 + 标注存疑」处理，不径改为甲子**。
5. **「天罗／地网／天空」贵人在本书的用法**（源L645、L648）——以先天/后天坤卦起贵人，含戊跨巳、壬跨亥等特殊规则，与通书单套阳贵表不同源。**本书两套并存（昼日之贵／暮夜之贵），项目只取通书那套**，此条判定标准确，本稿不采。
6. **「神在日」三十五日**（源L457）——本书列全三十五日干支；此即《协纪》源L98 力斥「荒诞不经」、请删之条。**项目按《协纪》定本正确留空**，本书此条只作互注证据（说明两书同源而《协纪》态度更严）。
