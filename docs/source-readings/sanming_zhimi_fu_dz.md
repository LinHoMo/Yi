## 一、书目与版本

源L3 提要：旧本题"宋岳珂补注"，但"珂所有着有九经三传沿革例、媿郯録、程史、金陀粹编、宝真斋法书赞、玉楮集诸书而不闻其有是书，宋史艺文志亦不着録"（源L3）；馆臣判断："程史中有珂与瞽者杨长论韩侂胄禄命及论幕官袁韶禄命一条其説颇详，则珂亦颇讲是事，或术家因而依托欤"（源L3）——**四库否定岳珂 authorship，归为宋人依托**。本书自元明以来诸家命书多引其文（如《兰台妙选》中指迷赋语），"即此本检勘并相符合，知犹宋人所为"（源L3）。原书一卷，四库采《永乐大典》辑本，岳珂之名削除不载。源L3：`书中所论大抵专主子平于夹马夹禄拱库拱贵辨论详尽往往为他家所未发而拱库一条尤称精晰`——书中专论子平，重心在**夹马/夹禄/拱库/拱贵**四事（OPT-01 关联）。

**体系定位**：本书为**子平专题赋体赋**，以"一气肇判两仪定位"起兴，系统归纳子平诸法。与其他纳音取象类书（李虚中/兰台/五行精纪）不同，本书严谨地以子平为框架、逐条演绎：两仪→五行→星辰→五常→支干→相养/相击→合冲→三元→干支组合→吉凶总断。判语层虽有吉凶命定（"夭""贵""夭折"等），但**纯结构占比较高**——可抽出大量的十神/禄马/学堂/旺衰结构标签。

## 二、逐卷（章）深读

### 两仪・五行・星辰（源L13 起）

源L13：`一气肇判兮两仪定位`→以"一气—两仪—五行—星辰—五常"起赋，为子平宇宙论前置。`五行周流兮万物从类`、`其丽乎天地为星为辰`→星辰为天之五行，在地为五岳在人为五脏——**天文/地理/人体配五行**一体三层。`其为乎人也五常五事在物之灵惟人为贵`→五行=仁义礼智信=人事五事（貌视言听思）。现状：core `BRANCH_ELEMENTS`/`STEM_ELEMENTS` 已备五行配天干地支，"五常五事"伦理映射未建。

### 支干否泰・纯杂清浊（源L13）

源L13：`粤自支干论其贵贱以逆顺定其否泰盛则复衰穷则更生有纯有杂有浊有清` → 以干支逆顺定否泰；`干为禄以支为命` → 干=权禄、支=资命——**干支分工**。现状：engine 以日干为我取干支十神为核心（`LIUQIN_TO_SHISHEN`），干支分工非主流判据但非冲突（OPT-02）。
源L13：`纯杂清浊者乃纯粹驳杂轻清重浊也盖人命欲纯粹而不欲驳杂五行欲轻清而不欲重浊纯粹轻清则为贵为荣驳杂重浊则主夭主贫`——纯粹/驳杂=吉凶分级。engine 通过 `strength`/`pattern` 输出格名但不量化纯粹/驳杂——差异登记。

### 相养/相击/夫妇/兄弟（源L13）

源L13：`相养所以相助相击所以相成`——相生为相养（吉），天冲地击有时反相成（贵格）。engine `pillar_relations` 标识相冲/相害但无"相成贵格"反转规则（OPT-03）。详见 OPT-03 附带。
源L13：`得者君臣之义以尅而推夫妇`——乙庚合为妻妇之合。现状：core 天干五合 `stems_wuhe` 已备，但"妇人尤宜"等伦理判语不进评分。

### 三竒遇贵/天乙最吉/攀鞍积财（源L13）

- 三竒遇贵，源L13：`三竒遇贵而推顺逆之详天乙最吉而分昼夜之主` → 三竒（乙丙丁/甲戊庚）须分顺逆（阳竒顺行、阴竒逆行）；天乙贵人分昼/夜贵人（丙丁昼贵在酉亥、壬癸夜贵在卯己——与李虚中命书天乙贵人同口径）。三竒"顺/逆"规则 engine 未建（OPT-04）。
- 攀鞍积财，源L13：`攀鞍主积财巨万偏官必出于杂流`→攀鞍=驿马前一位（马前六秀），生旺则积财；偏官重出变鬼。现状：驿马 `shensha` 已有，攀鞍/马前六秀层未建。
- 夹禄夹马/拱库拱贵，源L13：`夹禄夹马重职髙名拱库拱印必富必贵`→夹=虚拱；夹禄（如乙禄在卯见寅辰）、夹马（如亥卯未马在巳见乙巳辛亥）、拱库（墓库正印之地）、拱贵——**虚拱系列** engine 未建（OPT-05）。

### 凶格：财居八败/沐浴衰破（源L13）

- 财居八败，源L13：`财居八败则官爵歇灭运入阳刃则财物耗散`→纳音长生第八位=死败位，逢财=八败。engine 未建八败判据。
- 沐浴衰破，源L13：`沐浴衰防亲姻哭送骨肉颠倒亲戚分离`→ 沐浴=咸池=长生前一位。engine 有桃花（咸池）神煞但未建"长生前一位"沐浴定位。
- 月杀衰，源L13：`月防衰兮早嵗寒儒胎贵旺兮生于世胄`→ 月令衰则早岁寒儒；胎旺则出世家。engine 月令强弱已有，"早岁寒儒"命定断语不进评分。
- 三刑全，源L13：`三刑全则仆马惊蹶七煞聚则为官贬剥`→ 三刑全与"仆马惊蹶"——凶象结构注册不进评分。
- 主本休囚，源L13：`主本休囚行藏汨没`→ 主本（年日根基）休囚则一生汨没。engine 日主强弱已判但无"主本双弱"复合判定。
- 总论吉凶，源L13：`吉防相半进退流滞力微则徐行气盛则旋蹶` → 命有吉防参半，须分"力微/气盛"——engine 用 strength_score 量化，但未建"徐行/旋蹶"语义层。

### 总断：李广不侯与命运有定（源L13）

- 全书总论，源L13：`李广不侯叔敖为相皆天命之有定每人事之可测`→ 以李广、孙叔敖典故证"天命有定"。
- 管窥结尾，源L13：`愽乎管窥庶几一悟` → 全书末句，谦辞"管窥之见，庶几一悟"。
- 四库选材，源L3：`惟专以月建及胎元为推测之本则不为定论`——提要指出以月建+胎元为推论之本的局限；与 engine 的胎元（`tai_yuan`）已有但仅作辅助而非核心一致。
- 神白经引用，源L13：`神白经云易精为阳为清简精为隂为浊`——引用他书立论，可与多书互参但仅作文本交叉，不作孤证。
- 夹马夹禄精晰，源L3：`于夹马夹禄拱库拱贵辨论详尽往往为他家所未发`

## 四、对勘与口径分歧

1. **四库否定岳珂 authorship**：SAME as sanming_zhimi_fu 提要——"旧本题宋岳珂补注"实为依托；取用判据时归"宋佚名"，不挂岳珂。
2. **"三竒遇贵须分逆顺" vs 通用三竒**：通用三竒仅以"见之三竒即为贵"，本书强调"顺/逆"——阳竒顺行、阴竒逆行为全书特有，engine 未建此规则。
3. **"攀鞍" vs "马前六害"**：本书攀鞍与六秀、马前六害三名同义——engine 驿马 `shensha` 仅有驿马一字，攀鞍系列应补。
4. **全书结构重"夹拱"**："夹马/夹禄/拱库/拱贵"四法为本书最重心（提要：`夹马夹禄拱库拱贵辨论详尽`），现行 engine 完全无此系列——重大缺口（OPT-05）。
5. **与《兰台妙选》互参**：本书"五行各有竒仪须分逆顺"与兰台"三竒贵人"同口径（三分法/逆顺），两书可互参但不作为唯一来源。
6. **判语全体为吉命定断**："夭""夭折""夭于建命之宫"——凶象结构注册但断语不进评分（铁律三）。
7. **四库混合钞本问题**：L13 末段紧接《星命总括》书志语（L14 有 `<子部,术数类>`），两书合钞于《永乐大典》同一门，不可互混。本书止 `愽乎管窥庶几一悟`。

## 五、不适用与存疑

- **夭/夭折/夭命凶事**：源L13 `短夭者命带尅刑` etc——凶象结构注册不进评分。
- **伦理命定**：`阴刃为妨夫之煞`（L13）——现代问域不采。
- **孝服哭泣断**：`白衣有气格……泣涕涟如`——凶事不采。

**存疑**：

- **四库"月建及胎元"批评**：提要批评"专以月建及胎元为推测之本"——engine 月建+胎元均有但以月令提纲胎元辅助，未至"专以"程度。
- **合钞本的独立性**：L13 在"愽乎管窥庶几一悟"后紧接"星命总括"书志标记（L14），本书正文分界是否止于此？或者 L13 仍包含了星命总括的若干内容？暂按四库无"星命总括"一书判断，L13 为指迷赋全篇；星命总括为另册（L17 起），不影响本书解读。
- **神白经引文的文本真实性**：神白经原文须另考；本书抄语`易精为阳为清简精为隂为浊`与通行易理解有出入，抄录时可能有形讹，引用只作文本参考。
- **冲处"相成"的精确边界**：如甲子纳音金→庚午纳音土，土生金=相成——精确纳音生克逻辑，engine 可据此实现（OPT-03 附带）。
- **三竒"顺/逆"定义**：顺=顺行十二支节、逆=逆行十二支节；engine 未建"行运方向"对三竒的作用差异。
