## 一、书目与版本

《黄金策》，旧题明·刘基（刘伯温）著。**托名可由内证坐实**：避乱章夹注自述"不幸海倭窃发，横行吴越之间"（源L3201），倭乱为嘉靖间事，刘基（1311-1375）不及见——成书当在明中后期，托名刘诚意以重其术。本书是六爻"总诀（千金赋）+ 分门占断（三十余章）"体系的总纲书：《卜筮正宗》尊之为"作后学之津梁"，全书主体即黄金策直解；《增删卜易》多处逐条批驳或引申其文（如"空下伏神易于引拨"）。与《增删卜易》并称六爻后期两大源头。

### 总断千金赋（源L5-291）

### 天时（源L292-470）

占天气章：以六亲代天象——父母为雨、妻财为晴、子孙为日月、兄弟为风云、官鬼为雷电阴晦，明言"当究父财，勿凭水火"（不用卦宫水火取象），再配五行四季定轻重，末及占法取期。此章是引擎天气占（question_use_gods"天气·雨/晴"族）的直接书源。

- 取用总纲，源L295：`天道杳冥，岂可度思旱涝？易爻微妙，自能验彼之阴晴，当究父财，勿凭水火。` → 占晴雨以父财二爻为主，不取水火之象。现状：天气族词典已按占雨→父母、占晴→妻财分流，取用一致，已入库。
- 核心对句，源L299：`妻财发动，八方咸仰晴光；父母兴隆，四海尽沾雨泽。` → 财动主晴、父动主雨；夹注（源L300）：`卦中父动主有雨，财动主晴。` → 并列"无父不雨、无财不晴"的否证条件。现状：已入库（天气族 citation 与 inference 分层）。
- 风雷各有所主，源L322：`若论风云，全凭兄弟；`、源L327：`要知雷电，但看官爻。` → 兄弟风云、官鬼雷电，旺动定大小。现状：天气族目前只分流雨/晴两问，风、雷问法未建（如需"今天有风吗"类查询应补 inference 条目或在 _meta 登记不采）。
- 久晴久雨定式，源L365：`父持月建，必然阴雨连旬；`、源L369：`兄坐长生，拟定狂风累日。` → 用神临月建/长生主持续，至墓绝日方转。现状：长短期判断属叙述层，引擎未建持续性模型，合理不采。
- 取期法，源L459（注）：`占雨看父爻，久晴占雨父爻衰弱，主旺日有雨` → 应期随用神旺衰动静取日。现状：liuyao_timing 的通用应期法可覆盖，未单建天气应期。

### 年时（源L471-479）与国朝（源L480-484）——存赋不注

两章皆"存赋不注"：年时占一年水旱兵灾、丰歉休祥（源L471：`阴暗晴暑，天道之常，水旱兵灾，年时之变。`）；国朝占国家兴废（源L480 章题起，"本宫旺相，周文王创八百年之基"）。断语面向王朝年岁与天变，**现代问域无对应求测项，且铁律一（机械运算归代码）下"国运"亦非可用神覆盖之事**——两章判据不采，登记为不适用；其中"身持福德，其年必获休祥；世受刑伤，世岁多遭惊怪"（源L477）之类六亲旺衰逻辑与他章同构，仅作体系佐证。

### 征战（源L486-589）

占两军胜负：世应分彼我、子孙为我将、官鬼为彼帅、父母旌旗、财为粮草、兄弟伏兵；多举韩信背水、项羽乌江等史例作象。判据示例，源L486：`观世应之旺衰，以决两家之胜负；将福官之强弱，以分彼我之军师。`。**为何基本不采**：现代问域无两国交兵；但其"世旺克应则胜、应旺克世则负"的世应对抗结构与竞争/竞标类问法同构（question_use_gods"竞争·竞争对手"族），可作该族 citation 的旁证书源，不单独建模。末句"要识用兵之利器，五行卦象并推详"（源L585）属象法，不采。

## 五、不适用与存疑

**不采章节及理由**（机械门禁下不进引擎，登记于分析层之外）：

- 年时、国朝（L471-484）：断年岁丰歉与王朝兴废，无现代对应问域；天变断语与铁律三口径冲突。
- 征战（L486-589）：两军交战问域不存在；其世应对抗结构仅作"竞争"族旁证。
- 避乱（L3200-3369）：倭乱背景；机制层（鬼动为祸、子持世免）可映射避祸类问法，方位断不采。
- 鬼神（L1797-1809）、娼家（L3901-3902）：祀典与妓馆问域不适用。
- 症候级断语（疾病章 L1446 起"火属心经…"）：医疗断言只可作"以专业意见为准"的叙述素材，不进评分（铁律三）。
- 寿限三限法（身命章 L927）、避方法（避乱/出行章地支方位）：纯象法/命定断言，不建。

**转录与 OCR 缺陷登记**（引文照录主源原样，不作改字）：

1. 源L290：`求占者签后而灵：筮必诚心，何仿子日。`——"签后"当作"鉴后"（W 作"鑒後則靈"）、"何仿"当作"何妨"，形误。
2. 源L2827：`后嗣主富货繁华之茂。`——"货"当作"贵"（W 作"富貴繁華"）；同行"凶兆归魂（游魂）亦作凶推"括注为转录者补字，非原书。
3. 源L49-50：夹注"占事以动爻为事之始，以变出／爻为事之终"被换行截断，此类跨行断句在本源夹注中多处存在，引文规则（不跨行）天然规避。
4. 源L2017：`易尽三才，占丰遗乎六畜？`——"丰"为"豈"之形误（W 作"豈遺"）。
5. 源L1252：`姅必逢官，`、源L1256：`妉须遇虎。`——"姅""妉"皆罕用字（姅谓孕伤、妉或为"娙"之误），义待善本核。
6. 源L471-479、L480-484、L1797-1809、L2827-2828、L3901-3902：五处"存赋不注"章正文为整段长行、无夹注，与有注章体例断裂——是否转录者删注，待考。

**存疑**：

- 主源夹注的注家身份：夹注多次称"予"并举己验卦例（如源L1910-1911 连举四例、源L3297 举明夷之谦卦），与《增删卜易》野鹤自述口吻相类但内容不同源；疑为某清人注释系统（姚际隆本/《卜筮全书》系统的另一注本），待善本对照。
- "10、疾病"跳号：合并转录痕迹还是底本原貌，待卜筮全书善本核对卷十界。
- 蚕桑章"火爻为蚕命"（源L1939 蚕为蜀女所化说）属神话取象，机械层无法验证，未采。
