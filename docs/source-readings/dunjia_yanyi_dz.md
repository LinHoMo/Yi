## 一、书目与版本

**作者与成书**：明代程道生撰，字可生，浙江海宁人，生平不详。源书首题跋自述"四卷"，书中多引嘉靖、万历年号，最晚至万历四十二年（1613），故撰于明末。清代收入《四库全书》，后有四库珍本印行。

- 源L5：`《遁甲演义》四卷，明代程道生撰。道生字可生，浙江省海宁县人。生平不详。`
- 源L11：`遁甲与六壬是相通的，只是各有所侧重。` → 全书定位句：奇门与六壬同源而侧重不同（奇门偏军事、偏天文历法）。
- 源L722：`盖太乙奇门六壬，皆同此应，故为之三式。` → **"三式"（太乙／奇门／六壬）同源**是本书明示的门户立场，对本项目六壬科有直接文献意义。

## 二、逐卷（章）深读

### 卷一·遁甲源流与四家奇门（L18-42）

本卷先定"局"的分层：黄帝创始四千三百二十局（一时一局），风后合并为1080 定局（冬至阳生起坎艮震巽为阳遁、夏至阴生起离坤兑乾为阴遁，各540），太公立七十二活局，张子房撮四候为阴阳各九局得十八局。术语随文白话：**硬局**＝1080 定局（每局六十时不变）；**活局**＝72／18 局（星仪符使预布于局中，只随加临转移）；**局**＝五日六十时为一局换局单位。

- 源L20：`昔黄帝始创奇门，四千三百二十局法` → 局数谱系之源起，四千三百二十＝一年三百六十日×十二时。
- 源L24：`上元一宫起甲子，中元四宫起甲子，下元七宫起甲子。` → 年家奇门三元起局：上元一宫、中元四宫、下元七宫起甲子，俱逆飞六仪、顺布三奇。
- 源L30：`甲己遇四孟，为上元，在一宫起甲子。` → 月家奇门三元分局：年干甲己遇四孟（寅申巳亥）为上元起一宫、遇四仲为中元起七宫、遇四季为下元起四宫。
- 源L36：`分阴阳二遁，按节推排，三日一局。顺行六甲，周而复始。` → 日家奇门：**三日一局**、不入中五、按节推排——日家奇门是本书中口径最简的一支。
- 源L42：`假如阳遁一局，甲子在坎，天蓬为直符，休门为直使，管十时，至癸酉止。` → 时家奇门的核心结构：**值符＝旬首（甲子）所在宫的原始九星，值使＝该星所落之门**（如甲子在坎→天蓬为直符、休门为直使），一旬十时（甲子至癸酉）由值符管束。

### 卷一·赋诀与超神接气置闰（L44-123）

本段是本书的**义理与历法核心**。四篇赋（《烟波钓叟赋》《黄帝阴符经》《奇门原始》《遁甲神机赋》）把九宫八卦、九星八门、三奇六仪、六仪击刑、伏反吟、三奇入墓、五不遇、天网、击冲、六十格、三遁、八神、干维全部写成歌诀；随后"超神接气置闰诀"解决**历法-局的对齐问题**——这是本书对后世影响最大的技术贡献，也是与六壬"超神接气"之争同源的核心议题。

- 源L46：`八门又逐九星行。九星逢甲为值符。八门值使自分明。` → 烟波钓叟赋：九星与八门同行、九星逢六甲为值符、符上之门为值使（承L42 之法）。
- 源L102：`歌日：接气超神为准的。超者，超过也。神者，日辰也。` → **超神／接气**定义：符头（甲己日）先于节气到＝超（用未来之节）；节气先到而符头未到＝接（留待符头）。
- 源L104：`上局永无拆补借用之理。` → **拆补**定位：拆补之局"永为下之残局"，只有下局可被前节残局借用，上局绝不借用——拆补方向是单向的。
- 源L106：`要知置闰在何时？端在芒种与大雪。` → **置闰定点**：芒种、大雪之后（阳极阴终），小满／小雪之交虽超九日十日亦不可置闰。
- 源L120：`男顺寅，女逆申，皆起五虎` → 本命行年法：男顺行至寅、女逆行至申起五虎遁，泊宫生克刑害以**纳音**论——本书唯一涉及命理的段落，跨科（六爻／八字）视角。
- 源L120：`假如得开休生三门，又合乙丙丁三奇，亦未便为全吉，犹忌余宫犯格` → 全书最重要的**残余宫判据**：三奇三吉门齐备仍须检点余宫百十余格，"犯格"与否是吉凶分水岭。

### 卷二·三遁与奇仪吉格（L125-249）

本段讲"三遁"（天遁＝生门六丙合六丁、地遁＝开门六乙合六己、人遁＝休门六丁共太阴）与奇仪相配的吉格（飞鸟跌穴＝丙加甲、青龙回首＝甲加丙、玉女守门＝丁奇游六仪、三奇得使＝乙加甲戌甲午／丙加甲子甲申／丁加甲辰甲寅）。三遁的共同结构：**上盘奇 ＋ 中盘门 ＋ 下盘仪（或神）** 三者同宫，方成"遁"，是本书少数**结构化的三要素合参判据**。

- 源L926：`初出天门，六戊也入地户，六己也过太阴，六丁也居青龙，六甲也` → 出天门入地户过太阴居青龙法：战场趋避的**四步方位程序**（六戊→六己→六丁→六甲）。
- 源L910：`六甲旬孤上坐者胜，虚上坐者负。` → 博奕胜负局的孤虚法：六甲旬上孤虚（子丑寅卯／辰巳午未／申酉戌亥）定胜负——**骰子／博戏场景的占法**，与六壬"课体"不同源。

### 卷二·格局总汇（L249-347）

本段是本书的判据库：**"百十余格"**。每格统一体例——歌诀一句（含吉凶倾向）＋《三元经》释义（《奇门大全》旁注，多本引）＋王璋／葛洪／汤谓按语＋一个具体局例。格局按机制可分六类：

1. **奇仪相击类**：青龙逃走（乙加辛）、白虎猖狂（辛加乙）、朱雀投江（丁加癸）、腾蛇跃跷（癸加丁）、飞鸟跌穴（丙加甲）、青龙返首（甲加丙）——同一对奇仪，加法方向不同吉凶相反。
2. **庚维类**：庚为太白（白金）／丙为荧惑（火），故庚加丙＝白入荧、丙加庚＝荧入白；庚加六癸＝大格、庚加六壬＝小格、庚加六己＝刑格、庚加日干＝伏干格、日干加庚＝飞干格、庚加直符＝伏宫格、直符加庚＝飞宫格，并按年／月／日／时分为岁格／月格／日格／时格。
3. **星宫关系类**：伏吟（天蓬加天蓬）、反吟（天蓬加天英）、门迫宫迫（宫制其门／门制其宫）、三奇入墓（乙临坤六宫／丙临乾六宫／丁临艮八宫）。
4. **干维类**：五不遇（时干克日干，庚日庚午时之类）、六仪击刑（甲子直符加卯、甲戌加未、甲申加寅、甲午加午、甲辰加辰、甲寅加巳）。
5. **门户类**：八门吉凶（休生开为三吉门，伤杜景惊分用途、死门主吊死行刑）、天网四张（六癸所加，一二三四宫为网低可出行、五六七八九宫为网高不可出）。
6. **星气类**：九星旺相休囚废、大凶星（天蓬天芮）小凶星（天柱天英）在旺相时降级为中平。

- 源L325：`六仪击刑何太凶？甲子直符愁向东。` → 六仪击刑歌诀起句。
- 源L329：`就中伏吟为最凶，天蓬加着地天蓬。` → 伏吟定义句（"上盘天蓬加地盘天蓬"）。
- 源L333：`天蓬若到天英上，须知即是反吟宫。` → 反吟定义句（天盘一宫蓬星加地盘九宫）。
- 源L339：`宫制其门不为迫，门制其宫是迫雄。` → 门迫／宫迫的方向判别：宫制门不为迫、门制宫为迫；吉门被迫不成事、凶门被迫凶事尤甚。
- 源L343：`天网四张无路走，一二网低有路踪。` → 天网高低宫分层（一二宫网低可走、三四入墓、八九高张）。

### 卷三·九星分野与主客胜负（L360-470）

本段转向**应用层**。先把九星与星名（字）配齐（天蓬字子禽、天芮字子成、天冲字子翘、天辅字子卿、天禽字子公、天心字子襄、天柱字子中、天任字子韦、天英字子威），再给每星的宜忌（宜祭祀／宜将兵／宜嫁娶，忌移徙／忌市贾），并以"时令旺相"修正——**同一九星在旺相与休囚下吉凶等级不同**。然后是"遁甲利客／利主"：以天盘星与地盘星的生克判胜负，并叠加"本方五色云气"（天蓬水星主黑气从北、天柱天心主白气从西、天任天禽天芮主黄气从东北土位、天英主赤气从南）作为**方位色气助胜**的附加条件。

- 源L384：`大凶天蓬与天芮，小凶天柱及天英。` → 九星吉凶分级原文（上吉＝辅禽心、次吉＝冲任）。
- 源L394：`九星 旺 相 休 囚 旺 相 废 休 囚` → 九星旺相休囚废的月令查表（配合 L396-L404 五行分星逐月旺相休囚）。
- 源L448：`天盘星克地盘星，在四时旺相日时` → 主客胜负总纲：星克为客胜、地盘克天盘为主胜，再须旺相日时与云气为佐。

### 卷三·时奇起例与奇遁布局（L710-962）

本段给出**两例完整排局示范**（万历二十五年壬申日用小满中局阳遁二坤／万历二十五年辛丑日用夏至中局阴遁三震），逐句说明直符取法、直使顺逆、奇仪落宫、吉凶判词（丙午时"凤入丹山"、"宫迫不吉"、"乙奇到坤入墓"等），是本书唯一可机械复算的算例。随后是布局法（三盘九星／八门／九宫，乙为日奇、丙为月奇、丁为星奇，六仪寄宫，甲隐六仪之下为天乙贵神）、玉女反闭诀与十二日图式、真人步斗法、六甲出行诀、孤虚博奕法、六甲阴符法与禁敌法（**属符法禁术，本项目一律不采**）。

- 源L444：`天辅之时，有罪无疑斧锧，在前天犹赦之` → 天辅之时：甲己日己巳时等五组——本时得吉星，结构上偏向"事有回旋"。
- 源L742：`三重象三才，上层象天列九星，中层象人开八门，下层象地列八卦九宫。` → 奇遁布局法总纲（三盘＝三才）。
- 源L722：`盖太乙奇门六壬，皆同此应，故为之三式。` → 三式同源说（对源六壬科）。
- 源L918：`甲子旬子上起青龙，甲戌旬戌上起青龙` → 六甲出行诀：按旬起青龙顺行十二支，出行趋避所用。
