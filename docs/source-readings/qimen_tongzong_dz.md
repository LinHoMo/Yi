## 一、书目与版本

**作者与成书**：不署撰人。书前自序托名"先王"立法，卷首《奇门遁甲统宗源流》把术数源流上溯至黄帝、吕望、张良，明代王守仁门人孝成君进《奇门真传》（李氏奇门）、林士徵本（林氏奇门），明末陶仲参李／林二家成《陶真人遁甲神书》——源流自陈即已"缪紊"，故本书性质是**明末清初奇门汇录编纂本**，非一时一人之作。

**术数定位**（源L6）：奇门为兵事而设，"遁于六仪之下而不见其形"，故名遁甲；六甲为至尊之神，宜藏不宜露、所喜惟土所憎惟金，故有乙奇内合、丙丁外制；架构为八门＋八神＋三盘（天地人）＋三奇，并以六十时干为经、四时八节为纬，合计四千三百二十局。

**版本形态**：单文件，卷一二三＋卷十至十二存，**卷四～卷九（阳遁／阴遁各九局图谱）在本抓取本中作"（略）"处理**（源L540：`奇门遁甲统宗卷之四～九 （略）`）。故本篇不是完整奇门局谱，缺的是"逐局排盘实例"，不是判据条文。

**凡例十条（L13-24）** 是本书的方法论总纲：并存异说、取理正者、兵事避忌、格局最重、选择重衰旺休囚、会合为上吉、阴阳宅配合生命化命、择吉须配斗首五行太阳吉凶星煞、占法分动静、占天时诸说不可偏废。

## 二、逐卷（章）深读

### 卷之一（L43-208）——起局法：遁甲起例、超接置闰、四十格

本卷是全书的方法论地基。**遁甲起例**（源L53）给出阳遁／阴遁的完整排布规则：自冬至阳生起坎一宫，坎艮震巽四卦统气十二候、分三十六局计五百四十为阳遁，故顺布六仪（甲子戊…甲寅癸）、逆飞三奇（乙日奇／丙月奇／丁星奇）；自夏至气降起离九宫为阴遁，逆布六仪、顺飞三奇。术语：**阳遁＝顺仪逆奇，阴遁＝逆仪顺奇**；**仪＝六甲所遁之仪（戊己庚辛壬癸），奇＝乙丙丁**。

**超接与置闰**是本书最硬的一块历法技术：符头（甲己子午卯酉为上元、寅申巳亥为中元、辰戌丑未为下元）与节气不同到时，以"超"（节未至而符头先到，用未来节气）或"接"（节已至而符头未到，待符头至）调和；超接积累成余数则置闰，闰只放在芒种、大雪二节之后与冬至、夏至二至之前。卷中甚至给出康熙五十六年至五十八年的完整置闰worked例（超九日、置闰奇三局、闰奇方终等）。凡例第三条自陈"亭亭白*、三门四户、大马方之类，须从岁月太阳查算，书中未敢预载"，是自认的边界。

**奇门四十格**（L77-119）是可枚举的判据表：天、地、人三遁；龙回首／鸟跌穴；云风龙虎神鬼六遁；龙逃走／虎猖狂／蛇妖矫／雀投江；三奇得使／玉女守门；大格／刑格／岁格／月格／日格／时格／小格／伏宫／伏干／飞干格；太白入荧／火入金乡；反吟／伏吟／五不遇格／三奇入墓／时墓／六仪击刑／六仪受制；地罗遮蔽／天网四张；尺寸高低。

旺衰两套标准并存：**门随节旺**（源L123：冬至休门旺、生门绝、伤门胎、杜门沐、景门死、死门囚、惊门休、开门废），**星随月旺**（源L127：九星旺于子月、相于本月、死于父母月、囚于鬼月、废于妻月）。另有"迫"——门与宫相克为迫（源L131：开门临三四宫金克木、休门临九宫水克火、生门临一宫土克水等八条）。

核心判据：

- 源L53：`自冬至阳生起坎一宫，坎、艮、震、巽四卦统气十二候，分三十六局，计五百四十，为阳遁，故顺布六仪` → 阳遁排布总纲：四卦统气十二候、三十六局、五百四十。
- 源L54：`五日一元，遇甲己日为气交，而非甲己则以超接之，即拆局补局之法` → 一元五日、气交看甲己、非甲己则拆局补局。
- 源L74：`置闰之法，在芒种、大雪二节之后，冬至、夏至二至之前` → 闰的可插区间（他节虽超十日不可置闰）。
- 源L47：`甲加丙兮龙回首，丙加甲兮鸟跌穴。回首则悦怿易逐，跌穴则显灼易成` → 第一吉格对：甲加丙、丙加甲，主军／客军各得其位。
- 源L47：`庚临值符伏宫格之名，值符临庚飞宫格之说` → 庚与值符的两格（伏宫／飞宫）——卷十一展开为天乙伏宫／天乙飞宫。
- 源L48：`就中伏吟为最凶，天上蓬加地上蓬` → 伏吟的基本结构（天地盘同宫），吉门奇遇之亦不吉。
- 源L123：`冬至：休门旺，生门绝，伤门胎，杜门沐，景门死，死门囚，惊门休，开门废` → 八门十二长生式的门节旺衰表。
- 源L127：`九星旺于子月，相于本月，死于父母月，囚于鬼月，废于妻月` → 九星旺衰的月份口径（父母月＝申、鬼月＝亥、妻月＝未）。
- 源L131：`开门临三四宫（金克木） 休门临九宫（水克火）   生门临一宫（土克水）` → 迫的判据：门／星五行被宫位所克。
- 源L146：`冬至惊蜇一七四，夏至白露九三六，小寒二八五相随，小暑八二五之间` → 二十四节气的九局数口诀（冬至起一七四，夏至起九三六）。
- 源L159：`一逢坎上一坎休，芮死还排第二流，更有冲伤居震位，巽逢杜辅数为头` → 值符值使诀：值符落宫即定值使门。

### 卷之二（L210-350）——门星神仪、阴阳遁起例与年／月／日奇门

本卷是**排盘算法卷**。九星八门六仪八神的固定配属（源L227-233）是全书的符号表：九星坎一天蓬、坤二天芮、震三天冲、巽四天辅、中五天禽、乾六天心、兑七天柱、艮八天任、离九天英（天禽阳遁阴遁俱寄坤，一本阴遁寄艮）；八门坎休、艮生、震伤、巽杜、离景、坤死、兑惊、乾开；六仪甲子遁戊…甲寅遁癸；八神阳遁一值符二腾蛇三太阴四六合五勾陈六朱雀七九地八九天，阴遁序有别（朱雀下有玄武、勾陈下又白虎）。

**起例三法并列**：旬首取符使（源L250：地盘旬首所临之宫，其星即为值符、其门即为值使）、值符加时干、值使加时支、小值符加大值符。另有年奇门（源L258：上元甲子六十年阴遁一局、中元四局、下元七局，共一百八十年一周，用逆不用顺）、月奇门、日奇门两法、遁年／遁月／遁日奇法、日奇布五符、日奇起青龙、德刑、宝和义制伏（源L284）。本书在日奇门后**自陈其可疑**（源L263：`然皆不解，姑存`；源L276 更明说"以兵机决于俄顷，万无再查年月之理……姑备录之，以俟选择之用，非奇门所急也"）——这是难得的作者自我否定，价值很高。

**旺衰与类神**：五阳时（源L286：甲乙丙丁戊为阳，将兵利客宜先举）／五阴时（源L288：己庚辛壬癸为阴，将兵利主宜后应）；八门所主、九星所主各逐项列"宜／不宜"；三奇喜怒（乙＝玉兔、丙＝火、丁＝星奇最灵）逐宫给落宫名；八卦／九星／八神类神给出物象与人事映射。

旺衰总纲两条极重要（结构性的"加减分"而非"吉凶定论"）：

- 源L298：`右八门最怕迫制，吉门有气益吉，无气减吉；凶门有气益凶，无气减凶` → 门的吉凶随旺气浮动（吉门减吉亦减、凶门减凶亦减）。
- 源L308：`右九星有气而合奇门，吉者益吉，凶者减凶。若无气而不合奇门，凶者益凶，吉者不吉` → 九星须"有气"且"合奇门"才加分，两缺则反向。

### 卷之三（L352-538）——兵事分主客、背击、神煞群与奇门演卦

本卷是**军事占断卷**，占全书的 tactical 比重最大。主客之分为全书最基础的一条结构判据（源L382：宫为主、星门为客，客生星门利客、宫克星门利主、两相比和主客势均、一克一生则主客互伤）。

**背击**（源L386）是一串"背彼击我"的方位宜忌：背生击死、背孤击虚、背雄击雌、背德击刑、背亭亭击白*、坐三胜、避五不击、趋三避五、背天目击地耳、背游都太岁月建大将军太阴月建河魁、避地丙、急则从天马方出，并附五干日的方位禁忌（甲乙日不西攻、壬癸日不攻四维、丙丁日不北攻、庚辛日不南攻、戊己日不东攻）与"不可囚攻相、以死攻生"。

**神煞群**逐条给表：孤虚（源L388：年月日时俱以前一位空亡为孤、孤冲为虚，并按万人／千人／五百／百／数十人分级取年／月／旬／日／时孤）、雄雌（春寅夏巳秋申冬亥为雄、对冲为雌）、亭亭白*（源L392：以月将加正时，视神后所临为亭亭方、功曹胜光天置所临为白*方）、游都鲁都、三胜地（值符九天生门）、五不击（值符值使九天九地生门五营）、趋三（值使到震）／避五（值使到巽）、天马方、旺相休囚四时表、天目（源L408：六旬各一）、地耳、太岁（地盘岁支之宫）、月建、太阴、大将军（源L418：寅卯辰年巳、巳午未年卯、申酉戌年午、亥子丑年酉）、时中将星（源L420：申子辰日卯时、巳酉丑日子时、亥卯未日午时、寅午戌日酉时）、天罡时、破军加时法、天营、四神、旬中地丙日（源L432）、五将方（源L434）、太阳临时法、九星吉凶歌、行兵杂摘、占风、迷路法、涉险法、出入山中法、逃避法、下营法。

**奇门演卦**是本书与《周易》接口处：符使演卦取地盘值符宫为内卦、天盘值使宫为外卦（源L479），门方演卦取八方定位为外卦、所临八门为内卦（源L483）。由此卦象定主客雌雄、阵势得失、节候（应期）——节候段以"世爻未土败子、所绝于巳、破于辰、受克于寅卯、空于甲申旬"推出甲申旬寅卯巳酉年月日时，是本书少见的**可机械化应期推法**。主客雌雄段（源L487：世为客、应为主，世克应／应生世利客先动、应克世／世生应利主后动）与阵势得失段（阵名旗色主客五行相克：圆阵／尖阵／方阵／长阵，配白红黄青绿旗）也是结构化的。

- 源L382：`宫为主，星门为客。客生星门利客，星门生宫利主。宫克星门利主，星门克宫利客` → 主客生克定先动后应。
- 源L386：`背生击死，背孤击虚，背雄击雌，背德击刑，背亭亭击白*` → 背击六取的结构化口诀（背后所倚者吉、身前所击者凶）。
- 源L388：`孤虚：年月日时俱以前一位空亡为孤，孤冲为虚` → 孤虚的推法（旬内前一位空亡为孤、其冲为虚）。
- 源L392：`亭亭白*：以月将加正时，视神后所临为亭亭方；功曹、胜光、天置所临为白*方` → 亭亭白*须用月将加正时起，与"五不击"不同法。
- 源L406：`旺相休囚：春木相火旺水废金囚土休，夏火相土旺木废水囚金休，秋金相水旺土废火囚木休，冬水相木旺金废土囚火休` → 四时旺相休囚全表。
- 源L408：`天目：甲子旬庚午，甲戌旬庚辰，甲申旬庚寅，甲午旬庚子，甲辰旬庚戌，甲寅旬庚申` → 天目六旬表。
- 源L418：`大将军：寅卯辰年巳，巳午未年卯，申酉戌年午，亥子丑年酉` → 大将军年支三合定宫。
- 源L420：`时中将星：申子辰日卯时，巳酉丑日子时，亥卯未日午时，寅午戌日酉时` → 时中将星（日三合定卯／子／午／酉）。

### 卷之十（L542-680）——玄机赋（上）：八将各会八门六十四诀

本卷是**结构化占断的模板集**：值符、腾蛇、太阴、六合、白虎、玄武、九地、九天八将，各自会休、生、伤、杜、景、死、惊、开八门，逐条给"天时／行兵／主将／客将／捕捉"五段。段式高度固定，**结构上接近可机读的槽位表**。

例：值符会开门（源L571-572）判"天晴、有奇则晴无奇则霖四十日、宜舟不宜陆、主将百战百胜、客将败逃亡"；太阴会惊门（源L599）判"霖雨、东方多险可破、来降有名无实、三日出师全胜、捕捉和则大功捉则大祸"；九天会伤门（源L669）判"大晴且三月旱灾、峻岭六月可破、外亲接见大利、客将管鲍之交来不可击其衡"。

**卷内缺文登记（重要，且书源自相矛盾）**：源L596 标注「（注缺。太阴会景门，及太阴会死门赋，均缺。）」、源L654 标注「（注缺，九地会伤门，九地会杜门赋诀，均缺）」。但**正文实际存有"太阴会死门"（源L597）与"九地会杜门"（源L655）**——即注缺标注与正文冲突。逐条点数：八将×八门应 64 诀，实际存 62 诀，**真正只缺太阴景门、九地伤门两诀**。此外卷首另有五将（六合／白虎／玄武／九地／九天）各一首"军性"总诀（源L544-555），非八门格局，不计入 64。**不得以注缺标注为准扩大缺文范围，也不得以对称性补写太阴景／九地伤。**

### 卷之十一（L683-781）——玄机赋（中）：门气、飞伏宫、击刑入墓、阴余之气

本卷把卷一的四十格逐条展开为**吉凶如何加减**的细则，是全书判据密度最高的一段。

1. **八门气**（源L687-694）：休门隐伏、生门可战（一敌万人／坐生击死）、伤门加乾兑或合金则败北、杜门闭塞、景门锋不可挡、死门唯退保、惊门虚惊、开门四通八达。
2. **荧白／飞伏宫**（源L697-706）：天乙飞宫（值符加庚）不宜进兵、后应则吉，乘生门及六仪相合可免；六丙加庚为荧入白（利主急进）、六庚加丙为白入荧（贼来先备）；特别警告"值符是六庚须避丙丁、且不可移军到景门"，庚临丙名为飞勃／格勃，**切勿错认龙回首**。
3. **阴阳强弱**（源L708）：阳时神居天上用上强、利客先动；阴时神居地下用下强、利主后应；三胜（值符、九天、生门）为坐地出击之位。
4. **美格相克**（源L720）：龙回首、鸟跌穴、三诈五假、九遁"最忌相克"，行兵尤忌下克上；又忌时干克日干（主下犯上、主胜客）。
5. **三奇要用须符使**（源L722）：三奇须合值符值使两宫方得力，再须落旺地、再须合休门相生；合惊开二门则受金克、力减半。
6. **奇仪相合**（源L728-729）：乙庚、丁壬、丙辛、戊癸、甲己五合为"和合"，安营下寨最利，主客对垒宜议和。
7. **六仪击刑**（源L749）：逐宫列甲子到三宫、甲戌到二宫、甲寅到四宫、甲申到八宫、甲辰到四宫、甲午到九宫，**即使六仪为值使亦不可用**。
8. **三奇入墓**（源L751）：乙丙到乾为墓、丁到艮为墓，所谋百无一成。
9. **三格相逢**（源L753）：庚加己刑格、加癸大格、加壬上格又小格，三格相逢"车破马倒、中途而止、慎勿追赶"。
10. **天乙飞伏宫**（源L754-757）：飞宫则将军随天上值符而飞（远避勿攻）、伏宫则移帐房到天上丙丁方避之。
11. **阴神余气翻变**（源L776-777）：阳将加天上值符、阴神加天上值使之宫，"吉能变凶，凶能变吉"；余气以天盘八门五行权四时气候（旺／相／休／囚／废）。卷末给出总纲（源L777）：`是故，星仪门将遇凶，未可竟言凶，遇吉未可竟言吉`——**这是本书的判据元规则：不得单以格局定吉凶，须查阴神余气**。
12. **八门余气**（源L779-780）：以天盘八门旺相休囚为余气，开则通、杜则阻、景小喜不久长、休为藏聚、伤能转运捕捉、惊多忧惶。

- 源L697：`天乙飞宫莫急进，乘之生合可逃生` → 飞宫的解法（生门与六仪相合可免）。
- 源L708：`阳时利为客，宜先动，用上强；阴时利为主，宜后应，用下强` → 阴阳时与主客先后的固定配对。
- 源L720：`美格者，如龙回首、鸟跌穴、三诈五假、九遁之类，最忌相克` → 吉格的反向条件。
- 源L722：`三奇最吉，若要用之，须合值符值使两宫，然后得力` → 三奇须双宫相合。
- 源L749：`甲子到三宫，甲戌到二宫，甲寅到四宫，甲申到八宫，甲辰到四宫，甲午到九宫，皆为击刑` → 六仪击刑逐宫。
- 源L751：`三奇入墓，闭塞不通，暗昧不振，诸事皆凶` → 入墓之闭塞性质。
- 源L753：`六庚加己为刑格，加癸为大格，加壬为上格又为小格` → 庚的三格。
- 源L777：`是故，星仪门将遇凶，未可竟言凶，遇吉未可竟言吉` → 元规则：吉凶须留余气之机。
- 源L779：`吉凶全凭余气救，生则生兮死不死` → 余气定生死之转。

### 卷之十二（L783-851）——玄机赋（下）：克应物象、推人命运、选择吉日

本卷分三块。**克应物象**（源L791-806）：以三奇六仪推占物体形状颜色（甲乙木直瘦、丙丁火偏斜尖、戊己土方正黄、庚辛金圆砂碎、壬癸水多纹弯曲）；九星色（蓬白、芮黑、冲碧、辅绿、禽黄、心白、柱赤、任白兼黄、英紫兼赤）；八将物（值符青龙贵物钱财、腾蛇怪异空虚、太阴雕琢文书羽毛、六合布帛果实、白虎燥裂铁石、玄武鱼蛇字迹、九地故旧昏暗、九天刀斧旋转有声有足）；八门物（休门坎坑包裹、生门初成如山、伤门转动有响、杜门闭塞未成、景门华彩光芒、死门死而不活、惊门伤损歪斜、开门圆通刚健）。**这套"形／色／方／圆／声"的物象映射是八科里唯一以物理属性为主轴的占断体系**（命科重体用、六爻重爻象、择吉重神煞）。

**推人命运**（源L807-843）：以生时奇门之局为本命，次看九星；正时推占则以天上时干为本身、值符下地盘为住宅子孙、值使之门为立业妻妾官职客旅；六亲配门（父母兄弟子孙官禄疾厄妻妾财帛 × 八门，源L813-828 逐门逐亲断语）；八将配年命（源L829-830：值符加本命非贵即富、腾蛇古怪、六合妻妾宫主淫佚、玄武财帛宫主聚财、九地疾厄宫不喜、九天官禄宫主显达）；格局占命（源L831-832：奇仪无克、九星不投墓库击刑、不合凶格、落子午卯酉四正宫、阳时阴星生旺为最尊贵之格）；值符九星透卦配重卦定大限小限（源L842-843：每爻十年、五年一爻，大限阳升阴降、小限反之）。

**选择吉日**（源L844-849）：本命行年不可遇刑冲破害；自刑之日尤不可用；甲辰壬申寅癸一天网一地网；总得太阳对照。然后是**十二支游神**（源L849）：以地盘岁支位上起一太岁、二太阳、三丧门、四太阴、五官符、六死符、七岁破、八龙德、九白虎、十福德、十一吊客、十二病符，顺行十二宫——**这一条是本书与择吉科最直接可对接的表结构**（同为"按月／日支起一神、顺行十二位"的建除／黄黑道式轮转）。
