## 二、逐卷（章）深读

### 通神论·三元与顺悖（源L69-83）

任注本开篇立"三元（天地人）"与"顺悖"两总纲：天元（干）、地元（支）、人元（支中所藏），"总不越此三元之理，所谓万法宗也"（源L72）；并强调"八字贵乎天干地支顺而不悖"（源L83）——顺者接续相生、悖者反克为害，是命科"四柱流通、五行生化"取向的书源。"命贵中和，偏枯终于有损"（源L83）与《穷通宝鉴》"贵在折衷"同构，是强弱/中和评分的总原则。

- 三元总纲，源L70：`欲识三元万法宗，先观帝载与神功。` → 三元为万法宗，引擎日主/支藏/人元取法与之同源。
- 顺悖，源L83：`八字贵乎天干地支顺而不悖也` → 干支顺生为吉、反克为凶，是命科"流通生化"判据的书源。
- 中和总纲，源L83：`命贵中和，偏枯终于有损` → 强弱以中和为贵，与引擎强弱评分取向一致。

### 知命与用神总纲（源L85-88、L209-212）

《知命章》点出全书方法枢纽——"顺逆之机须理会"，并痛批"不论日主之衰旺……总以财官为喜"的流弊；关键在于一个"用"字："用之为财不可劫……其要在一'用'字"（源L88）。《配合章》进一步把"用神"抬到命中至理："命中至理，只存用神，不拘财、官、印绶、比劫、食伤、枭杀，皆可为用"（源L212）。这是八字引擎"用神"概念最权威的疏证来源。

- 顺逆之机，源L86：`要与人间开聋聩，顺逆之机须理会。` → 全书枢纽句；顺逆判据在 verdicts"格局顺逆"分支应据此类句补引文（见 §六 OPT-01）。
- 用神之"用"，源L88：`用之为财不可劫，用之为官不可伤，用之印绶不可坏，用之食神不可夺` → 四句定"用"之不可伤，是"用神不可损伤"总纲。
- 用神总法，源L212：`命中至理，只存用神，不拘财、官、印绶、比劫、食伤、枭杀，皆可为用` → 用神不拘名目、唯日主喜忌是问；引擎"用神"层与之同源，但主源逐字引文未入库（§三/§六）。

### 形象与方局（源L922-925、L1220-1223）

《形象章》论"两气成象"："两气合而成象，象不可破也"（源L923），任注扩为十种双清/双敌之局，强调"相克务须均敌，切忌偏重偏轻"（源L925）。《方局章》论三会方（寅卯辰东方等）重于三合局（亥卯未木局）："凡三字全为成方，如寅、卯、辰全，其力量较胜于亥、卯、未木局"（源L1223）。这两章是"独象/两气成形/方局"判据的书源，现引擎在 pattern 的"一行得气、两气成形"变格中部分落地。

- 形象，源L923：`两气合而成象，象不可破也。` → 两气成象不可破，是"两气成形"格的书源。
- 形象展开，源L925：`两气双清，非独木火二形也` → 十种双清/双敌，格分十种。
- 方局，源L1223：`凡三字全为成方，如寅、卯、辰全，其力量较胜于亥、卯、未木局` → 方重于局，是方局识别的书源。

### 八格与月令定格（源L1385-1388、L1581）

《八格章》是格局论的枢纽："财官印绶发偏正，兼论食伤八格定"（源L1386），任注给出取格铁律——"先观月令所得何支，次看天干透出何神，再究司令以定真假，然后取用，以分清浊"（源L1388），并严斥兰台妙选等奇格异局"尽属谬谈"。《月令章》更直陈"月令者，命中之至要也。气象、格局、用神，皆属提纲司令"（源L1581）。这与引擎"月令定格、取格以提纲为重"的方法完全同源。

- 八格诗诀，源L1386：`财官印绶发偏正，兼论食伤八格定。` → 八格纲领。
- 取格铁律，源L1388：`先观月令所得何支，次看天干透出何神，再究司令以定真假，然后取用，以分清浊` → 月令→透干→司令→取用→清浊，五步取格法。
- 月令提纲，源L1581：`月令者，命中之至要也。气象、格局、用神，皆属提纲司令` → 提纲司令为格局/用神之本。

### 体用·衰旺·中和（源L1511、L1616、L1899）

《体用章》界说体用："体者形象气局之谓也，如无形象气局，即以日主为体；用者用神也，非体用之外别有用神也"（源L1511），并揭"旺极者抑之反激、弱极者扶之徒劳"的颠倒妙用。《衰旺章》破"得时即旺"死法："得时俱为旺论，失令便作衰看，虽是至理，亦死法也"（源L1616），并列出"五行颠倒之真机有十"——"木太旺者而似金，喜火之炼也"（源L1616）即是从强从弱判据的先声。《中和章》"中和者，命中之正理也"（源L1899）与前面三元章的中和总纲呼应。

- 体用界说，源L1511：`体者形象气局之谓也，如无形象气局，即以日主为体；用者用神也，非体用之外别有用神也。` → 体用即用神，ditian_sui.json 体用论（刘基注本）与之同源。
- 衰旺死法，源L1616：`得时俱为旺论，失令便作衰看` → 破死法，主源"日干不论月令休囚，只要四柱有根"与引擎强弱评分一致。
- 五行颠倒，源L1616：`木太旺者而似金，喜火之炼也` → 从强/从弱判据先声，已入 verdicts 从格引文（刘基注本层）。
- 中和，源L1899：`中和者，命中之正理也。即得中和之正气，又何患名利之不遂耶？` → 中和评分原则同源。

### 清浊·真神假神（源L2856-2858、L2946、L2991）

《清浊章》诗诀"澄浊求清清得去，时来寒谷也回春"（源L2856），任注以"命之最难辨者，清浊两字也"为纲，强调"澄浊求清"（源L2858）。《真假章》判真神假神："真者，得时秉令之神也；假者，失时退气之神也"（源L2946），并论"真神失势、假神得局，法当以真为假，以假为真"（源L2991）——这是"从格/真假"判据的哲学基础，与 verdicts"从格引文"的《從化論》 verse 同源。

- 清浊诗诀，源L2856：`一清到底有精神，管取生平富贵真。澄浊求清清得去，时来寒谷也回春。` → 澄浊求清，格局清浊判据。
- 清浊界说，源L2858：`命之最难辨者，清浊两字也。` → 清浊为最难辨之关。
- 真神假神，源L2946：`真者，得时秉令之神也；假者，失时退气之神也。` → 真/假神定义。
- 真假互化，源L2991：`气有真假，真神失势。收神得局，法当以真为假，以假为真；` → 真假互化，从格判定 basis（verdicts 从格引文已含滴天髓從化論 verse）。

### 顺逆·寒暖·燥湿（源L3087-3089、L3129-3131、L3186-3188）

《顺逆章》论气势不可逆："顺逆不齐也，不可逆者，其气势而已矣"（源L3087），"不可逆者，当令得势之神，宜从其意向也"（源L3089）——从格"从旺神"的哲学依据。《寒暖章》"天道有寒暖，发育万物，人道行之，不可过也"（源L3129），任注"寒虽甚，要暖有气，暖虽至，要寒有根，则能生成万物"（源L3131）是调候思想的源头性论述。《燥湿章》"地道有燥湿，生成品泯，人道得之，不可偏也"（源L3186），"燥湿者，水火相成之谓也"（源L3188）与寒暖并立为调候两轴。

- 顺逆，源L3087：`顺逆不齐也，不可逆者，其气势而已矣。` → 气势顺逆，从格/顺局逆局依据。
- 顺逆展开，源L3089：`不可逆者，当令得势之神，宜从其意向也。` → 从旺神意向。
- 寒暖，源L3129：`天道有寒暖，发育万物，人道行之，不可过也。` → 寒暖总纲。
- 寒暖展开，源L3131：`寒虽甚，要暖有气，暖虽至，要寒有根，则能生成万物。` → 寒暖互根。
- 燥湿，源L3186：`地道有燥湿，生成品泯，人道得之，不可偏也。` → 燥湿总纲。
- 燥湿展开，源L3188：`燥湿者，水火相成之谓也` → 燥湿即水火相成。

## 四、对勘与口径分歧

对勘方法：主源（殆知阁 dz，`ditian_sui_chanwei_dz.dz.txt`）与维基文库评注本（C，`di-tian-sui-chan-wei.wikitext.txt`）据 `data/sources/crosscheck_report.json` 的 `di-tian-sui-chan-wei` 键比对——containment_primary 0.9992、jaccard 0.9913、window_hit_rate 0.825，判定"高度一致"。两本**同为任铁樵注本**，只是转录源不同（殆知阁 vs 维基文库），差异以异体字/脱讹为主（"瞹/暖""収/收""忣/急"等），引文逐字门以主源 dz 为准，这些异文在 §五 留档。

**关键口径分歧（本项目内）**：本仓 `disciplines/ming/data/ditian_sui.json` 的"所本"字段明写 `data/sources/di-tian-sui.wikitext.txt`（**K，刘基注本**），其各章 `source_lines` 亦指向 K（如天干论 K:128-188、從化論 K:334-341、体用论 K:393-403、衰旺论 K:416-419、寒暖论 K:448-455）；而本主源是**任铁樵注本**（C/dz 层）。即 ditian_sui.json 承载的是"刘基原注 + 诗诀"层，主源承载的是"任铁樵疏证"层——**同一《滴天髓》、不同注层**。因此 §三 中标注"已入库（指到 ditian_sui.json）"的判据（体用/寒暖等），其实际书源是 K（刘基注本），主源任注本只作同概念补强，二者不可混为一谈。建议见 OPT-02。

**另一口径**：`verdicts.json` 的 `_meta` 写明格局引文真值源为"《子平真诠》《滴天髓》通行本逐字常见句，原书全文未入库，故不标注 offset"；其"从格引文" `_meta` 又明指原文见 K（di-tian-sui.wikitext.txt，從化論/從象/假從章）。这说明 verdicts 对滴天髓的引用是**通行本短语/刘基注本层**，未逐字指回本主源任注本。本主源任注本可补这一"可指回 offset"的缺口（OPT-01/04）。

## 五、不适用与存疑

**不采内容及理由**（不进引擎，登记于外）：

- **神煞/奇格异局**：任注本虽在《八格章》斥兰台妙选等"尽属谬谈"，但全书仍含少量神煞语境（"桃花咸池""金锁铁蛇"等，源L88 仅为批判提及）。本项目八字引擎以十神/格局/强弱/调候为机械层，神煞不在覆盖域，不建。
- **六亲论·女命/小儿断语**：六亲论诸章（夫妻、子女、女命章、小儿等）含时代性的人身/性别断语，超出用神覆盖域，不采；引用须按铁律三（偏向/信号）转述。
- **命例造**：全书大量命例为古例且多涉"家破身亡""刑妻克子"等断语，不可作数据用，仅作语境参照，且须按铁律三口径。
- **性情/才德/疾病断语**：六亲论末章（性情、疾病、出身、地位）以命定人品与疾厄，不进评分，叙述层亦慎用。

**OCR/转录缺陷登记**（引文照录原样，主源 dz）：

1. 源L3130：`寒之甚，瞹之至，内有一二成象`、"五阳这候""阳乘阳位"——"瞹"当作"暖"、"这"当作"之"（K 作"暖"）。
2. 源L3131：`若寒甚而瞹无气`——同"瞹/暖"讹。
3. 源L1616：`木太衰者而似水也，宜金以生之` 段中"奶之轻者也""根挭""这旺"——"奶"当作"余"、"挭"当作"梗"、"这"当作"此"，系转录讹字（K 对应作"余气者"）。
4. 源L1928：`总要流通生化，，收局得美为佳`——多一逗号；"比劫为忆忌""祖上寒微"等——"忆"当作"抑"，转录讹。
5. 源L3187：`过于湿者，滞而无成` 段"木火伤官要湿也""金水伤官要燥也"——与穷通宝鉴调候体系统一，非讹，但提示调候双轴。

**存疑**：

- ditian_sui.json 与 master 主源任注本的"注层差"（刘基注本 vs 任铁樵注本）目前仅在本文档与 crosscheck 中显式区分，ditian_sui.json 的 `_meta` 未注明"任注对照"，易误认二者同源——建议 OPT-02 在 json 增注记。
- 主源任注本"寒暖/燥湿"是否应进 TIAO_HOU 机械表：因 TIAO_HOU 书源已标穷通宝鉴，且滴天髓寒暖燥湿是**思想源**而非月支×日干处方表，宜作叙述层引文而非重复入库——见 OPT-03。
- 主源"清浊/真神假神"逐字引文（L2858/L2946/L2991）与 verdicts 从格引文（刘基注本 verse）属同概念不同注层，是否并立登记待裁——见 OPT-04。
