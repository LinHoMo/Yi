## 一、书目与版本

本书是**纳音论命体系的祖源书**：卷首四库提要明确其成书真相——旧题"鬼谷子撰、唐李虚中注"，实为"疑唐代本有此书，宋时谈星学者以说阐入其间"（源L6）的层累文本；四库馆臣依晁氏原目厘为三卷，自《永乐大典》辑出（源L6：`惟《永乐大典》所取其文，尚多完具`）。韩愈墓志称李虚中"以人之始生年月日所值日辰支干相生胜衰死王相，斟酌推人寿夭贵贱"——即**年月日三柱（不含时）之法**，提要考证"首论六十甲子不及生人时刻干支，其法颇与韩愈墓志所言始生年月日者相合"（源L6），而后半多称四柱，实起于宋，真伪杂糅。后世传星命之学者皆以虚中为祖（源L6）。卷首自序（源L9）托言司马季主遇鬼谷子"至晓出遗文九篇，包括三才指陈万物"，且自序署"元和初载"——馆臣案语即以"唐惟天宝至德称载"指其作伪（源L11：`案唐惟天宝至德称载此序后元和而亦称载是即作伪之一证`）。

**体系定位（对引擎最重要）**：本书论命以**三元**为纲——干为天元禄、支为地元财命、纳音为人元身命（源L115-116），以年为本、日为主（源L124），判轻重、辨真假邪正、观升降清浊，全部围绕**纳音五行**与禄马神煞展开。这与本仓库命科现行的**子平日主法**（以日干为我、十神生克、月令格局、调候）是两套不同范式：同一天干地支，本书取"本命纳音"论身，子平取"日干"论我。**本书判据不得未经换算直接接入子平 analyze**（详见 §五/OPT-02）。

**主源形态**：殆知阁转录本无分卷版心，卷次由行内"李虚中命书卷上/中/下"标出（源L13/L84/L233）；各篇再以双字标题分节（通理物化、真假邪正、升降清浊、衰旺取时、贵贱所成、三元九限、天承地禄、水土名用）。卷上 L14-74 为六十甲子逐柱断语（每柱一句"某子天官藏，乃…之X，（贵格判语。）"），是全书机械结构最规整的部分。

## 二、逐卷（章）深读

### 卷上·六十甲子纳音逐柱断（源L12-75）

六十甲子每柱一句断语：先给干支拟象名（"天官藏""禄官承""神头禄"），再以纳音五行的状态（旺衰、墓库、生克）给"贵格判语"（括注）。这是**纳音论命的最小判据单元**，每句自成一个可独立核验的处方，但判语是吉凶断语层，机械层只有"纳音+旺衰+生克"结构。核心判据：

- 甲子金，源L14：`甲子天官藏，是子旺母衰之金，溺于水下而韬光须假火革` → 海中金坐子（沐浴地），金沉水下须火革方扬名——"纳音+坐支状态→取用"的最小模型。现状：core 纳音表（`core/yishu_core/symbols.py` NAYIN）已备纳音五行，"纳音坐支状态取用"层引擎无，登记为体系差异。
- 乙丑金，源L15：`乙丑禄官承，乃库墓守财之金，不嫌鬼旺之方，喜见禄财之地` → 金库之金不怕鬼旺；括注"平和贵格，不须禄到"。现状：纳音墓库状态判语未入库，合理不采（纳音论命层未建）。
- 丙寅火括注的转录校字，源L16：`（命入贵格，不用子【或“干”】禄。）` → 括注内【或"干"】为转录者两读校字，说明底本此处有异文（§五）。
- 六十柱收束总论，源L75：`此六十位五行支干相乘，要分轻重，若金溺水下，火出水上，木不得金之所制，木无成也` → 全部六十柱断语的方法论收束：轻重二字是纳音法的核心变量。现状：轻重概念未入引擎。
- **转录缺陷重灾区**：源L70：`庚申神头禄，乃未坚柔末之木，春相夏旺，金重而得火，土重而得水，则为出常之器。不畏阳官，要官鬼旺。` 与源L71：`辛酉神头禄，乃未坚柔末之木，春相夏旺，金重而得火，土重而得水，则为出常之器。不畏阳官，要官鬼旺。`——L71 整句复制 L70（仅干支换字），真正的辛酉断语在源L72：`辛酉神头禄，乃包秀结英之木，喜于生旺，忌见金多，得土水相乘为物之贵，二者各旺而不得水，亦为奇特之材。不嫌官鬼，厌甲为财。` → **L71 是转录重出的假条**（六十柱现 61 行），引用辛酉时必须取 L72（§五/OPT-06）。

### 卷上·贵人禄马诸法（源L76-83）

本卷后半是**神煞法**：本家贵人取法、天乙贵人颂、贵神优劣（进神/交神/退神/伏神/羊刃贵神/截路空亡贵神等名目×六十甲子）、贵格三等、紫虚局诗诀、贵合贵食、天乙贵神合。这是本书与现行引擎最接近的部分——天乙贵人口诀与 `core/yishu_core/shensha.py` 完全同口径：

- 本家贵人命法，源L76：`本家贵人命者，如甲人有戊有庚有丑有未是也大贵` → 甲戊庚人见丑未为大贵，且"然细分之则甲尤喜未，庚尤喜丑，各归其库也"——贵人分归库位的细化。现状：`shensha.py` TIAN_YI_GUI_REN（甲/戊/庚→[丑,未]，乙/己→[子,申]，丙/丁→[亥,酉]，壬/癸→[卯,巳]，辛→[午,寅]）与此同口径，但注释出处挂《三命通会》通行起例、verified=false；本书提供可逐字回指的更早书源（OPT-01）。
- 贵人总颂，源L77：`天乙贵人者，三命中最吉之神也。若人遇之，主荣名早达，官录易进。` → 引"三命指掌"；断语层不进评分，神煞标签层一致。
- 贵合贵食（引"阎东叟书"），源L82：`如甲戊庚贵在丑未，甲得己丑己未，戊得癸丑癸未，庚得乙丑乙未` → 天干五合把贵人干支"合入"命内为贵合，食神干支为贵食——**干合与神煞的复合判据**。现状：天干五合在 core（relations），神煞在 shensha，复合层未建；判据可指回，登记为可选扩展（OPT-01 附带）。
- 紫虚局诗诀，源L81：`贵人交互人多贵，旺气相乘馆殿资，切莫五行伤著主，令人闲地冷清虚。` → 互换见贵须五行不伤主；诗诀层不采。
- 贵神优劣表（源L78-79）：进神/交神/退神/伏神/羊刃贵神/截路空亡贵神等按六十甲子列吉凶等第——神煞等第表，机械层可验但断语为官爵言，登记不采。

### 卷中·通理物化：三元与四柱（源L84-137）

宇宙论铺陈（清浊二气→八卦→十干十二支）后，落到**三元分工**与**四柱权重**两个可操作结构：

- 三元定义，源L115：`元命胜负三元者干禄支命，纳音身各分衰旺之地。`、源L116：`干主名禄贵权，为衣食受用之基；支主金珠积富，为得失荣枯之本；纳音主材能器识，为人伦亲属之宗。` → 干管贵贱、支管贫富、纳音管才能器识——**三元各管一域**。现状：子平法以日干一元统摄（十神/强弱/格局），无三元分工；此书判据若入引擎须先立体系边界（OPT-02）。
- 四柱权重，源L118：`四柱者胎月日时三元为万物之本，四柱乃五行之辅佐` → 胎月日时四柱与三元的关系；随后胎/月/日/时各按"主事几分子分"计权（源L119：`胎主父母祖宗者十分，主事者二分`）——**数值化的柱位权重表**。现状：引擎无柱位加权机制；子平重月令提纲、本书重日时（"大抵年为本则日为主"，源L124），两法重心不同，登记差异。
- 纳音数理，源L97：`甲己真宫，乙庚真商，丙辛真羽，丁壬真角，戊癸真徵。` → 十干配五音（真气德合）；源L98：`寅午戌火体，亥卯未木体，申子辰水体。巳酉丑金体` → 三合局配四象体。现状：三合局 core 有（SAN_HE_GROUPS），五音层无（合理不采，属音律象法）。
- 纳音生成数，源L99：`六十纳音者，配由十干十二支，周而终之数也。`、源L104：`故经云：先甲后子纳音金者数也` → 纳音由干支数（甲己子午九…巳亥四）加减得五行——纳音的**数理推导公式**。现状：core 纳音为查表（NAYIN），无数理推导层；两法等价，无需改。
- 轻重总法，源L136：`复以轻重之理，方得贵贱之原。须以六十纳音支干轻重取衰旺制度，方定贵贱也。` → 逐柱轻重是全书裁决器；源L137 给出实例格"体轻用重"（辛未年壬辰月甲申日甲戌时）。

### 卷中·五行多寡论性情与真假邪正（源L138-232）

"水得水多/火得火多…"二十条五行多寡性情断（源L138-162），再入真假邪正、升降清浊两篇。性情断语不进引擎；本段可取的是**真假合的机械结构**：

- 性情断例，源L138：`水得水多，则沉潜伏溺，小巧多权，苗而不秀，声誉汪洋。` → 五行多寡→性情；源L142：`火得火多，则崇礼义泊，明外昏内，自华而俭，既旺既己，不可速达。` 与源L143：`火得火多，则崇礼义泊，明外昏内，自华而俭，既旺即己，不可速达。` ——**L142/L143 重出**（"既己/即己"一字之差），转录重复，引用取其一（§五）。现状：性情断语不采（人格判断，铁律三口径慎用）。
- 守位真假，源L184：`守位则正，失方则邪。` → 甲寅乙卯在亥卯未为正体、居巳酉丑为失位——**纳音干支专位**判真假。现状：未入库；专位概念与本书末篇"神头禄"呼应。
- 阴生阳死，源L185：`阴生阳死，逆顺相因。甲气申方，乙绝酉位。` → 阳干顺行阴干逆行的长生十二宫分配——core 十二长生表已备（symbols），口径一致。
- 真假干合，源L202：`子巳体壬丁之会，卯申同乙庚之交` → 子中癸与巳中戊、卯中乙与申中庚的**藏干暗合**——支藏干合的机械判据。现状：藏干 core 有（CANG_GAN），跨支藏干暗合未建；可作标签层扩展（OPT-03 附带）。
- 干支专位不冲，源L382（神头禄篇，提前引证）：`凡甲寅得庚申不为刑，乙卯得辛酉不为鬼，是木女金夫之正体` → 专位干支相冲不以为刑——**专位豁免规则**。现状：未入库，登记。

### 卷中·升降清浊（源L208-232）

清浊升降论贵贱：清得地转清、浊会浊愈浊（智仁清/礼义浊），五行"得地"与否决定层级。判据多为吉断层，机械结构有二：

- 官鬼与禄位，源L213：`禄位有无，认于官鬼。` → 身有地禄更要干中无官鬼，"有官鬼虽贵而多殃"——纳音法以官鬼为忌的定向。现状：与子平"官星为用"取向不同，体系差异登记。
- 五行相救，源L214：`身土遇火生而渐利，命水得金降而优长。金多须火或从革以成名，木重得金揉曲直而任使。` → 五行偏枯的调停法——**此句与子平调候/扶抑精神相通**，可作叙述层旁证。
- 时禄格局例，源L216：`时居日禄，当得路于青云。` → 日禄归时格（附己巳年己巳月己巳日庚午时实例）；现状：日禄归时属子平格局范畴，verdicts 未收此名目，登记。
- 四季土所从，源L245：`辰为木之土，戌为金之土，未为火之土，丑为水之土。` → 四库各随所藏成土用；与 core 墓库概念（辰水库/戌火库/丑金库/未木库）**取象方向相反**（本书按"土随所生"言，core 按"库藏"言）——口径差异，登记不混用。

### 卷下·衰旺取时与贵贱所成（源L233-307）

衰旺取时讲十二宫的进退（进角孤/退角寡、华过衰而实成）；贵贱所成汇集**八条贫贱格**与诸吉格，是全书判语最密的一段：

- 贫贱格总表，源L257：`贵贱所成，刑聚败极。`、源L258：`四柱不收，甲子得丙寅丁巳辛亥壬申之类。`、源L264：`柱多隔角，辛丑得辛卯，甲子得甲戌。` → 刑聚败极/四柱不收/五行未备/数无取用/一方前后/柱多隔角/真者失时/假者殃克/主本倒乱/父子乖违，每格附干支实例——**负格判据库**。现状：verdicts 无对应；断语为"贫贱害身"级，不进评分，机械结构（如"日克年、时克月"）可作标签实验（OPT-05）。
- 父子乖违，源L268：`父子乖违。日克年，时克月，贫贱之人皆从此出` → 以年月日时的干支相克定六亲乖违；纯命定断语，登记不采。
- 三奇，源L284：`五行各有奇仪，须分逆顺。`、源L285：`甲戊庚金奇喜辰戌丑未或金方，乙丙丁火奇喜寅午戌或酉方` → **三奇贵人**分五组（甲戊庚/乙丙丁/丙辛癸/丁壬甲/甲己丙）并各配喜方，与通行"天上三奇甲戊庚、地下三奇乙丙丁、人中三奇壬癸辛"分法**不同**（本书还多出"丙辛癸水奇""丁壬甲木奇""甲己丙土奇"三组）——**三奇有两种口径**，实现前须择一并留档（OPT-03）。现状：`shensha.py` 无三奇表。
- 七元疾厄（源L304-305）：干鬼冲破主头目之疾、纳音支犯主手足之厄——疾病断语，不采（铁律三）。

### 卷下·三元九限与天承地禄（源L308-386）

大运小运起法与九限名目，是天承地禄（六十干支两两合德）与神头禄（专位干支配十二天将）之前的应用层：

- 大运起法，源L309：`自生得节日为初，阳男阴女顺而理，阴男阳女逆而推。` → 与 ming_tables.py 大运方向（阳年男/阴年女顺行）一致；"三日成之一年"（同段）与 `DAYS_PER_LUCK_YEAR=3` 一致——**书源与引擎同构**，可为 ming_tables 大运注释补并列书源（OPT-04 附带）。

## 四、对勘与口径分歧

本书无对勘本（registry `crosscheck` 为空，殆知阁孤本转录），无法跑 `tools/crosscheck_source.py`。版本校验只能**内证**：

1. **四库提要自证**：卷首提要（源L6）完整交代辑源（《永乐大典》）、卷数依晁公武《郡斋读书志》三卷、以及"托名于虚中之注鬼谷，以自神其术"的成书判断——本仓转录本保留提要全文，属四库本系统，非民间坊刻杂抄。
2. **内证矛盾已由馆臣点明**："首论六十甲子不及生人时刻干支……后半乃多称四柱，其说实起于宋，与前文殊相谬戾"（源L6）——**本书本身就是两个时代的叠加层**：卷上六十甲子断近唐法（三柱），卷中卷下四柱九限近宋法。引用时须分清层位：与韩愈墓志同构的是纳音三柱层，四柱权重（胎月日时）层已非虚中原法。
3. **转录重出**：源L71 辛酉条复制源L70 庚申正文（仅换干支字），致六十甲子现 61 行；源L142/L143"火得火多"重出两行。此类是殆知阁转录层缺陷，非底本异文（§五/OPT-06）。
4. **与现行引擎的口径分歧（体系层，最重要）**：
   - 三元 vs 一元：本书干禄/支命/纳音身三分（源L115-116），引擎子平日干一元统摄——**同一"用神"一词两义**，本书之"禄"是干禄非十神比肩；混用即错。
   - 小运起法：本书男起丙寅/女起壬申（源L311），pattern.py 自生时干支起——两法在古籍中并存，引擎取子平通行法，本书法仅登记。
   - 三奇分法：本书五组（源L285）与通行三分（天上甲戊庚/地下乙丙丁/人中壬癸辛，《兰台妙选》源L75 同）不同——若实现三奇须择一口径并留档两法。
   - 四库土性：本书"辰为木之土…"（源L245）与 core 墓库（辰=水库）取象方向不同——core 墓库不动，本书句只作体系差异登记。
5. **官鬼定向相反**：本书"禄位有无，认于官鬼"（源L213）以官鬼为病，子平正官多为用神——两法对同一十神的吉凶取向相反，是体系差异而非某方讹误，禁止用本书校正子平评分。

## 五、不适用与存疑

**不采内容及理由**：

- **六十甲子逐柱吉凶断语**（L14-74）：断语层为"贵格/夭折/贫贱"级命定断言，机械层（纳音+坐支+旺衰）引擎未建纳音论命层——整体登记不采，待将来若建"纳音结构标签"层再评估。
- **性情人品断**（L138-162）：五行多寡定"奸诈小人/好食无厌"式人格判断，铁律三口径下不进评分、叙述层亦慎用。
- **官爵等第断**（L78-83 贵神优劣、L80 贵格三等、"官居一品/两制两省"）：科举官制断语，现代问域无对应。
- **疾病灾厄断**（L304-305 七元疾厄）：医疗断言须专业意见提示（铁律三），不建。
- **修仙出命句**（L114）：`出五行之外者，生死在乎我` —— 修行超命数段，与推演无关。

**OCR/转录缺陷登记**（引文照录原样）：

1. 源L70/L71/L72：辛酉条三现——L71 复制 L70 正文（`辛酉神头禄，乃未坚柔末之木，春相夏旺，金重而得火，土重而得水，则为出常之器。不畏阳官，要官鬼旺。`），真条在 L72；六十甲子断语因此现 61 行。
2. 源L142/L143：`火得火多，则崇礼义泊，明外昏内，自华而俭，既旺既己，不可速达。` 与 `火得火多，则崇礼义泊，明外昏内，自华而俭，既旺即己，不可速达。` 重出（"既己/即己"一字异）。
3. 源L102：`取极之数而先称九，而后损之八七五***也` ——行尾"***"为转录乱码（原文疑为"四三二"递损数列）。
4. 源L123：`凹柱相冲然无配合纳音，取宾主保义情亲，以定胜负。` ——"凹柱"为"四柱"之形讹。
5. 源L16：`（命入贵格，不用子【或“干”】禄。）` ——转录者以【或"干"】存两读，底本异文未定。

**存疑**：

- **"未坚柔末之木"**（L70 庚申）：文义未安（他本或作"坚成之木"类），无对勘本可核，存疑。
- **卷上是否原有"时柱"**：提要谓虚中法不及时辰，但卷中已有"时主用度进退向背力气胜负皆十分"（源L121）的时柱权重——两说并存的层累痕迹，引用判据时按提要口径优先归层。
