## 二、逐卷（章）深读

### 四阳四阴定理：天干阴阳机械计数

本书核心机械判据之一：以胎、月、日、时四柱天干阴阳多寡推父母寿夭——年仪/月仪诀。

- 四阳克母，源L18：`四阳俱立定知难有阴尊` → 胎月日时四柱天干阳多阴少（阳干甲丙戊庚壬），断母不寿。**机械结构**：统计胎/月/日/时四柱天干，计数阳≥4 → 触发标签。现状：`pattern.py` 有 `ten_god_combos` 做十神组合统计，但**天干阴阳独立计数层**未建（OPT-01）。口径提醒：凶象只标"偏向母宫信号"，不述"必克母"（铁律三）。
- 四阴克父，源L18：`阴覆全逢不见阳尊老夀` → 乙丁己辛癸阴干居多→父不寿。现状同"四阳"，可对称扩展（OPT-01 附带）。
- 阳干/阴干口径，源L18：`阳干者甲丙戊庚壬为阳干也` + `乙丁巳辛癸为阴干也` → 与 core 阴阳表（`core/yishu_core/relations.py` `STEM_YINYANG`）一致，无需改。

### 纳音轻重与干克区别

- 音克权重大于干克，源L18：`时来破日音凶而干见还轻`、源L18：`凡干尅在头面音尅在身及四支也故干轻音重也` → **纳音相克 > 天干相克**的严重度权重模型；且"干克在头面、音克在四肢"将克应映射到身体部位。现状：纳音在 `core/yishu_core/symbols.py` NAYIN 有，**音克权重层未建**；身体部位映射属医疗断言（铁律三），不采归经。
- 本家可证口径，源L19：`月建日时有月者为之月仪也假令甲午人辛未日时当年六月是辛未乃有贵有仪` → 月仪/年仪为年时/时日干支尊卑配——engine 无对应。

### 神煞天将体系：功曹/传送/朱雀/玄武

本书天将体系与现行命科神煞分属两套体系：

- 功曹/传送格，源L18：`寅为功曹主曹吏申为传送主道路上`、源L18：`寅申庚甲商路吏人` → 寅=功曹（曹吏）、申=传送（道路）取象职业归属。现状：`core/yishu_core/shensha.py` 收子平通行神煞，**未收功曹/传送等天将语义体系**；六壬科有天将体系，学科归属边界需明确（OPT-03）。
- 道士/僧人断，源L18：`丙戊丁甲时运戌亥道士僧人`、源L18：`壬多艮坎道士须尊` → 以戌亥见丙丁戊甲 + 壬多子丑位→僧道。现状：职业断语铁律三口径下不采；但干支条件可作结构标签候选（OPT-02 附带）。
- 他乡外立，源L18：`子午逢之他乡外立`、源L18：`子午为阴阳二路上见庚甲者主他乡外立也为庚甲二干至水火之真路而败也` → 子午+庚甲→迁移他乡。现状：迁移断语不采；子午冲 engine `CHONG_PAIRS` 可覆盖结构。

### 三竒/三交/四象与官事刑凶

## 四、对勘与口径分歧

本书无对勘本（registry `crosscheck` 为空），四库即从《永乐大典》辑出。版本校验只能**内证**：

1. **提要自证**：提要（源L3）明言"旧本题晋郭璞撰张颙注""勘验书中多涉江南方言疑书与注文均出自张颙一人之手"——四库馆臣已否定郭璞 authorship，定位"晚出依托之本"。取用判据时须归"张颙"或"佚名"，不挂郭璞（OPT-04）。
2. **四库存目定位**：提要肯定"如论年仪月仪六害三竒三交四象之类尤多所阐发"（源L3）：给出四个关键词，可作本书方法论的**最小标签集**；提要批评"专以月建及胎元为推测之本则不为定论"，指示月建≠胎元判定差异。
3. **与现行引擎的口径分歧**：
   - 本书"四阳/四阴"以**天干阴阳计数**为变量，engine 强弱判据以"生扶 vs 克泄耗"生克加权和为主——两法判断的不是同一维度。可并行计数为"辅助信号标签"，不与 engine 强弱结论混用。
   - 本书神煞体系偏向天将语义命名（功曹/传送/朱雀/玄武/勾陈/太常/太阴等），`shensha.py` 收子平通行神煞，**与六壬天将体系同名异义**——混用即错。
   - 五行多寡直断（"水火多→某病/道士/僧人"等 40+条）进 engine 会触发铁律三（命定断言不采），只可作**可选标签实验层**而非评分层扩展。
   - 命宫算法差异：本书"生月上虚起神命阳顺阴逆数之到天上生时为命宫"（L18），engine `ming_gong_branch` 的"寅起正月逆数至生时"初值表不同，不一致一化。
   - 月建≠胎元：提要已批评（源L3），engine 有胎元`tai_yuan`与月建两路判据，互相不混用。

- **凶灾命定断**（"自缢""自残""军盗亡殁""阵前分首"）：不采，结构注册即可。

**OCR/转录缺陷**：本书单行超长（L18 约11332字、L19 约4199字），转录使用`夘`（卯异体 U+5918）、``（玄异体 U+8698）、``（传形讹）、``（将形讹）、`【囚】`占位符（原刻校字），引用时以原貌照录，不擅作简化（§六/OPT-04）。
