## 二、逐卷（章）深读

### 卷一·大六壬心印赋（L19-L201）——起课四门与九宗门条件

本卷以「六壬如人，先明日辰」开篇，术语随文白话：**日辰**＝日干加日支，为课之主体；**地盘**＝十二支固定之位；**天盘**＝月将加时后浮于地盘之上的十二神。术语解释：**天干阳也，干上得者曰日** → 日干／地支之上各有一神，此神称「上神」，四课由此而生。

**十干寄宫**（L20）：源L20：`甲课在寅乙课在辰，丙戊课在巳，丁己课在未，庚课在申，辛课在戌，壬课在亥，癸课在丑。` → 与《六壬大全》完全同歌，属跨书共有的定名源。

**月将（中气换将）**（L21）：源L21：`正月雨水后日躔娵訾之次入亥宫，乃登明将也` → 十二将按中气（非节）换将，雨水后入亥为登明、大寒后入子为神后。此为 `YUEJIANG_POLICY = "zhongqi"` 的书源依据。

**四课阴阳定位**（L22）：源L22：`天干阳也，干上得者曰日，干上阳神为第一课，乃阳中之阳也` → 第一课阳中之阳、第二课阳中之阴、第三课阴中之阳、第四课阴中之阴，序号固定不可颠倒（后文涉害「涉之深浅」、昴星「阴日／阳日」全依赖此编号）。

**三传相因**（L23）：源L23：`俱以所得发用为初传，以初传地盘上所乘者为中传，以中传地盘上所乘者为末传，故曰相因也。` → 三传的机械递推式，是九宗门全部取法的共同出口。

**九宗门逐门条件**（L23-L29）：

- 贼克二门（L23）：下贼上＝重审，上克下＝元首；L24 明言「上克下曰克，下克上曰贼」并以阳日／阴日定比用取阳／阴。
- 比用·知一（L24）：阳日取子寅辰午申戌之阳神，阴日取丑卯巳未酉亥之阴神。
- 涉害二名（L24）：源L24：`先以寅申巳亥上乘之神为用，则涉之深而建名曰见机` → 涉害深者用四孟神，名**见机**；源L24：`若孟神上无克贼则以子午卯酉上乘之神为用，此涉之浅而又名曰察微` → 涉害浅者用四仲神，名**察微**。二名是**同一门的两个分支标签**，与《六壬大全》「涉害」单一课名不同，是本书独有的细分。
- 遥克二名（L25）：源L25：`名神遥克日，曰蒿矢课` → 上神遥克日干＝蒿矢；日干遥克上神＝弹射。二者力轻，择一仍用比用法。
- 昴星（L26）：源L26：`阳日则取酉上所得之神为发用` → 阳日取天盘酉上之神发用，阴日取地盘酉下之神发用；中末传阳日辰作中传日作末传、阴日反之。
- 别责（L27）：源L27：`若阴日得之以地支之三合前一位用之，而不用乘神，静之机也。`；源L27：`三合前一位者，如巳酉丑、亥卯未，酉日用丑，丑日用巳，未日用亥是也。` → 阳日取天干五合寄宫、阴日取地支三合前一位，**不用天上乘神**。触发条件（L27）：四课首尾相同（只三课）或二三相同（亦三课）。
- 伏吟（L28）：源L28：`有克者取克，不过癸乙二干而已。` → 伏吟有克者仍取克，范围限癸、乙二干；无克者阳日自干上发传、阴日自辰上发传，迤逦三刑。刑分三等：L28 自刑（午辰酉亥）、二字刑（卯刑子、子刑卯）、三字刑（丑刑戌戌刑未未刑丑、寅刑巳巳刑申申刑寅）。
- 返吟（L28）：源L28：`反吟乃子加午、卯加酉，十二神各临冲射之位也。`；源L28：`若夫丁未、己未、辛未、丁丑、己丑、辛丑六课无克，乃名无依` → 返吟无克六日（丁未己未辛未丁丑己丑辛丑）另立**无依（无亲、井栏）**之名，取支神井栏冲射所得为初用，日支所乘为中传、日干所乘为末传，井栏＝丑冲未、巳冲亥。
- 八专（L29）：源L29：`阳日则顺从干上阳神得三而止；阴日则逆从支上阴神得三而止` → 干支同位只得二课，有克仍走贼克／比用／涉害，**无克不复取遥**，专用八专。

**天将布法**（L29-L30）：源L29：`天乙居中，后六前五` → 贵人（天乙）居十二将之中位，其后六位为天空、白虎、太常、玄武、太阴、天后，其前五位为腾蛇、朱雀、六合、勾陈、青龙。顺逆判据（L30）：源L30：`在天门之前、地户之后则顺行；若居地户之前、天门之后则逆行。` → 十二将相对贵人的顺逆由贵人所在位定：处天门（寅）之前、地户（戌）之后则顺，处地户之前、天门之后则逆。

### 卷一·赋后课体杂名（L128-L201）——附卦名与规则条件

赋文四字一诀，○注给条件，是六十四课体中除九宗门外的一批**结构课体**。摘其条件明确者：

- 龙首（L154）：太岁、月建、月将、贵人同为发用。
- 龙战（L156）：卯酉日辰／行年发用。卷二 L405-L406 补充「用卯为龙战，用酉为虎斗」。
- 芜淫（L166）：上神互克干支。
- 淫女（L168）：初传天后、末传六合，中传见卯酉。
- 三交（L170）：子午卯酉仲神全在三传。卷二 L412-L413 补充「有克发用二交」。
- 九丑（L172）：乙戊己辛壬日更得四仲相并，又大吉加仲上。卷二 L614-L616 给出「真九丑」十日干支清单。
- 斩关（L174）：魁罡加干支，更得六合或青龙。
- 游子（L176）：辰戌丑未为四季在三传，本静而丁神天马入之。
- 天狱（L178）：源L178：`○凡用神囚死更天罡加日本之上曰天狱卦` → 用神落囚死 + 天罡（辰）加日。
- 天网（L180）：源L180：`○凡时与用神并克天干者曰天网卦` → 时干与用神**并**克日干。
- 无禄（L186）：四课皆上克下。绝嗣（L188）：四课皆下贼上。→ 二者与《毕法》「四上克为无禄、四下贼为绝嗣」同（卷二 L393-L395 复见）。
- 励德（L190）：源L190：`○贵人当卯酉之上曰励德卦。` → 卷二 L398-L399 细化为「贵人临卯酉分前后」：阳神立贵人后为小人恃势、阴神立贵人前。
- 乱首（L192）：日加辰而被克。卷二 L371 表述为「日临辰而受克为乱首」。
- 曲直（L196）：三传亥卯未；L198 从革＝三传巳酉丑；L200 炎上＝三传寅午戌；L202 润下＝三传申子辰。
- 稼穑（L194）：辰戌丑未全在三传。
- 玄胎（L182）：寅申巳亥全在三传。
- 冬蛇掩目（L143）：昴星课 + 腾蛇发用。虎视转篷（L145）：昴星课 + 白虎发用。

以上每条「○注」的**前半句均为可机械判定的结构条件**，后半句的断语（主灾／主淫／主破散）属 narrative 候选。本项目 `kemu.json` 的 64 条 `note` 大量取自《六壬大全》卷七~十课经集，**本书这批条件是尚未对撞的第二个来源**。

### 卷二·大六壬九天玄女指掌赋（L324-L620）——日辰加临八名与杂门

卷二体例与卷一互为补：卷一释「怎么起课」，卷二释「起课之后怎么加减判断」。

**日辰加临八名**（L371-L386）——这是本书最干净的一组纯结构课体，全部是「日／支」二者的位置与生克四种组合，无任何神煞依赖：

- 源L371：`日临辰而受克为乱首，主行悖逆之道。` → 日干加日支、被支上神克。
- 源L372：`辰临日而受克为赘婿，不能自立其身。` → 地支加日干、被日干克。
- L374-L377：辰临日而生日＝自在；日临辰而受生＝俸就。
- L378-L381：日临辰而生辰＝历虚；辰临日而受生＝归宠。
- L382-L383：同类相加＝培植和合（比肩）。
- 源L384：`日辰交生名为脱骨` → 日上神与辰上神互生。
- 源L385：`日辰交克号曰无涉` → 日上神与辰上神互克。

注：卷二 L373 以庚寅日寅加申为例释「辰临日而日克之」；L379 释「日临辰而生辰」为「我去生他，他为脱气」。

**四位旺相休囚死**（L246-L252、L368）——五行状态标签的取用原则：源L248：`○旺气发用利求官，相气发用利求财，囚气发用讼则囚系、呻吟，死气发用病必死亡哭泣，休气发用疾病淹缠，若日墓同之必凶。` → 「旺／相／休／囚／死」是**五种机械状态**（按月支判，五行同派），本书用它做一切用神取用的总闸；「日墓」＝日干落墓位，为第六个特殊态。L363 另给顺逆定「前／后」的可机械算法：源L363：`如甲课在寅则卯为后而丑为前。` → 寄宫之后一位为「后」（未来），前一位为「前」（已往），配合 L360 `用在日前事情已过，用居日后事起将来。` 构成**时序方向标签**。

**克应期**（L365）——引苗公七位克应诀，源L365：`如见寅卯则应在辰月辰日辰时，如见巳午则应在未月未日未时` → 用神落某支则应某支之月日时。此条在结构上可机械实现（纯支序映射），但其**应用**是断应期（预测），属 narrative 候选。

**四位课体**（L441-L443）——三光与三阳的完整条件，本书给得比《六壬大全》更细：源L443：`用旺相一光，吉神临用二光，日辰旺相当令三光；用旺相一阳，日在天乙前二阳，贵顺布三阳，忌克破刑冲害。` → 三光为**累加式**三条件（用旺相／吉神临用／日辰旺相当令），三阳亦三条件（用旺相／日在天乙前／贵顺布），且明确「忌克破刑冲害」的否决项。此条是本项目**可直接落地**的机械结构：三光三阳条件全部只依赖旺相与天将布法，无神煞。

**六仪三奇四奇三奇位**（L446）——旬奇与旬仪的完整映射：源L446：`旬首发用为六仪，子戌旬奇在丑，申午旬奇在子，辰寅旬中奇在亥` → 六仪＝旬首之仪发用；三奇位＝子戌旬→丑、申午旬→子、辰寅旬→亥。此与 `kemu.json` 的 `rules.xun_qi`（子→丑、戌→丑、申→子、午→子、辰→亥、寅→亥）**逐位一致**，可作跨书互证。

**天魁／死神／丧魄／飞魂四煞**（L448-L450）——四煞的**定位算法**（结构）与其断语（叙事）分离：源L450：`死神正巳顺十二，是虎乘死神加日主死，加辰主丧，有吉可解。丧魄正未逆四季，飞魂正亥逆十二。` → 死神起巳顺行十二、丧魄起未逆四季、飞魂起亥逆十二；L450 前段另注「天魁在酉逆，因仲非河魁也」（天魁指河魁，非指玉堂）。

**三奸**（L714）——日辰关系组的第九条：源L714：`凡亥子丑有一位加于地盘仲上，则对冲处便为三奸。` → 亥／子／丑（孟）任一临地盘四仲（子午卯酉）之时，其对冲位定三奸。属纯位置条件。

**六神藏／四煞没**（L671-L673）——两组天将布法状态：源L673：`六神藏者，蛇临子，朱临丑，勾临卯，空临巳，虎临武玄临申是也。` → 螣蛇临子、朱雀临丑、勾陈临卯、天空临巳、白虎／玄武／（青龙）临申为六神藏；L673 前段「四煞即辰戌丑未而加四孟，则化凶为吉」为四煞没。两者均为**天将乘临的机械位置模式**，不含吉凶。

**空亡三段定位**（L582-L584）——源L582：`空亡乃耗散之神，初斩首、中折腰、末刖足。` → 空亡落初传／中传／末传各有名目，属纯位置分档；源L583：`辰戌为网罗之煞，辰覆巢、日毁卵、而用逵。` → 同一旬空落日辰（静位）名为覆巢／毁卵、落用神（动机）名为置逵。此条**把旬空与三传位置做了一个纯结构的映射**，是本书独有的可落地条件。

**孤立日辰与日墓**（L435-L436）——源L436：`如寅卯日当春之时则巳为孤丑为寡` → 四季之前为孤、之后为寡，示例春令（寅卯日）则巳孤、丑寡。属纯月令—日支条件。

**四离／四绝**（L431-L433）——源L431：`四离前一日为天寇，利居家而不利远行。`；源L432：`四绝前一日为天祸，事体绝而又复重兴。` → 天寇＝四离（四至：春分秋分冬至夏至）前一日；天祸＝四绝（四立：立春立夏立秋立冬）前一日。**此条比《六壬大全》更简明可机械化**（大全用「今日干支临昨日干支」，指南只取「前一日」），且不依赖旺相。

**类神取法**（L222-L243、L705-L719）——文看青龙、武看太常、捕贼看玄武、占天看云龙风虎、候风占雨看青龙白虎、迁官看天吏（寅）天城（卯申）、占捕盗贼看玄武之阴神、占行人以酉（东南行）／卯（西北行）为中途。L713 另给一套：「占功名先看吉神吉将，占官职当明天吏天城」。**类神表本身是可结构化的映射（占题 → 类神支）**，但断语部分全部超出骨架。

### 卷二·分类形状与时神段（L620-L793）——支物象与时神关系

## 四、对勘与口径分歧

**对勘本一致度（实测）**：对勘本 `liu-ren-zhi-nan.wikitext.txt` 长度 >8 的正文行 720 行，709 行在主源中有逐字对应（98.5%）。未命中 11 行中 9 行是维基文库语法（`{{Header|…}}`、`<!--====六壬指南/1======>`、`#[[/1|卷一注释心印赋]]`、`==大六壬心印赋==` 等），**实质异文仅 1 处**：

3. **天网条件**：本书 L180 作「时与用神**并**克天干」（时干与用神须同时克日）；L438 复述为「时克日而用又助之名曰天网」，两句同书而措辞微异（**一者强调并，后者强调用神为助**）。同书内部异读，登记为存疑（见 §五），实现时取「并克」读法并标 `verified=False`。

5. **「指南」书名与入库语料的历史**：本仓 `disciplines/liuren/data/cases/le_adjudication.json` L85 曾记「《大六壬指南》：仓库无此书语料（data/sources 无指南条目）」，L193 已按 2026-10-05i 入库情况翻案为维基文库实际书名《六壬指南》（旧条目按「大六壬指南」探得 missingtitle 系漏检）。**本解读稿以现状（已入库）为准**，该处历史记述不更正。

**口径归属**：机械结构条件以**本书 ○注层**（更细、有条件）为第一来源，**《六壬大全》课经集**为课体名与象辞来源；数值取用（涉害深浅、贵人顺逆）以现行引擎口径为准，差异一律进异说桶，不径改。

## 五、不适用与存疑

**不适用登记（超出骨架，一律不采）**：

1. **全书赋文断语与 ○注后半句断语**：心印赋「先凶后吉终成喜庆之征，始吉终凶终见悲哀之兆」、指掌赋「伏吟任信宜用静，去盗非遥」「八专之音不宜男子波波」等，**以及所有 ○注中「主灾／主祸／主淫／主破散／主吉庆」部分**——本项目只落地其前半句结构条件，断语一律 narrative 候选。
2. **十二支物象（州域／屋舍／人物／疾病）**：见 §三第 25 条。同一支多重取象（如丑为扬地、宫殿、桥梁、庭院、秃头、病腹脾肠）且无裁决规则，不可机械化，只作留底。
3. **类神断占法**（文看青龙、武看太常、捕贼看玄武、候风占雨看青龙白虎、占行人以酉卯为中途等）：占题→类神映射可读，但全部须年命／行年（引擎无年命层）且输出为占断方向，超出骨架。
4. **「神将克神为外战、神克将为内战」（L357-L359）**：「灾自外来／祸由内起」是方向判断；其结构部分（将克神／神克将两种互克形态）可算，但与课体命名不接，暂不立条。
5. **克应期推算（L365）**：条件可机械（支序映射），但用途是推算事应何月何日何时，属预测输出，超出骨架。
6. **疾病占与官灾占（L740-L742、L755-L766）**：「虎克日辰官灾痨病」之类为吉凶断语；另本项目无疾病科。
7. **旬空／墓神的吉凶用法**（L791 `财遇天中，产业倾颓；鬼临旬尾，官灾不起，`）：结构（财落空亡／官落旬尾）可算，方向不采。

**存疑登记（未读懂或同书异读，禁止脑补）**：

1. **天网同书异读**：L180「时与用神并克天干」vs L438「时克日而用又助」。两读不等价（一为并克、一为用神助克），**如实并存，未裁决**。
2. **贵人顺逆三说并存**：天门（寅）／地户（戌）为界（L30）、子至巳为阳／亥至午为阴（L726）、以及 L273 的「顺则凡事顺、逆则凡事逆」（纯断语无定位）。三说的分界集合不一致，**登记为口径异说桶候选，未裁决**。
3. **涉害深浅的「害」如何计**：L24 只说「涉之深／涉之浅」并给出四孟／四仲取用，未言沿途计害之法；`jiuzongmen.py::_she_hai_deep` 自定「上神自所临地盘位涉归本家、沿途上克下／下贼上各计一害」并标 `verified=False`。本书对此**无补充说明**，口径缺证，如实登记。
4. **涉害「俱比／俱不比」的取舍（L340 `克贼重重比涉害`）**：赋文一句带过，未给判定细节；`le_adjudication.json` 已把涉害异说列为三类失配之一。
5. **天魁即河魁（L450）**：「天魁在酉逆，因仲非河魁也」——此说以天魁为河魁（戌），与通行「天魁＝玉堂（丑）」不同。本仓 `kemu.json` 未见天魁／玉堂条目，**双方口径均未落地，不臆断**。
6. **「八迍五福」（L454-L455）**：「八是阴数…五是天之中数」——以数目阴阳释课名，规则本身不机械（何为八件事何为五件事无判据），且断语居主，**不采**。
7. **顺逆连茹／三间／四孟四仲四季的数十个别名**（L458-L535）：每条都是「三传某顺序＋季节」条件＋断语。别名密集且同书多处重出（如三交在 L170 名为三匿、在 L412 又名二烦；游子在 L176 与 L418 两次定义），**名词与条件的一一对应需逐条核，本轮不落**，登记待办。
8. **卷三《会纂占验指南》与卷四《神煞指南》正文缺失**：目录列出（源L8：`卷三六壬会纂占验指南`、源L9：`卷四大六壬神煞指南`），主源与对勘本**均只有卷一卷二正文**（对勘本 1568 行止于指掌赋末）。故本书的神煞部分（年命、驿马、天马、红砂、破碎煞等）**本轮无从解读**，登记为待补增量；`le_adjudication.json` q8 亦已指出下一步增量应为他本语料全文入库。
