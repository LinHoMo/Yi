## 二、逐卷（章）深读

### 卷一 测字十法（L12-124）

本卷立十法总纲：字有「体」，测有「法」，法即对字的加减乘除变换目录。开篇引邵子（雍）两条为全书立论：

- 源L12：`盖一字之来必各有体，因其体之隐现不同，故其测之变化不定。` → 测字对象是「体」（字形结构），吉凶不在字义本身而在体之隐现——这是全书把「字」当**运算对象**的宣言。
- 源L12：`体立而后用行。` → 邵子体用论直接移入测字：字形为体、所问之事为用。此语在梅花易数中是「体卦用卦」总纲（见 `disciplines/meihua/` 的体用生克层），本书借同一对概念指字形/问事，同名异理，见 §四。
- 源L12：`字不加减，不足以开问者之蒙昧` → 十法共同内核：对原字作笔画加减变形，使新字与新象对应所问之事。
- 源L14：`因其所问之事而推之，据吾所触之几而断之，百不失一。` → 装头法定义后的效果声明；「触几」即随机触机，是全书反复出现的不可机械化要素。
- 十法各自定义配例：装头（上添笔成字，L14）、接脚（下添笔，「字如人之体，有冠必有履」，源L36）、穿心（字中穿笔，L42）、包笼（周围包裹，L48）、破解（劈破加笔，「破易而解难，破平正而解奇幻，观后字可知」，源L56）、添笔（「添乃补不足，减乃损有余耳」，源L72）、减笔（有限定条件，「非事之当而理之正，不可漫然用之也」，源L82——减笔不可滥用，须事理正当方可用，是十法中最明确的一条**使用前置条件**）。
- 对关法被作者推为第一：源L86：`其法，专取头足首尾。` → 只取字的头尾两截各自成字，如「先」为牛头虎足/生头死足（源L88：`先（牛头虎足、生头死足）善（美头喜足）帛（皇头帝足）`）；源L86：`此法最简捷，其用又最广，为字中第一要义，学者更宜究心。` → 对关是十法中**机械性最强**的一法（首尾拆分规则明确），若将来扩科，这是拆字算子库的第一候选。
- 摘字法：源L96：`不妨摘字中一二些小笔画以断之，无不奇中。` → 从字中摘出小部件独立成字。
- 观梅测字：源L102：`观梅之法活泼泼地，惟在人之心镜光明，随物洞照而不遗纤毫，庶可得之。` → 第十法不再拆字，而是就字起象、随机应变；作者自陈此「邵子之心诀」。下附十天干字象：
  - 源L104：`天（凡事空虚，然利于行动。若问功名，宜于晴朗之日。此举一端，变化由人）` → 单字直出象意，且带**时间条件**（功名宜晴朗之日）。
  - 源L116：`木（春旺秋衰。亦观其何字，若松柏桂梅之类，又不在衰旺中论）` → 五行字象带旺衰（春旺秋衰），且给**例外开关**（松柏桂梅不按季节旺衰论）——旺衰+例外的双层结构，与五行旺衰判据同形。
  - 源L124：`审其来意与字到时上下左右远近之影响，借而用之，否则拆字。此至精之诀也。` → 观法的完整输入清单：来意、书写时环境（上下左右远近）。即测字的「情境变量表」。

### 卷二 心易六法（L126-192）

借六书（象形/会意/假借/谐声/指事/转注）立六门，每门配例。

- 象形法三分类：以字象物、以物象字、以字象字（L128-134，如「贵（破柜）」）；第四类以意象字：源L136：`以意象字：辛（似幸）未（似来）了（似了）兔（似免）夫（似失）桃（似挑）` → 字形近似（非字源）触发象意，是「形近替换」算子。
- 会意法：整字出象，如源L140：`烟（因风吹火之象，事必借力方成）` → 会意断语自带**因果解释**（烟=风吹火，故借力）。
- 假借法：源L168：`旦（借为春）千（借为夏）甲（借为秋）夕（借为冬）此四时借用于一日也。` → 假借即「字义引申开关」；下引立/子/口/心/化诸例皆借人事事物为用（L170-178）。
- 谐声法：源L182：`秤心（即称心）齐（内中差了即差在内也）耗（来日到了，倒到同音）` → 同音替换算子（谐音吉凶），是测字与民间谐音占共用的机制。
- 指事法：源L186：`其法必审其情性，察其动静，兼明其踪迹方妙` → 指事即按所问之事直接取格（通向卷四卷五）；其条件清单：源L188：`曰观人，曰察色，曰辨言，曰辨事，曰察墨，曰辨纸，曰观时，曰相机，曰正论勿好奇，曰言语不可杂。` → **十项情境条件**（观人/察色/辨言/辨事/察墨/辨纸/观时/相机/正论勿好奇/言语不可杂），是全书最系统的「输入侧校验表」。
- 转注法：源L190：`一字有二义、三义四义` → 多音多义字按读音切换断语；实例：源L192：`如临字问病，断不吉，则曰临丧，临乃去声也。王字问求财，断曰旺相，王乃去声读之。` → 转注是**读音开关**：同字异读改断。这是十法六法中最接近「机械条件分支」的一条（条件=读音，输出=断语）。

### 卷三 测字取格大法（L194-1084）

全书主体。总纲先立断语生成次序：

- 源L194：`法先详其五行生克，次观其六神动静。假若五行相生、六爻安静，则取吉格断之，否则以凶格断之。` → 取格总纲：**先五行生克、次六神动静**，再按吉格/凶格出断。这里把六爻体系的五行/六神语汇整体移植进测字——但测字场景里并无爻位与日月的实体，移植的是**语汇与吉凶倾向**，不是推演结构（§四）。
- 其后按部首编排格库：氵部（L196-238）、火部（L240）、金部（L242-254）、木部（L256-286）、土部（L288-296）、灬/丶/冫/丨/丿/彡/刂（L300-332）、数字部（一至十，L334-372）、几/厂/广/疒/亠（L378-414）、囗/冂/聿/匕/日/月/雨/山/川/石/田/米/豆（L420-544）、人/亻/彳/目/耳/手/口/心/忄（L546-644）、言/立/见/足/走/之/扌/才（L646-708）、页/曰/力/攵/又/方/非/欠/予/子/女/尸/食/皿/糸（L710-820）、巾/衣/寸/夕/西/艮/巳/酉/匀/阝/门/户/斤/车/臼/戈/弓/宀（L822-940）、贝/玉/羽/毛/凶/豸/犭/虍/牛/隹/鸟/鱼/虫（L942-1026）、竹/艹（L1028-1084）。
- 格库中借用六爻语汇的显例（证「语汇移植」判断）：
  - 源L358：`交（六爻乱动）` → 「六爻乱动」直接作为「交」字的断语意象。
  - 源L936：`穿（财爻落空空自嗟呀）` → 「财爻落空」入测字格。
  - 源L986：`牛（朱雀敛翼，先有一半，欲告无言）` → 六神（朱雀）入格。
  - 源L872：`陆（邻里和睦，土空则陷）` → 「土空则陷」与《易》五行空亡义理相通。
  - 源L490：`朋（胭脂零落，股肱有损）` → 断语以人体/人事喻字形，属纯意象格。

### 卷四 双句格法（L1086-1112）

一句格不足时以两句成文（松格）。作者自陈其适用层级：源L1086：`又有一句不能尽其所问之事，必用两句，语意方显者，乃松格也` → 双句格是单句格的表达扩展，非独立判据。例：

- 源L1096：`雨（否头，泰脚。）` → 以《易》卦名拆字（雨=否字头+泰字脚?——实为字形联想），卦名语汇入格。
- 源L1102：`崖（太岁当头，佳人有损。）` → 「太岁」入测字格。
- 源L1094：`焉（似马不能行动，似为服药无用。）` → 字形近似双断（似马/似为），与卷二象形法呼应。

### 卷五 测字散格法（L1114-1194）

散格立「骨格」概念：部件的**方位语**（头/脚/心/尾/中/来/去）作为束字义的语义原子。

- 源L1114：`盖骨者，束字义之物。用束字义之物为断字义之文` → 骨格定义：用部件方位词生成断语文本。
- 源L1136：`十（车心 舟尾来头 用尽 本来 不成才 针头）` → 单部件「十」在不同字中的位置各出不同意象（车心/舟尾/来头/针头），是方位算子的词表。
- 源L1188：`艮（根脚）占（上告乩动 点头 毡中）吉（半喜半结）` → 「占」字散格含「乩动」，占具语汇入格。

### 卷六 杂占赋（L1196-1208）

外应总赋：把天文、地理、人事、器物、禽虫一律当「应」，与所写字互证。

- 源L1198：`试观云开月朗，正为诸事豁达之机；雾合烟迷，定主百务淹埋之象。` → 天文外应总纲：气象→事态的映射。
- 源L1204：`若逢人事之来，即乃天机之现。` → 人事外应总纲：高官显宦利于求名、匠子主门庭改换、妊妇事萌于内等数十条（同行连排）。
- 源L1206：`鸿雁得宾朋之信，虺蛇防毒陷之谋。` → 禽虫外应例。
- 谐音占法密集段：源L1206：`见李问讼有理，逢杏占婚有幸，无衣可断无医。` 与源L1206：`纸为止，行人不来；书为输，官司必屈。` → 李=理、杏=幸、衣=医、纸=止、书=输，同音直断——卷二谐声法的规模化应用。

### 卷七 至理测法（L1210-1318）

五十余则实断案例，每例「断—验—字理自陈」三段，是全书唯一给出推演过程的部分，也是 OCR 重灾区（§五）。抽核心七例：

- **欠字问六甲**（L1210）：源L1210：`欠加两点为次，故知非首胎。加土为坎。坎，中男也，故知生儿。` → 拆字+八卦象（坎为中男）+日期合笔（初十加十一成坎）三层叠加。
- **门字问病**（L1212）：源L1212：`门字之形，乃日有余、月不足耳。` → 门=日月框合，月不足→女病必死。字形与日月（时间）绑定。
- **亥字问幼疾**（L1216）：源L1216：`亥乃孩不见子之象，上是六不全，中是久不得，下是人不长` → 亥=孩去子，三重拆解叠加数谶（月尽/时尽）；同例又以「一乃生字之终，死字之始」（源L1216）、「土能克水难过五日」收束——一例连用拆字、数谶、五行生克三套机制。
- **火字问出行**（L1226）：源L1226：`火字叠见，乃炎字也。北方水乡，此去有既济之义，故利耳。` → 两火成炎、北方水地成既济卦象——拆字+卦象+方位五行的复合。
- **凫字问官司**（L1228）：源L1228：`枭神头，白虎脚，勾陈身，膋蛇尾，四凶齐犯。` → 字分头身脚尾四段，各配六神（枭/白虎/勾陈/膋蛇），六神从六爻的「爻位标签」移用为「字形段位标签」。
- **元字二例同字异断**（L1230/L1232）：一断生女一断生男，作者自解：源L1232：`夫一字之来有一字之机` ——同字因笔画数奇偶、写法（三笔/四笔）不同而异断；并引邵康节：源L1232：`字同事不同，不宜此而宜彼；事同字不同，倏变吉而变凶。` → 这是全书的方法论自我声明：**输出依赖写者情境，同输入不同输出是特性而非缺陷**。与引擎「同输入同输出」的机械可复现要求正面冲突（§四）。
- **幸字问病**（L1236）：源L1236：`幸字反有三不幸焉。问病不宜见士与木` → 字面吉字反断凶（幸含辛劳、不成桑木、不完五十），展示了「反断」条件（问病+年庚四十九）。
- **磨字问地**（L1284）：源L1284：`设若书一仙字便能成仙，书一鬼字即能见鬼乎？` → 作者驳「字面直断」：字恶不必断凶——承认字面义与断语可分离，是全书少有的方法论自觉。

## 四、对勘与口径分歧

- **与梅花易数（`disciplines/meihua/`，书源 `meihua_yishu_dz.dz.txt`）**：本书卷一观梅测字法与卷二心易六法均托邵雍（梅花易数同为托邵之作）。「体立而后用行」（源L12）在梅花体系中指体卦/用卦生克，在本书中指字形/问事——**同名异理**。两书的「观梅」命名同源（邵雍观梅占），但本书观梅断的是字象，梅花断的是卦象。只可文献对话，不可把测字条目并入梅花判据。
- **与六爻（`disciplines/liuyao/`）**：卷三格库与卷七案例整体借用六爻语汇（五行生克、六神、财爻落空、六爻乱动、太岁、驿马），但测字场景无排盘实体——同一「白虎」在六爻中是日辰起六神落于爻位，在本书中是字形某段的凶神标签。语汇同源、结构不同，不构成口径冲突；若做「意象词源」考据可互证。
- **本书内部**：卷七「元字」两例同字异断（L1230 断女、L1232 断男，皆验）——作者以「字同事不同」「一字之来有一字之机」自洽，实质是把**书写情境纳入输入**。这与引擎的确定性契约（同输入同输出）不可调和：测字若要机械化，必须显式定义情境变量（卷二指事十法即其雏形），否则同字异断无法复现。本批不解决此问题，登记存疑。
- 与本批其他三书（推背图/诸葛神数/周公解梦）无直接条目冲突；谐音直断机制与《周公解梦》无涉，与《秘本诸葛神数》的笔画数应机制分属两路（拆形 vs 数应），互不冲突。
- **与《推背图》拆字谶互证（2026-10-07 补记，OPT-tuibeitu_dz-03 的反向链，双向一致）**：
  本书卷一**对关法**（源L86：`其法，专取头足首尾。`，源L88 头足首尾各成字之例）与
  《推背图》§三 判据 1 的**拆字合字谶**（该书源 `data/sources/tuibeitu_dz.dz.txt` **L32**：`木易若逢山下鬼　定于此处葬金环`）
  属**同一拆字机制**——把一字拆成两截、各成两字，再取两字之象。

  | 机制 | 本书《测字秘牒》 | 对书《推背图》 |
  |---|---|---|
  | 拆一为二、各取象 | 对关法（源L86：`其法，专取头足首尾。`） | §三 判据 1（其源 `data/sources/tuibeitu_dz.dz.txt` **L32**：`木易若逢山下鬼　定于此处葬金环`） |
  | 两截成字式样 | 源L88 `先（牛头虎足、生头死足）` | `木易`→杨、`半圭半林`→土木、`一兀`→元 |
  | 增损笔画成新字 | 其余九法（添笔/减笔/穿心/包笼/破解，卷一 L12-124） | `签筒去竹`→佥、`木木`→林 |

  **口径**：**同构 ≠ 同源**。本书是**测法**（由来意＋字随机起象），《推背图》是**谶语**
  （预设四字韵语定象），对象与流程都不同——**只可互证机制，不可并轨**；
  《推背图》属 none-zazhan（无对应学科），其谶语**不入任何结构层**。
  正向链见 `docs/source-readings/tuibeitu_dz.md` §四「拆字机制与《测字秘牒》同构」条。

## 五、不适用与存疑

**不适用理由**：

1. **无对应学科**：AGENTS.md 八科清单不含测字，且学科层禁新增目录（不预留目录、不写占位实现）。判「不适用」是正确行为，本篇即留底。
2. **谶纬式触机不可机械化**：卷一观梅法、卷二指事法（观人察色辨纸观时）、卷六杂占赋（外应）全部依赖临场随机触发，作者自己称「神而明之，存乎其人」（L124/L1208）——这类条目永不满足铁律一「机械运算归代码」。
3. **断语为文学格**：卷三四五断语（「名重金瓯」「破镜分钗」）是意象修辞库，无推演结构；若将来做叙事语料，须与判据物理隔离（铁律二同构要求）。

**OCR 缺陷登记**（引文一律照录原样，不得据以改字）：

- 缺字占位：L110 `□若夏与晚`、L132 `芒（破□）`、L1214 `是以知其节掺之囗二次嫁也`、L1270 `蜉□之羽`；注意全书「囗」兼有部首字与缺字占位两用（如 L420 部首行「囗」为部首非缺字），须逐处辨。
- 成段乱码：L1238 麟字例（`因显唬骸按俗郑？贵人之格也` 前后文不通，断语主体失真）、L1264 寅字例引号错乱、L1266 公字例（`故不笪即断也`用字存疑）。
- 杂入拉丁字母：L1258 虬字例（`L 为半九之象`——「L」为 OCR 产物，所指何字不明）。
- 用字存疑：L150 `居（跋胡幹尾之象`——「跋胡疐尾」出《诗·豳风·狼跋》，「幹」疑为「疐」之讹；L1292 `一人以飒字差别行人`——「差别」疑为「卜问」类动词之讹；L1218 `其羽以张字问吉凶`——「羽」疑为「友/仆」之讹。均存疑不改引文。
- 卷端题署（L1）体例为转录者所加，非原书序文；成书年代无书内证据，存疑。

**口径提醒（铁律三）**：卷七案例含「死矣！尚何问焉」（L1212）、「此儿殆难矣」（L1216）、「果自缢于监中」（L1218）等绝对凶断与死亡叙述。此为书源留底内容；本项目任何出口（报告/对话）若引测字，凶象必须按「偏向/有信号」口径软化，且测字断语本身已判不适用，不存在出口路径。
