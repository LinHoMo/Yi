## 一、书目与版本

**作者与成书**：唐王希明撰。据四库提要，希明开元时以方技为内供奉、待诏翰林，此书乃其奉敕所编，见于《新唐书·艺文志》。书中多自称「臣」，可证。惟提要指出书中推太乙积年有至宋景祐元年者，则后人已有增入，非尽希明之旧——本书是「唐人原书＋宋人增补」的复合文本。

**源流**：太乙为术数七家之一（《史记·日者传》），《汉书·五行家》有《太乙阴阳》二十三卷已佚。今存次序出自《周易·乾凿度》太乙行九宫法，而「次序乃特右旋，以干巽为一九」——即太乙九宫**不依洛书（干一坤二）**，而依九宫右旋。此点与后世奇门洛书口径不同，是本书第一处口径分歧（见 §四）。

**内容架构**：以**太乙**（主神，居九宫）、**天目/地目（计神）**、**五将**（监将、主客大小将、上下二目）构成八将，与《乾凿度》「计神与太乙合之为八将」同源（源L3）。以**岁／月／日／时**为纵纲，以**三基（君基/臣基/民基）**、**五福**、**大小游**、**四神／天乙／地乙／直符**、**十六神**、**八门**、**九宫分野**为横纬，构成中国术数史上最完整的「将门」课体框架之一。全书十卷，从推历法（积年积月积日时刻）起，历天盘布局、九宫分野、德合svc战判、灾异占、杂占。

**主源形态**：单文件，无对勘本。含四库提要（L1-5）、序（L11-12）、卷一至卷十正文。每卷前有「推 X 法」目录（双行小字），卷末有该卷尾题（如 L200「太乙金镜式经巻一」用异体「巻」）。

## 二、逐卷（章）深读

### 卷一（L24-200）推历与时计：天盘布局的算术底座

本卷是全书的「引擎层」：把「上元甲子到所求年」的积年积月积日积时算出来，再依四层除法（周纪法三百六十 → 元法七十二 → 太乙小周法二十四 → 三约）得出太乙落宫。术语白话：**周纪法三百六十**＝一纪的日数；**元法七十二**＝一元之数；**太乙小周法二十四**＝太乙行一周八宫所需之数；余数「以三约之」得宫数（1-9），不满者为入宫以来年数。

核心判据：

- 源L61：`其宫数命起一宫顺行八宫不游中五筭外即得太乙所在及入宫以来年数也` → **太乙行九宫的「不游中五」铁律**：八宫循环，中五宫寄而不入。此律与六壬/纳甲「不寄坤」同构，是将门共用的底层规则。
- 源L63：`命起武徳顺行十六神遇隂徳大武重留一筭外即天目所在` → **天目（天盘十六神）的推法**：以天目周法十八除余，命起武徳顺行十六神，逢隂徳、大武则「重留一」（即该神不布、下一神替补），故实际常驻神不足十六。
- 源L55：`上考往古每年减一筭下检将来每年加一筭` → 往古纪年「减一筭」、将来「加一筭」的上元纪年推算通法，是全书一切积年表的公因子。
- 源L187：`以大游纪法七百二十去之不尽以三分纪法二百四十除之余以三十约之为直门数` → 岁计八门直使的推法：七百二十去余，二百四十再除，三十约得门数。**纪法 720 / 240 / 30** 三层是全书的数表骨架。
- 源L151：`明太乙天目类时计终法立五将式之天乙朝暮治神` → 「天乙朝暮治」：时计五将式以天乙（十二将之首）分朝暮——甲日朝治小吉、暮治大吉，戊庚反是；乙日反是；丁日朝治登明、暮治从魁；癸日朝治太乙、暮治太冲，壬日反是。此**「朝治/暮治」= 六壬昼夜贵人**的同构机制。
- 源L162：`后一天后水主蔽匿妇人淫乱事` → 十二将（太乙式五将式）中的天后主事——**天后、太阴、太常、玄武、白虎、天空、螣蛇、朱雀、六合、勾陈、青龙**这一组将名与 core 中大六壬的 `TIAN_JIANG_ORDER` **十二天将同名同序**（仅「贵人／螣蛇」在本书作「天乙贵神」，玄武作「玄武」，勾陈亦作「勾陈」），是本书与大六壬最硬的共用底层（详见 §四、§六 OPT-01）。
- 源L168：`更以日度加时因歩六壬式知天乙成败之分` → **作者自述跨用六壬式**：「立五将亦未能决定大小将之吉凶」，故须「更以日度加时，因步六壬式」以定天乙成败——这是本书与大六壬「将门同源」的书内自证，也是本篇唯一可落地方向的书源依据。
- 源L169：`以此观之诸将吉凶定矣` → 卷末结语：立冬六日庚申时的完整占例（阴遁第六纪壬子元二十七局，太乙在九宫大武为天目，午为计神，巳为合神；客大将在九宫、客参将在七宫；庚日天乙朝治大吉），给出「据此观之，诸将吉凶定矣」的结构化读法。

### 卷二（L202-285）义理总纲：太乙所主／五将／九宫／八门／十六神／运式八条

本卷是全书**术语与取象的字典层**，也是本篇「判据留底」价值最高的一卷。术语白话：**太乙**＝天帝之神，主使十六神，顺行八宫，三年徙一宫，三年分治天／地／人；**五将**＝太乙（人君）＋上下二目（辅相）＋主客大小将（定主客）；**八将**＝太乙＋计神（＝天地人三才之数，八卦之象）。

核心判据：

- 源L12：`太乙天帝之神也下司九宫中建皇极钦若` → 全书的**定位句**：「太乙＝天帝之神，下司九宫，中建皇极」——太乙是九宫之主，与「八门为用、十六神为纬」构成一体。
- 源L3：`又有计神与太乙合之为八将犹易之八卦也` → 四库提要给出**八将的来源**：计神与太乙相合即八将，犹易之八卦；「其以岁月日时为纲而以八将为纬」——纵四时、横八将的课体模型。
- 源L212：`五将者太乙监将幷上下二目主客大小将也` → **五将构成**：太乙为人君、上目（荧惑/始击将）属客、下目（镇星/文昌将）属主，客大将（辰星）主兵革、主大将（太白）主战斗；「主客两阵相当，乘生气者胜，乘死气者败」——**胜负的第一判据是「生气/死气」，即旺相之实操化**。
- 源L214：`九宫之义法以灵龟以二四为肩六八为足左三右七戴九履一此为不易之常道也` → **九宫的物理定形**（灵龟象）：二四为肩、六八为足、左三右七、戴九履一——这是「右旋」九宫次序的图形依据，亦是本书「太乙差一位」说与《乾凿度》分歧的源头。
- 源L215：`八三四九为阳二七六一为隂` → **九宫阴阳宫分**：八三四九为阳宫、二七六一为阴宫（与四库提要「次序乃特右旋」同源）。此九宫阴阳分组**与六壬九宫无涉**（六壬不用九宫），故不与现有八科共用。
- 源L215：`凡至阳絶之气与事皆凶也` → 书源明写「至阳绝之气与事皆凶」——**凶象判据的总纲**。按铁律三，本项目引用此条时只作结构层「绝气位有凶象信号」的登记，不作必然性断语。
- 源L217：`开门直干位在西北主开向通达休直坎位正北主休息安` → **八门与八卦方位一一对应**：开门乾（西北）、休门坎（正北）、生门艮（东北）、伤门震（正东）、杜门巽（东南）、景门离（正南）、死门坤（西南）、惊门兑（正西）；「开休生三门大吉，景门小吉，惊门小凶，死伤杜大凶」——**吉凶三分档**（吉/小吉/小凶/大凶），比六壬的十二将吉凶更粗，但结构同源。
- 源L220：`子神曰地主建子之月阳气初发万物隂生故曰地主也` → **十六神的命名机理**：每神以「建（所值月建之月）＋物候」命名，如子神「地主」（阳气初发、万物阴生）、申神「武徳」（万物欲死、荠麦将生）——**十六神＝十二月建的名物候异名**，是本书独有的取象层。
- 源L228：`申神曰武徳建申之月万物欲死荠麦将生故曰武徳也` → 同上，十六神命名之第二例（武徳＝申神，与卷一 L63 天目「命起武徳」正相扣合：天目十六神的起点神即申神武徳）。
- 源L236：`经云运式之仪有八一详太嵗所在欲求计神` → **运式八条**（全书的起课流程）：一详太岁、二详太乙所在宫以立监将、三详何神为天目以置文昌始击诸神、四详何神为计神以知主客计、五详何神为始击（以计神加艮为鬼门方求幽冥吉凶）、六视天地二目各在何所以求主客之算、七详置算之数以定主客大将之宫、八论主客置算（得十置一、得二十四弃二十置四）。
- 源L3：`又有计神与太乙合之为八将犹易之八卦也` → **八将＝八卦的类比**是全书的建模总纲。
- 源L12：`正二局有隂阳之殊糺六壬附时计之谬` → 序中直指**「六壬附时计」为谬说**，判定「糺」之（即主张纠正）——注意这与 L168「因歩六壬式」并不矛盾：L168 是借六壬式定天乙成败（用），序这句是驳前人把六壬时计**附**于太乙（斥），一取一斥，是 §四 的重要分歧点。
- 源L409：`太乙在八三四宫者为地内宫` → 卷四「太乙在天外地内法」：太乙在八三四宫为地内宫（主人、利于先起），在九二七六宫为天外宫（助客）——**先起/后应的地内天外判**，与卷四主客「先动者为客」互为表里。

### 卷三（L287-381）课体判据：掩击迫囚关格＋三门五将立成胜败钤

本卷是全书**最可机械化的判据层**：十二个「犯」（掩、击、迫、囚、关、格、对、四郭固、四郭杜、执提、提挟）各给出定义句与吉凶倾向，再以「太乙三门五将立成胜败钤」把九宫 × 十六神（天目）铺成 9×16 的胜败矩阵（主源 L318-335），最后给出阳局/阴局各七十二局的五将立成表（L337-367）。术语白话：**掩**＝始击将临太乙宫（劫杀之义）；**击**＝客目在太乙前一辰/后一辰/前一宫/后一宫；**迫**＝四将在太乙左右（宫迫灾缓、辰迫灾急）；**囚**＝诸将与太乙同宫；**关**＝主客将目同宫；**格**＝客目与太乙对宫；**对**＝文昌将与太乙冲而相当；**四郭固/杜**＝相関而不出兵；**执提/提挟**＝开门生门合冲为执提、客主两将与太乙挟为提挟。

核心判据：

- 源L295：`经曰始击将临太乙宫谓之掩` → 掩的定义（始击将＝上目＝荧惑之精，与太乙同宫）。
- 源L299：`宫迫灾防缓辰迫灾急疾` → 迫的**缓急分档**：宫迫灾缓、辰迫灾急——凶象力度以「辰迫 > 宫迫」分档，是本书少见的「力度量化」判据。
- 源L301：`经曰囚者簒戮之义也` → 囚的定义（簒戮之义），且区分「阳气绝气之地大凶」「绝阳绝阴之地自败臣受诛」，即囚的凶象强度还要看所落之宫是否为绝气位。
- 源L394：`经曰五将发不发谓始击将无掩击文昌将无囚迫主客大小将无相闗即门具将发` → **「五将发」= 门具将发的完整定义**（卷四「推五将发不发」首条）：始击无掩击、文昌无囚迫、主客大小将不相関，谓「门具将发」；反之为「五将不发」，「三门不具不可出兵，五将不发不可临战」——**发/不发 = 全书唯一的二元总闸**。
- 源L398：`经曰主客者先后之理动静之义也` → 主客之义（先后、动静），定法两条：野战先动为客、先安居者先动为主；胜负取决于「三门具＋五将发＋阴阳和」。
- 源L187：`李淳风云常以开门加太乙即太乙之八门也` → 八门的加法：**以（直使）开门加太乙之宫**，得太乙之八门；同法可得主大将、客大将、定计大将各自之八门——**四盘八门同源**的加法定义。
- 源L176：`吉道谓开休生三门是也` → 「吉道」定义为开休生三门（卷四考时法）——与卷二 L217「开休生三门大吉」互证。
- 源L398 附：主客所起之神取东隂德、南和德、西大炅、北大武——**四正为「始发之神」**的定位法。
- 源L443：`经曰五福太乙所临之分无兵革疾疫饥荒水旱之灾` → 卷五四神体系之五福：五福行宫有四十五年移一宫、二百二十五年一周，五福宫为黄秘（西河之乾）、黄始（辽东之艮）、黄室（东吴之巽）、黄庭（西蜀之坤）、玄师（洛阳中原）——**五福是纯吉位，与吉凶将神分属不同层**。

### 卷四至卷十（L383-887）兵占、灾异、九宫分野与百事杂占

卷四至卷六是**事占层**：卷四兵战（出师、向背、置阵随地、天外地内、奇伏、风云飞鸟助战、阵有云气定胜负）；卷五以君基/臣基/民基（邦国分野）、五福、大游（纪法七百二十、元法四千三百二十、乘行率一百二十、行宫三十六）、小游（与四神/天乙/地乙/直符同用）构成太乙的长周期层——

- 源L453：`经曰大游太乙者巡考八宫与小游同宫一考三十六年十二年治天十二年治地十二年治人` → **大游太乙**的定义与周期（与小游同宫，一考三十六年，内分十二年治天、十二年治地、十二年治人，二百八十八年一周），并给出「太乙在阳宫辽东不见兵，太乙在阴宫蜀汉可以全身」——**以方位定安危**的取向。
- 源L623：`同类为旺生我为相尅我为死我尅为囚我生为休` → **卷六太乙七术的旺相口诀**（本书的旺相体系，与 core 的月令旺相不同源，见 §四）：同类为旺、生我为相、克我为死、我克为囚、我生为休。**这是本书与大六壬、六爻、择吉**都不共享**的第三套旺相口径**（core 的 `WANG_XIANG_XIU_QIU_SI` 是月令旺相），故不可直接对源。
- 源L627：`经曰天目所筭主以长筭宜缓短筭宜急` → 卷六术九（长短占缓急）：天目算数以长为宜缓、短为宜急，「长多利深入，短少利浅入；长为胜，短为负」——**以算数多少定战略纵深**。
- 源L635：`经曰多少以占胜负者客以多筭临少主人败客以少筭临多主人胜也` → 卷六术十三（多少占胜负）的反直觉定式：客算多临少则主败、客算少临多则主胜（与直觉相反，须照录）。
- 卷六太乙七术（临津问道／狮子反掷／白云卷空／猛虎相拒／雷公入水／白龙得云／回军无言）皆以**「吕申加某宫，看大神（大武/太阳）所临之下」**为统一手法——**加一个十六神（吕申）取大神所临**是太乙七术共用的取象法，与六壬「日干加时取天将」同型。
- 源L682：`四百五十六嵗为一阳九也十三年移一邦命起寅邦顺行十二邦筭外即阳九所在也` → 卷七阳九之灾：入元之初末或与太岁冲并于分野，灾为亡国弑君；四元一元四千五百六十、一阳九四百五十六岁、十三岁移一邦，命起寅邦顺行十二邦。**阳九/百六是纪元级灾异框架**，与《汉书》「阳九百六」同源。

卷七（天皇/帝符/天时/太尊/飞鸟/五行/八风/五风/三风太乙）是一组**天象将与太乙相合的占候层**（合旺相之地则风雨云气各应），并附十精云气法（以云气色＋日时计定变发时刻）——属**观天象占候**，非结构课，不作结构层判据。

卷八是**纯天文地理底账**：陈卓《九州分野躔次》重订的二十八宿分野度、每州郡县分划表，以及九宫分野（九宫＋绛宫交州/明堂益州/玉堂幽州）。此卷的价值在于**它与 core 的 `ganzhi_calendar`／`zeji_tables` 的十二宿/黄黑道属同一天文底层**，是可对源的高价值留底（见 §六 OPT-02）。

卷九、卷十是**事占与择日**——

- 源L846：`但以日计太乙局法看太乙局在何元纪宫分定上下无掩迫闗撃则某日可以行师出军征讨兴造百事` → 卷十「太乙择日」：**明确删去**太阴九地/太阳九天等古法，只用日计太乙局法 + 无掩迫关击定可否用事。这是本书**自身择日口径的收敛**，与 `core/yishu_core/zeji_tables.py` 的建除/黄黑道路径**不是同一套**。
- 源L848：`但取时计太乙门具将发阳隂和主客无掩迫则为吉时` → 卷十「太乙择时」：王希明削去各家分等算数的「胶柱」之说，只取「门具将发＋阴阳和＋主客无掩迫」为吉时——**择时判据极简且全为结构条件**。
- 源L869：`凡占万物皆以太乙立休旺神决之` → 卷十杂事收束：**万物之占一律以「太乙落在旺相之位」为总决**——与卷二 L212「乘生气者胜、乘死气者败」同一条原理的两处表述。
- 源L656：`若考往古每年减一下检将来每年加一` → 卷七积年法：积年法在卷五、卷七重出（L656 推至宋景祐元年甲戌），与卷一 L55 同式——**可对勘的同书自证**：凡推往古即每年减一筭，推将来即每年加一筭。

## 四、对勘与口径分歧

**本批内无对勘本**（`crosscheck` 为空），故无跨版本对勘。以下为**本书内部**与**项目现有八科**之间的口径分歧，逐条登记：

1. **九宫次序：右旋 vs 洛书**。本书太乙九宫「特右旋，以干巽为一九」（源L3），即太乙起于一宫而右行，与《乾凿度》同源；奇门（大六壬同层的奇门一路）用洛书顺行。**同名「九宫」而次序相反**，扩科时须显式区分，不可共用一张九宫序列表。
2. **旺相第三套口径**。本书 L623「同类为旺、生我为相、克我为死、我克为囚、我生为休」是**将神同类**旺相；`core/yishu_core/symbols.py:446` 的 `WANG_XIANG_XIU_QIU_SI` 是**月支**旺相；六爻/梅花另有多层旺衰口径。三者不同源。本项目口径以 core 月令旺相为准；本书这一套**登记为异口径，不合并**。
   > **行号更正（2026-10-07）**：本条原写 `symbols.py:432`，实测 `WANG_XIANG_XIU_QIU_SI` 定义在 **`core/yishu_core/symbols.py:446`**（`wangxiangxiuqiusi()` 在 `:462`），`:432` 有误。已在 `symbols.py:446` 上方补「异口径并存」注记（OPT-taiyi_jinjing_dz-06）。
3. **序批「六壬附时计」vs 正文借用六壬**。序中主张纠正「糺六壬附时计之谬」（源L12），正文却明写「更以日度加时因歩六壬式知天乙成败之分」（源L168）。两者不矛盾：序所斥是**把六壬时计附于太乙之上**（体例之误），正文所借是**取六壬式为工具定天乙成败**（用其法）。项目口径：**六壬引擎自身口径以 `core/yishu_core/liuren_tables.py` 为准，本书借用不改动六壬任何表**。
4. **十二将名同、名序同，但「太乙」一名两义**。本书 L157-167 的十二将与六壬十二天将同名同序；但 core `liuren_tables.py:41` 中「太乙」是**处暑后的月将名**（与本书 L24-187 的「太乙」是九宫之主、本书全篇主神**完全无关**）。这是本篇最易致混淆的一点，须在任何引用 core 月将表之处加一处异名警示。
