## 二、逐卷（章）深读

### 卷首体例：甲子日十二局与「干上」标题的机械意义（L2–L107）

卷首甲子日十二局是全书体例的标本，每局标题的「干上」为该课干上神，次行即抛课体标签。

- 课体标签起手式，源L3：`　　课体：伏吟，元胎。` → **标签行恒在标题下一行**，格式 `课体：A，B，C。`（全角句号收尾，偶见分号讹体，见 §五 L2639）。
  这是全书 717 局共751 处标签行的统一格式，可作机械解析锚点。现状：解析入口未建，属机械结构，可评估（OPT-01）。
- 课义撮要行，源L4：`　　课义：两贵差跌，六虎陈列，病讼皆畏，仕宦怡悦。` → 四字对仗撮要，
  **「病讼皆畏」「仕宦怡悦」属吉凶断语，narrative 候选/超出骨架**，不得入结构层。
- 分事占断行（典型行首），源L7：`　　天时：水火伏匿，龙神入庙，无雨有风。` → **全占断层的取样**：
  天时/家宅/婚姻/胎孕/疾病/求财/捕获/遗失/行人/出行/征伐十余项并列，纯叙事，超出骨架。
- 引诀行，源L8：`　　毕法云：虎临干鬼凶速速，日乘旺禄休狂妄，虎乘遁鬼殃非浅，宾主不投刑在上。` →
  四句七言诀，每句后括注取象条件（本书常以半角括号嵌小字注），诀文本身吉凶，属narrative；
  **但括注内的取象条件是结构判据**——如本书同课括注给出的「(初传旬空，中传日鬼，末传脱气，皆无益)」类条件是可判定的。

### 课体标签体系与九宗门取用条件（L109–L2592 抽样）

九宗门在本书**不是规则章，而是标签词**（与《六壬大全》卷一作为规则源的地位不同）。
其定义性语句散见于解曰，措辞比《大全》更细，常附**量化**与**变体条件**——这是本书对引擎最有价值之处。

- **涉害之深浅可数「几重」**（本书量化口径），源L1021：`卯亥皆比涉害，卯得四重，亥得五重，宜以亥为用，此即用孟上神为见机之说。`
  → 深浅以「重」计（几重），取重多者为用；此与《大全》涉害口诀「孟深仲浅季当休，复等柔辰刚日宜」一致而更具体。
  现状：`scripts/jiuzongmen.py` 已落涉害门，此「几重」**计数口径未核**，属机械结构，建议核（OPT-04）。
- **涉害取用的复等/柔辰刚日细则**，源L481：`比同，涉害同，加孟又同，故刚日用干上之子发用。诀所谓复等柔辰刚日差者是也。`
  → 与 `verdicts.json#men.涉害.basis` 的「复等柔辰刚日宜」同源互证，可作口径一致的书源对证。现状：已入库(口径一致)。
- **别责取用两分**（刚柔异法），源L536：`阳日取干合上神为用，阴阳不备，全无克制，事主变更，动则有咎。`
  与源L788：`四课不全不克，别从其类，责取支合前神为用。` → 阳日取干合、柔日取支合前一辰，与《大全》别责条一致。
  现状：`kemu.json` 别责 `implemented=true`，维持。
- **伏吟「自任」分支**，源L1303：`天地鬼神，不动不克，无所取，择自任。其刚进用于时，故名自任。`
  → 伏吟不得用时**另立「自任」格**，条件＝天地鬼神不动不克（纯结构）。现状：`kemu.json` 无「自任」课目，属结构格名候选（OPT-03）。
- **闭口课的书源三变体**，源L709：`庚日反吟伏吟，皆是地盘旬首上神乘元武，为闭口课。`
  与源L1867：`甲戌旬中未为旬尾，未临戌上，是旬尾加旬首，谓之闭口。`、源L2380：`巳乃旬尾，遁癸为闭口`
  → 本书给出**三种可判定的闭口条件**（旬尾加旬首／元武乘地盘旬首／发用遁干），《大全》仅「旬尾加旬首」一种口径。
  现状：`kemu.json` 闭口 `implemented=true` 但只见单一条件，属**明确的判定条件缺口**（OPT-02，P1）。
- **昴星四名随刚柔与季节变名**，源L1436：`此昴星之卦，名冬蛇掩目，亦名虎视。` →
  与《大全》昴星条「一曰春虎视，夏转蓬，秋昴星，冬蛇掩目」同构；本书以「虎视／冬蛇掩目」双名对应刚柔两日。
  现状：`kemu.json` 昴星 `implemented=true`（虎视／转蓬格），维持。

### 结构格名定义层：三传不出四课与诸「格」的判定条件（L139–L2641）

本书把一批**三传/四课的几何结构**命名为独立「格」，条件全部为机械可判，是本书最宜落结构层的一层。

- **循环／回环／盘珠＝三传不出四课**（三书互证），源L139：`三传不出四课，为循环格。`、
  源L2641：`三传不出四课，格号循环，吉凶皆不能成。`、源L1699：`干支自作三合，三传不出四课，名回环格。`、
  源L16：`三传皆在四课为盘珠格。`
  → **同一机械条件（传不越四课）在本书有四名：循环／回环／盘珠／（连茹变体）**；
  `kemu.json` 已收「盘珠」（implemented=true），**「循环」「回环」未收**（OPT-03）。
- **赘婿＝支神临干而被日干克**，源L2641：`支神临干，为戊所克，曰赘婿课。` → 条件极干净，可直接落结构层。
- **顾祖格三支特定序**，源L1753：`又午辰寅为顾祖格，盖午为寅之子孙，寅乃午之长生，自午传寅有复旧庐之象。`
  → `午→辰→寅` 逆传为顾祖，条件可判。
- **杜传格＝自刑＋中投支上＋末取冲**，源L2275：`用起自刑，中投支上，复自刑。末取冲，传行杜塞，名杜传格，事主中止改图。`
  → 三条件复合，机械可判。
- **折腰格＝中传空亡**，源L1840：`又中空名折腰格，主中间无力，首尾不应，所以相遇之中，尚有阻滞。`
  → 纯机械条件（只有中传落空），最宜落地。
- **弹射＝日遥克神**，源L634：`日遥克亥神而逢空，是弹射而无丸` → 与「神遥克日＝蒿矢」成对；
  源L1211：`　　断曰：遥克蒿矢，已属疏远。今又空亡，是毫无影响。` 可见二名对举（蒿矢／弹射）。
  现状：`verdicts.json#men.遥克.basis` 已含「神遥克日曰蒿矢，日遥克神曰弹射」，口径一致。
- **涉三渊＝孟位不动＋申戌子**，源L205：`孟动不动涉三渊，申戌子兮在日前` → 条件含固定三支（申戌子）与「孟不动」。
- **自任／元胎并列标签**，源L6：`此自任之卦，又曰元胎，利静不利动，利上不利下，利君子不利小人。`
  → 「自任」与「元胎」在本书断语中为**一名二格**（伏吟之自任 vs 玄胎之元胎），登记见 §五。

### 天将乘临与昼夜贵人（L5、L679、L1285、L862 抽样）

天将在本书的使用**高度机械化**：几乎全是「某支＋某将」的二项组合，直接落到结构标签。

- **昼夜贵人差跌（可判）**，源L5：`昼贵临于夜地，夜贵临于昼地，谓之贵人差跌。`
  → 昼夜贵落宫与昼夜之常位错位即成格，条件纯结构。`kemu.json` 无此格，属结构格名候选（OPT-03）。
- **天将生克随昼夜分途（可判）**，源L679：`巳临庚上，昼乘勾陈，则土将能生。夜乘朱雀，则火将为克，天将生克，吉凶分途矣。`
  → **同一支神，昼将/夜将生克不同**——这是「昼夜贵人/天将分途」的判定结构，机械可判且直接影响四课取用层。
  现状：`verdicts.json#tianjiang` 有十二将逐条 verse，但**未见「昼/夜分途生克」的判定结构**，属增量（OPT-05）。
- **脱上逢脱（链条可判）**，源L1285：`日干生亡神，上神生天将，名为脱上逢脱。` →
  结构为「干→上神→天将」逐级相生而致脱，机械可判。
- **贵多不贵（三传皆贵人）**，源L1285：`又三传皆是贵人，谓之贵多不贵。` → 计数型结构条件。
- **脱盗格（干上脱气＋天将元武）**，源L862：`干上亥乃脱气，天将又是元武，为脱盗格。` → 二条件复合，可判。
- **六虎陈列（课传乘白虎计数）**，源L5：`四课上两寅属虎，二子乘虎，初传寅虎，末传申虎，所谓六虎陈列也。`
  → 数白虎所临之课传位置成格，机械可判但工程量较大。

### 月将与四维（L1609、L5875、L2131、L4615 抽样）

本书**不含起课章**，月将只在引诀/占验中作条件出现，用法集中在「四维为月将」与「月将上某将」两类。

- **四维为月将**（重复两见，互证），源L1609：`贵登天门，神藏煞没；丑加亥者为的，四孟月尤佳，缘四维为月将也`、
  源L5875：`丑未临亥，为贵登天门。凡谋皆利，诸恶潜踪，四孟月占尤的，以四维作月将也。`
  → 「丑加亥＋四孟月占」为贵登天门的构成条件，四孟月（四季末月）即四维为月将。机械可判，属起课层口径的书源旁证。
- **月将上青龙／月将为墓而改格名**，源L2131：`况年上乘月将青龙，主片言人相。`；源L4615：`戌加午是墓神覆宅，如戌为月将，却名太阳照宅`
  → **月将参与课体改名**（戌为月将则墓神覆宅易名太阳照宅），是「月将＋课体」交互的少见实例，机械可判（OPT-05）。
  现状：`liuren_tables.py` 有月将表与中气换将，但**月将参与课体命名的交互判定未见**。
- 注意：本书**无「月将加时」四字诀**（grep `加时` 命中 0），起课层仍以《六壬大全》为唯一真值源。

### 断语层与分事占断（narrative 候选，全书约半数篇幅，明确不采）

断曰与分事占断两段是本书篇幅最大的部分，形态为「课体象解＋分事吉凶」，含大量时代价值观与不可机械化的经验判断。

- 断曰典型（narrative 候选），源L2003：`反吟课体，南北相易，东西互居，事多反覆。占必多疑，遇凶翻吉，得喜乃忧。`
  → 「反吟事多反覆」是课体象，属叙事；**可采的只有「反吟」这一结构标签本身**。
- 分事占断取样（narrative 候选），源L2005：`占病宜视日干之禄神，为禄粮神，日干之食神，为运粮神，不宜受克与落空，如占久病，必绝食而死。`
  → 内含一条机械结构（「日干禄神/食神为占病所视之神，不宜受克落空」），可作结构标签候选；
  但「必绝食而死」是断语，**按铁律三只能表述为「结构上偏向病久不食之信号」**。
- 干支人宅取象（可判），源L4774：`干为身，支为宅，身被卯克，宅被午克，皆上克也。`
  与源L310：`支为宅舍，非添修屋瓦而何。` → 「干为身／支为宅」＋「上克」为结构条件，可判；
  「居家昏暗／官非灾患」为断语，narrative。

## 四、对勘与口径分歧

**对勘本：无**（登记表 `crosscheck: []`）。以下为与本批已落盘文献的口径比对。

**与《六壬大全》（liu-ren-da-quan.md）——同门不同层，无冲突但权重不同。**
《大全》是本项目九宗门发用规则、贵人起例、月将加时的**唯一真值源**；本书是占验集，**不提供起课章**（grep `加时` 命中 0、
`月将`仅 25 见且全在引诀/占验语境、`天将`55 见皆为「乘临」组合而无十二将释名）。
故起课层仍以《大全》为准，本书只能作**判定条件与分布实证**的第二书源。

**三处需明确裁定的口径分歧**：

1. **闭口课条件：本书三变体 vs 《大全》单一条件。**
   《大全》闭口为「旬尾加旬首」一种；本书给出三种（旬尾加旬首／地盘旬首上神乘元武／发用遁干），
   且明示「不必旬尾加旬首也」（源L76：`元武乘神临于旬首，即为闭口课，不必旬尾加旬首也。`）。
   **裁定**：以《大全》为主条件，本书变体作**并列扩展条件**登记入 `kemu.json` 闭口条（OPT-02），不替换主条件。

2. **「三传不出四课」的归属：结构格 vs 涉害辨异。**
   本书明确把该条件与涉害**分开**：源L400：`以回环格言之，此系重审，非涉害也。`
   即「传不出四课」在本书是**独立格名（循环／回环／盘珠）**，不是涉害的浅深计数结果。
   与《大全》涉害口诀「各涉归本家数其受克深浅」不冲突——两者是不同层级的判定。
   **裁定**：循环／回环／盘珠三名单独作结构格（OPT-03），涉害几重计数另计（OPT-04），二者不得混用。

3. **同一机械条件多名并存（循环／回环／盘珠；自任／元胎；蒿矢／弹射）。**
   本书一名多格现象普遍（`源L6`：``此自任之卦，又曰元胎……``）。
   **裁定**：`kemu.json` 的课目名以**《大全》卷一「课目」64条**为准，本书别名一律作`variant` 字段登记，不另立课目，
   与《六壬断案》已有的「课体为成象命名、九宗门为发用规则」层级口径一致（详见 `liuren_duanan_dz.md` §四）。

**与《六壬断案》（liuren_duanan_dz.md）——同为占验集，体例最接近，无冲突。**
断案 216 则、编号 01–216、按占事分组；本书 717 则、按日辰×十二局全排列。
断案以「先生析曰」辨正课体与取用之别，本书以「解曰」推演并缀「毕法云」引诀。
两书**互补**：断案提供课体取象用例，本书提供判定条件的量化与变体。

**本批内无口径冲突。** 本书与《六壬大全》《六壬粹言》《六壬指南》《六壬断案》均可并存，唯一需防的是上述第1 条
闭口条件扩张时不得推翻《大全》主条件。

## 五、不适用与存疑

**不采内容及理由（一律narrative 候选/超出骨架，不得塞进结构层）**：

1. **课义行**（全书 717 处，如源L4「两贵差跌，六虎陈列，病讼皆畏，仕宦怡悦」）：
   四字对仗撮要，**吉凶断语＋结构名混串**，无法拆出纯机械条件，且本身即断语。**不采**。
2. **断曰行**（全书 723 处）：课体象解＋吉凶断语。如源L2003「反吟课体……占必多疑，遇凶翻吉，得喜乃忧」——
   按铁律三，只能表述为「结构上偏向事多反覆之信号」，**不得输出方向**。**不采为判据**。
3. **分事占断行**（天时／家宅／婚姻／胎孕／疾病／求财／捕获／遗失／行人／出行／征伐，天时行见源L7）：
   全书约半数篇幅，含大量时代价值观与不可机械化的经验判断。**不采**。
4. **毕法云/课经云/指南云/古鉴/心镜云/订讹云/玉门经/袖中金等引诀正文**：
   如源L8 四句七言，**吉凶属叙事候选**。仅其**括注内的小字取象条件**（如「初传旬空，中传日鬼，末传脱气」）
   可另行评估为结构条件，本轮不采。
5. **古验/占验案例**（吴越春秋 4、指南 90、古鉴 76 等处所记史事与占验）：
   属古籍案例，按铁律二与交付过程物理隔离，仅可作事后校验，**不作实时推理依据、不作对齐分调参**。
6. **一类吉凶的现代改写一律禁止**：如源L2005「如占久病，必绝食而死」之类，
   若需提及，只能写「结构上偏向久病不食之信号」。
