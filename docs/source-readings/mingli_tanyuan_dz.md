## 一、书目与版本

**作者与成书**：民国袁树珊（字陨生，《命稿》作者之师友辈）著。袁树珊为民国著名命理学家，《命理探源》为其"入门综合教程"体例之作——以"本原→起例→强弱→宜忌→化合刑冲→先贤名论→润德堂藏稿→星家十要"八卷框架，将子平术从头教起：先干支历基础→起盘法→强弱→喜忌→刑冲合→案例→职业伦理（星家十要）。

**全书性质**：命理入门综合教程——不偏格局、不偏调候、不偏辨证，而是将诸家之学融为一体、由浅入深。最大特色是"先立基础（本原/起例），再论推断（强弱/宜忌/化合刑冲），末附案例与教学"——系统教学而非单一专题。项目铁律"机械运算归代码"在此书中得到充分体现：全书"推年/推月/推日/推时"四章全为机械起例法。

**主源形态**：殆知阁转录单文件。目录（L3-14）＋卷一 本原（L18-240）＋卷二 起例（L241-348）＋卷三～卷八。已知缺陷：① 纳音五行逐句注释造成单行字数极多；② 引文套引文造成 OCR 讹字密集；③ "丙丁属获为南方"＝"属火"之讹。

## 二、逐卷（章）深读

### 卷一 本原（L18-240）——基础历法学：天干地支起至二十四节气

本卷为"命理入门第一课"：先以《五行大义》《群书考异》释天干名义（"甲者拆也"……"癸者揆也"），再以《考原》释地支生肖（子=鼠因阴极幽潜……亥=猪因阴敛持守），继以干支五行／四时方位（东方木南方火……），再以六十花甲子纳音五行逐句注释，末以五合／六合／三合／六冲／六害／三刑／十二月建／二十四节气收尾——构成 project 整个核心历法学的"书源字典"。

核心判据：

- 源L20：`甲、乙、丙、丁、戊、己、庚、辛、壬、癸，此为十天干。` → 天干定义（source L22 复列地支定义）——engine ganzhi_calendar 的干支字面量源。
- 源L48：`甲乙属木，为东方。丙丁属获为南方。戊己属土，为中央。庚辛属金，为西方。壬癸属水，为北方。` → 干支五行与四时方位（注："属获"＝"属火"之 OCR 讹字）。
- 源L56：`甲子乙丑海中金。` → 纳音歌起始——source L58 续以五行释义"故曰海中金"。
- 源L184：`甲与己合化土，乙与庚化金，丙与辛合化水，丁与壬合化木，戊与癸合化火。` → 五合五行——project 六合五合的源。
- 源L196：`申子辰合水局，亥卯未合木局，寅午戌合火局，巳酉丑合金局。` → 三合五行——三合局源（symbols.py SAN_HE_GROUPS）。
- 源L202：`子午相冲，丑未相冲，寅申相冲，卯酉相冲，辰戌相冲，巳亥相冲。` → 六冲——symbols.py CHONG_PAIRS。
- 源L208：`子未相害，丑午相害，寅巳相害，卯辰相害，申亥相害，酉戌相害。` → 六害——symbols.py HARM_PAIRS。
- 源L210：`《考原》云：六害者，不合也。凡事莫不喜合而忌冲。` → 六害释义起首——源 L208 复列六害干支对。
- 源L214：`子刑卯，卯刑子，为无理之刑。寅刑巳，巳刑申，申刑寅，为恃势之刑。丑刑戌，戌刑未，未刑丑，为无恩之刑。辰、午、酉、亥，为自刑之刑。` → 三刑——symbols.py THREE_PUNISHMENTS。
- 源L218：`储泳云：三刑是极数，盖天道恶盈满则覆也。翼氏风角曰：金刚火强，自刑其方。` → 三刑的哲学正当化——"天道恶盈满则覆"。

### 卷二 起例（L241-348）——推年／推月／推日／推时／推大运的机械方法

本卷全为机械操作步骤："推年法视人所值生年干支为主/以立春节为纲""推月法由人生年遁月之干支为主""推日法由人生日遁得""推时法由人生日遁得生时之干支为主"，配手掌图实例。术语：**推年**＝以立春节为纲；**推月**＝五虎遁（甲己之年丙作首）；**推日**＝查历书初一干支逐日顺数；**推时**＝五鼠遁（甲己还加甲）；**推大运**＝阳男阴女顺行／阴男阳女逆行＋三日折一年。

核心判据：

- 源L245：`推年之法，视人所值生年干支为主，以立春节为纲，其区别有三` → 推年机械规则——engine chart.py 推年法的书源。
- 源L265：`甲己之年丙作首，乙庚之岁戊为头，` → 五虎遁歌——月干起法語源。
- 源L271：`甲己年正月起丙寅，乙庚之年正月起戊寅，丙辛之年正月起庚寅，丁壬之年正月起壬寅，戊癸之年正月起甲寅。` → 五虎遁表——engine TIGER_MONTH_STEM 表源。
- 源L299：`甲己还生甲，乙庚丙作初，` → 五鼠遁歌——engine 时干起法源（source L301 续丙辛从戊起以下）。
- 源L315：`凡推大运，俱从所生之日，阳男阴女顺行，数之未来节，阴男阳女逆行，数之过去节，皆遇节而止。三日为一岁` → 大运起法——dayun_direction 的源。

### 卷三～卷五 强弱／宜忌／化合刑冲（L349-500+）

卷三论强弱（月令扶抑／党众为强），卷四论宜忌（喜神／忌神定义），卷五论化合刑冲（合化条件／六冲／三刑的宜忌逐项分析）。三卷合为"格局＋喜忌＋刑冲"的项目核心分析规则的简明版。术语随文白话：**强弱**＝月令为本、党众为强；**宜忌**＝喜神宜旺相、忌神宜休囚；**合化**＝甲己合土助力所需。

核心判据（以卷三天干地支补遗为例）：

- 源L361：`《古歌》云：子宫癸水在其中，丑癸辛金己土同，` → 地支藏遁歌（与《渊海子平》L42 同源异述）。

**十神偏正口诀（本书最具引擎价值的判据）**：卷三以"生我/克我/我生/我剋/同我"五路分设偏正，是十神定义的**白话论证版**——与《渊海子平》L54 的古定义互为表里，且给出"阴阳同类/异类"的判别法则，正是 core 十神表所缺的"为什么这样分"的依据。

- 克我者·偏官正官，源L437：`何以谓之克我者，如甲乙木日干，见庚辛金是也。然克我之中，有偏正之殊，故有为偏官、正官之不同。` → 正官/七杀（偏官）之分的白话定义：甲（阳木）见庚（阳金）为偏官七杀，见辛（阴金）为正官。现状：core 十神阴阳归属已入，但**"偏正何以如此分"的书源论证未登记**。
- 生我者·偏印正印，源L439：`何以谓之生我者，如甲乙木日干，见壬癸水是也。然生我之中，有偏正之异，故有为偏印、为正印之不同。` → 正印/偏印之分同理；并引《说文》"印者，执政所持之印也"、万育吾"朝廷设官分职，畀以印绶"论证正印之贵。现状：概念已入 ditian_sui.json，论证未追。

### 卷六～卷八 先贤名论／润德堂藏稿／星家十要（L500+）

卷六汇录《考原》《三车一览》诸家名论；卷七为润德堂藏稿（命例）；卷八"星家十要"为命理师职业伦理——"一命二运三风水四积阴德五读书"＋"不可轻言祸福"等伦理条。

## 四、对勘与口径分歧

**对勘本**：本轮未提供对勘 wikitext 本——本批内无直接冲突。

**与《渊海子平》的口径异同**：

1. 同一关系：《命理探源》卷一大量转引《渊海子平》条文（地支藏遁歌 L361／五合／三合／六冲／三刑），与《渊海子平》逐字高度重合——engine 底层表出处应两书并注。
2. 本书胜处：在《渊海子平》之上叠加《考原》《五行大义》《三车一览》等多层引文——engine 底 tables 取"通行定式"（以《渊海子平》本为主）。
3. 源 L56 纳音起始——L58 逐句释义与 engine NAYIN 表仅映射五行不同，释义层应存 references。

**与《穷通宝鉴》的关系**：两书无直接冲突——《穷通宝鉴》论"调候用神"，《命理探源》论"历法与起例"——层次不同（调候 vs 历法）。

## 五、不适用与存疑

**书源明写否定→不适用**：本编未发现全书级否定条文——"命理探源"为入门教程，各节叙述未做批判性排除。

**转录缺陷登记**：

1. 纳音五行部分（L56-178）逐句注释体——一行内"甲子乙丑海中金"＋"子属水又为湖……水旺而金死墓故曰海中金"——行号密度高但单行字数极多。
2. 引文套引文（《渊海子平》＋《考原》＋《三车一览》三层叠加）机械对勘时须区分何者为"本书原文"为何者"所引古籍原文"——推荐先以 NFKC＋简繁折叠归一后再做 shingle containment。
3. 源L48"丙D属获为南方"＝"属火"之 OCR 讹字——引文采信时须对勘《渊海子平》等本后再入库——禁止按读数改数据（AGENTS.md 铁律四 §五逐格对拍要求）。
4. 目录段 OCR 讹误少（均为八卷清单），可以目录为基准定各章起止行号——但各章首行原书以"卷 X 卷名"为标题（如"卷一 本原"），行号以实际起首内容行为准。
3. 源L48"丙D属获为南方"＝"属火"之 OCR 讹字——引文采信时须对勘《渊海子平》等本。
4. **底本脱敏坏字符**：源L190 章题作`****五行`（实为"六合"，盖底本清洗时"六合"被敏感词规则误替换），同型坏字符另见源L216"三刑生于三合，亦如六害生于****之义"（疑为"六生"或"六合"）。凡本书引文若落在含`****`的行上，**不得作为判据入库**（该字不可考），须回溯它本校勘后再用。
