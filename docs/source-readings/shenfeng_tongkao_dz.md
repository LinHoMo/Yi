## 一、书目与版本

**作者与成书**：明代张楠（号神峰子，临川西溪逸叟）著。张楠"究心此道四十余年"，有感于《五星指南》《琴堂虚实》《渊海子平》诸书"颇有不根之言，进退之说无确然一定示人之见"，遂将诸书判为"正说／谬说"两栏对举——合于五行生克之理者为"正说"，不合者为"谬说"。书原名《命理正宗》，四库全书存目。

**全书性质**：命理辨谬＋病药说＋大量命例实践的论战著作。核心纲领：① 立"五星正说／谬说""子平诸格正说／谬说"辨伪；② 创"动静说""盖头说""六亲说""病药说""雕枯旺弱损益生长八法说"；③ 以数百命例（"见验说"）逐一证实或证伪各格。最大特色是"以案例驳古法"——每立一说必附命例。

**主源形态**：殆知阁转录单文件。叙（L1-7）＋五星正说类（L8-13）＋五星谬说类（L14-22）＋男女合婚说（L22）＋总论子平谬说类（L14-31）＋动静说（L32-34）＋盖头说（L35-36）＋六亲说（L37-38）＋病药说类（L39-40）＋雕枯旺弱四病说（L41-45）＋损益生长四药说（L46-51）＋正官格（L52-99）＋偏官格（L100-148）＋大量命例＋时上一位贵格（L266-267）＋其余格局。

## 二、逐卷（章）深读

### 叙至诸格辨谬（L1-31）——五星谬说驳／子平诸格辨伪

本段为神峰子辨驳诸五星书与子平书中"不根之言"的核心论述。先立"五星正说"（以五行生克为"正理"）驳"五星谬说"（纳音／生肖／小儿关煞），再立"子平诸格谬说"驳日贵格／日德格／魁罡格等"无中生有"的神煞取用。术语随文白话：**五星正说**＝以五行生克为正；**谬说**＝无根之谈。

核心判据：

- 源L7：`立五星正说，五星谬说，子平诸格正说，子平诸格谬说，动静说，盖头说，六亲说，病药说，雕枯弱旺损益生长八法说，人命见验说，盖取诸尊崇正理，辟诸谬说之意` → 全书纲领：正说／谬说对举＝尊崇正理、辟诸谬说。
- 源L15：`夫金木水火土，原天一生水，地二生火，即以水一、火二、木三、金四、土五次第列之。后类景即是以海中、炉中、大林、路旁之妄说配其纳音五行为歌` → 驳纳音：纳音（海中金／炉中火等）配五行次序是"妄说"——后代牵强附会。
- 源L25：`日贵格，如甲戊庚牛羊，乙巳鼠猴乡之类也。焉有斯理` → 历举日贵格／日德格／魁罡格／勾陈得位为"子平中之谬说"（"焉有斯理"起即驳斥，同节续斥诸伪格）。

### 动静说／盖头说／六亲说（L32-38）

三段紧接辨谬之后，立"正说"替代"谬说"：动静说立"天干动只能攻克天干动、地支静只能攻克地支静"（天干地支不可交叉攻取）；盖头说立"干为上、支为下，干吉则出头面好"（干透支藏的吉凶不同）；六亲说立"年月日时宫分配／用神配六亲分配"为正理——驳五星六亲相配。

核心判据：

- 源L33：`何以为之动也？其体属阳，阳主动。故天行健。圆转循球而无端。故以人之八天干透露于上者，为之动也。` → 动静说总纲：天干属阳＝动、地支属阴＝静——动攻动为亲切、静攻静为亲切。
- 源L36：`何以谓之盖头也？如人之一身，独有头为一身为端也。` → 盖头说：干为头面（出头面之吉凶），支为四肢肚腹——干凶出头面、干吉出头面好。

### 病药说／八法说（L39-51）

病药说是全书最核心的判据体系——"有病方为贵，无伤不是奇"的出处。四病＝雕／枯／旺／弱；四药＝损／益／生／长。合称"病药八法"＝以药治病＝以有余损之、以不及益之。术语随文白话：**病**＝八字中"所害之神"（使八字不美的那个字）；**药**＝"去其病"的那个字（制约病神的字）。

核心判据：

- 源L40：`何以为之病？原八字中原所害之神也；何以为之药？如八字原有所害之字，而得一字以去之谓了` → 病药定义：病＝"所害之神"；药＝去其病之字。
- 源L40：`有病方为贵，无伤不是奇；格中如去病，财禄两相随。` → 病药说口诀（全书名言）——出处实为《神峰通考》，非他书。
- 源L43：`贵具有根而桔也，不贵其有苗而桔也。苟若官星无根，官从何出？` → 枯病：无根则虽有苗（天干）亦不贵——"根在苗先"（"何以为之枯也"见 L43 同节）。
- 源L47：`何以谓之损？损者，损其有余也。然木生震位，正木气之当权也。金产竞宫，正金神之得位。当权者不宜资助` → 损药＝损其有余——对其当权之神不宜资助。

### 正官格与偏官格（L52-167）——格局辨正＋大量命例

本卷逐格（正官／偏官／时上一位贵）给出"正确示范"＋"错误示范"对比例命例。每造以"楠曰"张楠自评——先点格局（身强杀浅／土厚埋金），再判大运吉凶，末应验。术语：**正官格**＝月令正官＋身旺＋行官旺；**偏官／七杀格**＝月令七杀＋有制（食神制杀）；**弃命从杀**＝日主无根＋四柱纯杀＋从杀旺运。

核心判据：

- 源L53：`正官者，何以言之？盖以阳见阴，阴见阳，故曰一阴一阳之谓道，如人之一夫一妇之有配对也。` → 正官定义重申。
- 源L100：`偏官为阳见阳、阴见阴，原非阴阳配合。更得食神伤官，以制去其凶锐，虽先为克我之凶神，今则驯致其凶，而反为我之奴仆也。` → 偏官定义：原为凶神，得食神制之则为"偏官"（权柄）。
- 源L101：`弃命从杀格，缘日主全无一点生气，四柱纯然有官杀，则不得已而只得从杀也。` → 弃命从杀格成立条件：日主无根＋四柱纯杀——畏见根／畏制杀运。

## 四、对勘与口径分歧

**与对勘本（wikisource）的差异**：两版本篇目结构一致（叙→五星正说→五星谬说→子平谬说→八法说→正官格→偏官格→命例）；行号差异主因：wikisource 繁体排版每行字数不同。采信以主源为准。

**与《子平真诠》的口径关系**：

1. 本书辨伪取用——指出日贵／日德／魁罡等"神煞格局"不根五行生克；《子平真诠》则系统化"月令取用→格局→高低"三段式。两书互补：本书破伪，彼书立正。
2. 《滴天髓》引用"有病方为贵"而不言出处；本书即为该口诀的原出处——引《滴天髓》时应补溯源至本书。
3. 与《穷通宝鉴》调候的关系：病药说从"八字有偏"入手，与"寒则暖之、燥则润之"的调候原理同构——但病药更偏"去所害之神"（如比肩多为病用官杀），调候更偏"调候气之寒热湿燥"。

4. 吕才合婚上中下三婚（源L22）：妄说——"不足信也"。
5. 日贵格／日德格／魁罡格（源L25-27）："谬说无疑也"——engine pattern.py 不应注册这些格局。
