## 一、书目与版本

**作者与成书**：旧题"余春台"辑，原书又名《栏江网》，为命学调候类典籍之祖。全书以"五行总论"起，逐月逐日给出十天干的调候用神清单——同一日干在不同月令下所需"调剂候气"的神完全不同。与《滴天髓》的哲学总纲互补：《滴天髓》讲"理"（形象／方局／中和），本书讲"术"（某日某月取何调候）。

**全书性质**：调候用神字典——以日干×月令二维矩阵组织，每格给出"用神＋喜神＋忌神"组合，并附命例。最大特色是"以月令气候病药为急"：冬季寒则丙火为急、夏季炎则壬水为急，不以格局贵贱为前提。

**主源形态**：殆知阁转录单文件，始于"五行总论"（L1-13），次论甲乙丙丁戊己庚辛壬癸十干；每干以"三春／三夏／三秋／三冬"四段分述，段内逐月命例。已知缺陷：① 部分命例干支竖排；② 异体字（如"剋"通"克"）全书通用；③ 少数命例仅标"举人""进士"无干支。

**对勘本**：`data/sources/qiong-tong-bao-jian.wikitext.txt`（维基文库繁体排版本）。两版本章目一致（五行总论→十干分月），wikisource 含更多诗作引文；差异以简繁、标点为主，判据采信以主源为准。

## 二、逐卷（章）深读

### 五行总论（L1-13）——五行大义／生克／调候根源

本卷起首给"五行"正名（"五行者本乎天地之间而不穷者也"），再论五行相生相克、五行性（火为太阳性炎上、水润下等），末以"才官印食贵人驿马之微意"点明全书调候逻辑——以折衷为贵、无有余不足之累。术语随文白话：**过与不及皆为乖道**，折衷＝归於中道＝调候的根本追求。

核心判据：

- 源L5：`五行者，本乎天地之间而不穷者也，故谓之行。` → 五行定义：五行是天地间运行不息之气，非静态元素。
- 源L7：`火为太阳，性炎上。水为太阴，性润下。木为少阳，性腾上而无所止。金为少阴，性沉下而有所止。` → 五行性情：十干取象的原理源——甲木腾上（少阳）、丙火炎上（太阳），是调候取象的哲学基础。
- 源L11：`过与不及，皆为乖道。故高者抑之使平，下者举之使崇，或益其不及，或损其太过。所以贵在折衷，归於中道，使无有余不足之累，即才官印食贵人驿马之微意也。` → 调候总则：以折衷为贵，抑高举下、益不及损太过——整个"调候"体系的逻辑起点。

### 十干分月调候（L14-550+）——日干×月令二维用神清单

本卷为全书核心：甲乙丙丁戊己庚辛壬癸十干，各自以三春／三夏／三秋／三冬四段，逐月给出调候细则。每格判据结构为"用神（急）＋喜神（辅）＋忌神（克用神者）"，附命例证实。术语随文白话：**用神**＝调候急需之干；**喜神**＝辅用神之干；**忌神**＝克用神之干；**格局**＝八字整体气势（本书不废格局但以调候为急）。

核心判据（逐条照录，择最能代表"该项目现状"的关键格）：

- 源L24：`正月甲木，初春尚有余寒，得丙癸逢，富贵双全。癸藏丙透，名寒木向阳，主大富贵。` → 正月甲木调候：丙火＋癸水暖木——丙癸双透为最高格；"寒木向阳"是经典判据标签。
- 源L40：`四月甲木退气，丙火司权，先癸後丁。` → 四月甲木调候：癸水为急（四月火炎非癸不济）。
- 源L57：`三秋甲木，木性枯槁，金土乘旺，先丁後庚，丁庚两全，将甲造为画戟` → 七月甲木调候：丁庚双透——丁制金、庚劈甲，缺一不可。
- 源L84：`十月甲木，庚丁为要，丙火次之。忌壬水泛身，须戊土制之。` → 十月甲木调候：庚丁为急——寒木向阳之另一种形式（无丙用丁）。
- 源L100：`正月乙木，必须用丙，因天气尤有余寒，非丙不暖，虽有癸水，恐凝寒气，故以丙火为先，癸水次之。` → 正月乙木调候：乙木与甲木同需丙暖，先丙後癸。
- 源L167：`三春丙火，秉象至威，阳回大地，侮雪欺霜，端用壬水，为扶阳，名曰天和地润，既济功成` → 丙火总则：三春丙火壬水为尊——扶阳既济。
- 源L216：`三夏丙火，阳威性烈，专用壬水。若亥宫壬水无力，回克泄气故也，仍用申宫长生之水，方云富贵。` → 夏丙专用壬：壬水刚烈制丙光。
- 源L92：`十二月甲木，天寒气冻，木性极寒，无生发之象，先用庚劈甲，方引丁火始得木火有通明之象，故丁次之。` → 腊月甲木调候：庚劈甲引丁——无生发之象须庚为先导。

### 调候实操要点（贯穿十干诸月）

本节总括贯穿全书的实操原则：① 调候用神以月令气候为唯一前提，与格局用神可并存；② "用神太多不宜克制须泄之为妙"（源L46）；③ "凡用神太多／太少"均须以月令为中轴权衡；④ 各月调候口诀中的"先X後X"顺序反映轻重缓急，不是取舍次序——"先癸後丁"＝癸为主、丁为佐，两者皆需；⑤ "寒木向阳""画戟格""天和地润"等原著名词是对调候成功结构的高度概括标签，对命例对齐分有关键指示意义。这些原则构成 "调候→格局→运程" 三层分析的基础层。

核心判据：

- 源L46：`凡用神太多，不宜克制，须泄之为妙。` → 调候层级的"太过"处理：过多不宜克制而宜泄——与《滴天髓》"损之斯成"一脉相承。
- 源L97：`三春乙木，为芝兰蒿草之物，丙癸不可离也，春乙见丙，卉木向阳，万象回春，须癸滋养根基。` → 乙木与甲木同需"丙癸"为调候双翼，但乙为花草、甲为乔木，微细差别在于乙重癸滋、甲重丙泄。

## 四、对勘与口径分歧

**与主源及 TIAO_HOU 表（`core/yishu_core/ming_tables.py`）的关系**：

1. **调候用神与格局优先权**：本书以"调候为急"——同一八字月令偏寒偏燥时，调候用神优先于《子平真诠》的格局取用。project 的 evaluate.py 已同时含格局与调候两层，但优先顺序（孰主孰从）未见显式规则。建议：当调候与格局用神冲突时，以调候为"体"、格局为"用"——本书立场。
2. **与《滴天髓》寒暖燥湿章**：《滴天髓》论寒暖为总论，本书以月令为矩阵展开；寒暖燥湿系原理，穷通宝鉴系条例。两部书应互补，不应矛盾。project 的 TIAO_HOU 表引用出处标注（`disciplines/ming/data/tiaohou_quotes.json` 书证逐字）应同时追注两书。
3. **对勘本（wikisource）差异**：wikisource 版本五行总论部分含更多引文（如《考原》《五行大义》），章节行号因排版不同而大异；但十干分月调候逐条内容与主源相同，采信以主源为准。
4. **与《神峰通考》病药说**：《神峰》"有病方为贵"以病药取用神——与本书调候逻辑同源（寒为病、暖为药）。project 病药说在 `disciplines/ming/data/rules/rule_registry.json` 有登记，但缺少穷通宝鉴的本体论支撑说明。

## 五、不适用与存疑

**书源明写否定→不适用**：本编未发现书源整体否定任何一条调候格（全书逐格皆为"用／喜忌"正面陈述），故不适用登记为 0。

**转录缺陷**：

1. 主源异体字（剋→克、煆→煅、馀→余）全书通用，引文采信时按 NFKC 归一化处理。
2. 部分命例仅标"举人""进士"无干支（如 L42-47 命例），判据采信时只取格中用神句，不依赖命例干支。

**未读懂／无法机械化的段落**：

1. 源L8：`夫五行之性，各致其用。水者其性智，火者其性礼，木其性仁，金其性义，惟土主信`——五行性情映射性格，属五德心理学化阐释，project 在 narrate 层有使用，但非主判据层级。
