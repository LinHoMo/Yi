## 一、书目与版本

汉·京房撰，吴·陆绩注；三卷。四库全书子部术数类占卜之属，卷首提要（L1-5）记：
房本姓李，吹律自定为京氏，字君明，东郡顿邱人，受《易》于焦延寿，元帝时以言灾异
得幸，为石显等所嫉，出为魏郡太守，卒以谮诛。提要并录京房著目十余种（易传三卷、
章句十卷、飞候、妖占、逆刺占灾异等），今惟《易传》存。

书名「易传」而绝不诠释经文：上、中卷以八卦分八宫，每宫一纯卦统七变卦，注世应、
飞伏、游魂、归魂诸例；下卷首论揲蓍布卦，次论纳甲法、二十四气候配卦、四易、
六亲等爻。四库馆臣断言「后来钱卜之法实出于此」，并引项安世语：世所传《火珠林》
即其遗法（源L3：`世所传火珠林即其遗法以三钱掷之`）——本书因此是六爻纳甲筮法的
祖源文献，本仓库 core 的八宫归属、纳甲表、世应体系即其现代存续形态。

主源形态：四库电子文本单行极长（如 L16 一行即乾宫首卦全文约千字），109 行承载
全书；L1-5 提要与衔名，L13-45 卷上（乾、震、坎、艮四宫），L53-81 卷中
（坤、巽、离、兑四宫），L95-97 卷下总论，L98 晁公武跋，L99-106 八宫卦序速览表，
L109 卷尾。OCR 变体字密集（隂/阴、兊/兑、巻/卷、凢/凡、徳/德、専/专），

## 二、逐卷（章）深读

### 卷首提要（L1-5）

四库馆臣给出两个对后世影响极大的判断：其一，本书体例「上巻中卷以八卦分八宫每宫
一纯卦统七变卦而注其世应飞伏游魂归魂诸例」（源L3：`上巻中卷以八卦分八宫每宫一纯卦统七变卦而注其世应飞伏游魂归魂诸例`）；其二，钱卜祖源论——三钱掷法（两背一面为坼、
两面一背为单、俱面为交、俱背为重）即由京氏遗法演化，火珠林为其中介。提要同时
批评陆德明《经典释文》把八宫世次附会到《周易》经文之下是「误之甚矣」——八宫是
占筮体系，不是经文结构，这条界线至今有效。

### 卷上·乾宫至艮宫（L13-45）

每卦体例固定：卦象定性 → 飞伏与世位 → 建候（月气起讫）→ 积算 → 五星从位 →
二十八宿从位 → 分气候（三十六或二十八）→ 人事物象 → 阴阳升降 → 转下卦。
乾为首宫范本，源L16：`【干下干上】干纯阳用事象配天属金与坤为飞伏居世【壬戌土癸酉金】`——
飞神壬戌土即乾上爻，伏神癸酉金即对宫坤上爻；「与坤为飞伏」定下八纯卦对宫互配的
飞伏系。乾宫六亲以古名入歌，源L16：`水配位为福徳【甲子水是干之子孙】木入金乡居宝贝【甲寅木是干之财】`——
福德=子孙、宝贝=妻财，与今名一一对应；下卷总论更给出全套古名（见 §三 #5）。
姤卦立「多以后世注家所谓取少为贵」的断卦立场，源L17：`定吉凶只取一爻之象【多以少为贵】`——
一爻动定吉凶是八宫变卦体系的灵魂，也是六爻「独发易取」的上源。
宫序推进的机理每卦末句点明（乾宫「阳极隂生降入姤卦」→ 剥极「游魂荡入晋」→
「复本宫…大有为归魂」），大有卦总束语源L22：`凢八卦分为八宫每宫八卦八八六十四卦定吉凶配人事`。
卷上复卦句为焦京系统的卦气支点，源L58：`易云君子道长小人道消又曰七日来复`。

### 卷中·坤宫至兑宫（L53-81）

坤宫起坤「纯隂用事…与干为飞伏【癸酉金壬戌土】」，与乾宫互为镜像——乾坤两表
合看即飞伏对宫配的全部信息。坤宫序（复临泰大壮夬需比）与坎离艮兑诸宫序逐卦
与 core 八宫表一致（见 §三 #1）。每宫转宫逻辑严格按「乾生三男（震坎艮）、
坤生三女（巽离兑）」父母六子次第，震宫束语源L23：`干生三男次入震宫八卦`。
坎宫范本给出阳陷阴中的定性（源L30：`坎以阳居中为重刚之主故以坎为险阳变隂成于险道今以隂变阳止于为节`），
转卦句「今以隂变阳止于为节」即坎宫二世节的由来——八宫次序不是排列组合，
而是一逐爻消长的机械过程，这正是它能被程序化的原因。

### 卷下·总论（L95-97）

下卷是全书的方法论压缩包，六爻筮法的全部机械构件在此定型：

1. 纳甲法：乾坤纳甲乙壬癸「表覆载之始终」，震巽配庚辛、坎离配戊己、艮兑配丙丁，
   源L97：`震巽之象配庚辛【庚阳入震辛隂入巽】`——与 core NAJIA_STEMS 逐卦一致
   （乾甲壬/坤乙癸/震庚/巽辛/坎戊/离己/艮丙/兑丁）。
2. 四易：以世次分天地人鬼四层，源L97：`一世二世为地易三世四世为人易五世六世为天易游魂归魂为鬼易`。
3. 六亲古名：源L97：`八卦鬼为系爻财为制爻天地为义爻【天地即父母也】福徳为宝爻【福徳即子孙也】同气为専爻【兄弟爻也】`——
   官鬼=系爻、妻财=制爻、父母=义爻、子孙=宝爻、兄弟=専爻。
4. 二十四气候配卦：以节气起爻（如源L97：`立春正月节在寅坎卦初六立秋同用`），
   每节气一爻、逐月逐爻轮转，属京房卦气系统，不属六爻排盘主路径。
5. 生气死气：源L97：`寅中有生火亥中有生木己中有生金`——五行寄生十二宫的另一支
   表述，与长生诀互为表里。
6. 积算起宫：源L97：`干起已坤起亥震起午巽起辰坎起子离起丑艮起寅兊起【阙】`——
   兑宫起支四库本即缺文，且「干起已」之「已」于巳/己两可，积算全表不可复原。

### 晁公武跋与八宫表（L98-106）

晁跋是理解本书概念体系的最清晰入口，七个「谓之」：世、应、飞、伏、建、积、互。
世应定义，源L98：`其进退以几而为一卦之主者谓之世`；飞伏定义与对宫原理，
源L98：`世之所位而隂阳之肆者谓之飞`、源L98：`以隠显佐神明者谓之伏`，夹注
「干与坤震与坎巽与离艮与兊」四对、且「以飞某位之卦乃伏某宫之位」——对宫飞伏
的系别被这里点破。建、积定义，源L98：`起乎世而周乎内外参乎本数以纪月者谓之建`、
源L98：`终之始之极乎数而不可穷以纪日者谓之积`。末附八宫速览表（L99-106）
逐宫列本宫与七变卦，经逐宫对拍与 core EIGHT_PALACES 完全一致（含游魂归魂位次），
是 core 八宫表最可靠的外部真值源（见 OPT-02）。

## 四、对勘与口径分歧

无对勘本（登记表 crosscheck 为空），本节录三条体系口径：

1. 世次命名：京氏以本宫纯卦为「宗庙居世/上世」，后世（含本项目
   core/yishu_core/symbols.py EIGHT_PALACES）称「六世」。symbols.py 模块头已声明
   「本宫首卦的世代标签为六世」，与本书无实质冲突，属命名层差异。
2. 飞伏系别：本书飞伏为**对宫互配**（八纯卦飞神伏神取对宫同位爻，如乾伏坤癸酉；
   一至五世则取本宫首卦同位爻，如姤伏乾初爻甲子）。《周易尚占·飞伏例》把两系
   并存表述（八纯归魂用相配卦，余用本宫）；《卜筮正宗》伏神章则统一取本宫首卦。
   引擎采本宫系——对八纯/归魂卦，两系给出的伏神不同（乾纯卦：本宫系无伏神可言，
   对宫系伏癸酉金），这是实盘可观察的口径分歧，登记进 OPT-03。
3. 三钱掷法口径：四库提要记「两背一面为坼、两面一背为单、俱面为交、俱背为重」，
   与《周易尚占·以钱代蓍》「一背为单、二背为拆、三背为重、纯字为交」经换算
   完全一致（提要按「面」计数、尚占按「背」计数），并与六爻通行口径及引擎
   chart.py 铜钱摇卦一致——无分歧，录此备查。

## 五、不适用与存疑

- 建候、积算、分气候、五星、二十八宿五套卦气数术：引擎未实现，六爻排盘主路径
  亦不需要（六爻判据以六亲生克+日月旺衰为纲）。四库提要所列京房佚书
  （飞候、四时候、混沌、委化等）多半是这套卦气体系的专书，本书残存片段不可复原
  全貌——整体标不适用，个别片段（二十四气候配卦表）若未来做择吉/卦气专题再核。
- 游魂卦飞伏配对存疑：晋（乾宫游魂）注「与离为飞伏【己酉金丙戌土】」，伏神
  丙戌土既非乾宫首卦同位爻（壬午火）亦非晋之对宫（坎四爻戊申金），书内无注可解，
  历来聚讼——存疑不硬解，引擎不采。
- 积算起宫兑宫缺文（兊起【阙】）、「干起已」巳/己两可——原文即不可复原，存疑。
- OCR 变体字清单（引用必须原样）：隂=阴、兊=兑、巻=卷、凢=凡、徳=德、専=专、
  竒=奇、廵=巡、賛=赞；另有 L3「务趋防径」疑「务趋简径」之讹。
- 提要所列京房著目与《汉书·艺文志》著录卷帙不合，提要已自辨（晁陈二家书目
  以杂占条例合易传为四卷）——版本沿革存目备考，不影响判据抽取。
- L99-106 速览表中「筮嗑」为「噬嗑」、「頥」为「颐」之讹，与各宫正文对读可校正。
