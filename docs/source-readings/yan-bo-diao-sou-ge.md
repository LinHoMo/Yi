## 一、书目与版本

《烟波钓叟歌》是**奇门遁甲的总纲歌诀**，旧题北宋通人所作、经明·罗通增删修改（源L2 维基文库 Header 记「北宋通人所作，後經明朝羅通增刪修改」）。凡研奇门者必背此歌，故称「烟波钓叟歌」。全书仅 84 行七言，用韵语概括遁甲起局、天三门地四户、伏吟返吟、三奇入墓、六仪击刑、天盘奇仪、九星五行旺衰、击刑制迫等全部要点。

## 二、逐卷（章）深读

### 起局总纲与三遁（源L2–L19、L76–L81）

歌诀开篇即立遁甲二遁之理（阳遁顺、阴遁逆），并以「二至还乡一九宫」定阴阳消长与九宫配属；继之给出起局三步：排九宫（纵横十五图）、分八节、一气统三。**值符值使的运转规则**是全歌最核心的机械层：「值符常遣加时干，值使顺逆遁宫去」（源L19）。天三门地四户与三遁（天遁月精华盖、地遁日去紫云蔽、人遁太阴）是遁法分类的总纲（源L32–L36、L76–L78）。

- 阴阳二遁总纲，源L2：`陰陽逆順妙難窮，二至還鄉一九宮。` → 阴阳消长与九宫配属的纲领；对理解二至（冬至夏至）还乡是全歌起点。
- 值符值使加时干，源L19：`值符常遣加時干，值使順逆遁宮去。` → **起局核心机械规则**：值符加时干、值使顺逆行宫，是奇门起局的机械层（与项目"机械运算归代码"同源，属可完全机械化的规则）。
- 天三门地四户，源L32：`天三門兮地四戶，問君此法如何處？` → 天冲/太乙/从魁为天三门（私门），地户除危定开为地四户（私门），是遁甲门遁法的分类骨架。
- 三遁定法，源L76：`天地人分三遁名，天遁月精華蓋臨。` → 三遁（天/月精华盖、地/日去紫云蔽、人/太阴）的取象定义，属机械结构层。

### 伏吟返吟、击刑入墓与八门九星（源L39–L56、L105–L123）

凶格集中区：游三避五（源L42「能識遊三避五時」）、伏吟返吟（源L43–L45）、六仪击刑与三奇入墓（源L47–L55）、五不遇（源L56「五不遇時龍不精」）。另有八门吉凶（源L105–L108）与九星五行旺衰（源L117–L123），后者是**遁甲与八字共用的五行底层**。

- 游三避五，源L42：`能識遊三避五時，造化真機須記取。` → 「遊三」（三为生气）「避五」（五为死地），是遁甲择宫的核心吉凶法则。源L39 `三為生氣五為死，勝在三兮衰在五。` 更明确：生气在宫三、死地在宫五。
- 伏吟最凶，源L43：`就中伏吟最為凶，天蓬加著地天蓬。` → 伏吟（天地盘同位）主凶的成格条件；返吟见源L44–L45（八门返伏同理、生在生死在死）。
- 三奇入墓，源L49：`三奇入墓宜細推，甲日那堪` → 同行正文作「見未」，即甲日见未宫为三奇入墓（`{{另|入坤|見未}}` 取「見未」），属机械判据层。
- 五不遇，源L56：`五不遇時龍不精，號為日月損光明。` → 五不遇（时干克日干）为凶格，机械条件明确（源L57「時干來剋日干上」）。
- 九星配五行，源L117：`要識九星配五行，須求八卦考羲經。` → 九星五行配属（坎蓬水、离英火、坤艮土、乾兑金、震巽木），**是遁甲与八字/梅花共用的底层**；源L119 更以 `旺相休囚看重輕` 点出四时的旺衰权衡，与项目 core 的旺衰表同构。
- 迫门制宫，源L131：`門制其宮是迫雄。` → 门宫迫/制的机械判定条件（门制宫为迫，同行源作「宮制其門不{{另|迫門|為迫}}」，即宫制门不为迫），是可完全机械化的结构标签。

## 四、对勘与口径分歧

**与《遁甲演义》《奇门宝鉴》的关系**：本书是**歌诀总纲**，而《遁甲演义》《奇门宝鉴》《奇门遁甲统宗》《奇门法窍》（均已另行解读）为其**展开与占验**。本书之"二遁/九宫/值符值使/三奇六仪"等规则，在四书展开本中应可一一对源；引用时以本书为**纲领级**书源，占事细则以展开本为**细则级**书源，二者层级不可混同。

**与项目现有八科的关系**：本书奇门遁甲无对应学科。但其中**五行生克、旺相休囚、干支**三层为八科共用底层（已入 core），可作对源留底；**奇门特有的局数、三奇六仪、九星八门、门宫迫**等，则纯属奇门，不在现行八科范围。

**与《六壬》月将的表面相似与实异**：本书"二至还乡"与六壬"月将加时"都涉历法，但本书按节气三元（接气超神）起局、六壬按月将加时起课，是**两套不同的历法起局机制**，不可混用。

**本批内无其他口径冲突。**

## 五、不适用与存疑

**不采内容及理由**：

1. **兵占断语**（源L62–L71「百战百胜君须记」「大臣宜居击对冲」等）：属兵家用兵占断，含明确吉凶方向（"百战百胜""为客是高强"），**属叙事候选/超出骨架**，不入结构层，且按铁律三不得直接作军事决策依据（应提示以专业意见为准）。理由：奇门无对应学科，且军事吉断风险高。
2. **占断式趋避辞**（如"卒然有难宜逃避""万事皆凶不堪使"）：属古法趋避吉凶，现代问域弱，不入引擎。
3. **天马、天乙击冲等求胜格**：属叙事候选，仅照录留底。

**异文/转录登记**（维基文库以 `{{另|正|異}}` 标异文，引文取正文）：

1. 源L8「一千八{{另|百|十}}」——正文作**一千八十**（当从「十」，奇门总数一千八十之说通行）；「百」为异文。
2. 源L49「甲日那堪{{另|入坤|見未}}宮」——正文作**見未**（三奇入墓，甲日见未宫为入墓，当从「見未」，「入坤」为异文）。
3. 源L44「天蓬若到天{{另|央|英}}上」——正文作**天英**；「央」为异文。
4. 源L120「與我同行即為{{另|我|相}}」——正文作**相**（旺相）；「我」为异文。
5. 源L136「請觀歌裏{{另|真|精}}妙訣」——正文作**真妙訣**（另有「真賢莫相與」为异文）。凡此歌诀版本差异较多，引用宜注明底本。

**存疑**：

- 本书为流传最广的奇门总纲，但**具体起局法（拆补/置闰、超神接气）与《遁甲演义》《奇门宝鉴》展开本可能有出入**（本书只云"節氣推移時候定"，未详置闰），如遇起局分歧，须以展开本为准并注明层级。
- 本书"八门"（开休生伤杜景惊死）虽与六爻八宫卦名同源，但**门名与卦名体系不同**（八门为遁法，八宫卦为六爻纳甲），不可因同名而互串。
