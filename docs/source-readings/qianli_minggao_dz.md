## 一、书目与版本

本书为民国时期（约 1935-1940 年）韦千里所著现代子平教材，以**教学问答 + 分类论述**编写，在传统命书中属于最现代化、条目最清晰的一种。杨叔和序（源L4-6）列为起，全书以起例问答入门，逐次铺开天干/地支/五行/强弱/六神/格局/运限/流年/六亲/女命/富贵吉寿十二篇。

**体系定位**：本书严格遵循**子平正统十神系统**——以日干为我、十神生克为框架，无纳音论命层、无神煞主导格局判断，与现行 engine 的子平日主法完全同构，是最易对照验证的著作。判语中含有相当比例的**命理教学阐述**（而非纯粹吉凶命定），如"七杀者……二阳相克……隔七位相战克故名七杀"，此类为象数解读（可作叙述层旁证）而非机械规则。

## 二、逐卷（章）深读

### 起例问答（源L166-330）

本系统问答集包含八字推演的全部机械推演基础：

- 十干定义，源L169：`甲、乙、丙、丁、戊、己、庚、辛、壬、癸，此为十天干`——与 core 天干表（`HEAVENLY_STEMS`）一致。
- 推年以立春为标准，源L192：`推年以立春为标准，其区别有三也。`——engine `ganzhi_calendar` 以立春年为界，同口径。
- 推月歌诀，源L205-206：`甲己之年丙作首，甲年己年之正月，皆为丙寅`——五虎遁口诀，与 `TIGER_MONTH_STEM` 一致。
- 月建固定，源L203：`正月建寅`（固定建寅为正月）。6月为**未**非午。
- 推时歌诀，源L252：`甲己还加甲，乙庚丙作初，丙辛从戊起，丁壬庚子居，戊癸何方发，壬子是真途`——五鼠遁口诀。engine 时干法与此同。
- 天干阴阳，源L255：`甲丙戊庚壬皆为阳，乙丁己辛癸皆为阴`——与 `STEM_YINYANG` 一致。
- 大运顺逆，源L257-258：`大运起点根据月建。如男命所生之年天干属阳或女命所生之年天干属阳，运皆顺行；男命天干属阴或女命天干运皆逆行`——与 `dayun_direction` 口径一致（阳年男/阴年女顺行）。

### 强弱篇（源L963-1015）

身强弱判断的三条标准：

- 身强三条件，源L968-970：`（一）月令旺相：如甲木日干，生于春冬`、`（二）多帮扶：如甲木日干，四柱多水多木`、`（三）支得气：如甲木日干，生于亥年寅日卯时（甲生于亥临官于寅，帝旺于卯，气盛为得气）`——与 engine 强判三要素（月令+生扶+得气）基本同构。"支得气"=长生/临官/帝旺位，对应 `ROOT_HEAVY_STAGES`。
- 最强三档，源L972+：`（一）最强：既当令，又多帮扶`、`（二）中强：仅多帮扶而失令`、`（三）次强：既不当令又少帮扶但年日时支得气`——三级分法与 engine 的 strength_score 连续量化不同但可对应（OPT-01）。
- 身强喜抑四因，源L985-989：`（一）受克：即克我，如甲木见金克`、`（二）被泄：即我生，如甲木见火泄`、`（三）被分：即我克，如甲木见土分`、`（四）气衰`——克泄耗三路与 engine `TEN_GOD_GROUP` 一致；"气衰"=五行在受克月令。

### 六神篇（源L1015-1311）

系统定义十神（六神）：

- 十神总述，源L1017：`五行之理只是生我克我，我生我克。但不设名目，不便推详，五行阴阳生克之代名词也。自有此代名词立，执五行生克以衡量人命`——与 engine `relations.ten_god` 同构。
- 七杀定义，源L1070：`七杀者，又名偏官。二阳相克，二阴相克，犹二男不同处，二女不同居，不成配偶故谓之偏官。又以其隔七位，而相战克，故曰七杀`——七杀即偏官=克我同性者。engine 有七杀（`七杀`/`偏官`列为 `官杀` 类），同口径。
- 正官定义，源L1024：`正官者，如一县之有邑宰。`——克我异性=正官。engine 十神同。
- 印绶定义，源L1215：`印绶者，乃五行生我之名。乃我气之源，为生气，为父母，又能护我官星`——生我者=印。印护官星精神与 engine 十神生克结构一致。
- 伤官四用，源L1025-1040：`泄身，生财，敌杀，损官`——伤官（我生异性）四作用，engine 十神不直接定义"作用"层（OPT-02）。
- 伤官利弊当否，源L1045-1053：身强爱伤官（泄）、身弱忌身官（克）——"当/不当"取决于强弱，与 engine `useful_god/taboo_god` 逻辑一致。

### 格局篇（源L1373-1834）

- 八格外格，源L1654：`论命由阴阳五行干支之生克，进而取八格与用神，已可十得八九。`——八格+外格。engine `PATTERN_BY_MONTH_GOD` 已立八格外，有 `_from_judge` 从格外格，与此同结构。
- 格外篇名目，源L1654+：曲真/炎上/稼穑/从革/润下/从财/从杀/从儿/从旺/从强/化气/建禄/月刃——engine 从格名目基本覆盖，差异登记。
- 格局假令例，各格附实例干支（如"癸酉年辛酉月丙寅日丁酉时"），仅作开发测试参考（案例库隔离铁律二）。

### 运限篇 / 流年篇 / 六亲篇

- 运之差别，源L1834+：`行运之能力`——大运对命局影响力分级；engine `dayun_liunian_interactions` 已有运/年互动标签。
- 流年关系，源L1981+：`流年与运之关系`——流年×大运的三类作用（升/平/降）。
- 六亲定义，源L2043+：`何为六亲`——父母妻子兄弟；engine `relations.LIUQIN_TO_SHISHEN` 已备六亲↔十神映射。

## 四、对勘与口径分歧

1. **全书与 engine 同构度最高**：本书与现行 engine 的子平日主法几乎完全对齐——十神/格局/大运顺逆/扶抑用神全部同口径。是最适合对齐分回归的古籍之一（golden/holdout 的黄金样例）。
2. **月令旺相 vs 月令本气十神**：本书以"月令旺相"（四季正位）为身强依据；engine 以月令本气十神定格——两法互补但不相等。engine 重月令格局取用，本书重月令旺衰判断。
3. **"支得气"定义差异**：源L970：`甲生于亥临官于寅，帝旺于卯，气盛为得气`——以十二长生定气盛与否。engine `ROOT_HEAVY_STAGES`=临官/帝旺/长生，与此一致；但 engine 还加了墓库余气轻根（`ROOT_LIGHT_W=0.25`），比本书"气衰"定义更细化。
4. **伤官四作用 vs engine 十神生克**：engine 的十神结构只定义"十神类"（`TEN_GOD_GROUP`），不定义"作用"（泄身/生财/敌杀/损官）——本书提供了十神与格局的交互作用枚举层。
5. **外格外段名目**：engine 从格名目（`_from_judge`）与本书格外篇名目（曲真/炎上/稼穑/从革/润下/从财/从杀/从儿/从旺/从强/化气/建禄/月刃）基本一致，差异登记。
