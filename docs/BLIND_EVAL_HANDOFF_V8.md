## 一、做了什么

### 1. 思维链（`scripts/thinking_chain.py`）

| 项 | 说明 |
|----|------|
| 格局标签扩展 | `_inject_pattern_tags` 增强：伏神/飞克伏/伏生飞/飞空得出/反吟/日辰合世/变卦六合/动空/出旬/原神生用 等经典别名；同时输出 `[格局]` 与 `[格局要点]` |
| 应期密度 | `_predict_timing` 前置「重点应期：X日、Y日…」，收集用神/日月/动变支/原神旺日/伏神/旬空；并输出节奏人话（次日/年内/不安） |
| 断语口径 | 合处逢冲+婚姻 → `平/不利`；价格类凶象 → `下跌` |
| 用神多现 | 动而自伤（回头克/化绝）优先级降于「静而完整」——ZS011 由丑改未，对齐古籍「财爻未土」 |
| 上下文透传 | `_build_reasoning_chain(..., context=)` 可读 advanced_analysis / 变卦 / 日辰 |

### 2. 解读文风（v9 修正，用户反馈「不能另贴人话章节」）

- **只有一份正文**，从头到尾按师傅口吻写：结论 → 卦与用神 → 动变格局 → 时间 → 建议
- `human_narrative.py`：`build_human_narrative` 产出 `body` 连续段落 + `process` 备查推演，**不再**与古典腔并列
- `thinking_chain` 各步 `summary_text` 改为叙述体，分数只作括号备查；格局标签仍独立字段供评估
- `advice_framework`：建议从写入时就是白话；分类按问题关键词（子病→疾病，不再默认「事业」）
- HTML / `index.html`：概览首屏即完整解读；「推演过程（备查）」置后，不抢正文
- SKILL.md 明令：禁止「人话/古典」两张皮；自检——正文若像字段报表则不合格

### 3. 人话层（历史说明）

旧版曾尝试「人话层」外挂章节，**已被否定并改为统一正文**。函数名 `human_narrative` 仍保留，职责是撰写唯一交付正文。
