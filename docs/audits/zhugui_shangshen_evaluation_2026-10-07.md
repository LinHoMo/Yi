## 二、书源考证

### 2.1 《卜筮全书》原文（L3131-3141）

```
六、助鬼伤身：

    生助官鬼者，不过妻财也。不宜发动，动则衰鬼变成旺鬼。旺鬼遇之，其势愈凶。
    且如申日占得离卦，鬼临应爻克世，本非佳兆，更兼妻财发动，生助鬼爻，其凶愈不可当。
    此乃助鬼伤身也。凡卦鬼克身世者，无财凶有限。若有两财皆动，其祸不可胜言。
    倘得子孙发动，福神来解，庶可反凶成吉，转祸为祥。
```

虎易注（L3137-3141）进一步明确三条件：
1. 助鬼：妻财临日月或卦中发动 → 生助鬼爻
2. 伤身：鬼爻冲克世爻/卦身
3. 合助鬼伤身：鬼可伤克身世 + 子孙独发可解（但子孙+财同动 → 子孙生财、财生官，反成连续相生，官鬼更旺）

## 四、结构分析：为何不新增

### 4.1 判定依赖链

「助鬼伤身」的完整判定需要以下子结构全部具备：

| 子结构 | 当前是否支持 |
|---|---|
| 鬼爻（官鬼）识别 | ✓ 已有 |
| 世爻/卦身定位 | ✓ 已有 |
| 鬼克身世（冲/克） | ✓ 已有（CHONG_PAIRS / KE_CYCLE） |
| 妻财识别 | ✓ 已有 |
| 财动（发动判断） | ✓ 已有（暗动/明动分析） |
| 财生鬼（连续相生路径） | ✗ 无跨爻连续相生路径分析 |
| 子孙独发 | ✓ 已有（独发判断） |
| 子孙克鬼 vs 子孙生财的冲突 | ✗ 无优先级裁决逻辑 |
| 两财皆动 → 祸不可胜言 | ✗ 无多财联动判断 |

### 4.2 核心缺口：连续相生路径的优先级裁决

书源最关键的难点不在单个子结构，而在**财动 + 子孙动同时出现时**的裁决：
- 书源原文明确：「子孙发动可以克官鬼，如果妻财同动的话，子孙不但不克官鬼，反而子孙生财，财又生官，形成连续相生，使官鬼更旺」
- 这需要一套「连续相生路径」的拓扑分析（A生B、B生C → C受益），当前六爻学科的 engine 不具备此跨爻路径分析能力。

## 五、裁定：暂不新增，落档

### 理由

1. **跨爻路径分析缺失**：当前 classical_enhancements 各函数都是"单视域"分析（只看一个结构层），不支持「财→鬼→身」和「子→财→鬼」两条竞争路径的同时判定与优先级裁决。
2. **回归风险已验**：此前已有接入后评分下降的先例（OPT-LEDGER §四），再次接入需先有 holdout 用例。
3. **书源内尚有歧义**：虎易注 L3141 指出「学者千万不要和前句连在一起去运用」，说明书源本身对该格局的运用条件存在注释家分歧，不应急于编码。
