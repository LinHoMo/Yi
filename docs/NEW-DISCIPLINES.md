# 新学科可行性论证（通用基座候选评估）

> 范围：在现有六科（`ming` / `ziwei` / `liuyao` / `meihua` / `xiaoliuren` / `zeji`）之外，
> 论证哪些术数门类适合作为**下一步新增的通用基座**。本文只做论证，不含实现。
> 三条铁律见 `AGENTS.md`；全文分数一律称**古籍案例对齐分**。
> **相科（面相、手相、堪舆）按铁律明确不做**，仅在 §4 作反例，不预留目录。

## 一、评估维度与「通用基座」判定标准

| # | 标准 | 含义 | 为什么是硬门槛 |
|---|---|---|---|
| G1 | **判据树清晰** | 取用/取象走可枚举分支，非灵感联想 | 判据树清晰，`analyze` 才能输出 `{因子, 权重, 判据, 所本法则}`；靠联想只能塞进 `narrate`，等于把运算交给 LLM，违反铁律一 |
| G2 | **内核复用度高** | 干支历/生克/旬空/长生/神煞可直接用现有 `core` | 复用度低＝第二套内核，违反「唯一真值源」 |
| G3 | **可建评测集** | 古书有带结论的实例（起局可还原＋有断语） | 无古例则建不出对齐分，tune/holdout 分离无从谈起 |
| G4 | **可合参** | 问题域与六科正交或可对齐，能进 `synthesis` | 只能自说自话者，加进来只增表面积 |

**「有趣但孤立」的典型形态**：起局漂亮但断法无判据树（纯辞类）；或只有歌诀无实例（无法建评测集）；或问题域与六科完全重叠。

## 五、口径与免责

1. **本文是工程可行性判断，不是对任何门类「灵验程度」的判断。** 不主张亦不否认任何术数的现实效力；G1–G4 衡量的是**可机检性、可复用性、可评测性、可合参性**，与「准不准」无关。
2. **一切分数称「古籍案例对齐分」**——衡量引擎输出与古籍案例要点的吻合度，用于回归审计，**不是现实预测命中率**。报分必带**集合名＋样本量 n＋是否参与调参**，禁止只给百分比。文中**机械一致率**（三传是否与古书逐字相符、局数是否与算例相符）与**对齐分**是两类指标，**不得混算、不得互相冒充**。
3. **案例库与解读过程物理隔离**（铁律二）。本文提到的占验课例仅可用于测试运行器、用户明确要求的事后校验、用户主动询问「有无类似案例」三种场景；**解读交付前禁止打开案例库、提及案例名、以案例类比佐证**。
4. **口径诚实**：凶象用「偏向／有…信号／结构上」，不用「注定／一定／绝无可能」。医疗、法律、投资及重大决策一律提示以专业意见为准。
5. **文献证据分级**：①**已联网核实**（维基文库页面实际取到，或四库提要原文可见）——《六壬大全》《太乙金镜式经》《灵棋经》《遁甲演义》《烟波钓叟歌》《焦氏易林》《皇极经世》《太玄经》《御定星历考原》《大六壬指南》；②**仅检索旁证、未取到正文**——《星学大成》《果老星宗》《协纪辨方书》，入库前须复核；③**明确标「待核」**——金口诀古籍版本、铁板神数可靠版本、《奇门遁甲统宗》《御定奇门宝鉴》。**凡标待核者，不得以确定语气写入 `references/`，也不得据以写 `analyze` 判据。**
