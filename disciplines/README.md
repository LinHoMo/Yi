## 迁移注意

`liu-yao/` 是一个独立 git 仓库（历史里有历法修正与评分器重建的关键提交）。
迁入本目录时要连同 `.git` 一起移动，并决定 `Yi/` 顶层的版本控制拓扑（单仓 or 子仓），
不能只做文件复制——复制会丢掉可回溯性。
