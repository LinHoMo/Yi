接入方式见 `../docs/CONTRACT.md`。

| 学科 | 归属 | 状态 | 说明 |
|---|---|---|---|

**当前批次（M0–M4）只做卜**：六爻 + 梅花 + 小六壬 + 择吉均已落地。命（四柱八字）只立接口与数据格式，不写推演。
**相科不做**：面相、手相、堪舆均不在路线图内，也不预留空目录——占位目录最后只会变成僵尸目录。
理由见 `../docs/YI-PLAN.md` §五：内核过早抽象容易被抽成"六爻的形状"，
所以每上收一次内核，就立刻找一个新的真实消费方来验证（梅花的 `lunar.py`、小六壬与择吉的 `zeji_tables.py` 即此验证）。

## 版本控制

`disciplines/liuyao/` 原为独立 git 仓库（历史里有历法修正与评分器重建的关键提交），
已于 2026-09-22 经 `git subtree` 并入本单仓（见 `liuyao/docs/CHANGELOG.md` 该条），
现全仓库统一一个 git 版本库，顶层即仓库根；新学科直接在此单仓内建目录即可。
