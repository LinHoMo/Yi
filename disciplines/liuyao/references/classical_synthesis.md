# 第一部：《火珠林》——纳甲法之源

## 一、历史背景

《火珠林》相传为唐末宋初麻衣道者所撰，是现存最早系统论述六爻纳甲法的专书。其法源于西汉京房的纳甲体系，经唐末道士整理而成书。《火珠林》确立了以"五行生克"为核心、以"六亲"为纲领的完整断卦框架，后世一切六爻法无不以此为根基。

## 二、纳支捷法歌

### 歌诀全文

```
乾坎艮震为阳位，子寅辰午申戌顺。
巽离坤兑为阴方，丑卯未巳酉亥逆。
阳顺阴逆隔节数，用前纳甲并所属。
```

### 注解

- **阳四卦**（乾、坎、艮、震）：以子、寅、辰、午、申、戌顺行纳支（自下而上）
- **阴四卦**（巽、离、坤、兑）：以丑、亥、酉、未、巳、卯逆行纳支（自下而上逆排）
- **隔节数**：每隔一位地支装一爻（即子→寅→辰→午→申→戌，中间各隔一位）

### 八卦纳支完整表（自下而上，初爻至上爻）

| 卦 | 初爻 | 二爻 | 三爻 | 四爻 | 五爻 | 上爻 | 阴阳 |
|----|------|------|------|------|------|------|------|
| **乾**（金） | 子 | 寅 | 辰 | 午 | 申 | 戌 | 阳 |
| **震**（木） | 子 | 寅 | 辰 | 午 | 申 | 戌 | 阳 |
| **坎**（水） | 寅 | 辰 | 午 | 申 | 戌 | 子 | 阳 |
| **艮**（土） | 辰 | 午 | 申 | 戌 | 子 | 寅 | 阳 |
| **巽**（木） | 丑 | 亥 | 酉 | 未 | 巳 | 卯 | 阴 |
| **离**（火） | 卯 | 丑 | 亥 | 酉 | 未 | 巳 | 阴 |
| **坤**（土） | 未 | 巳 | 卯 | 丑 | 亥 | 酉 | 阴 |
| **兑**（金） | 巳 | 卯 | 丑 | 亥 | 酉 | 未 | 阴 |

**规律**：
- 乾震初爻同起于子，坎起寅，艮起辰——四阳卦各差一位
- 巽起丑，离起卯，坤起未，兑起巳——四阴卦自下而上逆排

## 三、装卦完整流程

### 步骤一：六次摇钱得卦

用三枚铜钱摇六次，每次记录正反面组合：
- 三个正（背）= 老阴（\.\.），动爻，变阳
- 两正一反 = 少阳（—），静爻
- 一反两正 = 少阴（--），静爻
- 三个反 = 老阳（○），动爻，变阴

从下往上画六次，得本卦与变卦。

### 步骤二：纳干支

按纳支捷法歌，将各爻装上地支；同时按纳甲口诀装天干：

```
乾纳甲壬坎纳戊，震纳庚兮巽纳辛，
离纳己兮艮纳丙，坤纳乙癸兑纳丁。
```

### 步骤三：安世应

```
八纯卦世在六，一世卦世在初爻。
二世卦世在二位，三世卦世在三爻。
四世卦世在四爻，五世卦世在五爻。
游魂卦世在四爻，归魂卦世在三爻。
```

应爻与世爻隔三位（世 + 3 = 应）。

### 步骤四：定六亲

以卦宫五行为"我"，按各爻地支五行生克关系配六亲：

```
生我者父母，我生者子孙。
克我者官鬼，我克者妻财。
同我者兄弟。
```

### 步骤五：装六神

以日天干起六神，自下而上排列：

```
甲乙起青龙，丙丁起朱雀。
戊日起勾陈，己日起腾蛇。
庚辛起白虎，壬癸起玄武。
```

### 步骤六：查旬空

以日柱干支定该旬空亡的地支：

```
甲子旬中无戌亥，甲戌旬中无申酉。
甲申旬中无午未，甲午旬中无辰巳。
甲辰旬中无寅卯，甲寅旬中无子丑。
```

## 四、"卦定根源，六亲为主"原则

《火珠林》最核心的原则是**以六亲为断卦主线**。卦象确定后，以五行生克关系定六亲，六亲代表各类事物：

| 六亲 | 代表事项 |
|------|---------|
| 父母 | 文书、学业、长辈、房屋、庇护、契约 |
| 子孙 | 福气、投资回报、子女、医药、解除忧患、快乐 |
| 官鬼 | 官职、压力、病灾、丈夫（女测）、官方、灾祸 |
| 妻财 | 财富、妻子（男测）、实际利益、物质资源 |
| 兄弟 | 竞争、破财、同辈、阻碍、争夺 |

## 五、"财官伏五乡"——飞伏神法

### 核心概念

《火珠林》提出**"财官伏五乡"**的核心法则：

- **用神（财或官鬼）不现于本卦**时，不代表用神消失，而是"伏藏"于其他位置
- **五乡** = 五个可能的伏藏位置（一至五爻之下）
- **世下伏爻为的**——以世爻所在位置为本，寻找本宫首卦对应的伏神

### 飞伏神定义

- **飞神**：本卦中出现之爻（当前所在位置）
- **伏神**：本宫首卦对应位置之爻（隐藏的真实用神）

### 伏神之吉凶判断

| 伏神状态 | 吉凶 | 说明 |
|---------|------|------|
| 伏神得飞神生助 | 吉中藏凶，终须出头 | 伏神有气，待时而出 |
| 伏神被飞神克制 | 凶中有险 | 用神受制，难以出头 |
| 伏神临日辰月建 | 当日即出 | 日辰引出伏神，当下应事 |
| 飞神被冲开 | 伏神得出 | 忌神被冲则伏神出现 |
| 伏神临空亡 | 不易得 | 出空时可出，否则终难见 |

### 寻伏神方法

1. 确定用神（如求财则寻妻财爻）
2. 在本卦中查找是否有该六亲出现
3. 若不现，取本宫首卦（八纯卦），以本卦世爻对应位置取该爻地支
4. 该地支即为伏神，所临本卦之爻为飞神
5. 判断飞神与伏神的生克关系

# 第二部：《黄金策》——总断千金赋

## 一、概述

《黄金策》旧题为明刘基（刘伯温）所著，是六爻法的集大成之作。其《总断千金赋》一文被视为六爻断卦的"总论"，系统阐述了断卦的基本原理和核心法则。后世诸书多以此赋为纲领进行扩展。

## 二、《总断千金赋》核心条文

### 动静阴阳，反复变迁

> "动静阴阳，反复变迁。"

**释义**：卦中六爻有动有静，动则变、静则不动。动爻为事情变化的驱动力，静爻为事情的基础状态。反复变迁指事物在动与静的交替中产生吉凶转化。

**断卦应用**：
- 动爻代表未来变化趋势，静爻代表当前状况
- 动爻多少反映事情复杂程度
- 动变之间的生克关系决定吉凶转化方向

### 万象纷纭，一理融贯

> "虽万象之纷纭，须一理而融贯。"

**释义**：断卦时虽有万象纷呈（六亲、六神、五行、世应、飞伏、空破等众多因素），但必须以一个核心原则贯穿始终——即"用神旺衰"与"生克关系"这一理。

**断卦应用**：不要分散断卦，先锁定用神，再用月建日辰判断旺衰，后用动变看生克，最后辅以六神六亲做细节补充。

### 太过不及之理

> "有贤不肖之殊，卦有过不及之异。太过者损之斯成，不及者益之则利。"

**释义**：
- **太过**：用神旺极而无克制——需损之（克泄）方能成事
- **不及**：用神太弱而无生扶——需益之（生助）方能有利

**断卦应用**：
- 用神得月日双生又得动爻生扶且无克制 → 太过，反不吉，需待克制方平衡
- 用神休囚受克又无生扶 → 极弱，需待生扶之时令方应吉
- 这是辩证法则之一：物极必反

### 生扶拱合，克害刑冲

> "生扶拱合，时雨滋苗；克害刑冲，秋霜杀草。"

**释义**：
- **生扶**（动爻生用神）如春雨润苗：用神得生则旺，事情顺利
- **拱合**（动爻拱合用神）如合力相助：合力帮扶则有力
- **克害**（动爻克用神）如秋霜杀草：用神受克则衰，事情受阻
- **刑冲**（三刑六冲）如寒风破坏：冲破用神则力量消散

**断卦应用**：

| 关系类型 | 地支组合 | 对用神的影响 |
|---------|---------|-------------|
| 六合 | 子丑、寅亥、卯戌、辰酉、巳申、午未 | 合住用神，事缓成；合忌神则忌神被绊住，吉 |
| 六冲 | 子午、丑未、寅申、卯酉、辰戌、巳亥 | 冲散用神则凶；冲去忌神则吉 |
| 三刑 | 寅巳申、丑未戌、子卯、辰午酉亥 | 刑害主伤痛、官司、慢性之患 |

### 长生帝旺与死墓绝空

> "长生帝旺，争如金谷之园；死墓绝空，乃是泥犁之地。"

**释义**：
- **长生帝旺**：五行在十二宫中得气之阶段，好比金谷园般繁华兴旺
- **死墓绝空**：五行失气之阶段，好比地狱（泥犁）般荒凉无望

### 空亡的含义

- **用神落空亡**：力量消失，事虚难成
- **忌神落空亡**：凶事减轻，虚惊则无实祸
- **旺相逢空**：出旬则实，暂时停滞
- **休囚逢空**：空亡难起，终无果

## 四、分类断法要则

### 身命章

> **世爻为主，六亲定命。**

- 世爻代表一生命运的主宰
- 六亲定先天根基：父母为祖上、兄弟为手足、子孙为后代、妻财为家业、官鬼为事业功名
- 世爻旺相得生助 = 一生顺遂
- 世爻休囚受克 = 多灾多难

### 家宅章

> **二爻为宅，五爻为人。**

- 二爻代表房屋宅舍，旺相则宅吉，休囚受克则宅凶
- 五爻代表居住之人，旺相则人安，休囚受克则人不安
- 二爻生五爻（宅生人）→ 吉
- 五爻生二爻（人益宅）→ 吉
- 二五相克 → 人与宅不和

### 婚姻章

> **男占以财为妻，女占以官为夫。**

**男测**：
- 妻财爻为用神，旺相得生则妻贤貌美
- 财爻动而化进则感情增进
- 财爻动而化退则感情衰减
- 财爻伏藏被飞克则婚难成

**女测**：
- 官鬼爻为用神，旺相得生则夫贤有志
- 官鬼动而化进则感情稳定
- 官鬼动而退神则感情退化

**通用原则**：
- 世应相生 = 双方有情
- 六合卦 = 情投意合
- 六冲卦 = 各怀心思

### 功名章

> **官鬼为用，父母为文昌。**

- 官鬼爻代表官职、事业、权力
- 父母爻代表文书、学历、资质
- 官鬼旺相得月日生助 = 仕途通达
- 官鬼临青龙 = 升迁有望
- 官鬼入墓休囚 = 仕途受阻

### 求财章

> **财爻为用，子孙为财源。**

- 妻财爻为用神，旺相有力则财聚
- 子孙爻为财源（生财之源），旺相有气则财运长远
- 财爻持世克世 = 财来就我，易得
- 财爻伏藏空亡 = 难得之财
- 兄弟持世 = 多破财之虑

### 出行章

> **世爻为主，子孙为平安。**

- 世爻旺相得生 = 出行平安顺利
- 世爻逢空破克 = 出行有险
- 子孙爻临世动 =一路平安
- 官鬼临世动 = 途中防灾祸
- 六冲卦 = 出行多变，事不安稳

### 疾病章

> **官鬼为病，子孙为医。**

- 官鬼代表病症与病因
- 子孙代表医药和治疗方案
- 官鬼旺相无制 = 病重
- 官鬼休囚被克 = 病轻
- 子孙旺相有力 = 医药有效，可愈
- 用神（世爻）被官鬼克 = 病及自身
- 官鬼持世 = 久病难愈之象

# 第三部：《卜筮正宗》——十八论与问答

## 一、概述

《卜筮正宗》为明末清初王维德（号洪绪）所著。书名取"卜筮正宗"，意在纠正当时卜筮书中诸多谬误，恢复六爻古法之正宗。全书核心为**十八论**与**十八问答**，系统总结断卦方法论并纠正前人之失。

## 二、十八论提要

### 第一论：世应论用神

> **核心**：世爻为自身，应爻为彼方。用神取法以所占事项定，世应二者相辅相成。
>
> 世应相生相合，事情和谐；世应相克相冲，事情对立。世卦（我方）宜旺，应卦（对方）关系需看具体事项。

### 第二论：用神元神忌神仇神论

> **核心**：五位一体分析方法。

| 名称 | 定义 | 五行关系（以用神五行为"我"） |
|------|------|------|
| **用神** | 所占问之事的核心爻 | 即问题本身 |
| **元神** | 生用神者 | 生我者（即父母） |
| **忌神** | 克用神者 | 克我者（即官鬼） |
| **仇神** | 克元神者 | 克父母者（即妻财） |
| **世爻** | 自身，用神的承载者 | — |

**断法规则**：
- 元神动生用神 → 有外力相助，吉
- 忌神动克用神 → 有人阻扰，凶
- 仇神动克元神 → 助力被破坏
- 用神自旺或得生扶 → 不需元神亦可

### 第三论：空破论

> **核心**：旬空与月破为六爻中极重要的两类特殊状态。

**旬空**（又称空亡）：
- 甲子旬空戌亥，甲戌旬空申酉，甲申旬空午未……
- 用神逢空 = 力量暂时消失
- 出旬（十日）逢值之日 = 空亡填实之时

**月破**：
- 爻被月建相冲 = 月破（如子月午爻为月破）
- 月破之爻 = 极衰无力之象
- 月破逢日合 = 可解
- 月破逢动爻生 = 可救

**空破并见**：
- 用神既空且破 = 极难有成
- 忌神既空且破 = 凶事自消

### 第四论：向吉凶论

> **核心**：**用旺世兴**——用神旺相同时世爻有气，方为全吉。

- 用神旺而世爻衰 → 事虽好而我无力享之（替人作嫁）
- 世爻旺而用神衰 → 我虽好而事与愿违
- 用神世爻俱旺 → 大吉，事成且我有益
- 用神世爻俱衰 → 大凶，事败且我受损

### 第五论：随官入墓论

> **核心**：入墓指五行进入辰戌丑未之墓库。

**四墓库**：
- 辰为水之墓
- 戌为火之墓
- 丑为金之墓
- 未为木之墓

**随官入墓**：用神随官鬼入墓，多主凶险，如疾病进入膏肓、事情陷入绝境。

**入墓吉凶判断**：
- 用神旺而入墓 = 暂时受阻，待冲墓则出
- 用神衰而入墓 = 凶象，难以复出
- 忌神入墓 = 凶事暂藏，亦为不利

### 第六论：占疾病论

> **核心**：疾病占以官鬼为病源，子孙为医药，世爻为己身。

- 官鬼旺而无子孙制 = 病重难愈
- 子孙旺而克官鬼 = 医药有效
- 世爻克官鬼 = 自身抗病力强
- 官鬼持世 = 久病缠身
- 官鬼入墓 = 病入膏肓

### 第七论：占生死论

> **核心**：占生死以用神（被占之人对应的六亲）为主，兼看世爻。

- 用神被日辰月建重克 = 极凶
- 用神伏藏被飞克 = 生命堪忧
- 用神被三传（年、月、日）俱克 = 凶多吉少
- 忌神化进神 = 病情恶化
- 用神化进神 = 病情好转

### 第八论：反吟伏吟论

> **核心**：反吟伏吟为特殊卦象变化。

**伏吟**：
- 卦变为各爻地支相同（如乾变震=子寅辰午申戌 → 子寅辰午申戌）
- 主忧虑呻吟、哭泣、反复不顺
- 用神伏吟 = 事情反复、忧心忡忡

**反吟**：
- 卦变为各爻地支相冲（如巽变乾=丑亥酉未巳卯 → 子寅辰午申戌，地支相冲）
- 主反复无常、忽东忽西、难以安定
- 反吟化出，事多反复

### 第九论：月破论

> **详解**：月破为极凶之象，但需看具体情况。

- 用神月破无解救 = 大凶之象
- 用神月破逢日合 = 可解（合能解破）
- 用神月破有动爻生扶 = 可救
- 用神月破逢冲 = 更凶
- 忌神月破 = 反为吉（凶事被破）
- 月破逢空 = 空破并见，无力之极

### 第十论：进神退神论

> **核心**：动爻化进则力量增强，化退则力量减弱。

**进神**（力量递增）：
- 寅→卯、巳→午、申→酉、亥→子
- 丑→辰、未→戌（土库进）

**退神**（力量递减）：
- 卯→寅、午→巳、酉→申、子→亥
- 辰→丑、戌→未（土库退）

**断法**：
- 用神化进 = 事情越来越有利，前景光明
- 用神化退 = 事情越来越困难，力不从心
- 忌神化进 = 阻力越来越大
- 忌神化退 = 阻力逐渐消除

### 第十一论：内外身论

> **核心**：内卦为自身/家庭，外卦为外界/他人。

- 内卦旺相 = 自身/家庭兴旺
- 外卦旺相 = 外界环境有利
- 内卦克外卦 = 我强彼弱
- 外卦克内卦 = 彼强我弱
- 内外相生 = 和谐互助

### 第十二论：飞神伏神论

> **核心**：用神不现则寻伏神，飞神与伏神的生克关系为关键。

**伏神得出条件**（飞神不妨碍伏神）：
1. 飞神生伏神 → 伏神得出有力
2. 伏神克飞神 → 伏神强行出头
3. 日辰冲起飞神 → 伏神脱离飞神压制
4. 伏神临日辰月建 → 伏神当天即可出

**伏神不得出条件**：
1. 飞神克伏神 → 伏神被压制
2. 伏神生飞神 → 伏神泄气于飞
3. 伏神休囚无气 → 本身无力
4. 伏神临空月破 → 难得出头

### 第十三论：六合论

> **核心**：六合主合拢、聚合、和谐，但需看具体情况。

**六合卦**（内外卦地支相合）：
- 乾为天 → 不合（非六合）
- 天地否（子丑合、卯戌合、申巳合）→ 六合卦
- 此类卦共8个

**爻之六合**：
- 子丑合土、寅亥合木、卯戍合火、辰酉合金、巳申合水、午未合土

**六合吉凶**：
- 用神逢合 = 事缓成、有人牵绊、事情拘执
- 忌神逢合 = 忌神被绊住，反为吉
- 合处逢冲 = 合久必分
- 六合化六冲 = 先好后散

### 第十四论：六冲论

> **核心**：六冲主分离、解散、冲突、迅速。

**六冲卦**（内外卦地支相冲）：
- 乾为天（子午冲、寅申冲、辰戌冲）→ 八纯皆为六冲卦
- 共8个六冲卦

**爻之六冲**：
- 子午冲、丑未冲、寅申冲、卯酉冲、辰戌冲、巳亥冲

**六冲吉凶**：
- 用神逢冲散 = 事不成
- 忌神逢冲散 = 事可成
- 近病逢冲 = 病愈
- 久病逢冲 = 病危
- **"近病逢冲即愈，久病逢冲即死"**
- 六冲化六合 = 先散后合

### 第十五论：三刑论

> **核心**：三刑主刑伤、痛苦、长期之患。

**三刑组合**：
1. **无恩之刑**：寅刑巳、巳刑申、申刑寅
2. **恃势之刑**：丑刑戌、戌刑未、未刑丑
3. **无礼之刑**：子刑卯、卯刑子
4. **自刑**：辰午酉亥自相刑

**三刑吉凶**：
- 用神被刑 = 用神受损，凶
- 忌神被刑 = 忌神受制，吉
- 三刑齐见 = 大凶（需三个地支同时出现）
- 二刑已有 = 有隐痛之患

### 第十六论：独静独发论

> **核心**：多爻安静仅一爻动 = 独发；多爻发动仅一爻静 = 独静。

- **独发**：一爻独动，此爻为事情关键，集中观此爻生克制化即可
- **独静**：一爻独静，此爻为事情枢纽，可以从静爻中看破机微
- 独发之爻 = 事情的主驱动力
- 独静之爻 = 事情的核心阻滞点

### 第十七论：归魂游魂论

> **核心**：归魂游魂为两种特殊卦类，各有其象。

**游魂卦**（本宫第七卦，世在四爻）：
- 主犹豫不决、心思不定、变化无常、迁移不定
- 占出行 = 走走停停，无固定目的地
- 占婚姻 = 情志不定，难以专一

**归魂卦**（本宫第八卦，世在三爻）：
- 主归心似箭、安于现状、保守稳固
- 占出行 = 终将归来
- 占婚姻 = 心有所属，安定之象

### 第十八论：辟诸书之谬

> **核心**：纠正当时卜筮书中的常见错误。

主要辟谬内容：
1. **辟卦身之谬**：卦身实为多余，以世爻为主即可
2. **辟星煞之谬**：天乙贵人、天赦等各种星煞与六爻无关
3. **辟本命之谬**：拿求测者生肖来断卦是不必要的
4. **辟先天后天卦之谬**：后天卦变等法在实际断卦中验之不准
5. **辟各种杂法之谬**：简化体系，回归用神本位

## 三、十八问答（精选核心问答）

### 第一问：三传克用

> **问**：年、月、日三传俱克用神，且无一生扶，当如何断？
> 
> **答**：此为**寡不敌众**之象。用神被三传（年 pembangunan、日辰）齐克，即使有一动爻来生，亦是杯水车薪，**用神弱极，凶象明显**。除非用神得众多动爻齐来生扶方可解救。

### 第二问：回头之克

> **问**：用神动而化出变爻回头克用神，何解？
> 
> **答**：此为**回头克**。回头之克最为凶险——如同求助于人而反被其所害。用神被回头克 = 内部瓦解，事与愿违。若回头克之爻有制化（被月日或他爻所克），凶象可减。

### 第三问：原神动生用

> **问**：元神（生用神之爻）动而来生用神，吉中是否有凶？
> 
> **答**：原神生用本为吉，但需看原神自身状态：
> - 原神旺相有力来生用神 → 大吉
> - 原神休囚月破来生用 → 有心无力，吉中藏凶
> - 原神化退神 → 助力渐失
> - 原神被仇神克制 → 原神自身难保，无力生用

### 第四问：三合成局

> **问**：三合局成立，如何判断吉凶？
> 
> **答**：三合局分**生局**与**克局**。
> - 合成用神局 → 大吉（力量倍增）
> - 合成原神局 → 吉（生助有力）
> - 合成忌神局 → 大凶（合力克用）
> 
> 合局须三字齐全方成化，缺一字为**待时之合**，待最后一字值日补全方应事。

### 第五问：日冲暗动

> **问**：日辰冲爻，是明动还是暗动？
> 
> **答**：日冲休囚之爻为**日破**（彻底无用）；日冲旺相之爻为**暗动**（暗中发力）。暗动虽不如明动之强烈，但其力量不可小觑——如暗中推波助澜之人，虽无形却有实质影响。

### 第六问：月破再论

> **问**：月破之爻是否绝对无用？
> 
> **答**：月破并非绝对无用：
> - 月破逢日建生扶 → 可救
> - 月破逢动爻生扶 → 可救
> - 月破逢日合 → 合能解破
> - 月破逢空亡 → 空破并见，无力之极
> - 月破无解 → 终为无用

### 第七问：六合再论

> **问**：六合是否主吉？
> 
> **答**：六合分情况：
> - 用神逢合而无克 → 有人相助，事可成
> - 用神被合住而失其用 → 事被牵绊难成
> - 合住忌神 → 忌神被绊，不能为害，吉
> - 合处逢冲 → 先合后散

### 第八问：六冲再论

> **问**：六冲是否主凶？
> 
> **答**：六冲分情况：
> - **近病逢冲即愈**：新近之病被冲则散，是好事
> - **久病逢冲即死**：久病体弱逢冲则败
> - 用神逢冲散 → 事不成交
> - 忌神逢冲散 → 障碍消除，吉
> - 冲中遇合 → 暂时分散终会合拢

### 第九问：用神不现看伏神

> **问**：用神不现在本卦中如何处理？
> 
> **答**：用神不现，须从本宫首卦寻伏神。
> 
> **伏神得出四法**：
> 1. 飞神生伏神
> 2. 伏神克飞神
> 3. 日辰冲飞神
> 4. 伏神临日辰月建
> 
> **伏神不得出四法**：
> 1. 飞神克伏神
> 2. 伏神生飞神
> 3. 伏神休囚无气
> 4. 伏神临空亡月破

### 第十问：向吉凶原则

> **问**：如何判断是向吉还是向凶？
> 
> **答**：以**用旺世兴**为原则：
> - 用神旺相 + 世爻有气 → 全吉
> - 用神休囚 + 世爻无气 → 全凶
> - 用神旺而世爻衰 → 虽好而我无力享受
> - 世旺而用衰 → 我虽好而事与愿违

### 第十一至第十八问（要点提纲）

**第十一问**：论日辰月建同功异位
- 月建主长期之力量（一月内），日辰主当下之力量（当日）
- 二者同生用神 = 大吉；同克用神 = 大凶

**第十二问**：论动爻与静爻的关系
- 动爻有力可生克静爻，但力量较月日为小
- 动爻冲静爻可暗动，静爻自动爻为静

**第十三问**：论用神多现
- 用神多现（卦中两个以上）→ 取旺相者为主用神
- 若两用神皆旺 → 各有所主，兼看之

**第十四问**：论世应的位置关系
- 世在一爻应在四，世在二应五，世在三应六
- 世应相克 = 彼此对立；世应相生 = 彼此相助

**第十五问**：论六合与六冲的转化
- 六合化六冲 = 先合后散
- 六冲化六合 = 先散后合
- 六合卦中逢冲 = 破局之期

**第十六问**：论病愈与病凶的判断
- 子孙旺相克官鬼 = 病愈之期
- 官鬼化进无子孙制 = 病加重
- 用神（世）被三重克 = 病入膏肓

**第十七问**：论应期的推断
- 用神旺相则应快，休囚则应慢
- 动爻逢合则应合逢值日
- 空亡出空之日为应期
- 入墓逢冲之日为应期

**第十八问**：论反复占验之法
- 同一问题不重复占（再三则渎）
- 以第一卦为准，第二卦为辅助参考
- 遇不可决之疑可再占

## 四、辟诸书之谬（补充要点）

1. **辟"天乙贵人之谬"**：天乙贵人之法源自八字命理，不适用于六爻
2. **辟"天月德之谬"**：天月德亦非六爻断法
3. **辟"八卦叶王之谬"**：八卦当王不当王之说为后人附会
4. **辟"卦名直断之谬"**：不可仅凭卦名断吉凶（如见晋卦就说"晋"=进）
5. **辟"世应分阴阳之谬"**：世应分阴阳之说是后人杜撰

# 第四部：《增删卜易》——实证校正

## 一、概述

《增删卜易》以野鹤老人原著、李文辉（觉子）整理增补而成。其最大特点是**实证精神**——以"屡验者存之，不验者删之"为原则，删去大量经不起实际验证的繁杂规则，以大量实例验证六爻断法的准确性。

## 二、学易方法论

### 学习次第

```
混天甲子六亲歌 → 装卦法 → 用神取法 → 动变分析 → 四时旺相 → 冲合空破
```

### 混天甲子六亲歌（总诀）

```
金之子水木之火，火之土位土同金。
水金土火木水土，生我父母我生孙。
克我官鬼我财克，比和兄弟六亲分。
```

### 装卦核心程序

1. 八卦纳甲定天干
2. 乾坤生六子定地支
3. 定世应（按八宫次序）
4. 以宫五行为我定六亲
5. 以日干起六神
6. 以日柱定旬空

## 三、屡验存删的实证精神

《增删卜易》的核心精神是**实证检验**：

- 理论若经多次预测验证有效 → **保留**
- 理论若无验或验之不准 → **删去**
- 凡书中所载，皆为作者或前人所亲自验证有效之法

这一精神使《增删卜易》成为最具实操价值的六爻经典之一。

## 四、关键修正

### 删去多余规则

野鹤老人认为，以下规则在实践中不验或歧义太多，宜删去：

| 删去项目 | 理由 |
|---------|------|
| **卦身**（月卦身） | 验之不准，使人歧路 |
| **身世**（以世爻起身世） | 又多一路判断，反而混乱 |
| **星煞**（天乙贵人、天月德等） | 八字命理之法，不验于六爻 |
| **本命**（求测者生肖） | 与六爻纳甲无关，删之 |

### 简化用神论

《增删卜易》主张用神取法宜**简洁明了**：

- 一个事项对应一个用神
- 不可漫无标准、多法并用
- 用神不现则寻伏神，不再另立他法
- 以世爻为主判断自身状态

### 旬空月破论修正

《增删卜易》对旬空月破有独特见解：

**旬空**：
- 用神逢空 = 出空可成（非绝对凶）
- 用神逢空但被月日冲克 = 虽出空亦无力
- 用神休囚逢空 = 难起

**月破**：
- 用神月破 = 凶，但分轻重
- 月破逢日合 = 可解
- 月破逢动爻生 = 可救

### "重内轻外"但"用神极弱不起"

- 内卦为近为本，外卦为远为末
- 用神在内 = 事在近处或本地
- 用神在外 = 事在远处或他乡
- **但用神极弱时，虽内外皆生之亦不起**

这一修正强调了用神本身旺衰的绝对重要性，不被位置所迷惑。

## 五、实占案例分析

### 案例一：占父病

> **问题**：父亲久病，吉凶如何？
> 
> **用神**：父母爻
> 
> **分析框架**：
> 1. 用父母爻看父亲状况
> 2. 看父母爻在月建日辰的旺衰
> 3. 看是否有动爻来生/克
> 4. 看官鬼（病源）与子孙（医药）关系
> 
> **若父爻被日冲月破**：
> - 父爻极衰 = 父亲身体状况极差
> - 看子孙（医药）是否有力克制官鬼（病源）
> - 子孙无力克官鬼 = 医药无效，凶象明显
> - 若父爻伏藏被飞克 = 凶兆加重
> 
> **判断**：久病逢冲，又加月破，多主危险。子孙无力，医药无功。

### 案例二：占子孙

> **问题**：子嗣事项或子女健康
> 
> **用神**：子孙爻
> 
> **分析框架**：
> 1. 子孙爻不现于本卦 → 寻伏神
> 2. 看子孙伏于何爻之下
> 3. 飞神与伏神关系判断伏神得出与否
> 
> **若子孙伏于父母爻下**：
> - 父母生子孙 = 飞生伏，伏神得出，吉
> - 但需看父母爻本身旺衰
> - 父母休囚无力 = 虽生而无力
> 
> **若子孙伏于官鬼爻下**：
> - 官鬼克子孙 = 飞克伏，伏神难得出
> - 主子女有病患或成长艰难

### 案例三：占婚姻

> **问题**：婚姻能否成？
> 
> **用神**：男占财爻、女占官爻
> 
> **分析框架**：
> 1. 看世应关系（男世应财、女世应官）
> 2. 看财/官爻的旺衰动静
> 3. 看六合六冲状态
> 
> **六合卦占婚**：
> - 世应相生 + 六合卦 = 天作之合，吉
> - 被合之爻太多 = 有第三者牵引之虞
> 
> **六冲卦占婚**：
> - 世应相克 + 六冲卦 = 各怀己见，难成
> - 动爻化冲 = 先顺后散
> 
> **用神旺衰判断**：
> - 财/官旺相无克 = 对方条件好，有望成
> - 财/官休囚受克 = 对方条件有欠缺或感情淡薄

### 案例四：占求财

> **问题**：求财是否能得？
> 
> **用神**：妻财爻
> 
> **分析框架**：
> 1. 妻财爻旺衰（得月日生扶则财旺）
> 2. 世爻状态（世旺能担财）
> 3. 世爻与财爻的关系
> 
> **财爻旺而生世**：
> - 财来就我，易得之财
> - 世有气可担财，事情可成
> - 得财多少看财爻旺度
> 
> **财爻克世**：
> - 财来就我，但财太大而身弱
> - 虽有财却艰辛得之
> - 如身太弱（世极衰）则财反为灾
> 
> **兄弟持世**：
> - 兄弟克财 = 多破财之忧
> - 须子孙动而通关（兄生孙、孙生财）方可化解
> 
> **财爻伏藏**：
> - 难得之财，须待伏神得出之时
> - 飞神克伏神 = 最终难得

### 案例五：占官非

> **问题**：涉诉吉凶如何？
> 
> **用神**：官鬼爻（官方/法官）、世爻（自身）
> 
> **分析框架**：
> 1. 官鬼旺相生世 = 官方为我主持公道，吉
> 2. 官鬼克世 = 官方对我不利，凶
> 3. 官鬼伏藏 = 官方态度不明
> 4. 子孙旺相克官鬼 = 可免于刑责
> 
> **关键判断**：
> - 世旺官生世 = 胜诉或和解有利
> - 世衰官克世 = 败诉或遭刑
> - 父母旺相（印星护身）= 文书有力

### 案例六：占失物

> **问题**：失物能否找回？
> 
> **用神**：妻财爻（财物）、父母爻（文书证件）
> 
> **分析框架**：
> 1. 用神在内卦 = 失物在家中或近处
> 2. 用神在外卦 = 失物在外地或远处
> 3. 用神逢冲 = 失物被搬动
> 4. 用神伏藏 = 失物隐藏在某处
> 
> **用神逢冲而能找回**：
> - 逢冲则动，物有移动
> - 若逢合则停止移动
> - 冲合之间可推断移动路径

## 二、四书的用神哲学对比

### 火珠林体系：用神/飞伏为主

- 用神为核心，飞伏为补充
- 当用神不现时，寻本宫首卦伏神
- 飞伏关系判断隐藏的吉凶信息

### 黄金策体系：五位一体（用/元/忌/仇/世）

- **用神**：所占问之事
- **元神**：生用神者（父母）
- **忌神**：克用神者（官鬼）
- **仇神**：克元神者（妻财）
- **世爻**：自身承载

五位联动分析，信息更全面但判断更复杂。

### 卜筮正宗体系：完善五位体系

- 在黄金策五位基础上，加入：
  - 世应关系分析
  - 空破论（旬空+月破）
  - 进神退神论
  - 飞伏神论
  - 六合六冲论
- 形成最系统化的分析框架

### 增删卜易体系：简化为用/元/忌，注重实证

- 删去仇神、卦身等繁复概念
- 回归以用神为核心、元神忌神为辅
- 强调"屡验者存之，不验者删之"
- 用实例验证简化后的体系有效性

## 三、"五乡"伏藏概念综合

### 概念来源

来自《火珠林》"财官伏五乡"之法，后世诸书各有阐释：

> 用神不现时，在第一至第五爻位置的可能性中寻找伏神。

### 五乡的含义

"五乡"并非五个固定位置，而是指：
- 用神可能伏藏于一至五爻之下（上爻不伏）
- 飞神（本卦位置）与伏神（本宫首卦对应位置）的关系决定伏神得出与否

### 寻伏神步骤

```
1. 确定用神类别（财/官/父/子/兄）
2. 在本卦中查找是否有该六亲
3. 若不现 → 取本宫首卦（八纯卦）
4. 以本卦各爻对应本宫首卦各爻
5. 找到用神对应的地支 → 该地支即为伏神
6. 判断伏神得出/不得出的条件
```

## 四、实战断卦综合流程

### 完整断卦步骤（融汇四书）

```
步骤一：装卦
├── 纳干支（火珠林捷法歌）
├── 安世应（八宫定位）
├── 定六亲（五行生克）
├── 装六神（日干起神）
└── 查旬空（日柱定空亡）

步骤二：取用神
├── 按问题类别取用神
├── 用神不现 → 寻伏神（火珠林法）
└── 用神多现 → 取旺相者

步骤三：旺衰分析（四时旺相法）
├── 月建五行定长期旺衰
├── 日辰五行定当下旺衰
└── 得月日双生 = 大吉；被双克 = 大凶

步骤四：动变分析
├── 动爻化进/化退
├── 回头生/回头克
├── 六合六冲
├── 三合成局
└── 进神退神论

步骤五：五位关系（黄金策法）
├── 元神动否 → 有无外力相助
├── 忌神动否 → 有无阻扰
├── 仇神动否 → 助力是否被破
└── 世爻状态 → 我用能否承载

步骤六：特殊论断（卜筮正宗法）
├── 旬空月破（空破论）
├── 随官入墓
├── 进退神
├── 飞伏得出
├── 三刑
├── 向吉凶
└── 进神退神

步骤七：六神六亲辅助
├── 六神临用神/世爻
├── 六神与六亲配合
└── 动爻上六神

步骤八：综合判断
├── 用旺世兴 = 大吉
├── 用旺世衰 = 有利但身弱难承
├── 世旺用衰 = 我强而事不顺
├── 用衰世衰 = 大凶
└── 太过者损之，不及者益之

步骤九：应期推断
├── 用旺应近，用衰应远
├── 静逢冲应，动逢合应
├── 空出空应，伏飞冲应
└── 墓冲开应，绝逢生应
```

## 五、核心断卦原则总结

### "一理融贯"原则

万象纷纭中，以**用神旺衰**和**生克关系**为唯一主线，不杂乱断。

### "用旺世兴"原则

用神旺相 + 世爻有气 = 全吉。

### "太过者损之，不及者益之"原则

极端状态反生变化，物极必反。

### "生扶拱合吉，克害刑冲凶"原则

五行生克为判断吉凶的基础框架。

### "动为趋势，变为方向"原则

动爻代表变化的驱动力，变爻代表变化的结果。

### "空破墓绝为失气"原则

旬空、月破、入墓、绝处为用神失气之象，视情况定凶吉。

### "六合主聚、六冲主散"原则

六合为聚合，六冲为分散，需结合所占事项性质判断。

## 四大经典断语精选（按主题分类）

### 论旺衰根本

> "月建乃万卦之提纲，日辰为六爻之主宰。"
> ——《黄金策·千金赋》
> **释义**：月建决定一卦之长期旺衰格局，日辰决定当下之力。二者为旺衰体系之纲领。

> "生克星不之若也，须忌神又无害。"
> ——《黄金策·千金赋》
> **释义**：月建日辰生克用神，比卦内生克优先级更高；月无害则忌神虽动亦无力。

### 论用神

> "用神为事之主，故取用为第一要务。"
> ——《卜筮正宗·用神论》

> "取验者存，不验者删。"
> ——《增删卜易·序》

### 论动变

> "动静阴阳，反复变迁。"
> ——《黄金策·千金赋》
> **释义**：动为阳主动，静为阴主静。动爻主事变化，静爻待时。

> "进神如春木愈盛，退神如秋叶渐零。"
> ——《增删卜易》

### 论空破墓绝

> "伏无提挈终徒尔，飞不推开亦枉然。"
> ——《黄金策·千金赋》
> **释义**：伏神需飞神提挈（引出）方有用；飞神不被推开则伏神终不出头。

> "虽用神旬空、月破，有生不救即为极衰。"
> ——《增删卜易》

# 第十三部：细微格局补遗

> 以下格局散见于《增删卜易》《卜筮正宗》诸篇，为实践中的细粒度规则，代码已实现但需要文本层面统一引据。

## 一、旬空的真假

**真空**：用神休囚无气 + 旬空 + 无生扶 = 真空难起，终不成。假空：用神旺相 + 旬空 + 有动爻或月日生扶 = 出空则实，待出旬填实之日应事。

- 真空断语：《增删卜易》"旺空待出，真空难起"。
- 真空应期：用神逢值逢冲之日（如寅空亡，寅日或申日填实）。

**假空应期**：出旬值日（如寅空亡，值寅日）或冲动空爻之日（如寅空亡，申日冲寅）。

## 二、月破的真破与假破

- 真破：用神月破 + 日辰再克 + 无动爻生 = 伤透难起。
- 假破：用神月破但日辰生扶，或动爻生扶 = 月破逢救，可补救。
- 《增删卜易》云："月破而在日辰生扶者，犹可救也；若在月日两破者，真破矣。"

## 三、冲飞露伏

伏神得出之正格：
1. **飞神被日辰冲**——飞神动摇，伏神自然脱离飞神压制。如伏神午火，飞神子水，日辰午火冲子水或日辰未土合午火皆可引出。
2. **伏神临日辰月建**——伏神当天即出，称为"当时而得出"。
3. **飞神休囚旬空**——飞神无力压制，伏神得出如隔纸。

## 四、随官入墓辨析

随官入墓分为三类（《卜筮正宗·随官入墓论》）：
1. **用神入墓库**——辰戌丑未为四墓，用神化入卦中墓爻或化入变爻之墓为凶。如用神子水化辰土（水之墓），申金化丑土（金之墓）。
2. **世爻随官鬼入墓**——世爻和官鬼同时入墓，称为"随鬼入墓"，占病占凶多主死亡之象。
3. **用神随鬼入墓**——用神化官鬼又入墓，多为凶象，田土占、官非占最忌。

**解救条件**：世用入墓但月日冲墓或动爻冲墓（如用神入辰墓，戌日冲开），墓开则解。

## 五、三刑应期

| 三刑 | 应期规则 |
|------|---------|
| 寅巳申（无恩之刑） | 值三刑地支之日或冲开之日应（寅日/巳日/申日，或亥日冲巳，寅日冲申，巳日冲亥） |
| 丑未戌（恃势之刑） | 辰日冲戌、丑日冲未等冲墓之日应 |
| 子卯（无礼之刑） | 卯日/子日应，或酉日冲卯、午日冲子 |
| 辰午酉亥（自刑） | 各逢值日冲时 |

**断法**：三刑多占病占讼占伤灾；但有解救（如世爻得月日生旺、动爻通关）时可减轻。

## 六、反吟伏吟识别细则

**反吟判定**：变卦六爻地支与本卦六爻地支位置相冲（非原爻相冲）。本卦巽为风（上巽下巽：巳卯丑/巳卯丑），变卦乾为天（子寅辰/午申戌），全卦地支位置相冲——"卦反吟"。卦反吟主事反复不安，卜婚卜事多不宁。

**伏吟判定**：变卦六爻地支与本卦六爻地支全相同。如乾变震（子寅辰午申戌），或坤变巽（未巳卯→丑亥酉在某些情况下构成伏吟）。用神伏吟事呻吟忧泣。

## 六乙日与六庚日的特殊断法

《黄金策》云："日辰为六爻之主宰。"日辰干支对用神的影响优先级仅在月建之下：
- **日辰合用神**——用神被合，事缓成或绊住。
- **日辰冲用神**——用神被冲散，事散。
- **日辰生用神**——用神得力，当下有力。
- **日辰克用神**——受制，事难。

## 七、三合局成立的严格条件

- **条件一**：三个爻皆动（或月日+卦中动爻）成一方之气。
- **条件二**：三合爻不为空亡（空则合不成）。
- **条件三**：三合爻无日辰月建来破（如申子辰合水，冲辰则局破）。
- **成立效果**：三合局成则一方五行力量极盛，整体参与对用神生克。

# 第十四部：火珠林纳甲条文补遗

> 以下为《火珠林》核心法诀原文摘录，供AI解读时直接引用对应条文。

## 一、用神断

```
用神渐上当作身，三四随之礼序伦。
五位第六为宗庙，六亲爻动定乾坤。
```

用神得位（临世应、得月日）为吉；用神失位（落空破墓绝）为凶。

## 二、六亲持世诀

```
鬼持世事难安，神静体空忧祸端。
财持世兮利求官，兄持世兮财必散。
父持世兮文契验，子持世兮病可安。
```

**释义**：
- 鬼持世——占病/凶/灾为凶；占官/女婚为吉。
- 财持世——占财/男婚为吉；占父疾为凶（财克父）。
- 兄持世——占财为凶（兄劫财）；占兄弟事为吉。
- 父持世——占文书学业为吉；占官非为凶（父克子）。
- 子持世——占病/医药为吉；占求官为凶（子克官）。

## 三、装卦定卦宫诀

```
八卦宫位世用推，六世八纯世在六。
一世二世三四五世分明载，
游魂四世归魂三。
```

## 四、占病独断

```
鬼旺病必重，子旺药有功。
父动鬼伤嗟，兄动病无凶。
```

鬼旺（官鬼旺相）病必重；子旺（子孙旺相）药必有效。父动制子（克子孙）则医药失效；兄动生子（兄弟生子孙）则间接益于医药。

## 五、占婚独断

```
男占妻财女占官，世应内外定乾坤。
六合姻缘天配合，六冲心事各西东。
财官持世最为良，兄动婚来必有妨。
```

男以妻财为用，女以官鬼为用；世应内外和合为吉。

## 六、占讼独断

```
鬼旺官非重，父兴状纸真。
财来生鬼处，有理也难陈。
```

鬼旺官非重（病讼连绵），父兴状有理；财来生官鬼则对方有理我方不利。

## 七、占出行独断

```
世动出行吉，兄动路途惊。
子动身安吉，父动阻行程。
```

世动化进为出行吉；兄弟动防劫财；子孙动一路平安；父动有文书事羁绊。

## 八、占求财独断

```
财旺财宜聚，兄兴财必伤。
子来生财处，万贯有余粮。
```

财旺而子孙动生财为财源滚滚；兄弟劫财、官鬼耗财为忌。
