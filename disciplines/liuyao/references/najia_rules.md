# 纳甲装卦规则参考

本文档涵盖纳甲六爻装卦的全部核心规则，包括天干纳甲、地支排列、八宫归属、世应定位、六亲配置、六神装配、旬空查法及五行旺衰体系。

## 一、天干纳甲规则

### 口诀

```
乾纳甲壬坎纳戊，
震纳庚兮巽纳辛，
离纳己兮艮纳丙，
坤纳乙癸兑纳丁。
```

### 分配表

| 卦象 | 卦性 | 纳天干（内卦/下卦） | 纳天干（外卦/上卦） |
|------|------|---------------------|---------------------|
| 乾 | 阳 | 甲 | 壬 |
| 坎 | 阳 | 戊 | 戊 |
| 震 | 阳 | 庚 | 庚 |
| 艮 | 阳 | 丙 | 丙 |
| 坤 | 阴 | 乙 | 癸 |
| 巽 | 阴 | 辛 | 辛 |
| 离 | 阴 | 己 | 己 |
| 兑 | 阴 | 丁 | 丁 |

### 说明

- 阳卦纳阳干：乾（甲壬）、坎（戊）、震（庚）、艮（丙）
- 阴卦纳阴干：坤（乙癸）、巽（辛）、离（己）、兑（丁）
- 乾为天、为父，甲为十天干之首，故乾纳甲；壬为阳干之终，故乾纳壬（首尾相贯）
- 坤为地、为母，乙为地干之首；癸为阴干之终，故坤纳乙癸
- 内卦纳本干之首，外卦纳同属之终

卯酉木爻土五行。
坎卦寅申子与辰，
戌爻艮土离火寅。
震木子午内初起，
巽木丑未离火戌。
艮土辰戌兑金巳，
巳酉丑上仔细寻。
坤未丑兮兑酉申，
乾震坎艮巽坤离。

### 阳卦与阴卦的区别

| 卦性 | 装法 | 方向 | 涉及的卦 |

### 八宫卦序歌

```
乾为天泽天夬，
火天大有雷天大壮，
风天小畜水天需。
天地否地天泰，
雷天壮风天大畜，
水天火天大壮。
```

### 八宫体系结构

每宫8卦，依次为：

1. **本宫卦**（六世卦）— 上下卦相同
2. **一世卦** — 初爻变
3. **二世卦** — 二爻变
4. **三世卦** — 三爻变
5. **四世卦** — 四爻变
6. **五世卦** — 五爻变
7. **游魂卦**（四世归魂）— 四爻变后下卦再还原（归魂即下卦三爻皆变回本宫）
8. **归魂卦**（三世归魂）— 下三爻全部变回本宫卦

## 四、世应定位法

### 总诀

```
天同二世天变五，
地同四世地变初。
本宫六世世三异，
人同游魂人变归。
```

### 口诀详解

此诀比较本卦与上卦（外卦）、下卦（内卦）的「天爻」（上爻）、「地爻」（初爻）、「人爻」（中爻/四爻或二爻）是否相同：

- **天同二世**：天内（上爻天干）相同，则世在**二爻**
- **天变五**：天内不同，则世在**五爻**
- **地同四世**：地内（初爻地支）相同，则世在**四爻**
- **地变初**：地内不同，则世在**初爻**
- **本宫六世**：内外卦完全相同（纯卦），则世在**上爻**
- **世三异**：天地人三爻皆不同，世在**三爻**
- **人同游魂**：人内（二爻/四爻中爻）相同，且为天变地位，则为**游魂**，世在**四爻**
- **人变归**：人内不同，则为**归魂**，世在**三爻**

### 更简化的口诀（八宫定位法）

```
八纯卦世在六，
一世卦世在初爻。
二世卦世在二位，
三世卦世在三爻。
四世卦世在四爻，
五世卦世在五爻。
游魂卦世在四爻，
归魂卦世在三爻。
```

### 世应位置对照表

| 卦类 | 世爻 | 应爻 | 说明 |
|------|------|------|------|
| 八宫本卦（六世/乾天、坤地等） | 六（上） | 三 | 世应在中间隔三爻 |
| 一世卦（一世） | 一（初） | 四 | 应爻 = 世 + 3 |
| 二世卦（二世） | 二 | 五 | 应爻 = 世 + 3 |
| 三世卦（三世） | 三 | 六（上） | 应爻 = 世 + 3 |
| 四世卦（四世） | 四 | 一（初） | 应爻 = 世 - 3 |
| 五世卦（五世） | 五 | 二 | 应爻 = 世 - 3 |
| 游魂卦（四世游魂） | 四 | 一（初） | 应爻 = 世 - 3 |
| 归魂卦（三世归魂） | 三 | 六（上） | 应爻 = 世 + 3 |

### 世应的意义

- **世爻（世）**：代表求测人自己、主体、是我方
- **应爻（应）**：代表求测对象、客体、对方/环境
- 间隔两位（世沿下数三爻即应），象征遥相关系
- 世为我，应为彼；世为我之事，应为之环境

## 五、六亲配置

### 口诀

```
生我者父母，我生者子孙。
克我者官鬼，我克者妻财。
同我者兄弟。
```

### 六亲五行生克关系

设宫五行属性为「我」：

| 与我的关系 | 六亲 | 五行关系 |
|------------|------|----------|
| 生我者 | 父母 | 该爻地支五行生宫五行 |
| 我生者 | 子孙 | 宫五行生该爻地支五行 |
| 克我者 | 官鬼 | 该爻地支五行克宫五行 |
| 我克者 | 妻财 | 宫五行克该爻地支五行 |
| 比我者（同我） | 兄弟 | 该爻地支五行与宫五行相同 |

## 七、旬空（空亡）

### 口诀

### 查法

以起卦日的**干支**确定所属旬位，该旬中无临官之地支即为空亡。

| 旬 | 日干支 | 空亡 |
|----|--------|------|

| 甲寅旬 | 甲寅～癸亥 | **子丑** |

### 快速查法

日干在哪个甲旬里，该旬末尾两个地支即为空亡。简便方法：

1. 以日干为主，**对冲**后即为空亡所在。例如：
   - 甲日空**戌亥**（对冲辰巳前两位）
   - 乙日空**戌亥**（同甲旬）
   - 丙日空**申酉**（同甲戌旬）
   - 丁日空**申酉**（同甲戌旬）
   - 戊日空**午未**（同甲申旬）
   - 己日空**午未**（同甲申旬）
   - 庚日空**辰巳**（同甲午旬）
   - 辛日空**辰巳**（同甲午旬）
   - 壬日空**寅卯**（同甲辰旬）
   - 癸日空**寅卯**（同甲辰旬）

> 注：此法以日干十干分五组速查，地支影响可忽略，但精确查法应以完整干支推算。

### 空亡吉凶判定
- **用神/世爻落空亡**：力量减半，事情不实、虚惊、难成。
- **忌神落空亡**：凶事减轻，虚惊则无实祸。
- **旺相逢空**：出旬（10日内）则实。
- **休囚逢空**：多主空亡难起，终无果。
- **动而逢空**：待出旬应事。
- **逢冲逢合**：冲空则实，合空则实。

## 十、随官入墓详解（出自《卜筮正宗》）

### 基本概念

**入墓**即爻值辰戌丑未四墓库，五行之气归于墓中。**随官入墓**专指爻随官鬼入墓，为六爻中最为凶险之格局之一。

### 四墓库五行属性

| 墓库 | 五行 | 所藏五行（入墓之物） | 说明 |
|------|------|---------------------|------|
| **辰** | 土 | 水（壬水、癸水） | 水土墓在辰 |
| **戌** | 土 | 火（丙火、丁火） | 火墓在戌 |
| **未** | 土 | 木（甲木、乙木） | 木墓在未 |
| **丑** | 土 | 金（庚金、辛金） | 金墓在丑 |

### 官鬼入墓

官鬼爻本身坐于或入于墓库地支，称为**官鬼入墓**：

- 官鬼五行属木 → 墓在未 → 鬼遇未则为入墓
- 官鬼五行属火 → 墓在戌 → 鬼遇戌则为入墓
- 官鬼五行属金 → 墓在丑 → 鬼遇丑则为入墓
- 官鬼五行属水 → 墓在辰 → 鬼遇辰则为入墓
- 官鬼五行属土 → 墓在辰 → 鬼遇辰则为入墓

### 随官入墓（最凶之格）

**定义**：非官鬼之爻随同官鬼爻一起进入墓库，如同病人随官吏一同进入坟墓。

**判断法则**：
1. 卦中官鬼爻发动或值日/月入墓
2. 世爻或用神与官鬼同墓（地支同为四墓之一）
3. 或官鬼动而化墓，世/用亦值此墓

**歌诀**：
```
随官入墓最凶凶，
世用临之祸不轻。
官鬼入墓身难保，
病人入墓必归冥。
```

### 占断要诀

| 占问 | 随官入墓之断 |
|------|-------------|
| **占病** | 极凶，主病重难愈，甚则有生命之忧 |
| **占讼** | 官司缠身难逃，甚则入狱 |
| **占出行** | 出行有阻，非常不利 |
| **占婚姻** | 婚姻有变，凶 |
| **占求财** | 财爻随官入墓，因财致祸 |
| **占功名** | 官爻入墓，仕途中阻 |

### 随官入墓与官鬼入墓之区别

| 比较 | 官鬼入墓 | 随官入墓 |
|------|---------|---------|
| 范围 | 仅鬼爻本身入墓 | 世/用/他爻随鬼入墓 |
| 危险度 | 凶，占病主缠绵 | 极凶（占病多主死） |
| 解救 | 冲墓可解 | 极难化解 |
| 古例 | 《卜筮正宗》："鬼入墓者，凶" | "随官入墓，其死必矣" |

## 十一、三刑详解（出自《卜筮正宗》）

### 三刑定义

三刑者，刑害之三刑也，乃地支间相互克害之格局。《卜筮正宗》云："三刑者，巳刑申，申刑寅，寅刑巳；丑刑戌，戌刑未，未刑丑；子刑卯，卯刑子；辰午酉亥自刑。"

### 三类三刑

#### 一、恃势之刑（丑戌未三刑）

| 名称 | 组成 | 性质 |
|------|------|------|
| 恃势之刑 | 丑刑戌、戌刑未、未刑丑 | 依仗权势，仗势欺人 |

- **成因**：丑中有旺水，戌中有墓火，丑恃水刑戌中之火。戌为六甲之尊贵，未为六癸之卑下，戌恃尊贵刑未。未恃旺土刑丑中之旺水。
- **占断**：主仗势欺人、得势忘形。占讼主有势力之人相欺，占婚主因门第悬殊生隙。

#### 二、无恩之刑（寅巳申三刑）

| 名称 | 组成 | 性质 |
|------|------|------|
| 无恩之刑 | 寅刑巳、巳刑申、申刑寅 | 忘恩负义，恩将仇报 |

- **成因**：寅中甲木刑巳中戊土，巳中丙火刑申中庚金，申中壬水刑寅中甲木。
- **占断**：主负心忘恩、恩将仇报。占人际主受恩不报反噬，占合作关系凶。

#### 三、无礼之刑（子卯相刑）

| 名称 | 组成 | 性质 |
|------|------|------|
| 无礼之刑 | 子刑卯、卯刑子 | 以下犯上，无礼无义 |

- **成因**：子属水，卯属木，本为母子相生。水过旺反生不养，子中癸水刑卯中乙木，为无礼之行。
- **占断**：主无礼苟且，以下犯上。占婚姻主淫乱不贞，占品行为不拘礼法。

#### 四、自刑（辰午酉亥）

| 名称 | 组成 | 性质 |
|------|------|------|
| 自刑 | 辰刑辰、午刑午、酉刑酉、亥刑亥 | 自寻烦恼，自己刑害自己 |

- **成因**：此四支本身内部气相矛盾。辰为水库，盛则溢；午为火旺，旺则焚；酉为金锐，锐则折；亥为水旺，旺则淤。
- **占断**：主自我纠结、自取其祸。占病主自己忧思成疾，占事主作茧自缚。

### 三刑在装卦中的应用

| 场景 | 判断方法 |
|------|---------|
| 卦中地支见三刑 | 三地支同见于卦中或月日 |
| 月日见三刑 | 月建与日辰处三刑之位 |
| 动爻处三刑 | 动爻之地支构成三刑 |
| 用神处三刑 | 用神被动爻（三刑之一）所刑 |

### 三刑占断总则

```
三刑发动用神伤，
世应逢之两不祥。
刑世求谋必受刑，
刑用疾病更凶亡。
三刑会合灾尤重，
单见之中亦不良。
```

## 十三、反吟伏吟详解（出自《卜筮正宗》）

### 基本概念

反吟与伏吟是卦变中地支相互冲击或重复的两种格局。

### 反吟

**定义**：卦变后地支相互冲击，或内外卦互变对冲。

**种类**：

| 类型 | 说明 | 举例 |
|------|------|------|
| **卦之反吟** | 卦变为其对冲之卦 | 乾变巽（子冲午、寅冲申、辰冲戌） |
| **内外反吟** | 外卦变与内卦对冲 | 地天泰变天地否之类 |
| **六爻反吟** | 六爻地支皆受冲 | 六冲变六冲 |

**具体反吟卦对应**：

| 本卦（六冲） | 变为（六冲） | 反吟特征 |
|--------------|-------------|---------|
| 乾为天 | 巽为风 | 子酉冲、寅亥冲、辰巳冲 |
| 震为雷 | 兑为泽 | 午卯冲、申酉冲、戌未冲 |
| 坎为水 | 离为火 | 子午冲、寅申冲、辰戌冲 |
| 艮为山 | 坤为地 | 寅申冲、午子冲、戌辰冲 |
| 天地否 | 地天泰 | 内外反吟 |
| 风天小畜 | 天风姤 | 内外反吟 |

**占断特征**：
- **反吟主反复**：事情反复来去，成败无常
- **心神不宁**：人心反复，进退不决
- **占病**：病情反复，时好时坏
- **占出行**：去而复返，返而复去
- **古诀**："反吟伏吟，哭泣淋淋。反吟之卦反复事。"

### 伏吟

**定义**：卦变后地支相同不变，或六冲变六冲而地支实则相同。

**种类**：

| 类型 | 说明 |
|------|------|
| **卦伏吟** | 卦变而地支不变 |
| **内外伏吟** | 内外卦皆不变 |
| **六爻伏吟** | 六爻地支皆重复 |

**具体伏吟卦对应**：

| 本卦 | 变卦 | 伏吟特征 |
|------|------|---------|
| 乾为天 | 震为雷 | 内卦子寅辰 → 子寅辰 |
| 坤为地 | 巽为风 | 内卦未酉亥 → 丑酉亥（部分伏） |

**占断特征**：
- **伏吟主忧郁**：忧愁呻吟，痛苦难言
- **停滞不前**：事情郁结，难以施展
- **占病**：忧思成疾，卧床不起
- **占事**：悲痛呻吟，无声哭泣
- **古诀**："伏吟之卦呻吟愁，不动不变化作忧。"

### 反吟伏吟对比

| 比较 | 反吟 | 伏吟 |
|------|------|------|
| 特征 | 地支相冲 | 地支相同 |
| 断事 | 反复无常 | 忧郁不伸 |
| 气象 | 激荡不安 | 沉滞郁结 |
| 古诀 | "反吟反复" | "伏吟呻吟" |

## 十四、飞伏神得出不得出四法（出自《火珠林》《卜筮正宗》）

### 基本概念

**飞神**：出现在卦面上的爻，覆盖伏神之位。
**伏神**：不出现卦面而隐于飞神之下的爻。

当用神不现卦中时，需取伏神。伏神能否得出（发挥力量），决定事情成败。

### 伏神得出四法（用神伏藏可得）

| 序号 | 得出条件 | 原理 | 经典出处 |
|------|---------|------|---------|
| 一 | **日冲飞神** | 日辰冲开飞神，伏神自然得出 | 《卜筮正宗》 |
| 二 | **飞神空破** | 飞神临旬空或月破，无力压伏，伏神得出 | 《火珠林》 |
| 三 | **飞神休囚** | 飞神休囚无气，压制力弱，伏得出 | 《增删易》 |
| 四 | **日/月生扶伏神** | 日辰或月建生扶伏神，伏神有得出之根基 | 《黄金策》 |

**歌诀得出**：
```
伏神得出四般看，
日冲飞神第一端。
飞神空破休囚者，
日月生扶伏亦安。
```

### 伏神不得出四法（用神伏藏难出）

| 序号 | 不得出条件 | 原理 | 经典出处 |
|------|-----------|------|---------|
| 一 | **月克伏神** | 月建克伐伏神，先天受损，伏神不得出 | 《卜筮正宗》 |
| 二 | **飞神旺相克伏神** | 飞神旺相腾达，强力压伏，伏神被压 | 《火珠林》 |
| 三 | **伏神入墓** | 伏神自行入墓，伏而不见，自然不得出 | 《黄金策》 |
| 四 | **伏神空破休囚** | 伏神本身旬空、月破、休囚无气，无力得出 | 《增删易》 |

**歌诀不得出**：
```
伏神不出四般禁，
月克飞强墓自临。
空破休囚无气力，
伏神终是隐山林。
```

### 飞神与伏神之关系判断

| 飞神五行 | 伏神五行 | 生克关系 | 伏得出难易 |
|----------|---------|---------|-----------|
| 生伏神 | 受生 | 飞生伏 | 易得出 |
| 克伏神 | 受克 | 飞克伏 | 难得出 |
| 伏克飞 | 相制 | 伏克飞 | 较易出 |
| 飞伏比和 | 同气 | 飞伏同 | 易得出 |
| 伏生飞 | 相泄 | 伏泄飞 | 难得出 |

## 十五、月破详解

### 月破定义

**月破**（又称月冲）：爻之地支与月建地支相冲，该爻即为月破，当月内最为衰弱。

### 月破十二支表

| 月建 | 月破（被冲之地支） |
|------|-------------------|
| 寅月（正月） | **申**（寅冲申） |
| 卯月（二月） | **酉**（卯冲酉） |
| 辰月（三月） | **戌**（辰冲戌） |
| 巳月（四月） | **亥**（巳冲亥） |
| 午月（五月） | **子**（午冲子） |
| 未月（六月） | **丑**（未冲丑） |
| 申月（七月） | **寅**（申冲寅） |
| 酉月（八月） | **卯**（酉冲卯） |
| 戌月（九月） | **辰**（戌冲辰） |
| 亥月（十月） | **巳**（亥冲巳） |
| 子月（冬月） | **午**（子冲午） |
| 丑月（腊月） | **未**（丑冲未） |

### 月破与日辰相互作用

| 情形 | 吉凶判断 | 说明 |
|------|---------|------|
| 月破逢日克 | **大凶** | 月破又逢日克，彻底衰弱 |
| 月破逢日生 | 先凶后吉 | 日生可补月破之危 |
| 月破逢日合 | **不破** | 日辰合住月破，阻止冲破之力 |
| 月破逢日冲 | 加倍凶 | 日日相冲，寅月申破逢申日 |
| 月破逢空 | 空破之地 | 双重无力 |
| 月破之爻发动 | 变进则吉 | 动化回头生则救 |
| 月破之爻静而不动 | 全月无望 | 当月内难以作为 |

### 月破实际占断法则

```
月破之爻最为忌，
用临月破事难成。
忌神月破反为喜，
喜神逢之却不成。
日辰冲合方能解，
出月值日始相应。
月破名为真大煞，
的的不虚此断情。
```

### 月破用例

**例一**：寅月摇卦，用神居申爻——用神月破。若日辰为巳，巳申相合，月破得合，可解其凶。

**例二**：午月摇卦，用神居子爻——用神月破。若日辰为丑，丑合子，则子水被合救，月破暂解。

**例三**：酉月摇卦，用神居卯爻——用神月破。日辰又逢酉（冲卯则为月破逢日冲），大凶之断。

## 十六、暗动量化

### 暗动定义

**暗动**：爻在月令旺相，受日辰冲之，虽无明动之象，但有暗动之力，如同静极思动，内蕴力量。

### 判断条件

| 条件 | 说明 |
|------|------|
| 必要条件 | 爻值月建旺相（得月令之生扶） |
| 触发条件 | 受日辰之冲 |
| 形态 | 在卦中不作明动论（无"○"、"×"标记） |

### 暗动力量量化

| 状态 | 占力量比 | 说明 | 经典依据 |
|------|---------|------|---------|
| 旺相暗动 | **约70%明动** | 月建旺相受冲，力量充沛，近乎明动 | 《增删卜易》："旺相之爻遇日冲，谓之暗动，其力与动爻相类" |
| 休囚暗动 | **约30%明动** | 休囚爻受冲而动，力量微弱，虽动不甚 | 《火珠林》："休囚遇冲，虽有暗动之意，其力甚微" |

### 暗动与明动力量对比

| 类型 | 占力量 | 吉凶应验 | 作用时效 |
|------|--------|---------|---------|
| 明动（老阳/老阴） | 100% | 显著、直接 | 持续有力 |
| 暗动-旺相 | ~70% | 较显著 | 月中有效 |
| 暗动-休囚 | ~30% | 微弱、隐晦 | 时日短暂 |
| 日破（月休囚逢冲） | 0%（彻底破坏） | 凶 | 当月不可用 |

### 暗动量化使用规则

```
暗动之法要分明，
月令旺衰最要清。
旺相逢冲暗力重，
休囚遇冲力轻微。
七成三成须熟记，
判断吉凶量力行。
日冲月破休囚者，
纵然发动亦无功。
```

### 暗动应期

| 暗动状态 | 应期 |
|---------|------|
| 暗动旺相 | 逢合之日（冲逢合、冲遇值） |
| 暗动休囚 | 逢值之时，稍纵即逝 |
| 暗动化进 | 逢值逢合应事 |

## 十七、用神多现断法（出自《增删卜易》）

### 基本概念

一卦之中，用神（所占事物对应之六亲）可能出现两三个动爻或静爻。此时须判断孰真孰假、孰为主用。

### 用神断法总则

| 方法 | 说明 | 适用场景 | 经典依据 |
|------|------|---------|---------|
| **弃原作旺** | 舍去世爻所在之爻，取发动之旺者 | 用神有世有动 | 《增删卜易》："用神多现，舍世取旺" |
| **弃世取动** | 舍去世位之爻，专取发动之爻 | 用神一动一静在位世 | 《增删卜易》："用神两现，取动不拘" |
| **取发动之爻** | 取发动之爻为用，不拘旺衰 | 用神两个以上，取动 | 《增删》云"舍其静而用其动" |

### 用神取舍五法

| 取舍顺序 | 判定条件 | 取舍原则 |
|---------|---------|---------|
| 一看动爻 | 用神有动有静 | 取**动爻**为用神 |
| 二看旺衰 | 两爻皆动 | 取**旺相**之爻 |
| 三看世应 | 皆旺无世应 | 取**世爻**上之爻 |
| 四看空破 | 皆旺一动一空破 | 取**不空不破**者 |
| 五看日月 | 皆取日月临方 | 取**临日辰/月建**者 |

### 用神两现之取舍

```
用神两现取何看，
动爻旺者是其端。
动静二爻取动断，
两动之卦取旺看。
若皆旺相当中论，
以世为主取一端。
空破休囚皆不用，
月建日辰定其官。
```

### 用神多现分类

| 用神出现情况 | 判断方法 | 举例 |
|-------------|---------|------|
| 一爻动一爻静 | 取**发动之爻** | 两子孙一静一动，取动 |
| 两爻皆动 | 取**旺相有力者** | 两财爻皆动，取旺者 |
| 一爻持世 | 持世之爻为**主用神** | 官鬼持世又现，取持世 |
| 一爻临月/日 | 取**临日辰、月建者** | 父母临月建，为用 |
| 一空一破一实在 | 取**实在之爻** | 一空一实在，取实在 |

## 十八、卦身法（出自《黄金策》）

### 卦身定义

卦身是卦之身体，代表事物的本体、根基。与用神相辅相成，用神断事之吉凶，卦身断事之根本。

### 装卦身法

**定位法**：以世爻阴阳定卦身。

| 世爻属性 | 卦身地支起法 |
|---------|-------------|
| 阳世（世在阳爻） | 从**子**起，自初爻向上寻 |
| 阴世（世在阴爻） | 从**午**起，自上爻向下寻 |

### 具体定位表

| 世爻位置 | 阳世卦身 | 阴世卦身 |
|---------|---------|---------|
| 初爻世 | 子（初） | 午（上） |
| 二爻世 | 丑（二） | 未（五） |
| 三爻世 | 寅（三） | 申（四） |
| 四爻世 | 寅（四） | 酉（三） |
| 五爻世 | 卯（五） | 申（二） |
| 上爻世 | 辰（上） | 未（初） |

**歌诀**：
```
阳世从子上起，
阴世午上寻。
初二三往上，
四五六皆同。
卦身定根基，
配合用神论。
```

### 卦身吉凶

| 卦身状态 | 断法 |
|---------|------|

| 卦身临鬼 | 忧患围绕本体，凶 |

### 断卦与卦身关系

```
卦身与用互相参，
用吉身安事可图。
用凶身受损根基，
用吉身败终无收。
卦身为基用为事，
根基牢固事方成。
```

## 十九、六亲持世断（出自《黄金策》）

### 基本概念

**六亲持世**：代表不同六亲（六事类象）的爻持世（坐于世爻），直接影响求测人自身的状态和事情走向。

### 六亲持世总论

| 六亲 | 持世之象 | 断法要诀 |
|------|---------|---------|
| **父母持世** | 辛苦、文书劳碌 | 占求事必多周折，劳心劳力，有文书牵扯 |
| **官鬼持世** | 忧患、疾病/官运 | 忧疑不解，占病不利，占官则有利 |
| **兄弟持世** | 破财、争竞 | 必主破财，与人争斗，不利求财 |
| **妻财持世** | 富裕、有妻 | 求财易得，男测婚有妻，富象 |
| **子孙持世** | 无忧、福气相随 | 万事无忧，灾祸不侵，心中喜悦 |

### 各亲持世分论

#### 父母持世
```
父母持世主辛苦，
文书文字系心间。
谋望求财多费力，
望官望禄亦艰难。
鬼动功名可得进，
财爻发动事不全。
居身居世多忧患，
文书之事费周旋。
```

#### 官鬼持世
```
官鬼持世最难当，
事务繁杂病亦占。
鬼动有官忧仕宦，
身灾口舌事多端。
鬼克世时无鬼旺，
身安无鬼事多安。
但临官鬼多惊恐，
出入行藏仔细占。
```

#### 兄弟持世
```
兄弟持世莫求财，
官兴须是作祸灾。
饮食朋友常来往，
好事终难许汝来。
财爻克世终有益，
官鬼无虞事可裁。
唯忌兄弟临身世，
切忌空亡事不谐。
```

#### 妻财持世
```
妻财持世主财荣，
女占成婚貌必丰。
官鬼当头防祸祟，
父母持世内无风。
化官定知官事起，
化子定然福禄隆。
财爻持世多吉利，
纵遇凶星亦不凶。
```

#### 子孙持世
```
子孙持世事无忧，
求名坐狱必然休。
避乱求安皆可保，
身安无祸亦无愁。
子孙持世为福德，
万事亨通不用求。
纵有危难终获利，
始知此世为福由。
```
