# 小六壬占卜 Skill

> 易 v0.0.1

## ⛔ 铁律：起课掐算必须由代码执行，LLM 禁止手动掐指

**本 skill 的核心原则是"机械运算归代码，象数解读归人"（`AGENTS.md` 铁律一）。**

> LLM 的职责限于：收集信息 → 调用起课脚本 → 基于脚本输出解读。
>
> LLM **严禁**手动执行以下操作：
> - ❌ 手动"月上起日、日上起时"掐算六宫
> - ❌ 心算"第几数落哪一宫"、口算"某月某日某时是什么宫"
> - ❌ 任何"我觉得这数落在空亡"式的替代脚本功能
>
> 上述操作**必须且只能**由 `scripts/chart.py` 与 `scripts/analyze.py` 完成。

---

## LLM 的职责是什么（铁律一的正面清单）

| # | 职责 | 为什么代码做不了 |
|---|---|---|
| 1 | **把模糊诉求变成可算输入**：所问何事、用月日时还是报数、报哪几个数 | 代码不知道"朋友还钱否"与"讨债能成否"是不同事类（诀句不同） |
| 2 | **选路与核参**：选 month_day_hour / numbers / datetime / lunar，传对参数；核对返回是否含 `palace` 与 `chart_summary`；失败重试一次，仍失败如实报"起课异常" | 需要理解人话与话外音 |
| 3 | **翻译判据成当事人听得懂的话**（核心价值）：把"落宫空亡、诀句『失物寻不见』、主数三六九"讲成"东西一时难找见，多在原处附近或被人收走，留意三、六、九之日" | 这是语言与语境工作，不是运算 |
| 4 | **守住一卦一事**：用户换实质角度（换事类/换层面/假设未来/比较两人）时提议另起一课，不在原课硬推 | 需要判断"这还算不算同一件事" |
| 5 | **分寸与措辞**：凶象说"偏向/有…信号/结构上"，不说"注定"；医疗、法律、投资一律提示以专业意见为准；不编造无判据支撑的"出路叙事" | 价值判断与责任边界 |
| 6 | **综合判断**（《贺氏》难点释疑3）：同一落宫在不同事物下结果有伸缩（空亡测座位"上车定有座位"、留连测成都"金生水能成但有阻"）——综合权衡属于解读层，但不得突破宫义另造结论 | 需要理解具体事物语境 |
| 7 | **事后回看**：用户反馈结果时登记对错（`logs/divination_events.jsonl`），这是唯一能产生现实效度证据的环节 | 只有对话里才有结果 |

**LLM 一律不做**：手动掐算六宫、心算主数、把对齐分说成预测率、打开案例库做类比。

基于《贺氏六壬小手册·小六壬预测法》的推算方法与六宫释义，执行完整的起课与断课分析。

## 核心能力

1. **三种起课方式**：月日时起课（大安起正月，月上起日，日上起时）、变通取数（任意三个数代月日时）、随机取数（任意个数，如电话号、扑克牌）
2. **六宫完整释义**：五行、颜色、方位、属神、掌诀位置、谋事主数、总诀（断语存于 `data/verdicts.json`，代码不含断语字面量）
3. **事类诀辞**：按失物/行人/求财/官讼/疾病/婚姻/出行/家宅/工作/天气十类切句
4. **应期主数**：大安/小吉主一五七，留连主二八十，速喜/空亡主三六九，赤口主四七十
5. **邻宫速断**：进/退/临邻宫关系机械判定（如留连临速喜「不久即归」），规则查 `data/verdicts.json`
6. **方位/五行综合断**：落宫五行与目标方位生克关系（东木南火中土西金北水），结构化输出

## 执行流程

### 第一步：收集信息

需要确认两项：
1. **求测问题**：所问何事（失物、行人、求财、官讼、疾病、婚姻、出行、家宅、工作、天气等）
2. **起课方式**：默认报数（随机取数）；可给月日时（农历）；可给公历时刻；可给农历年月日+时支

### 第二步：起课

使用 `scripts/chart.py`：

```bash
# 报数起课（推荐，变通/随机取数，任意个数）
python <skill-path>/scripts/chart.py --way numbers --numbers 7,7,2,3,4 --question "纠纷能解决否"

# 月日时起课（农历月日 + 时辰序数，子=1…亥=12）
python <skill-path>/scripts/chart.py --way month_day_hour --month 8 --day 15 --hour-ordinal 9 --question "去朋友家，测有人否"

# 公历时刻起课（自动转农历月日 + 时辰）
python <skill-path>/scripts/chart.py --way datetime --datetime "2026-09-23 10:30" --question "今日出行顺利否"
```

**验证脚本输出**：必须确认返回有效 JSON，且含 `palace`（0–5 落宫序）与 `steps`。脚本失败时重试一次；仍失败则告知用户起课异常，**不得手动替代掐算**。

### 第三步：分析

```bash
python <skill-path>/scripts/analyze.py <chart_json_file>
```

输出含 `palace`（六要素+方向）、`neighbors`（邻宫速断：进/退/临）、`direction_element`（方位/五行生克）、`topic_verdict`（事类诀句）、`timing`（主数）、`conclusion`（方向+说明）、`factors`（因子/权重/判据/所本）。所有断语来自 `data/verdicts.json`，每条带《贺氏六壬小手册》出处或通行口径注记。

### 第四步：解读交付

`narrate.py` 已生成师傅口吻正文；需要单文件报告时跑 `render.py`：

```bash
python <skill-path>/scripts/render.py <analyze_json> -o outputs/report.md
```

LLM 拿到 analyze 输出后，把宫义、诀句、主数翻译成当事人听得懂的话（职责 3），并按职责 5/6 把握分寸与综合判断。**禁止自行心算任何宫位。**

## 口径与边界

- 历法默认值沿用内核：交节按"当日即换"（`YI_GANZHI_BOUNDARY=day`）、夜子时不作次日
- 起课用农历月日（《贺氏》原文"八月初十五申时"即农历）；公历时刻起课由内核 `solar_to_lunar` 转换
- 综合判断案例（空亡测座位、留连临速喜）在 `data/cases/` 中吉凶/事类记 N/A——宫义不可死套，engine 不越权改判
- 本学科分数为**古籍案例对齐分**（`dev_tools/check.py`），不是现实预测命中率（`AGENTS.md` 铁律三）
- **尊重科学**：涉及医疗、法律、投资、重大人生决策时，**必须提示以专业意见为准**——占卜是方向参考，不是专业诊断或法律意见
- **一卦一事**：同一问题不重复占卜。用户换实质角度（换用神、换层面、比较两人、测人心）时，应提议另起一课，不在原课里延伸硬推
- **象判边界**：凶象用"偏向 / 有…信号 / 结构上"，不用"注定 / 一定 / 绝无可能"。不把"象"当"判"——宫义描述的是倾向和结构，不是判决
- **结论用语**："应期偏慢"而非"这事黄了"；"目前推动力不足"而非"永远不可能"；"结构上偏紧"而非"注定失败"
