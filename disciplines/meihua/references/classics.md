# 梅花易数 · 古诀原文索引

> **原文实体在 `data/classics.json`，本文件只做索引，不复抄原文**（避免双份真值源）。
> 原文来源：《梅花易数》卷一/卷二/卷三（维基文库字符级保存，繁体照录，无模型转写）。
> 构建器：`dev_tools/build_classics.py`（默认 dry-run，`--write` 落盘；逐条断言
> "引文是该篇的整行原文"，并断言 18 个占验/占例篇名**不入库**——AGENTS.md 铁律二）。

## 一、性质与用法

- 原文是**所本凭证**，不是判据：判据唯一真值源是 `data/verdicts.json`；
  原文不参与评分、不改判据。
- `scripts/analyze.py` 按本次实际命中的因子挑出**本次相关**的原文，放进
  analyze 输出的 `classics` 字段；`scripts/narrate.py` 在报告末段
  「所本原文（《梅花易数》逐字，繁体照录）」逐条列出（带篇名与源文件行号），
  供读者与上文逐句对照。
- 繁体照录导致报告中出现简繁混排：这是**原文自证**的设计（同 lingqi 的
  「书源原文」、zeji 的「参考书证」），不是排版疏漏。

## 三、**故意不收**的篇目（有据可查的取舍）

- 卷二《**卦斷遺論**》：其原文本身即以「西林寺額 / 今日動靜如何 / 牛哀鳴占」等
  占验例说理，逐字引入会把**案例名带进语料与报告**，违反 AGENTS.md 铁律二
  （案例库与预测过程物理隔离）。故该判据只保留规则名与要义转述
  （`data/verdicts.json#hexagram_special`），**不收原文**。
  ——这一取舍由 `build_classics.py` 与 `dev_tools/check.py` 的案例篇断言机械保障。
- 全部占验/占例篇（觀梅占、牡丹占、鄰夜扣門借物占、老人有憂色占、少年有喜色占、
  牛哀鳴占、雞悲鳴占、枯枝墜地占、風覺鳥占、聽聲音占、形物占、驗色占、
  觀物用易例、萬物戲驗 等 18 个篇名）：**不入库**。

## 四、验收（`cd disciplines/meihua && python dev_tools/check.py`）

`[1c] 古籍原文门` 三条不变式：

1. **逐字可回指**：`data/classics.json` 里每个原文串（含逐卦生克条）必须是
   对应卷次书源文件的**连续子串**；
2. **卷次覆盖**：卷一/卷二/卷三三卷均在库，逐卦生体/克体条各 8 条；
3. **案例篇隔离**：18 个占验/占例篇名不得出现在原文载荷里。
