# 命科 SKILL（骨架）

**状态：M5 契约占位。** 只暴露机械四柱因子，**不做**格局断语、大运吉凶、流年批断。

## 意图路由（根 SKILL）

- 问「一生格局 / 命运趋势 / 宜何业」→ 本骨架仅给四柱因子；推演未实现时正文须明示。
- 问具体一事 → 走卜科（六爻/梅花/小六壬/择吉），不越位。

## 能力

| 命令 | 作用 |
|---|---|
| `scripts/chart.py` | 出生公历/干支 → 四柱盘 |
| `scripts/analyze.py` | 藏干十神/纳音/神煞结构化 |
| `scripts/narrate.py` | 占位正文（明示未实现推演） |
| `scripts/render.py` | 因子报告 |
| `tools/check.py` | 契约完整性 + 冒烟 |

## 禁止

- LLM 心算四柱或十神（铁律一）。
- 在 narrate 里编命运结论。
- 把骨架输出说成「命已算准」。
