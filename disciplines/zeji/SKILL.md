# 择吉择日 Skill

> 易 v0.0.1

## ⛔ 铁律：择日盘必须由代码装配，LLM 禁止手动推算

**本 skill 的核心原则是"机械运算归代码，象数解读归人"（`AGENTS.md` 铁律一）。**

> LLM 的职责限于：收集信息 → 调用起局脚本 → 基于脚本输出解读。
>
> LLM **严禁**手动执行以下操作：
> - ❌ 手动推"某月某日是什么建除日"、"值什么神"
> - ❌ 心算"青龙起支""二十八宿哪天值日"
> - ❌ 任何"我觉得这天宜嫁娶"式的替代脚本功能
>
> 上述操作**必须且只能**由 `scripts/chart.py` 与 `scripts/analyze.py` 完成。

---

## LLM 的职责是什么（铁律一的正面清单）

| # | 职责 | 为什么代码做不了 |
|---|---|---|
| 1 | **把模糊诉求变成可算输入**：所为何事（嫁娶/开市/出行…）、哪几天候选、是否带时辰 | 代码不知道"结婚"与"开张"对应不同宜忌表 |
| 2 | **选日与核参**：传 `date`（公历 YYYY-MM-DD）与 `activity`；核对返回是否含 `jian_chu`/`day_god`/`xiu`；失败重试一次，仍失败如实报"起局异常" | 需要理解人话与话外音 |
| 3 | **翻译判据成当事人听得懂的话**（核心价值）：把"开日宜开市、天德黄道、壁宿吉，得分 2.5"讲成"这天开门营业三吉相合，是九月里最宜开张的日子之一" | 这是语言与语境工作，不是运算 |
| 4 | **守住一卦一事**：用户换活动（同一日期问不同事）或换日期重问时如实重算，不在旧盘硬推；同盘异事的宜忌按事类重新匹配 | 需要判断"这还算不算同一件事" |
| 5 | **分寸与措辞**：凶象说"结构上偏不利"，不说"注定"；安葬涉法规、医疗、投资一律提示以专业意见为准；不编造无判据支撑的"出路叙事" | 价值判断与责任边界 |
| 6 | **多日对比**：用户给多个候选日时逐日起局对比得分与宜忌要点，不替用户拍板（吉凶之外还有个人便利、民俗与专业意见） | 需要理解具体语境 |
| 7 | **口径透明**：机械因子（建除/黄黑道/值宿）对照通书核对过；宜忌表取《协纪辨方书》通行口径，个别通书有出入时如实说明 | 诚实交代规则出处 |

**LLM 一律不做**：手动推建除/黄黑道/星宿、心算得分、把对齐分说成预测率、打开案例库做类比。

基于《协纪辨方书》建除篇、卷五黄黑道与二十八宿值日规则，执行择日盘的装配与宜忌分析。

## 核心能力

1. **择日盘装配**：公历日期 → 干支四柱 + 建除十二神 + 日值黄黑道神 + 二十八宿值日（可带时辰取时辰值神）
2. **十类活动宜忌**：嫁娶/开市/出行/入宅/安葬/动土/祭祀/入学/上任/纳财，按建除宜忌表与值神宜忌表匹配
3. **综合裁决**：黄黑道 ±1（日辰第一权）+ 建除宜忌 ±1 + 星宿吉凶 ±0.5；≥1 吉、≤-1 凶、其间平（裁决口径见 `data/verdicts.json`，README 明示为规则应用非古籍定论）

---

## 执行流程

### 第一步：收集信息

需要确认两项：
1. **所为何事**：嫁娶、开市、出行、入宅、安葬、动土、祭祀、入学、上任、纳财等
2. **候选日期**：公历 YYYY-MM-DD（可多个逐日比较）；可选时支（如"午"）取时辰值神

### 第二步：起局

使用 `scripts/chart.py`：

```bash
# 单日择日盘（自动识别活动）
python <skill-path>/scripts/chart.py --date 2026-09-30 --question "开张营业吉否" -o scratch/chart.json

# 显式活动 + 时辰
python <skill-path>/scripts/chart.py --date 2026-09-30 --activity 开市 --hour-branch 午 -o scratch/chart.json
```

**验证脚本输出**：必须确认返回有效 JSON，且含 `jian_chu`（建除神）、`day_god`（日值神）、`xiu`（值宿）。脚本失败时重试一次；仍失败则告知用户起局异常，**不得手动替代推算**。

### 第三步：分析

```bash
python <skill-path>/scripts/analyze.py <chart_json_file>
```

输出含 `factors_detail`（建除/黄黑道/星宿三因子宜忌落点）、`yi`/`ji`（该活动有利/保留信号）、`conclusion`（方向/说明/得分/所本）、`factors`（因子/权重/判据/所本）。所有宜忌文字来自 `data/verdicts.json`，带《协纪辨方书》出处。

### 第四步：解读交付

`narrate.py` 已生成师傅口吻正文；需要单文件报告时跑 `render.py`：

```bash
python <skill-path>/scripts/render.py <analyze_json> -o outputs/report.md
```

LLM 拿到 analyze 输出后，把宜忌要点、综合裁决翻译成当事人听得懂的话（职责 3），并按职责 5/6 把握分寸与多日对比。**禁止自行心算任何建除/值神/星宿。**

## 口径与边界

- 干支历默认值沿用内核：交节按"当日即换"（`YI_GANZHI_BOUNDARY=day`），故寒露当日即换月建
- 农历范围：1900-01-31 起 150 年；范围外日期起局异常（`data/cases/` 中以 excluded 记录边界）
- 机械因子（建除/黄黑道/值宿）为历法真值，锚点 2026-09-23/24/25 与 10-01/10-08/10-13/10-15 对照通书黄历核对一致
- 宜忌表取《协纪辨方书》通行口径；个别通书（如某些网上黄历）宜忌略有出入，如实说明
- 综合裁决（黄黑道±1 + 建除±1 + 星宿±0.5）为学科自有口径，非古籍定论
- 本学科分数为**古籍案例对齐分**（`tools/check.py`），不是现实预测命中率（`AGENTS.md` 铁律三）
- **尊重科学**：涉及医疗、法律、投资、重大人生决策时，**必须提示以专业意见为准**——择吉是传统通书的方向参考，不是医疗诊断、法律意见或投资建议
- **象判边界**：凶象用"偏向 / 有…信号 / 结构上"，不用"注定 / 一定 / 绝无可能"。不把某个不利的建除或值神当"这天绝对不能用"的终判
