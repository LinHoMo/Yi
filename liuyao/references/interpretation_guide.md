# 六爻断卦方法论详解

本文档为六爻纳甲断卦的参考指南，涵盖用神取法、旺衰判断、动变分析、世应关系、六神辅助、经典断语、应期推断及注意事项。

---

## 一、用神取法

用神是断卦的核心分析对象，代表所占问的人或事。根据问题类别选取正确的用神是准确断卦的第一步。

### 用神取法总表

| 求测事项 | 用神 | 忌神 | 元神（生用神者） | 仇神（克元神者） | 参考说明 |
|---------|------|------|----------------|----------------|---------|
| 财运 / 投资 / 生意 | 妻财爻 | 兄弟爻 | 子孙爻 | 官鬼爻 | 妻财旺相得生则财聚，休囚受克则财散 |
| 事业 / 工作 / 升职 | 官鬼爻 | 子孙爻 | 妻财爻 | 父母爻 | 官鬼旺得有扶则官运亨通，受克则阻碍艰难 |
| 男测感情 / 婚姻 | 妻财爻 | 兄弟爻 | 子孙爻 | 官鬼爻 | 财爻为妻，财旺相生世则感情和悦 |
| 女测感情 / 婚姻 | 官鬼爻 | 子孙爻 | 妻财爻 | 父母爻 | 官鬼为夫，官旺生世则夫贤有情 |
| 学业 / 考试 / 文章 | 父母爻 | 妻财爻 | 官鬼爻 | 子孙爻 | 父母主文书学业，得官星生助则学业有成 |
| 子女 / 晚辈 / 儿孙 | 子孙爻 | 父母爻 | 兄弟爻 | 妻财爻 | 子孙旺相则子女聪慧安康 |
| 父母 / 长辈健康 | 父母爻 | 妻财爻 | 官鬼爻 | 子孙爻 | 父母爻受克则长辈不安，得生则安泰 |
| 兄弟 / 同辈关系 | 兄弟爻 | 官鬼爻 | 父母爻 | 子孙爻 | 兄爻旺则得力，受克则失助 |
| 官司 / 诉讼 | 官鬼爻 | 子孙爻 | 妻财爻 | 父母爻 | 官鬼临世应看何方得旺，官旺生世则胜诉 |
| 出行安全 | 世爻为主 | — | — | — | 世爻旺相得扶则出行平安，休囚受克则有险 |
| 失物寻找 | 妻财爻（财物）/ 父母爻（文书） | 兄弟爻 | — | — | 妻财在内卦不出园，失物逢冲可寻；财伏不现则难觅 |
| 疾病 | 官鬼爻（病症）+ 世爻（自身） | — | — | — | 官鬼旺则病重，官鬼衰则病轻；世克官鬼则病可愈 |
| 住宅风水 | 父母爻（建筑）+ 各爻位对应 | — | — | — | 二爻为宅，五爻为二爻之鬼为大门；六亲临爻位看对应事项 |

### 用神取法补充说明

1. **用神多现**：若卦中用神出现两个或以上，取旺相之爻为主用神，休囚之爻为辅助参考。
2. **用神不现（伏藏）**：用神在卦中不出现时，需从本宫首卦中寻找伏神之爻，不可直接断凶。伏神得飞神生助、月日引出则仍可用。
3. **用神空亡**：用神落空亡（旬空），力量大减。出空之日方可应事。

## 二、用神旺衰判断

用神的旺衰决定吉凶的基本方向。旺衰由月建、日辰以及卦内动爻三者共同决定。

### 旺衰判断规则

| 状态 | 判断依据 | 力量特征 |
|------|---------|---------|
| **旺** | 得月建生扶（月建五行生用神五行），或与月建同五行 | 力量最强，可主事成 |
| **旺** | 得日辰生扶，或与日辰同五行 | 当下力量充足，可主事成 |
| **相** | 用神之五行生辰月/日的五行 | 力量尚可，次之 |
| **休** | 月/日用神五行为被动相生方 | 力量衰弱，需待时机 |
| **囚** | 用神五行克月/日五行 | 力量微弱，多主不利 |
| **死（衰极）** | 被月、日双克，无一生扶 | 力量最弱，多主凶象 |
| **虚** | 落空亡（旬空） | 力量暂时消失，待出空方应 |

### 旺衰交互作用规则

1. **月建 + 日辰双得生扶** → 极旺，大吉之象
2. **月建生而日辰克** → 中和偏旺，可成但需付出努力
3. **月建克而日辰生** → 中和偏弱，有贵人助可达
4. **月建 + 日辰双克** → 极衰，大凶之象，事难成
5. **得忌神发动来克** → 原有旺衰状态被破坏，转凶
6. **得元神（生用神之爻）发动来生** → 即使休囚亦转吉，有外力相助

### 旺衰速查口诀

```
旺者逢生愈旺，衰者逢克愈衰。
得一生扶，虽衰可起；缺一克害，纵旺亦危。
月建为根，日辰为苗；根深苗壮，方能成材。
```

## 三、动变分析规则

动爻代表事情的变化趋势，变爻代表变化的结果方向。动变分析是判断事态发展的关键。

### 基本动变关系

| 动变类型 | 定义 | 吉凶判断 | 断语 |
|---------|------|---------|------|
| **回头生** | 动爻所化出之变爻动来生本爻 | 吉 | 力量增强，趋势向好，有人相助，后劲十足 |
| **回头克** | 动爻所化出之变爻动来克本爻 | 凶 | 力量减弱，趋势不利，阻力重重，内耗严重 |
| **化进** | 变爻为进神（如寅→卯、巳→午、申→酉、亥→子、丑→辰、未→戌） | 吉 | 力量递增，事态发展越来越有利，前景看好 |
| **化退** | 变爻为退神（如卯→寅、午→巳、酉→申、子→亥、辰→丑、戌→未） | 凶 | 力量递减，事态发展越来越不利，力不从心 |
| **化空亡** | 变爻处于旬空状态 | 虚惊或空欢喜 | 事情虚而不实，有望不可即，待出空则可实 |
| **化墓** | 变爻为辰戌丑未之墓库 | 受制收藏 | 力量被收藏不起，事有阻碍，待冲开方应 |

### 进神与退神对照表

| 五行 | 进神变化 | 退神变化 |
|------|---------|---------|
| 木 | 寅→卯（渐进） | 卯→寅（退步） |
| 火 | 巳→午（渐进） | 午→巳（退步） |
| 金 | 申→酉（渐进） | 酉→申（退步） |
| 水 | 亥→子（渐进） | 子→亥（退步） |
| 土（四库） | 丑→辰、未→戌（渐进） | 辰→丑、戌→未（退步） |

### 动变分析综合要则

1. **用神动而化进** → 事情会越来越顺利，力量持续增强
2. **用神动而化退** → 事情会越来越困难，力量逐渐消退
3. **用神动而被变爻回克** → 事情遇到内部阻力，可能事与愿违
4. **用神动而被变爻回头生** → 事情得到助力，发展顺利
5. **忌神动而化进** → 阻力越来越大
6. **忌神动而化退** → 阻力逐渐消除
7. **元神动而生用神** → 有外力推动事情向好的方向发展
8. **仇神动而来克元神** → 助力被破坏，好事多磨

### 多爻动时的分析方法

当卦中有多个动爻时，分析需分层：

1. **先看流动态势**：各动爻化进、化退、化空亡、化墓的方向是否一致
2. **再看过与不及**：若多数动爻回头生用神，则过度需防物极必反；若多数回头克用神，则需寻是否有解救
3. **关注关键动爻**：距离用神最近的动爻对用神影响最大
4. **有无通关化解**：若忌神克用神之间有关则可通关之五行动爻，则可化解凶象

## 四、世应关系

世爻代表自身（问我之事、我方），应爻代表对方或所占之事的状态。世应关系的吉凶影响整卦的大方向。

### 世应关系吉凶判断

| 世应关系 | 含义 | 吉凶 | 具体判断 |
|---------|------|------|---------|
| **世应相生** | 双方和谐互助 | 大吉 | 主动生助关系融洽，事情容易达成共识 |
| **世应相克** | 双方对立矛盾 | 凶 | 主动克助关系紧张，事情多有阻扰对立 |
| **世刑应** | 世克应但非正克 | 小凶 | 事情有勉强之意，虽能克助但需付出代价 |
| **应刑世** | 应克世但非正克 | 小凶 | 对方或此事对我不利，需注意防范 |
| **世应比和（同五行）** | 势均力敌 | 平顺 | 双方力量相当，事情平稳，吉凶看用神旺衰 |

### 世应爻位对应关系

| 本宫卦序 | 世爻位置 | 应爻位置 |
|---------|---------|---------|
| 首卦（纯卦） | 上爻（六爻） | 三爻 |
| 一世卦 | 初爻 | 四爻 |
| 二世卦 | 二爻 | 五爻 |
| 三世卦 | 三爻 | 上爻（六爻） |
| 四世卦 | 四爻 | 初爻 |
| 五世卦 | 五爻 | 二爻 |
| 游魂卦 | 四爻 | 初爻 |
| 归魂卦 | 三爻 | 上爻（六爻） |

### 世应分析要则

1. **世爻为自身**：代表问卦之人，旺衰判断参照月建日辰
2. **应爻为对方**：代表所占问之人或事，与世爻关系定和谐或对立
3. **世应俱空**：双方都无诚意，事情难成
4. **世应俱旺**：双方力量强，事情有实质发展
5. **世旺应衰**：我方占优，事情对我有利
6. **世衰应旺**：对方占优，事情对我不利
7. **世应之间有动爻**：中间有人或事介入影响双方关系

## 五、六神辅助解读

六神以起卦日天干为基准进行排列，辅助判断事情的细节和附加信息。

### 六神排列规则

| 起卦日天干 | 初爻起 | 顺序排列 |
|-----------|--------|---------|
| 甲日/乙日 | 青龙 | 朱雀 → 勾陈 → 螣蛇 → 白虎 → 玄武 |
| 丙日/丁日 | 朱雀 | 勾陈 → 螣蛇 → 白虎 → 玄武 → 青龙 |
| 戊日 | 勾陈 | 螣蛇 → 白虎 → 玄武 → 青龙 → 朱雀 |
| 己日 | 螣蛇 | 白虎 → 玄武 → 青龙 → 朱雀 → 勾陈 |
| 庚日/辛日 | 白虎 | 玄武 → 青龙 → 朱雀 → 勾陈 → 螣蛇 |
| 壬日/癸日 | 玄武 | 青龙 → 朱雀 → 勾陈 → 螣蛇 → 白虎 |

### 六神临用神/世爻的含义

| 六神 | 临用神/世爻之吉凶 | 事项特点 | 断法参考 |
|------|-----------------|---------|---------|
| **青龙** | 大吉 | 喜庆、正财、官运亨通、贵人相助、酒色欢愉 | 青龙临财主正财，临官主升迁，临父主文书喜庆 |
| **朱雀** | 吉中带凶 | 文书、消息、口舌、考试、通讯、争执 | 朱雀临父主文书消息，临官主口舌官非，动则争讼 |
| **勾陈** | 迟滞/凶 | 纠结、阻滞、田土、往事牵绊、抑郁忧虑 | 勾陈临财主田宅之事，临世主心事难解、纠结反复 |
| **螣蛇** | 惊恐/怪异 | 惊恐、怪异、虚惊、多疑、梦境、不真实 | 螣蛇临世主疑神疑鬼，临财主虚惊不实，动则怪异 |
| **白虎** | 主凶 | 凶险、凶丧、血光、刑伤、疾病、丧事 | 白虎临世主体弱，临官主刑伤，临财主破财凶险 |
| **玄武** | 暗昧/凶 | 暗昧、欺诈、私情、盗贼、阴谋、暗害 | 玄武临财主暗财，临世主心思不正，动则盗贼阴谋 |

### 六神应用要则

1. **六神非断卦主线**：六神为辅助参考，不能替代用神旺衰和动变分析
2. **临用神/世爻最验**：六神信息在产品用神或世爻上最为明显
3. **六神与六亲配合**：六神与临爻的六亲组合后综合判断，如"玄武临妻财"主暗昧之财
4. **动爻上的六神**：六神出现在动爻之上，其信息更为活跃和强烈

## 六、经典断语集

以下断语出自历代六爻经典（如《卜筮正宗》《增删易》《黄金策》等），经过千年实践的检验，是断卦的重要参考。

### 用神旺衰断语

- 用神旺相，得生扶 → 事必成
- 用神休囚，被克制 → 事难成
- 用神旺而落空亡 → 出空可成，然有延迟
- 用神伏藏得飞生 → 目下难成，终有出头之日
- 用神化进无克 → 步步高升
- 用神化退无生 → 日渐衰败
- 用神被绝处逢生 → 绝处逢生，有救

### 动变与生克断语

- 元动生用 → 有人助力，外力推动
- 忌动克用 → 有人阻扰，内部消耗
- 用神动而化绝 → 事将终止，力量用尽
- 用神动而化长生 → 事有新机，重新起步
- 用神动而化回头生 → 内外助力，势不可挡
- 用神动而化回头克 → 内部瓦解，事与愿违
- 忌神化回头克 → 阻碍自消，逢凶化吉

### 世应断语

- 世应相生 → 和顺，双方有益
- 世应相克 → 对立，双方有害
- 世应比和 → 平和，事可为
- 世爻旺而克应 → 我强彼弱，可制对方
- 应爻旺而克世 → 彼强我弱，需防受制
- 世应俱动 → 事多变，两面摇摆

### 六合六冲断语

- 六合卦 → 事聚、事缓、缠绵难解、人多牵绊
- 六冲卦 → 事散、事速、有聚有散、变动频繁
- 六合化六冲 → 先合后散，起初顺利而后变数
- 六冲化六合 → 先散后合，曾有波折而后安定
- 合处逢冲 → 表面和谐内有隐患
- 冲中遇合 → 暂时分离终会合拢

### 六合规则（地支相合）

子丑合、寅亥合、卯戌合、辰酉合、巳申合、午未合。

### 六冲规则（地支相冲）

子午冲、丑未冲、寅申冲、卯酉冲、辰戌冲、巳亥冲。

## 七、应期推断

应期推断是指根据卦象推算事情发生或应验的时间。

### 静爻与动爻的应期规则

| 静爻应期 | 动爻应期 | 说明 |
|---------|---------|------|
| 逢值 — 用神所临地支逢值日/月 | 逢合 — 动爻所化出之变爻逢合日/月 | 如用神临寅，静则寅日应，动化亥则申日应合 |
| 逢冲 — 用神所临地支逢冲日/月 | 逢值 — 动爻所临地支逢值日/月 | 如用神逢空亡，则出空之日应 |

### 用神旺衰与应期

| 用神状态 | 应期推断 | 说明 |
|---------|---------|------|
| 用神旺相 | 应期在近 | 事情发生在生扶用神的月日，或临值之日 |
| 用神休囚 | 应期在远 | 事情发生在用神旺相之时节，需待时运 |
| 用神化空亡 | 出空之日应 | 出空（旬空地支逢值日）之时为应期 |

### 化空亡与伏藏的应期

- **变爻落空亡** → 冲空之日（如子空亡逢午日）或出空之日应
- **用神伏藏** → 飞神被冲之日或伏神临值之日应
- **用神入墓** → 冲墓之日应（如辰日冲戌墓）

### 应期速断口诀

```
静者逢冲应，动者逢合应。
旺者当下验，衰者待时辰。
空者出空实，伏者飞冲现。
墓者冲开应，绝者逢生生。
```

## 八、注意事项

### 常见误区

1. **切忌用神不现（伏藏）时直接断凶**
   - 用神伏藏不代表事情无望，需看伏神是否得飞神生助、是否被月日引出
   - 伏神得飞神生助且月日引出时，事情虽迟终成
   - 伏神被飞神克制且月日不引时，方可断为难成

2. **忌神休囚时影响减弱**
   - 忌神虽克用神，但若忌神休囚无力，则凶象减轻
   - 忌神休囚又逢月破、日克，基本无力作用

3. **多爻动时看"主流"方向**
   - 多个动爻并非各自独立，而是形成整体能量流向
   - 找出主流方向（多数动爻的生克指向）作为主要判断依据
   - 个别逆势动爻为变数或杂音

4. **外应（用户描述的环境信息）可作为辅助参考**
   - 求测时的突发见闻、身体感应等可作为参考，但不能替代卦象
   - 外应与卦象相合时，判断更为有力
   - 外应与卦象相违时，以卦象为主，外应为旁证

### 其他重要原则

- **生死之事避问**：涉及生死重事时，应委婉提醒用户顺应自然、积极面对
- **医疗法律事宜**：涉及重大医疗决策或法律纠纷，务必建议用户咨询专业人士
- **反复占卜**：同一问题不应反复占卜，"再三则渎，渎则不告"
- **心态端正**：断卦之人是协助用户观察形势，而非替用户做决策
- **文化素养**：解读时兼顾《周易》的哲学智慧，不可不论理只论吉凶

### 断卦伦理

1. 不为不善之事占卜
2. 不为不当之事断语
3. 凶象宜含蓄表达，明示化解之道
4. 吉象宜提醒居安思危，不可得意忘形
5. 保持客观中立，不争一时得失

## 附录：五行生克与六亲关系速查

### 六亲五行生克关系

```
生我者 → 父母（庇护、文书、房屋）
我生者 → 子孙（后代、福气、投资）
克我者 → 官鬼（官职、压力、病灾）
我克者 → 妻财（财富、妻子/女友）
```

同书附例（源L631-632）：甲乙日例「青龙 朱雀 勾陈 螣蛇 白虎 玄武」、丙丁日例「朱雀 勾陈 螣蛇 白虎 玄武 青龙」——
与《增删卜易》六神章第十八（源L711-717）**完全一致**，两书互证，本仓取此。

### 二、「无某六亲」各卦歌诀 → 引擎纳甲实算

《卜筮全书》源L651-655 逐类列出缺某六亲的卦。对账结果：

| 歌诀类 | 歌诀卦数 | 引擎实算 | 结论 |
|---|---|---|---|
| 无父母（源L651，非逐字类目标目） | 10 | 10 | **逐卦一致** |
| 无兄弟（源L652，非逐字类目标目） | 6 | 6 | **逐卦一致** |
| 无妻财（源L653，非逐字类目标目） | 16 | 16 | **逐卦一致**（「孚」即中孚、「小过」在表内） |
| 无子孙（源L654，非逐字类目标目） | 15＋讹字「儿」 | 16 | **差一卦**：引擎另算「小过」亦无子孙，歌诀未列 |
| 无官鬼（源L655，非逐字类目标目） | 8 | 8 | **逐卦一致** |

**那一处差异如实钉住**（测试里的 `KNOWN_DIFF_NO_SUNSUN`）：歌诀缺「小过」而引擎有——可能是底本传抄
脱漏或「儿」为讹字所致，**现有书证不足以判定谁对**，故不改引擎、不改歌诀，只把差异显式登记。

### 三、游魂／归魂八卦歌 → 引擎八宫序

《卜筮全书》源L667「明夷与颐晋，需讼及中孚，小过并大过，游魂应在初」、
源L672「归妹及同人，师随蛊渐轮，比还兼大有，八卦是归魂」——
引擎八宫序里的游魂／归魂标记与歌诀**16 卦逐卦一致**。

### 四、年上起月歌／日上起时歌 → 引擎五虎遁、五鼠遁

《卜筮全书》源L677「甲己之年丙作首，乙庚之岁戊为头，丙辛之位从庚上，丁壬壬位顺行流，更加戊癸从何起，甲寅之上好追求」、
源L683「甲己还加甲，乙庚丙作初，丙辛从戊起，丁壬庚子居，戊癸何方发，壬子是真途」——
与八字科 `yishu_core.ganzhi_calendar` 的 `TIGER_MONTH_STEM`／`RAT_HOUR_STEM` **五组逐组一致**
（八字科测试只引歌文不引行号，避免跨科书证指针）。

### 五、六神空亡诀（断语层，非机械规则）

《卜筮全书》源L3408-3410「青龙空亡家虚喜，朱雀空亡讼得理。勾陈空亡无勾连，螣蛇空亡怪异已。
白虎空亡病可痊，玄武空亡盗贼死。」——这是**占断语**，不是起例规则；引擎只判"某六神是否落空亡"，
断语本身须照原书转述，不得当引擎输出。

### 六、定寅时法（子时口径）

《卜筮全书》源L689「正九五更二点彻，二八五更四点歇，三七平光是寅时，四六日出寅无别……」——
与引擎的子时区分（`distinguish_zi_hour`／`zi_hour_type`）相关，本批**未逐条对账**，列入下批。

## 十三、应期外部效度实测（574 批：《易冒》系 16 案）

> **先说口径**：以下数字是**外部集上的逐例计数**，不是"准确率"——
> 可判 n=16 < 30，按 546 批冻结的 decision_rule **不出率值**；"9/16"是**计数**，不得对外称准确。

**语料**：从《易冒》《易林補遺》逐条读出 16 案带**单点应期书证**的占验实例
（该书体例为「X建Y日占…得A之B卦…应Z日」，此前**零案例**被提取），
池在 `liuyao/data/cases/bushi_yingqi_candidates.json`，一次性开卷。

**冻结主指标**（沿用 546 批「顶-1 应期支一致」，开卷后未改）：

| 口径 | 结果 |
|---|---|
| 顶-1 应期支命中书载 | **1／16** |
| 书载应期支**落在引擎候选集合内**（归因线索，非指标） | **9／16** |

**结论（本批最要紧的一条）**：引擎**能推出**原书的应期支（候选集覆盖过半），
但**顶-1 的取舍与原书不同**——即缺口在**应期的排序／择取**，不在应期的推导。
《易冒》的应期多是"后待某日"这类**较远**的单点，引擎默认取**近应**，二者天然错位；
但这仍不能替引擎开脱：**排序口径未对齐**是实打实的能力缺口，已登记为后续改进方向。

**读法**：引用本节数字时须写"外部集逐例计数"，不得写成命中率；
`in_candidate_pool` 只是归因线索，**不是指标**，不得据此改冻结指标。

### 575 批：排序口径离线试验（**不改引擎、不动读数**）

用同一批 16 案离线试七种排序口径（工具 `dev_tools/yingqi_order_probe.py`，只读）：

| 口径 | 命中（逐例计数） |
|---|---|
| A 引擎现状（首支） | 1／16 |
| B 引擎序末支 | 0／16 |
| C 候选中日期最晚 | 3／16 |
| D 候选中日期最早 | 2／16 |
| E1 值日族优先 | 4／16 |
| E2 逢冲族优先 | 3／16 |
| E3 出空／填实族优先 | 0／16 |
| F 族优先＋最晚 | 4／16 |

**三层覆盖**（推导层的天花板）：日应期候选含书载应期支 **9／16**；另有 1 案仅月应期层覆盖；
**6 案在日／月／年三层候选中皆无书载应期支**。

**两条结论**：
① **推导层也有缺口**——即便排序完美，可覆盖上限也只有 10／16；
② **排序层没有"廉价解"**——最好口径只到 4／16，且 **n=16 太小，1–3 案的差别不构成结论**，
故**不接线**（接线会改读数、须声明新旧不可比），先把语料扩到 n≥30 再评。

**真问题**："多因一果时原书取哪一个"是**取舍判据**，不是排序参数；
靠规则族优先级硬凑出来的口径不构成能力，只是把一个数字换了个来源。
