## 一、书证清单（按判定层级排）

### A. 层级：日月并列最高；太岁 < 日月

| # | 引文（照录） | 出处 |
|---|---|---|
| A1 | 「日辰为六爻之主宰，月将是万卜之提纲。」 | 《增刪卜易》源L1446 |
| A2 | 「日辰为六爻之主宰，司四时之旺相…操生杀大权与月建同功。」 | 《增刪卜易》源L692 |
| A3 | 「日伤爻真罹其祸，爻伤日徒受其名。日月如天如君，六爻如臣如万物。日辰能刑冲克害得卦爻，而卦爻不能刑冲克害日月。」 | 《增刪卜易》源L1546 |
| A4 | 「太岁虽司一年之令，尊而不亲，难仰吉凶，皆不及日月…爻之衰者，太岁不能生之，爻旺者太岁不能制之」 | 《增刪卜易》源L1447 |
| A5 | 「日辰为六爻之主宰，喜其灭项以安刘。」 | 《黃金策》源L28 |
| A6 | 「月建乃万卜之提纲，岂可助桀为虐。」 | 《黃金策》源L32 |

**读出**：月建与日辰并居最高层。A2 是最硬的一句——`操生杀大权与月建同功`，
直接否掉"月重日轻"的任何权重设定（见 §三-①）。A3 同时给出一条**权限**：卦爻（含动爻）
不能反作用于日月，这条把"动爻克月建"一类算法判为越权。太岁、星煞不入方向判定（A4）。

### B. 用神定位：现 > 变 > 伏；不现则以日月为用

| # | 引文（照录） | 出处 |
|---|---|---|
| B1 | 「黄金策曰，飞爻变爻俱无用神者，始寻伏神。」 | 《增刪卜易》源L1109 |
| B2 | 「若用神不现，即以日月为用神，倘日月非用神者，则于宫首卦寻之」 | 《增刪卜易》源L1033 |
| B3a | 「伏神有用者有六：伏神得日月生者一也；伏神旺相者二也；伏神得飞神生者三也；」 | 《增刪卜易》源L1055 |
| B3b | 「伏神得动爻生者四；伏神得遇日月动爻冲克飞神者五也；伏神得遇飞神空破休囚墓绝者六也。」 | 《增刪卜易》源L1055 |
| B4 | 「自占吉凶者以世爻为用神」 | 《增刪卜易》源L436 |

**读出**：取用是**三级瀑布**（本卦现爻 → 变爻 → 伏神），且伏神"可用"有**六条可枚举条件**（B3）——
这正是事实层最该有的形状：六个谓词，可逐条判真假，不需要打分。

### C. 用神多现：古法五序 + 书内自记的例外

| # | 引文（照录） | 出处 |
|---|---|---|
| C1 | 「用神两现…舍其休囚，用其旺相，舍其静爻，而用动爻，舍其月破，而用不破，舍其旬空，用其不空，舍其被伤，用其不伤。此古法也。」 | 《增刪卜易》源L1396 |
| C2 | 「得其验者，应乎旬空月破，舍其不空，而用旬空，舍其不破，而用月破。」 | 《增刪卜易》源L1396 |

**读出**：C1 是五条**同层并列**的取舍键（旺 > 静动 > 破 > 空 > 伤），C2 是作者自记的**反向例外**，
且例外只出现在"应期"语境（"应乎旬空月破"）。
**现状**：该条已于第一百七十二批冻结为 `frozen_by_user`（`adjudications.json`），本文件**不重开**；
只记一条使用边界：**方向轴用 C1，应期轴另论 C2**。

### D. 生克夺取：贪生贪合，刑冲克害皆忘

| # | 引文（照录） | 出处 |
|---|---|---|
| D1 | 「贪生贪合，刑冲克害皆忘。」 | 《增刪卜易》源L1494 |
| D2 | 「又如用爻临巳字，卦中动出亥水，动克一火，若得卯木同动，亥卯未合成木局，反来生火，亦谓之贪合忘克忘冲」 | 《增刪卜易》源L1495 |
| D3 | 「动为始，变为终，最怕交争。动爻为事之始，变爻为事之终，不宜互相冲克。」 | 《增刪卜易》源L1467 |
| D4 | 「变爻戌土从无帮助正卦之爻」 | 《增刪卜易》源L1628 |

**读出**：**合 > 生 > 克 > 刑冲**不是权重问题，是**夺取关系**——一旦成合/成局，克与刑"皆忘"，
不该再按分加减。D4 是**作用域**限制：变爻只作用于本动爻，不帮正卦他爻。

### E. 抗性：旺相可敌；一拱一克可敌

| # | 引文（照录） | 出处 |
|---|---|---|
| E1 | 「用神旺相可以敌之，必然无妨，得祸亦轻。惟怕日辰动爻助他为害」 | 《增刪卜易》源L1663 |
| E2 | 「若得日月动爻帮助用爻，可以敌之，不伤于彼，事亦可成」 | 《增刪卜易》源L1620 |
| E3 | 「世爻未土，月拱日克，可以敌之」 | 《增刪卜易》源L2422 |

**读出**：E1 给出"旺衰 vs 克"的裁决——旺相可敌，但**忌神得日辰/动爻助**则不可敌（升级条件）；
E3 支持**月日等权相抵**（一拱一克 = 可敌），与 A2 的"同功"互证。

### F. 例外与冲突（不合并，逐条列）

| # | 引文（照录） | 出处 | 性质 |
|---|---|---|---|
| F1 | 「诸书皆以用神临月破如悖时也…虽有日辰之生，亦不能生，动而作忌神者不能为害，作变爻者不能伤克动爻。」 | 《增刪卜易》源L990 | 旧说：月破即死 |
| F2 | 「余得其验，动则能伤于爻，变则能伤于动…不动又无日辰动爻生助者则到底而破矣。」 | 《增刪卜易》源L991 | 野鶴自验：**动则能伤** |
| F3 | 「凡占近病，用神得遇旬空者，不拘日月动爻克害，用神出空之日即愈。即独此一事，论空不论克也。」 | 《增刪卜易》源L1619 | 近病专属：空压克 |
| F4 | 「有伤属不吉。救，是指卦中的动爻或日辰等来克制伤害用爻之爻。」 | 《黃金策》源L73 | 救神定义（注文） |
| F5 | 「用爻有气无他故，所作皆成；主象徒存更被伤，凡谋不遂。」 | 《黃金策》源L68 | 方向总纲 |

**F1/F2 是同一段里的两说**：先述"诸书"（月破者日生不能生、动不能害），紧接"野鹤曰"推翻它。
这不是抄错，是作者**用自验改古法**的痕迹——判定表必须选边，且要写明选边理由。

## 二、从书证读出的偏序（判定时"谁压谁"）

```
第 0 层  取用：现爻 > 变爻 > 伏神（B1/B2）；自占以世为用（B4）；两现按冻结序（C1）
第 1 层  环境：月建 ＝ 日辰（并列最高且"同功"，A1/A2/A5/A6）＞ 动爻 ＞ 静爻 ＞ 太岁/星煞（A4）
第 2 层  作用：合/局 ＞ 生 ＞ 克 ＞ 刑冲（D1/D2）；变爻只作用本爻（D4）
第 3 层  抗性：旺相可敌克（E1）；日月动爻助忌则不可敌（E1 后半）
第 4 层  例外：近病逢空论空不论克（F3）；月破兼动（F1 vs F2，待裁）
```

要点：**这是偏序，不是加权和**。第 2 层的"合 > 生 > 克"是夺取关系，落到实现上应当是
"高优先关系成立即抑制低优先关系"，而不是"各给一个分再相加"。

## 四、9 格判定表草案

**方向 3 态**（与现 verdict 词表的映射，见 §六 词表债）：
`成` ← 大吉/吉；`滞` ← 平吉/平；`不成` ← 不利/凶/大凶。

**置信 3 档**：`高` = 各层同向且无未决冲突；`中` = 有一处冲突已按 §二 裁决；
`低` = 存在未决冲突、或关键事实缺失（用神不现且日月非用神等）。

| | 置信 高 | 置信 中 | 置信 低 |
|---|---|---|---|
| **成** | 用神旺相有根，无克或有救（E1/F4） | 旺相但有一处克已被救/被合解（D1/F4） | 用神可取但取用有争（两现、伏神勉强出） |
| **滞** | 生克相抵（E3：一拱一克） | 合冲并见（合处逢冲 / 冲中逢合） | 用神中和而关键事实缺失（空破待填、应期无着） |
| **不成** | 用神休囚无根且受克无救（E1 后半） | 用神月破而静、无日辰动爻生助（F2 末句） | 忌神动而无制、或用神不现而日月非用神（B2） |

**进入规则（谓词，不写阈值）**：

- `成`：`用神有根` ∧ (`无克` ∨ `克有救`)，且不含 `合处逢冲`；
- `不成`：`用神无根 ∧ 受克无救` ∨ `月破而静 ∧ 无生助` ∨ `忌神动 ∧ 无制`；
- `滞`：其余——**默认不是"平吉"，而是"未决"**。这是与现状最大的语义差：现在"平吉"被当成一个档次，
  书里它更像"信息不足"。

### 八·补三：v3 修 bug + 世应层（321 批）

摊开 tune 逐例事实后，抓到三件事：

1. **一个真 bug**：`忌神无力` 写成了 `... or ji_pos`，而 `ji_pos` 是**列表**——
   于是 `if 忌神无力` 恒为真（任何忌神在位即成立）。319 批那版"忌神无力"规则基本是空转的。
2. **有气口径被我放宽过**：v2 把"中和"算进有气，理由是权宜；按书证（《黄金策》源L69 逐字「旺相为有气，休囚为无气」）

3. **缺一整层**：世应关系。九格里没有"用神生世/持世"，而底本里它是一等公民：
   《增刪卜易》源L3578「受克者必受其殃，生世者反得其济」

   两条一起进（Z12／Z13），否则只看正面条款会过拟合。

### 八·补五：开封与最终结论（328 批）——**不换判词**

预注册（`test_seal.json.judge_preregistration`）：假设「判定器在封存的外部 test 半边上
