# 样例：占病何日愈（seed=7）

就身体/病情来说，整体能成，可以往前推，不必太犹豫。这副卦是坤（坤宫·六世），起卦于丁酉月 癸卯日，旬空辰、巳。

六神方面：朱雀临用，阴日口舌稍抑。
子孙持世——子持世兮病可安——占病/医药为吉（《火珠林·病章》）　　古歌诀有云：子孙持世事无忧，求名坐狱必然休。避乱求安皆可保，身安无祸亦无愁。
卦身信号：卦身在初爻（兄弟）——占疾病: 兄弟为身
（推断所本：问题词典推断（占病·病症·近病·久病·病何·病愈·无古籍逐条出处））


事情的关键看官鬼（五行属木），落在卯三爻。官鬼（落在卯三爻）得月令之气，旺而有力。原神静而不动，旺而无源，靠自己撑。

病药方面，结构上有这样的信号：病有——用神受克（日月克身），有…压力信号；对应的药偏向：用神有气，偏向自立有根；原神在卦，待时而用。病药是结构信号，讲的是偏向与解处，不是断定结局；仍看应期与人事。

星煞旁参：天乙贵人临用爻；文昌贵人临用爻；天喜临用爻。星煞只记是否临爻/临日，不主吉凶。

卦里没有动爻——'静为无为，动为有象'，事情相对安静，吉凶主要看用神本身够不够力，而不是突然杀出什么变数。

方向可以推进，但别贪。有利面：用神旺衰（用神得令）；古籍格局加减（世克用神）。拖累面：合冲卦性（六冲卦）；三合局破（酉被日冲）。

**时间上**：应期偏速，当日或数日内就有信号，别错过。具体看——卯日应事，逢酉冲、逢戌合皆动。具体应期日历上落在：2026-09-26(用神旺相，当日可能应)、2026-09-27(用神旺相，次日之应)、2026-09-30(亥/卯/未合木局)。

**可以这样做**：
1. 卦象偏松，仍要按医嘱治疗，不要自行停药
2. 静养与规范治疗比四处求偏方更重要
3. 可关注用神得力的那几日是否症状减轻
4. 六冲主散，事不宜急进，先稳住阵脚再对冲解决；最忌讳冲动决策或仓促变动。

古人类似情境也说过：
- （《卜筮正宗·月破论》）月破之爻，如秋叶遇霜，失时无力，纵逢生扶亦难复。
- （《卜筮正宗·用神论》）子孙持世，克官鬼、释忧烦，官司失所望，病者渐安。

这份解读按六爻纳甲的规则推出来，讲的是方向与节奏，不是注定会怎样的预言。凶象只用「偏向／有…信号／结构上」讲，不用「注定／一定」。看病、打官司、做重大决定，仍以专业意见为准。
