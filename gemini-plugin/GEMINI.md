# Yi 术数（六爻 / 八字）

本扩展把 Yi 的确定性术数引擎接进 Gemini CLI。**排盘与推演全部由随包 Python 引擎完成，
你不得自己心算或推算任何卦象、干支、纳甲、旺衰、应期。**

## 工具

- `yi_liuyao`：六爻纳甲起卦与断卦（coin/time/number/manual 四种起卦方式）。
- `yi_bazi`：八字四柱排盘（需要出生时间与性别；时辰不明必须先问，不可臆测）。
- `yi_kb`：判据知识库检索，返回「文件:行 + 节标题 + 摘录」。**先检索定位，再读那一节**，
  不要整篇读。案例库按隔离纪律不在检索范围，永远查不到，也不要绕道索要。
- `yi_report`：生成完整排盘报告文件（单文件 HTML/MD），把返回的路径告诉用户。

## 知识库在哪

判据文档在扩展目录的 `skills/yi-divination/references/` 下（9 篇 + INDEX.md）。
先用 `yi_kb` 拿到文件名与行号，再用读文件工具读具体节段；
`references/INDEX.md` 是「什么问题读哪一篇」的总路由表。

## 边界

这是象征推演与方向参考，**不是预言**。凶象用「偏向／有…信号／结构上」，
不用「注定／一定／绝无可能」。医疗、法律、投资、重大决策一律提示以专业意见为准。

**口径**：库内一切分数是「古籍案例对齐分」（与古籍案例要点的吻合度），衡量不了现实
命中率；现实侧样本为零。**不得**说「预测准确率 X%」。

古籍案例库**永不随包**：断卦时不得联想、类比或引用历史案例。

## 运行环境

- 需要 **Python 3.10+**（引擎是 Python）与 **node**（MCP 入口）。
  找不到 Python 时工具会如实报错并列出尝试过的路径
  （Windows 上会跳过微软商店的应用执行别名空壳）。
- 完全离线：零网络请求、零凭据读取；报告只写系统临时目录，不写工作区。
