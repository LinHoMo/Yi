# 《焦氏易林》占辞 × core《周易》爻辞 交集核验报告

> 目的：机械证明《焦氏易林》4096 条占辞与 `core/yishu_core/hexagram_texts.py` 的
> 《周易》卦爻辞**同源分流**（各出机杼、互不引用），防止将来有人把《易林》占辞
> 当作《周易》爻辞的引文源，或反之。
>
> **本书无对应学科（none-tonggang，通纲）——本报告只核验，不改任何引擎、不入库占辞。**
> 口径：这是**文献比对**，不是对齐分、不是预测率（AGENTS.md 铁律三）。

## 一、核验对象与方法

| 项 | 内容 |
|---|---|
| 书源 | `data/sources/jiaoshi_yilin_dz.dz.txt`（5333 行，4096 条占辞） |
| core 侧 | `HEXAGRAM_LINE_TEXTS`（64 卦 × 6 爻 = 384 条爻辞）+ `HEXAGRAMS`（64 条卦辞） |
| 归一化 | 去标点（`，。、；：？！`）与空白，**只去标点、不改字**（不改字是铁律：引文须可回指） |
| 判据 | core 每一条辞归一后，是否为本书全文的**子串** |

**为什么按长度分档**：2 字词（`无咎`/`利贞`）是《周易》与本书**共用的通用断语词汇**，
不是引用；判定「引用了《周易》原句」的阈值取 **≥3 字**（最短的完整爻辞如「潜龙勿用」为 4 字）。

## 二、核验结果

core 侧归一后条目共 **448** 条（爻辞 384 + 卦辞 64）。

| 阈值 | 命中条数 | 结论 |
|---|---|---|
| ≥2 字 | **2** | 仅 `无咎`、`利贞`——**通用断语词汇**，非引用 |
| **≥3 字** | **0** | ✅ **交集为空**（原建议的预期达成） |
| ≥4 字 | 0 | ✅ 空 |
| ≥5 字 | 0 | ✅ 空 |
| ≥6 字 | 0 | ✅ 空 |

**结论：core 爻辞/卦辞中，没有任何一条（≥3 字）出现在《易林》占辞里。**
二者**同源分流成立**：共享的只有**卦名与卦画层**（已在
`docs/references/jiaoshi_yilin_gua_mapping.md` 落档对源），**辞层零交集**。

## 三、负例自证（证明本方法咬人）

按 AGENTS.md §四.8「新挂的门必须做负例自证」：往本书文本里**植入**一条 core 真爻辞，
确认核验方法会判红（而不是因为路径/解析错而空跑出 0）。

```
植入前：≥3 字命中 0 条
植入 core 爻辞「潜龙勿用」后：方法命中 → 判红 ✔
```

**方法有效性确认**：0 结果来自「真的没有交集」，不是来自扫描失败。
（本书 13823 个去重辞块全部参与比对，非空跑。）

## 四、复跑方式（只读）

```bash
cd core && python -c "
import re,sys; sys.path.insert(0,'.')
from yishu_core.hexagram_texts import HEXAGRAM_LINE_TEXTS, HEXAGRAMS
norm=lambda s: re.sub(r'[，。、；：？！\s]','',s)
yi={norm(t) for v in HEXAGRAM_LINE_TEXTS.values() for t in v}
yi|={norm(r[4]) for r in HEXAGRAMS}
yi={t for t in yi if len(t)>=2}
src=norm(open('../data/sources/jiaoshi_yilin_dz.dz.txt',encoding='utf-8').read())
print('core条目', len(yi), '| >=3字交集', sorted(t for t in yi if len(t)>=3 and t in src))
"
```

预期输出：`core条目 448 | >=3字交集 []`

## 五、结论与边界

- ✅ **交集为空（≥3 字）**，「同源分流」机械成立，可以作为将来的防误引依据。
- ⚠️ **2 字通用词 `无咎`/`利贞` 两端都有**——这是汉语断语的公共词汇，**不得**据此宣称
  「本书引用《周易》爻辞」，也不得据此把两者当同源。
- 本报告**不构成**「本书与《周易》何者更古/更源」的判断——只证**辞层无共享**。
- 本轮**未**新建 4096 条索引文件（那是 `OPT-jiaoshi_yilin_dz-01`，未做）；
  本轮**未**改动 `core/` 任何取值，**未**改动现有八科引擎。
