# 择吉（卜④）

通书择日：建除十二神 + 黄黑道十二神 + 二十八宿值日。机械因子（干支/建除/黄黑道/值宿）由内核 `zeji_tables` 计算，宜忌规则基于《协纪辨方书》通行口径。

## 一条命令出报告

```bash
# 起局 → 分析 → 报告
python scripts/chart.py --date 2026-09-30 --activity 开市 --question "开张营业吉否" -o scratch/chart.json
python scripts/analyze.py scratch/chart.json --out scratch/analyze.json
python scripts/render.py scratch/analyze.json -o scratch/report.md
```

质量门（一条命令跑完所有检查）：

```bash
python tools/check.py
```

说明：**本分数衡量引擎输出与案例库要点的一致性，不是现实预测命中率**（`AGENTS.md` 铁律三）。
案例库要点分两类：机械因子（建除/黄黑道/值宿，历法真值，对照通书核对）与规则应用（宜忌命中、综合方向，来自 `verdicts.json` 的《协纪辨方书》口径）。

**裁决口径透明声明**：综合方向（黄黑道 ±1 + 建除宜忌 ±1 + 星宿 ±0.5，≥1 吉 / ≤-1 凶 / 其间平）是**学科自有规则应用**，不是某部古籍的定论——各通书黄历的宜忌表本身互有出入，本学科取《协纪辨方书》通行口径并固定记录在 `data/verdicts.json`，以保证分数可复现。

## 已实现

- **chart 段**（`scripts/chart.py`）：公历日期（+ 可选时支）→ 干支四柱/建除十二神/日值黄黑道神/二十八宿值日；3 个通书锚点金标准自检（2026-09-23 平/箕、09-24 定/勾陈黑道、09-25 执/青龙黄道/牛）
- **analyze 段**（`scripts/analyze.py`）：三机械因子宜忌落点（建除宜忌/黄黑道吉凶/星宿吉凶）+ 活动宜忌要点 + 综合裁决（得分/方向/所本）；断语全部来自 `data/verdicts.json`（带出处）
- **narrate 段**（`scripts/narrate.py`）：师傅口吻正文（盘面要素/事类宜忌/口径收尾），只装配判据不新造结论
- **render 段**（`scripts/render.py`）：单文件 Markdown 报告（正文 + 盘面数据 + 判读因子）
- **案例库**（`data/cases/zeji_cases.json`）：tune 10 / holdout 5 / excluded 2（超范围边界），每例 expected 含建除/值神/黄道/值宿/宜忌命中/方向/得分
- **评分器**（`scripts/evaluate.py`）：复用 `yishu_core.eval`，维度 建除20/日值神20/黄道10/值宿20/宜忌命中15/综合方向15
- **质量门**（`tools/check.py`）：金标准指纹（15 例）+ 管线冒烟 + tune/holdout 分别出分带 n

## 纪律

- 择日盘必须由 `chart.py` 装配，LLM 禁止手动推建除/黄黑道/星宿（`AGENTS.md` 铁律一）
- 宜忌文字只在 `data/verdicts.json`，代码不含断语字面量
- 分数口径只作回归用，对外不宣称预测命中率；裁决口径是规则应用非古籍定论，如实声明
