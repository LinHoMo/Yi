# 八字科 SKILL

**状态：机械推演已立（非命运断言）。** 输出四柱、藏干十神、天干十神、空亡、强弱、格局、
喜用神、大运 8 步、流年干支对照；**不做**格局吉凶定论、大运流年批断、命运断语。

## 意图路由

- 问「一生格局 / 命运趋势 / 宜何业」→ 本层给机械因子与趋势骨架；解读归 LLM 转述，禁止宿命断言。
- 问具体一事 → 走卜科（**六爻** `liuyao`），不越位。

## 能力

| 命令 | 作用 |
|---|---|
| `scripts/chart.py` | 出生公历/干支 → 四柱盘（含空亡、天干十神） |
| `scripts/analyze.py` | 强弱/格局/喜用/大运/流年机械推演 |
| `scripts/narrate.py` | 因子正文（明确非命运断言） |
| `scripts/render.py` | 因子报告 |
| `dev_tools/check.py` | 契约完整性 + 冒烟 + 金标准 |

## 禁止

- LLM 心算四柱或十神（铁律一）。
- 在 narrate 里编命运结论（必富必贵、某年一定）。
- 把机械推演说成「命已算准」或现实预测命中率。

## 另两条铁律（操作版；全文见仓库根 `AGENTS.md` §一）

- **铁律二（案例库物理隔离）**：`data/cases/` 的命例只供评测层与用户明确要求的
  事后校验使用；解读交付前禁止打开案例库、提及命例编号、以命例类比佐证。
- **铁律三（口径诚实）**：本仓库分数一律是**古籍案例对齐分**（引擎与古书案例要点的
  吻合度），**不是现实命中率**；不得出现「预测准确率 X%」，报数必带集合名 + n +
  是否未参与调参；凶象用「偏向/有…信号/结构上」，不用「注定/一定」。
  完整读数与限制见 `README.md` 与 `docs/EVAL-PLAN.md`。
