## 口径（可回溯）

- **强弱**：藏干本/中/余气权重 1.0 / 0.5 / 0.25，叠加得令加权；取扶抑用神
- **格局**：月令本气十神 → 正格名；从格按《滴天髓》分级（真从/假从/从旺/从强/从气/从势），灰区例才留 `tentative` 标注
- **大运**：年干阴阳 × 性别定顺逆；顺行取下一节、逆行取上一节；三日 = 一年
- **十神**：运干/流年干对日主（`relations.ten_god`）
- **流年**：只给干支 × 十神对照，不批吉凶
- **纳音**与**神煞**：2026-09-29 自 `ming_tables` 按"两科共用"拆入 `symbols` / `shensha`（审计 B3）

| 集合 | 古籍案例对齐分 | n | 维度明细（满分例数／适用例数｜该维随机基线） |

三条必须与上表同屏读的限制：

- **总分被最机械的一维抬起**：holdout 的适用例里 `pillars` 占 363／532，而这一维是
  "给定公历日期反算四柱"，属**历法接线是否到位**，几乎不可能失手——它不是解读能力的证据。
  真正带判断含量的是 `pattern`（29/36）与 `cong_ge`（13/15），且后者 **n 只有 15、随机基线≈50%**，
  86.7% 相对基线的余量很薄，别把它读成"格局已断得准"。
- **四个维度是空的**：`ten_gods`／`hidden_stems`／`shensha`／`dayun` 在两集合里
  **0 例带期望值**（实跑显示 `0/0 n/a=532`），现按 N/A 剔除、不参与上面任何一个数——
  护栏空档，不是已验证（成因与取证路线见 `docs/EVAL-PLAN.md` §五 步 6 与 #14）。
- **532／138 是例数，不是考点数**：按（书·逐字引文·判准）去重后只有 **278／60** 个考点
  （全库 747 例＝405 考点，净多余 342；实跑 `python dev_tools/check_case_dupes.py`）。
  同一条调候格被建过两三遍，它在上表里的权重就是别格的 2–6 倍——**读分先读考点数**。
  按考点折叠后的实跑读数（`python dev_tools/eval_unique_keys.py`）：tune **100.0%（n=60）**
  不变；holdout **97.0%（n=278）**，比上表低 **1.4 分**，差额全部来自 `tiaohou`
  （98.5% → 96.2%）——被重复计数的那几行恰好都是**得分行**，所以原始口径偏乐观。
  两个数都真：本表按"例"计，折叠表按"考点"计；判解读强弱以后者为准（#39 未裁之前的读法）。
- **现实反馈通道已建、但证据仍为 0**：`dev_tools/feedback_store.py`＋`[21]` 回验门在
  #32 同批落地，`logs/reading_events.jsonl` 现为空库（门内读数 `在册 0 条`）。
  所以"回填 0 条"现在要读作**通道可测而现实样本尚未录入**，不再是"没有通道"。
  本节一切分数都是**与古籍案例要点的一致性**，不代表现实预测命中率（`SKILL.md` 铁律三）。
