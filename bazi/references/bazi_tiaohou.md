# 调候（《穷通宝鉴》月令取用）

> **这篇的定位**：调候是**取用神的一个维度**，不是取用的全部。
> 它回答的是「这个日干生在的这个月，气候上最需要什么来中和」——
> 寒月要暖、暑月要润，如此而已。它**不回答**「这个命好不好」「能发多大财」
> 「什么时候应」。把调候当命局总评，是这一篇最想拦住的事。

## 一、调候管什么，不管什么

《穷通宝鉴》的写法是逐月逐干地讲「此月此干，先取什么、次取什么」。它给的是**气候上的
首要矛盾**，原文说得很直：

- `初春尚有余寒，得丙癸逢，富贵双全。癸藏丙透，名寒木向阳，主大富贵`（《穷通宝鉴》源L24 逐字）

这里「余寒」是气候判断，「丙癸」是对治，「富贵双全」是**该书体系内的断语**——
引用它，是记录这本书怎么判，不是本库背书这句话能兑现。三者的层次不能混。

调候不管的事，列清楚：

| 不管 | 归谁管 |
|---|---|
| 格局高低（成格／破格） | `bazi_yue_shi_ge.md` 与引擎 `pattern` |
| 十神关系、六亲宫位 | `bazi_shishen_terminology.md`、`bazi_liuqin_gongwei.md` |
| 大运流年何时应 | 引擎 `dayun`／`liunian` 与 `yingqi` 层 |
| 吉凶总评 | `verdicts.json` 与判词层 |

## 二、查法：月令 × 日干 → 主用／辅用

120 条按「月（1–12）× 日干（甲乙丙丁戊己庚辛壬癸）」排。查法三步：

1. **定月**：以**节气**月建为准（寅月＝立春到惊蛰），不是农历月份；
2. **定干**：取**日干**，不是年干；
3. **读主辅**：`main` 是首要，`assist` 是次要。原文常以「先取 X，次用 Y」「X 为君，Y 为臣」
   「专用 X」三种句式给出，`via` 字段记的就是这个句式来源。

三条句式各自的意思不同，不能一律读成「两个都要」：

- **「专用 X」**——只此一路，别的不济事；
- **「先取 X，次用 Y」**——有先后，X 不透时 Y 才顶上来；
- **「X 为君，Y 为臣」**——君臣是配合关系，不是备选关系。

## 四、三条读法（比背表重要）

**一、调候看的是「太过／不及」，不是「缺」。**
寒月生人未必缺水，暑月生人未必缺火——病在**气候偏胜**，不在数量多少。原文讲「余寒」「火气渐炎」
「禾稼俱旱」，说的都是偏胜，不是缺项。所以「五行缺什么补什么」在调候这一层是错的读法。

**二、月令是提纲，日干是受体。**
同样正月，甲木要丙癸、丙火要壬庚，差别全在日干。**换日干就换一整套**，不能把某月的主用
当成本月通用。

**三、透与藏，分量不同。**
原文反复讲「两透」「藏」「透」，因为透干与藏支的力量不等。表里的「主用」是**方向**，
不是「有这个字就算成」。至于透没透、有几重、被不被合——那是引擎的活，不是这张表能答的。

## 五、边界（写死在这里）

- **调候不等于命局总评**。它只说气候这一路的中和，格局、六亲、运程另有判据。
- **不据调候断吉凶**。原文的「富贵双全」「科甲定然」是该书体系内的断语，本库引用它，
  是记录**这本书怎么判**，不是承诺结果。
- **不做健康、投资、法律、婚姻的结论**。涉及这些，一律以专业意见为准。
- **主用不透不等于命差**。原文常接着说「无 X 则平常」「有 Y 亦可」，条件句读全，别只读前半。
