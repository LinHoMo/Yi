## 一、五虎遁（推月法，源 L261-L292）

**段题与纲领**（源L263 逐字）：`推月之法，由人生年遁月之干支为主，以节令为纲，其区别有三：如在本月节令后生者，即以本月所遁干支为主；在本月节令前生者，即以上月所遁干支为主；在本月下一节令后生者，即以下月所遁干支为主。古歌云：`

**歌诀（源 L265-L269 三行六句，逐字见下表）**：

| 源L | 歌诀句 |
|---|---|
| 源L265 | `甲己之年丙作首，乙庚之岁戊为头，` |
| 源L267 | `丙辛必定寻庚起，丁壬壬位顺行流，` |
| 源L269 | `更有戊癸何方觅，甲寅之上好追求。`（行夏之时，寅为岁首） |

**白话逐条展开（源L271 逐字）**：`甲己年正月起丙寅，乙庚之年正月起戊寅，丙辛之年正月起庚寅，丁壬之年正月起壬寅，戊癸之年正月起甲寅。`

**与引擎表对拍**：`TIGER_MONTH_STEM` 存的是**寅月月干的天干序**（0=甲）：

| 年干 | 寅月干支 | `TIGER_MONTH_STEM` |
|---|---|---|---|
| 甲己 | 丙寅 | 2 ✓ |
| 乙庚 | 戊寅 | 4 ✓ |
| 丙辛 | 庚寅 | 6 ✓ |
| 丁壬 | 壬寅 | 8 ✓ |
| 戊癸 | 甲寅 | 0 ✓ |

**逐条一致，无差异。** 后续月份由 `ganzhi_calendar.py:271` 的
`m_stem_idx = (TIGER_MONTH_STEM[y_stem] + (m_branch - 2) % 12) % 10` 顺行推得，
即**寅月起、逐月顺行**，与源L271「甲己年正月起丙寅」的白话展开一致（源L273《考原》亦自陈「二月丁卯以次顺数」）。

**「立春为界」的书源实证**（源L275-L291 四例，本轮实测逐条 Read 核准）——本书不是简单按公历月，
而是**以立春交节时刻**切年＋切月，正是 `ganzhi_calendar` 的 `lichun` 年界口径：

- 源L275：丁卯年正月初一子时生，因**前一日未时立春**，故「初一日早属丁卯年正月」，遁得**壬寅**（丁壬起壬寅）。
- 源L277：丙午年正月初九日**巳**时生，因午时方立春，**作乙巳年十二月**推，遁得**己丑**（乙庚起戊寅，十二月顺数得己丑）。逐字：「不独丙午年作乙巳年推，且须作乙巳年十二月推」
- 源L279：丙午年正月初九日**午**时生，午时已交立春，**作丙午年正月**推，遁得**庚寅**（丙辛起庚寅）。逐字：「是午时已交立春，即作丙午年正月推」
- 源L281：跨年同理，戌时在酉时立春之后，**作丁未年正月**推。逐字：「不独丙午年作丁未年推，且须作丁未年正月推」（申时一例见 源L283 逐字：「是申时在酉时之前犹未立春，仍属丙午年十二月推」）

**登记**：以上四例是 `ganzhi_calendar` 年界口径的**书源侧依据**，两引擎函数
（`year_ganzhi_index`（气朔年界）/ `month_ganzhi`（月律建寅））本轮**零改动**。

## 二、五鼠遁（推时法，源 L297-L301）

**纲领**（源L297 逐字）：`推时之法，由人生日遁得生时之干支为主。古歌云：`

**歌诀（源 L299-L301 两行四句，逐字见下表）**：

| 源L | 歌诀句 |
|---|---|
| 源L299 | `甲己还生甲，乙庚丙作初，` |
| 源L301 | `丙辛从戊起，丁壬庚子居，` |

源L303 接续第三句（`戊癸何方发，壬子是真途。`，**已 Read 核准在 L303**）。

**白话逐条展开（源L305 逐字）**：`甲己日起甲子时，乙庚日起丙子时，丙辛日起戊子时，丁壬日起庚子时，戊癸日起壬子时。`

**与引擎表对拍**：`RAT_HOUR_STEM` 存的是**子时时干的天干序**（0=甲）：

| 日干 | 子时干支 | `RAT_HOUR_STEM` |
|---|---|---|---|
| 甲己 | 甲子 | 0 ✓ |
| 乙庚 | 丙子 | 2 ✓ |
| 丙辛 | 戊子 | 4 ✓ |
| 丁壬 | 庚子 | 6 ✓ |
| 戊癸 | 壬子 | 8 ✓ |

**逐条一致，无差异。** 后续时辰由 `ganzhi_calendar.py:281` 的
`h_stem_idx = (RAT_HOUR_STEM[day_stem] + h_branch) % 10` 顺行推得，与源L305「从甲子日顺数，至此日子时得丙子」一致。

**书源自陈的推演原理**（源L305 引《考原》）：`甲子日起甲子时，从甲子日顺数，至此日子时得丙子，故乙日起丙子。从甲至己，越五日暴六十时，花甲周而复始，故己日子时，亦为甲子时也。`
——即**五干一循环、六十时花甲周**的封闭论证，与表值「甲己同起」同构。
